# 控制 T2I 扩散模型"乱加细节"的系统性方法

先给结论：**"乱加细节"几乎从来不是单一超参问题，而是"条件信息量不足 → 模型回落到图像先验"的必然结果。** 细节（纹理、装饰、水印字、多余物体）在真实图像分布里是高概率模式，当你的 prompt 只说了 $30\%$ 的信息量，模型就用先验把剩下 $70\%$ 补齐——它觉得自己在"帮忙"。

数学上很直白。CFG 采样时的预测是

$$\tilde{\epsilon}_\theta(x_t, c) = \underbrace{\epsilon_\theta(x_t, \varnothing)}_{\text{无条件先验}} + s\big[\underbrace{\epsilon_\theta(x_t, c) - \epsilon_\theta(x_t, \varnothing)}_{\text{条件方向}}\big]$$

当 caption $c$ 的信息熵低（"a castle"），条件方向 $\Delta$ 的范数很小且方向模糊，采样轨迹基本由第一项 $p(x)$ 主导，而 $p(x)$ 里塞满了房子该有的瓦片、石纹、树枝、窗户格子。同时训练目标只最大化 $p(x|c)$ 的似然，**没有任何项惩罚"多生成了 $c$ 没要求的像素"**，所以模型天然没有"克制"的动机。这个不对称是根因。

## 一、先做诊断，别乱调参

按下面顺序排除，能省掉 $80\%$ 的无效试错：

| 现象 | 大概率病因 | 优先手段 |
|---|---|---|
| 细节是**均匀纹理型**（噪点、碎屑、肌理） | 采样器/步数/CFG 过高 | §2 |
| 细节是**语义型**（凭空多出手、多出桌椅、文字） | caption 信息不足、先验泄漏 | §3 §5 §6 |
| 只在**大分辨率/高清修复**后出现 | 分辨率外推 bucket 不匹配 | §2.4 |
| 只用了**某个 LoRA/微调模型**后出现 | 概念泄漏 / 过拟合 | §6.2 |
| 结构**崩坏但细节丰富** | 缺空间约束 | §4 |
| 边缘/色块**异常斑驳** | VAE 精度问题，不是模型的锅 | §7.1 |

> **关键提醒**：先确认你的 prompt 本身信息是否充足。把 prompt 当成"给外包设计师的工单"写——它没写的地方，模型就会自由发挥。这是最容易被忽略的一步。

## 二、推理时的零成本手段（先试这个）

<details>
<summary><b>2.1 CFG scale 与它的替代品</b></summary>

CFG 是双刃剑：$s \uparrow$ 提升 prompt 遵循度，但同时放大细节幻觉、过饱和、烧焦感。经验区间：

- SD1.5：$7\text{–}9$；SDXL：$5\text{–}7$；Flux/SD3：$3.5\text{–}4.5$（蒸馏模型更低）
- 想要"干净、少细节"，往下压 $1\text{–}2$ 而不是往上加

更好的替代方案：

- **CFG Rescale**：把预测的 $\epsilon$ 重新缩放到与无条件分支相同的统计量，抑制过饱和
  $$x \leftarrow x \cdot \frac{\|\epsilon_u\| \cdot \sqrt{d}}{\|x\|}$$
- **APG（Adaptive Projected Guidance）**：把条件方向中与无条件方向平行的分量投影掉，只放大正交的"真实语义增量"
  $$g = \epsilon_c - \epsilon_u,\quad g_\perp = g - \frac{g\cdot\epsilon_u}{\|\epsilon_u\|^2}\epsilon_u$$
  $$\tilde{\epsilon} = \epsilon_u + \phi\, g_\perp + \psi\, g_\parallel$$
  这能在 $s$ 较高时仍保持干净，是抑制"过引导型细节"最有效的单点改动。
- **CFG++**：重新设计引导的插值路径，允许用极低 CFG 而不牺牲遵循度。

</details>

<details>
<summary><b>2.2 采样器与步数</b></summary>

这是最被低估的一项。**祖先型（ancestral / SDE）采样器每步注入新噪声，等价于持续"重新掷骰子"，会累积出大量未被要求的细节**。

- 想少细节 → 用**确定性 ODE 采样器**：`DPM++ 2M Karras`、`UniPC`、`DPM++ SDE` 慎用
- 想多细节/更"艺术" → `Euler a`、`DPM2 a`、`DDIM` 加随机性
- 步数：太多步（$>50$）并不会更准，反而给高频伪影留出迭代空间；SDXL 通常 $25\text{–}30$ 步足够

</details>

<details>
<summary><b>2.3 噪声调度 / 预测目标（训练侧留下的坑）</b></summary>

- **Zero Terminal SNR**：标准 schedule 在 $t=T$ 时信噪比不为零，导致最后几步仍残留"无条件泄漏"，表现为细节无端增生。重训或使用 v-prediction / zero-SNR 调度能显著改善。
- **v-prediction** 模型在高噪声区更稳定，构图更贴 prompt。

</details>

<details>
<summary><b>2.4 分辨率与高清修复</b></summary>

- 训练分辨率 bucket 之外的尺寸会诱发**内容重复**（多出的头、多出的窗）。SD1.5 以 $512$ 训练，直接推 $1024$ 必崩。
- Hires fix / latent upscale：`denoise strength` 是细节注入的阀门。$0.35$ 以下基本是放大；$0.5$ 以上等于重画，必然加东西。想保持原样就给低值 + 换更保守的采样器。
- SDXL 的 refiner 在低 strength 下也会补细节，可控但别指望它不加东西。

</details>

**负面提示词**是廉价的兜底，但要精准而非堆砌：

```text
extra objects, clutter, busy background, watermark, signature, text,
jpeg artifacts, oversharpened, noise, grain, duplicated, deformed
```

## 三、条件注入：让 $c$ 真的"说满"

只要条件信息足够，先验就没有插手的空间。

<details>
<summary><b>3.1 注意力层控制（无需重训）</b></summary>

- **Prompt-to-Prompt**：直接编辑 cross-attention map，替换/冻结某个 token 的空间分布 → "只改一处，别动别处"
- **Attend-and-Excite**：强制每个 prompt token 都拥有足够强的 attention 峰值，解决"某个词被完全忽略、同时模型自己加戏"
- **Structured Diffusion Guidance**：约束 self-attention 的 KV 相关性结构，抑制语义漂移
- **Self-Attention Guidance / Perturbed-Attention Guidance（PAG）**：故意扰动 self-attention 特征，引导生成远离扰动结果，等效于"打击结构伪影"，对减少无意义纹理很有效
- **FreeU**：调节 U-Net backbone 与 skip connection 的权重。注意方向——它是**增加**细节的，想减细节要反向调
</details>

<details>
<summary><b>3.2 分词与权重语法</b></summary>

- 用 `(word:1.2)` 提升关键主体权重，用 `[word]`/负权重**抑制**不需要的概念
- 逗号分段的短词比长句更贴合 CLIP 的注意力分布
- 别指望 SD1.5 的 CLIP 理解复杂从句。要长 prompt 遵循度，换 **SD3 / Flux（T5-XXL，长上下文）**，这是架构级的改善，不是调参能补的

</details>

<details>
<summary><b>3.3 文本编码器本身的瓶颈</b></summary>

- CLIP text encoder 的 77 token 上限 + 弱组合能力，是"属性错绑、数量出错、自由发挥"的硬天花板
- **SDXL**：双 CLIP + OpenCLIP-ViT-bigG，明显改善
- **SD3 / Flux / PixArt-α**：T5 系列，长 prompt 遵循度是代际提升
- 若你在大规模自训，投资 text encoder 的收益往往高于调 U-Net

</details>

## 四、空间与结构约束：把"自由发挥"的维度关掉

扩散模型的自由度是逐像素的。你要是能砍掉空间自由度，"乱加细节"就无处落脚。

| 手段 | 约束维度 | 适用 |
|---|---|---|
| **ControlNet**（depth / canny / softedge / lineart / normal） | 结构 | 最通用，$1\text{–}2$ 张控制图足以锁住构图 |
| **T2I-Adapter** | 结构 | 轻量，参数少，适合组合多个 |
| **GLIGEN** | 包围盒 | 需要精确"谁在哪" |
| **MultiDiffusion / 区域提示** | 区域 | 一个 prompt 管一块，互不越界 |
| **Inpainting** | 局部 | 只重画指定区域，其余像素冻死 |
| **IP-Adapter** | 参考图 | 风格/内容锚定，降低自由创作 |

> **最强组合**：ControlNet(softedge, 权重 $0.5$–$0.7$) + 区域提示 + APG。基本上"想加也不知道往哪加"。

## 五、训练数据侧：这才是根因所在

如果你在自训/微调，前面所有推理技巧都只是创可贴。工业界的共识是：**caption 质量决定 prompt 遵循度的上限**。

<details>
<summary><b>5.1 密集重标注（Recaptioning）—— 收益最大的单项改动</b></summary>

- **DALL·E 3**：训练集 $95\%$ 使用模型重新生成的详细描述，而非原始 alt-text
- **PixArt-α**：用 LLaVA 生成密集 caption，配合 $87\%$ 美学筛选
- **CogView3/4**：递归 caption 增强

原理：短 caption 让 $p(x|c) \approx p(x)$，模型只能学到"图像先验"而非"文本→图像映射"。密集 caption 把条件熵拉满，模型被迫关注每个视觉元素，"自由发挥"的空间被压缩。

**做法**：用 LLaVA / Qwen-VL / GPT-4V 对每张训练图生成 $50\text{–}150$ 词的结构化描述，覆盖主体、属性、数量、空间关系、背景、风格。

</details>

<details>
<summary><b>5.2 数据清洗与筛选</b></summary>

- 美学分预测器（LAION aesthetic、HPS）过滤低质图 → 减少"垃圾细节"进入先验
- CLIP score / 图文一致性过滤，剔除 alt-text 与图不符的样本（这类噪声样本正是教会模型"忽略文本"的元凶）
- 去水印、去文字、去 UI 截图、去拼贴图
- 去重（近邻去重），避免某类构图过度主导先验

</details>

<details>
<summary><b>5.3 训练策略</b></summary>

- **长宽比分桶（Aspect Ratio Bucketing）**：SDXL 的关键设计，直接消除"生成大图就重复物体"
- **Caption dropout**（通常 $10\%$）是 CFG 的必要条件，但比例过高会让无条件先验过强 → 细节泛滥
- **Multi-aspect / 多分辨率训练**：改善外推尺寸的表现
- **损失加权**：对低噪声时刻加权（细节区），可让模型在小尺度上学得更稳
- 训练时长不宜过度——过长会过拟合先验，caption 遵循度反而下降

</details>

## 六、微调与对齐：给模型装一个"克制"的偏好

前面说训练目标没有惩罚"多生成"的项。要补上这个项，就得引入人类/模型偏好。

<details>
<summary><b>6.1 偏好对齐（消除细节幻觉的主力）</b></summary>

- **Diffusion-DPO**：构造 (prompt, chosen, rejected) 三元组，rejected 取"图文不符/多余元素"的样本，直接优化
- **DRaFT / Reward-weighted**：用可微奖励回传
- **ImageReward / HPS v2 / PickScore / VQA-based reward**：作为奖励模型，专门惩罚 prompt 里没有的元素
- **DDPO / RLHF 式流程**：完整但贵
- 关键是**奖励设计要包含"缺失惩罚"和"多余惩罚"两侧**，只惩罚"少了"会加剧加戏

</details>

<details>
<summary><b>6.2 LoRA / DreamBooth 的细节泄漏治理</b></summary>

这是最常见的实战坑：微调后模型到处冒出训练集的元素。

- **给固定元素也写进 caption**（背景、构图、光照都描述），否则它们会和触发词绑定
- 使用**正则化图**（同一主体、不同场景）
- 降低 rank、降低 LR、减少步数、早停；推理时把 LoRA 权重从 $1.0$ 降到 $0.6\text{–}0.8$
- 用 **Textual Inversion** 代替 LoRA 学"少而精"的概念，泄漏更小
- 训练集别只有 3\text{–}5 张——样本太少，模型只能靠先验填空

</details>

<details>
<summary><b>6.3 针对性小模型</b></summary>

- 训一个 **"detail suppressor" LoRA**：用 (简洁图, 冗杂图) 配对做 DPO，学"减法"
- **Textual Inversion 负向概念**：学一个 `[clutter]` embedding 直接塞进负面提示
- 已有开源方案：各种 `detail-slider`、`detail-tweaker` LoRA，本质是把细节强度做成了连续可调的向量方向

</details>

## 七、后处理与兜底

<details>
<summary><b>7.1 先排除 VAE 的锅</b></summary>

很多"细节问题"其实是 VAE：
- **fp16 溢出 → NaN/黑图/斑块**：用 `sdxl-vae-fp16-fix` 或强制 fp32
- SDXL 原版 VAE 有轻微伪影；可换 `madebyollin/sdxl-vae-fp16-fix` 或 TAESD 对比
- 分块解码（tiling）的接缝也会被误认为"细节"
- **诊断方法**：把生成的 latent 用不同 VAE 解码，或换模型重跑同一 seed。差异大 = VAE 问题

</details>

<details>
<summary><b>7.2 图像级后处理</b></summary>

- **Img2img 低 denoise 重跑**：$0.2\text{–}0.3$，等于"轻微规整"而非重画
- **局部 inpainting**：把水印、多出来的手、碎屑抹掉
- 传统 CV 去噪（guided filter / bilateral）对付纹理型噪声有效，但会糊
- 用分割模型（SAM）自动定位多余物体再 inpaint

</details>

## 八、速查表与推荐配方

**抑制细节（从便宜到贵，按序叠加）**

| 优先级 | 动作 | 典型值 |
|---|---|---|
| 1 | 写满 prompt（主体/属性/数量/位置/背景/风格/光照） | — |
| 2 | 降 CFG 或换 APG | SDXL $5\text{–}6$ / APG $\phi{=}1.2,\psi{=}0.5$ |
| 3 | 换确定性采样器 | `DPM++ 2M Karras`，$25\text{–}30$ 步 |
| 4 | 精准负面词 | 见 §2 |
| 5 | Hires denoise 调低 | $\le 0.35$ |
| 6 | ControlNet 锁结构 | softedge，权重 $0.5\text{–}0.7$ |
| 7 | 区域提示 | 分区不越界 |
| 8 | 换更强的文本编码器 | SD3 / Flux |
| 9 | 重标注 + 重训 | LLaVA dense caption |
| 10 | DPO / 偏好对齐 | 双侧惩罚 |

**典型干净配方（SDXL）**

```text
正向: "a single ceramic vase on a plain wooden table, soft daylight
       from left, minimal background, muted beige wall, centered composition"
负向: "clutter, extra objects, busy background, texture noise, watermark,
       text, signature, oversharpened, grain"
采样: DPM++ 2M Karras, 28 steps, CFG 5.0, 尺寸 1024x1024 (原生 bucket)
可选: ControlNet softedge 0.6 + APG
```

## 核心心智模型

把这四层想清楚，就不会乱撞：

1. **条件层**——让 $c$ 承载足够信息，先验才没有插手的余地（prompt 质量、文本编码器、caption 密度）
2. **引导层**——引导只放大"条件与无条件的差"，用投影类方法（APG/Rescale）而非无脑抬高 $s$
3. **空间层**——把逐像素自由度收敛成受控自由度（ControlNet、区域、inpaint）
4. **偏好层**——训练目标本身要显式惩罚"多生成"（DPO / reward），这是唯一能根治的层

前两层是当天就能见效的工程手段；**第三、四层才是真正把这个毛病改掉的地方**。如果你的目标是"治本"，预算应该优先投在密集重标注和偏好对齐上，而不是无限调 CFG。
