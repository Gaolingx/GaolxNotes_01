# 角色 LoRA 炼制简说

核心只有一句话：**让模型学会“这张脸是谁”，不需要学“这张图画什么”。** 其余所有操作都是在为这件事服务。

## 一、准备素材（最容易出错，却最容易被跳过）

- **数量**：15～30 张足够，质量比数量更重要
- **内容**：多角度（正、侧、45°）、多表情、多服装、多背景、半身和全身都要有
- **要求**：清晰、不模糊、无水印、无文字、脸不被遮挡
- **避免**：全是同一张脸放大裁切、同一姿势、同一背景（模型会把这些也当成“角色特征”学进去）

> 素材比例建议：**脸部特写占 1/3，半身占 1/3，全身和动态姿势占 1/3**。

## 二、打标签（角色 LoRA 最重要的一步）

这是角色 LoRA 和风格 LoRA 的最大区别：

| 内容类型 | 处理方式 |
|---|---|
| **固定特征**（发色、瞳色、脸型、特征服饰） | **不要写进标签**，让模型把它绑定到触发词上 |
| **可变因素**（服装、动作、表情、背景、视角） | **必须写**，告诉模型这些是变化的 |

因此每张图的标签长这样：

```
sks girl, smiling, red dress, sitting on bench, outdoors, full body
```

其中 `sks girl` 是触发词，其余只描述这张图**独有**的东西。

**中文用户注意**：如果用 SD1.5，标签用英文；Flux/SD3 可以用自然语言整句。

## 三、工具选择

| 工具 | 适合 |
|---|---|
| **Kohya sd-scripts** | 老牌标准，参数最全，SD1.5/SDXL 通用 |
| **FluxGym** | 不想折腾，界面化练 Flux LoRA，几小时会 |
| **OneTrainer** | 图形界面，SDXL 友好 |
| **ComfyUI + 训练节点** | 已经玩 ComfyUI 的顺手 |

新手直接从 **FluxGym** 或 **OneTrainer** 开始，不要一开始就自己写 `.toml`。

## 四、关键参数（先抄这套）

**SDXL / SD1.5 起步：**

```text
rank (dim)        = 16   （人物够用，32 更细腻但易过拟合）
learning rate     = 1e-4 （unet）
text encoder lr   = 5e-5 或直接冻结
batch size        = 1～2
epochs            = 10～20
repeat            = 按素材数调到总步数 1500～3000 步
optimizer         = AdamW8bit
scheduler         = cosine
```

**Flux 起步：**

```text
rank = 16～32
lr   = 1e-4
steps = 1000～2000（看素材量，一般 800～1500 就出效果）
```

判断够不够，看**总步数**而非 epoch 数：素材 20 张 × repeat 10 × epoch 10 = 2000 步，量级就对了。

## 五、判断效果（关键：会不会过拟合）

生成测试图时重点看：

- ✅ **成功**：换衣服、换场景、换画风，脸还是那张脸
- ❌ **过拟合**：画什么都是它、背景/构图开始“烧”、脸部僵硬像贴图、出不了别的角色
- ❌ **欠拟合**：脸不像、特征丢失、只能出训练时的姿势

**过拟合处理**：减少 epoch、降低 rank、加更多样的素材  
**欠拟合处理**：加步数、提 lr、素材质量检查

<details>
<summary><b>进阶：正则化图像 / 分层学习率 / 采样预览（点开看）</b></summary>

- **正则化图（regularization images）**：用底模生成 200～500 张“普通人”同标签图，防止模型把触发词泛化到所有图。SD1.5 时代很有用，SDXL/Flux 时代可以不做。
- **分层学习率**：`text_encoder_lr` 低于 `unet_lr`，能减少语言理解被破坏。
- **样本图预览**：训练中每 N 步生成一张同 prompt 的图，直接肉眼观察“脸从不像到像，再到僵”的拐点，比看 loss 曲线靠谱得多。**强烈建议开启。**
- **多分辨率训练**：开 `min_bucket_reso / max_bucket_reso` 让素材按长宽比分桶，避免拉伸变形。

</details>

## 六、三条新手最常见的坑

1. **素材里混了不同的人**：脸就学糊了。宁可少，必须“同一个人”。
2. **标签把脸的特征写进去了**：比如每张都写 `blue eyes`，那以后不写就不能出这个角色，触发词等于废了。
3. **训练完不测直接上生产**：一定用 3 组不同 prompt 交叉测（换画风、换场景、换构图），确认泛化。

# 分辨率 + 裁切 + PixAI Tagger

你这两个判断都挺对的，尤其第二点，不过 PixAI Tagger 用起来有个**反过来要处理的麻烦**，先讲这个。

## 一、高分素材怎么切

高分辨率素材的处理基本是以下这三件事：

**1. 分辨率要按桶限制，不要盲目追求高分辨率**

SDXL / Flux 训练的实际采样分辨率是 1024（SDXL 的 VAE 在超过训练分辨率外推时，效果会掉得很快）。所以：

- 原图 4K 直接喂进去：bucket 会把它缩回 1024，**等于白贡献，还会因为缩图丢失细节**
- 正确做法是先按目标分辨率**统一缩小**（短边 1024 或 1152），再进 bucket
- 如果要开 `max_bucket_reso` 到 1536+，就要接受显存和过拟合风险的双重增加；SDXL 尤其不建议这样做

**2. 面部裁剪：优先保留，但要控制比例**

高分全身图裁脸确实有效——脸在 1024 画幅里能占到足够像素，这是提升“像不像”最直接的手段：

- 裁剪时**带上脖子与肩线**，只裁到下巴会出“头浮空”的怪图
- 裁出来的脸部图占全集 **不要超过 30%**，否则模型会认为“这个角色的默认构图就是大头特写”，一旦超过 30%，全身、动态姿势就很难生成
- **不要对同一张脸的多次裁切**，那等同于把素材数量重复计算，并让 epoch 的计数出现偏差

**3. “三分法”有两种意思，你说的应该是分块裁切**

如果你的意思是一张全身图切成上、中、下三块：**仍然只算 1 张素材**。同一张图派生出的裁切都来自同一张图，要算作同一源的派生，那就得把 `repeat` 或总步数按“源图数”来算，否则实际训练量会翻三倍，从而直接导致过拟合。

> 如果你说的是三分法构图（主体在三分线上），那属于**素材多样性**问题。三分法、居中、特写、远景都要有，别全是一种构图。

## 二、PixAI Tagger：好用，但要删标签

PixAI Tagger（`pixai-lora-tagger-v0.9`，有 ONNX 版，官方定位就是给 LoRA 数据集打标）在动漫素材上质量确实高于 WD14 系：对画风、构图、光影的标签更克制，对插画类色彩的描述也更准确。

**但问题就在这里：** 它越准，就越会把你角色的固定特征全部标出来——

```
1girl, solo, blue eyes, long silver hair, ahoge, hair ribbon,
white dress, standing, outdoors, tree, sunlight, smile
```

`blue eyes / long silver hair / ahoge / hair ribbon / white dress` 全被打出来了。**如果直接拿去训练，这五个标签就变成了角色的“开关”**：以后你不写齐这五项，就生成不出这个角色，触发词相当于失效。

所以，针对角色 LoRA，**需要删掉与固定特征相关的标签**：

| 保留 | 删掉 |
|---|---|
| `standing`, `smile`, `outdoors`, `sunlight`, `tree`, `upper body` | `blue eyes`, `silver hair`, `ahoge`, `hair ribbon`, 特征服装 |

**参数上：** 阈值开到 `0.3`～`0.35` 起步（PixAI 的默认偏保守），宁可多打一些再删，也不要漏掉可变因素，否则模型只能把所有内容都绑定到触发词上。

**批量后处理**（可直接抄用，用于删除固定特征标签）：

```python
import re

FIXED = ["blue eyes", "silver hair", "ahoge", "hair ribbon", "white dress"]

def clean(tags: str) -> str:
    parts = [t.strip() for t in tags.split(",")]
    parts = [t for t in parts if t and t not in FIXED]
    return ", ".join(parts)
```

用这个逻辑把整个 `.txt` 目录清洗一遍，然后手动抽查 10 张，确认没有误删表情、动作标签。

## 三、把两部分连起来

```text
高分原图
  → 统一缩到短边 1024～1152（保长宽比，按桶分）
  → 全身图补一张带肩线的脸部裁剪（≤30%）
  → PixAI Tagger 批量打标（thr 0.3～0.35）
  → 删固定特征标签 + 加触发词前缀
  → 训练
```

<details>
<summary><b>几个容易漏掉的细节（点开）</b></summary>

- **触发词放在最前**：`sks girl, 1girl, solo, standing, ...`。位置放对能让注意力更快绑定。
- **PixAI Tagger 输出里的 `1girl, solo` 要留**，它对稳定构图有帮助；但如果是单人角色 LoRA，`solo` 长期留着也可能限制双人图生成，看需求删。
- **裁切图和原图共用同一句标签**，不要在裁脸上写 `portrait, close-up` 之类。除非你确实想练出特写能力，那样它就会变成“构图开关”。
- **Flux 用户**：标签是自然语言短句，PixAI Tagger 的逗号 tag 要么转成句子，要么少量使用，不要硬套。
- **打标后先跑一遍去重**：把标签文本完全相同或近似度高的图挑出来，重复标签的图往往是重复素材（PixAI 和 WD 都会把相近图打成一样）。

</details>
