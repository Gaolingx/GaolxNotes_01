# 大模型权重训练方式判别

### 🧑‍💻 User

对于一个llm pretrain weight，如何推断出他原生就是用fp8/fp4训的（预训练），还是说bf16/fp8训完了再量化（QAT）的？

---

### 🤖 Assistant

要判断一个 LLM 的预训练权重是“原生低精度（FP8/FP4）训练”得到的，还是“高精度（BF16/FP16）训练完再量化（PTQ/QAT）”得到的，通常不能只看权重文件的表面数值。如果作者发布了元数据或技术报告，那是最直接的；如果只有一个 `.safetensors` 或 `.bin` 权重包，则可以从**权重的数值结构**和**量化痕迹**入手分析。

下面给出一个系统的判断流程，按可靠度由高到低排列。

---

## 1. 看元数据（最可靠）
绝大部分公开的预训练模型都会附带 `config.json`、`model card`（README）或 `generation_config.json` 等。重点关注：

- **`quantization_config`**
  如果存在这个字段，说明模型经过了量化处理，通常会标明是 `gptq`、`awq`、`bitsandbytes` 还是 `fp8` 等。

- **技术报告 / 论文**
  如 “We trained the model natively in FP8 using Transformer Engine” 或 “We applied PTQ to W8A8 after BF16 training”。这是铁证。

- **权重文件名或 key**
  一些框架会保存额外的参数，例如 `*.weight_scale`、`*.weight_amax`、`*.weight_zero_point`。如果张量里全是一些没有 scale 的普通 weight，可能是原生高精度训练后未量化，或者原生低精度训练但已回存为主权重。

---

## 2. 数值分析（无元数据时使用）
假设现在我们只有一个纯权重张量（例如以 FP32 或 BF16 形式发放），而没有附带任何 scale/zero-point tensor。此时可以尝试复原量化参数，从而反推量化方式。

### 2.1 检查是否为“离散化 + Scale”结构
后量化（PTQ/QAT）最终导出时，通常会保存为：
$$W_{\text{stored}} = s \cdot Q$$
其中 $s$ 是 scale（浮点数），$Q$ 是量化后的整数或 FP8 可表示的值（通常为 per-tensor 或 per-channel）。
如果你发现对于某个 $s$，所有权重都极精确地落在 $s \times \text{FP8\_grid}$ 上，那几乎可以肯定是量化后保存的。

**具体操作：**
```python
import torch
import numpy as np

# 假设 w 是一维或二维权重 (out_features, in_features)
w = ...  # Tensor

# 尝试寻找 per-channel scale（逐行）
# 对于 FP8 E4M3，可表示的正规格子数约为 256（含符号共 255 个），我们可以枚举 scale
def find_scale_for_fp8_vec(vec, fp8_type='e4m3', search_ratio=10):
    # 假设 vec 都是 scale * q，q 是 fp8 可表示的数
    # 用 vec 的非零最大值来粗估 scale，然后微调
    max_abs = vec.abs().max()
    if fp8_type == 'e4m3':
        fp8_max = 448.0  # E4M3 max
    elif fp8_type == 'e5m2':
        fp8_max = 57344.0
    # 粗 scale
    coarse_scale = max_abs / fp8_max
    # 在一定范围内搜索，使得 vec/scale 全部落在 FP8 的离散值上
    best_scale = None
    best_err = 1e10
    # FP8 可表示值的集合（需生成或使用现有的库）
    # 这里简化为：看除以 scale 后是否足够接近半整数/整数（FP8 本身是浮点）
    # 较为准确的做法是利用 float8 的量化/反量化函数来回测
    for r in np.linspace(0.8, 1.2, 100):  # 实际可以自适应
        candidate_scale = coarse_scale * r
        # 模拟直接量化再反量化
        q = (vec / candidate_scale).clamp(-fp8_max, fp8_max)  # 这里用理想 clip
        # 但需要将 q 量化到 FP8 格式，如果本地有 float8 支持更好
        # 简化检验：看 vec 是否均匀分布且基本都是 scale 的整数倍？ 不行，FP8 的步长是不均匀的。
        # 更好的方法：使用 torch.fake_quantize 或直接转 float8 (e4m3) 再转回来
    ...
```
> **更直接的方法**：利用 PyTorch 的 `torch.float8_e4m3fn` 或 `transformer_engine` 包，直接将 `vec` 量化再反量化，对比原始 `vec` 与重构 `vec` 的误差。如果几乎所有元素都能完美重构（误差 < `scale * 0.2 * quant_granularity`），则存在量化结构。

### 2.2 观测误差分布
- **如果是 PTQ/QAT 导出再保存为高精度**：重构误差几乎为零（只受浮点舍入影响），且误差直方图会在 `0` 附近极度聚集。
- **如果是原生 FP8 训练，但保存的是 master weight（BF16/FP32）**：
  训练时 forward/backward 使用量化后的权重，但 optimizer 更新的是高精度 master weight，因此**最终权重不会受限于 FP8 的离散值**。
  在这种情况下，你拿到的权重会有微小的随机波动，不可能被一个简单的单 scale 完美重构。你会观测到**重构误差分布比较宽且连续**，类似于普通 BF16 训练的模型权重。

> 📌 这是区分两者的**核心数值线索**：
> - 后量化模型 → 权重严格坐落在量化格子上（可完美用 $s \cdot Q$ 表示）
> - 原生低精度训练但未作后量化 → 权重是自由的高精度值，会残留训练中的随机噪声。

### 2.3 检查权重的值域和尾数利用情况
FP8 E4M3 能表示的数值动态范围约为 $[-448, 448]$，E5M2 为 $[-57344, 57344]$。
- 如果拿到的权重（假设以 BF16 存储）最大绝对值恰好接近这些边界（如 448 左右），并且权重值有明显“分层”现象，很可能是后量化。
- 如果权重范围非常大（如几百到几千以上），且分布光滑，则大概率是常规高精度训练。

---

## 3. 特殊情况：QAT 与原生 FP8 训练的差异
- **QAT（Quantization‑Aware Training）**：训练时在前向传播中插入“伪量化节点”（fake quantization），反向传播使用 STE（Straight-Through Estimator）。最终导出的权重通常经过实际量化，因此也会出现第 2 节中的离散化特征。仅从权重很难区分是 PTQ 还是 QAT，只能通过训练脚本或性能报告推断。
- **原生 FP8 训练（如 NVIDIA TE）**：前向和反向的大部分计算都在 FP8 下执行，但 master weight 仍然保持高精度（FP16/BF16）。只有当用户特意保存 FP8 checkpoint 时，你才会拿到 `.fp8` 的权重文件；如果仓库直接提供常见的 BF16 权重，那它一定是 master weight，不会呈现量化离散性。

---

## 4. 总结与推荐策略
| 方法 | 能区分什么 | 限制 |
|------|------------|------|
| 查阅 config.json / README | 直接得到训练方式 | 需作者诚实标注 |
| 寻找量化参数张量 | 证明经过 PTQ/QAT 导出 | 不保证存在 |
| 数值离散性检测 + 重构误差分析 | 判断权重是否被投影到量化网格 | 需要已知 FP8 格式；若作者做了 QAT 但保留了高精度 master weight（几乎不可能）会产生混淆 |
| 值域分析与尾数检查 | 辅助判断 | 非唯一判别条件 |

**实际检查步骤建议：**
1. 搜索所有文件中的 `.json` 和 `.md`，快速定位 “quantization”、“fp8”、“QAT” 等关键词。
2. 加载几个权重张量，用 `torch.fake_quantize_per_channel_affine`（或直接转 float8）计算重构误差。若误差的中位数接近 0 且最大误差极小，则为量化导出；若误差有明显的连续分布，则为原始高精度训练。
3. 如果误差为零但权重张量名称里没有 scale，那可能 scale 被合并到了其他矩阵（常见于 AWQ/GPTQ），此时需要按激活顺序反推。

通过这些方法，即使没有文档，你也可以非常有把握地推断出权重的“出身”。
