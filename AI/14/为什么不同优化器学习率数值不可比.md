## 先说结论

**`1e-3` 这个数本身没有意义 —— 不同优化器的 "lr" 根本不是同一个单位。** 你观察到的三件事，是同一个事实的三个侧面：

| 优化器 | 更新量 | lr 的物理单位 | 典型 lr |
|---|---|---|---|
| SGD | $\eta\, g$ | 每单位梯度走多远 | $0.1\sim0.5$（B=256, vision）|
| SGD+Momentum | $\eta\sum_k\beta^k g_{t-k}$ | 同上，但被低通放大 $1/(1-\beta)$ | $0.1\sim0.9$ |
| AdamW | $\eta\,\hat m/\sqrt{\hat v}$ | **每个坐标的最大步长**（$\ell_\infty$ 信赖域，$\lvert\Delta\theta\rvert\le\eta$）| $3\text{e-}4\sim1\text{e-}3$ |
| Muon | $\eta\cdot\mathrm{NS}(M)\cdot c$ | **每个权重矩阵的谱范数步长**（算子范数信赖域，$\lVert\Delta W\rVert_2\approx\eta$）| $0.02\sim0.05$ |

三个"信赖域几何"完全不同（无约束 / $\ell_\infty$ / 谱范数），所以它们的数字本来就不该相等。**Muon 和 AdamW 必须分开设 lr，不是因为调参没调好，而是结构上必然。**

---

## 1. 为什么"动量优化器敢开大 lr"

动量本身**不**让 lr 变大，它做的是三件不同的事：

**(a) 直流放大：有效 lr 就是 $\eta/(1-\beta)$。**
常数梯度下速度收敛到 $v=\eta g/(1-\beta)$。$\beta=0.9$ 时有效步长是标称的 10 倍，$\beta=0.95$ 时是 20 倍。你看到的"大 lr"，一部分本来就是动量在偷偷放大。

**(b) 低通滤波：只放大平滑方向。**
动量是梯度的一阶 IIR 低通。一致的分量（平坦方向的真实信号）被放大；高频抖动（陡峭方向的振荡分量、minibatch 噪声）被衰减。于是：
- 平坦方向 $\eta\to\eta/(1-\beta)$，收敛快；
- 陡峭方向增益小，不发散。

这就是核心：**动量的阻尼接管了稳定性，而 lr 可以更大。**

**(c) 稳定性上界确实翻了倍。** Heavy-ball 在二次型上的稳定域是 $0<\eta\lambda<2(1+\beta)$，即 $\eta_{\max}\approx 2(1+\beta)/L$；$\beta\to1$ 时逼近 $4/L$，而裸 GD 只有 $2/L$。并且收敛率从条件数 $\kappa=L/\mu$ 改善到 $\sqrt\kappa$。

> ⚠️ 但要注意：**Muon 敢开到 `2e-2`，主要功劳是正交化，不是动量**（见第 3 节）。动量在 SGD 里的作用只是把它从 `0.1` 抬到 `0.5`。

---

## 2. 为什么 "SGD 的 lr 小了根本学不动"

三个原因叠加：

**(a) 每步进展 $\propto\eta$，字面意义上的线性。**
$\Delta f\approx-\eta\lVert\nabla f\rVert^2$。lr 砍 100 倍，同样的 step 预算下进展就是 1/100。SGD 在 ImageNet 上的"自然 lr"是 $0.1\cdot B/256$ —— **`1e-3` 对应 batch size ≈ 2.5**，即纯噪声级的小批量。在 $B=256$ 上用它等于欠训练 100 倍。

**(b) 没有预条件，所有参数共用一把尺子。**
Transformer 里各层梯度模长能差 1~2 个数量级：hidden 矩阵的 grad RMS 可能 1e-2，embedding / LayerNorm gain / bias 可能 1e-4。**Adam 的 $\hat m/\sqrt{\hat v}$ 把每个坐标归一化到步长 $\approx\eta$**，所以小梯度的参数照样在动；SGD 只有一个全局 $\eta$，小梯度参数等于冻住 —— 这才是"学不动"的实质。

**(c) lr 与 loss 尺度、batch size 强耦合。**
Adam / Muon 对梯度整体缩放**完全不变**：
$$\text{Adam: } (cm)/\sqrt{c^2v}=m/\sqrt v,\qquad \text{Muon: } \mathrm{NS}(cM)=UV^\top.$$
SGD 会变。所以 SGD 的 lr 必须每个问题、每个 batch size 重调，而 Adam/Muon 的 lr 是一个"可迁移"的数。

**`1e-3` 什么时候"够大"？** 当梯度 RMS $\approx0.01$ 时，SGD 用 `0.1` 的更新量是 $0.1\times0.01=10^{-3}$，正好等于 Adam 用 `1e-3` 的更新量。**两个数字差 100 倍，更新量却一样。** 这就是你感觉"1e-3 只有 Adam/Muon 敢开"的真正来源：它在那些优化器里代表的是**归一化后的步长**。

## 3. 为什么 Muon / AdamW 必须分组设 lr

<details>
<summary><b>展开：三条结构性理由</b></summary>

**① 量纲不同（上面已说）。** AdamW 的 lr 控制每个元素的步长，Muon 的 lr 控制每个矩阵的谱步长。同一个 `3e-4` 在 Muon 里等于几乎不动，因为 $\lVert\eta\,\mathrm{NS}(M)\rVert_2=3\text{e-}4$ 而矩阵典型谱范数需要每步变化 $\sim10^{-2}$。所以标准实现给出 Muon `lr=0.02` / AdamW `lr=3e-4`，差约 60 倍，这是**设计出来的**，不是调参手感。

**② Muon 的更新量还依赖矩阵形状。** $\mathrm{NS}(\cdot)$ 输出的奇异值全是 1，所以
$$\lVert O\rVert_F=\sqrt{\min(m,n)},\qquad \text{逐元素 RMS}=\frac{1}{\sqrt{\max(m,n)}}.$$
形状不同、更新量不同！所以 Muon 实现里必须补偿形状：
```python
update = zeropower_via_newtonschulz5(update, steps=5)
update *= max(1, grad.size(-2) / grad.size(-1)) ** 0.5   # 对齐不同形状
```
（有些代码库用 `0.2 * sqrt(max(A,B))`，目的相同：把逐元素 RMS 归一化成与形状无关。）**AdamW 没有这个问题**，它是逐元素归一化的。这个形状依赖本身就是"不能共用一个 lr"的硬约束。

**③ 你的参数组本来就不是一类东西。** 标准做法是三种参数、三种处理：

| 参数 | 优化器 | 原因 |
|---|---|---|
| 2D hidden 权重（Linear / Attn proj） | **Muon** | 有清晰的矩阵结构，正交化等价于"谱域归一化"，可以让所有奇异值同步增长 |
| Embedding / Unembed | **AdamW** | 稀疏、高方差、梯度尺度差异巨大 |
| LayerNorm gain、bias | **AdamW** | 一维、尺度敏感，正交化无意义 |
| 有时第一/最后一层 | **AdamW** | 输入输出层对 lr 最敏感，常常发散 |

**④ 动量和 weight decay 的语义也不同。** Muon 是"先累积动量再正交化"（$\beta=0.95$），AdamW 是 $\beta_1=0.9,\beta_2=0.95$ 且**解耦 weight decay 被 lr 缩放**（$\theta\leftarrow\theta(1-\eta\lambda)$）。所以改 lr 会顺带改有效正则强度 —— 这又是一个不能共享 lr 的理由。

</details>

## 4. 实操建议

```python
optimizer = MuonWithAuxAdam([
    dict(params=hidden_2d_params, use_muon=True,
         lr=0.02, momentum=0.95, weight_decay=0.0),
    dict(params=embed_and_head_params, use_muon=False,
         lr=3e-4, betas=(0.9, 0.95), weight_decay=0.1),
    dict(params=norm_and_bias_params, use_muon=False,
         lr=3e-4, betas=(0.9, 0.95), weight_decay=0.0),
])
```

**唯一可靠的统一诊断指标：update-to-weight ratio。**
$$\text{u/w}=\frac{\lVert\eta\cdot\Delta\theta\rVert}{\lVert\theta\rVert}$$
按参数组分别监控，训练初期目标 $O(10^{-3})$（经验值 ~5e-3），后期衰减到 $10^{-5}$ 量级。**如果某组的 u/w 比其他组差 10 倍以上，就是那组 lr 设错了。** 这个指标让"不同优化器不同 lr"从玄学变成可测量的工程。

<details>
<summary><b>补充：为什么"大 lr"必须配 warmup，以及 batch 关系</b></summary>

- 大 lr + 陡峭初始化（$L$ 很大）→ 前几百步必然在 $2(1+\beta)/L$ 之外，必须 warmup 把 $\eta$ 从 0 线性爬上来。
- SGD 严格遵循线性缩放 $\eta\propto B$（直到 critical batch size）；Adam/Muon 的 batch 依赖弱得多。**所以比较两个优化器的 lr 数字时，连 batch size 都无法对齐**，这也是"数字不可比"的又一层原因。
- Muon 的 lr 可以随宽度/形状近似常数地迁移（因为谱域归一化），AdamW 也可以；SGD 不行。这是 SGD 被大规模训练淘汰的核心原因之一。

</details>

### 一句话总结

> **lr 不是一个数，是一个"在某种几何下每步允许走多远"的约定。** SGD 的约定是"梯度单位"，AdamW 是"逐坐标单位"，Muon 是"谱单位"。动量做的是低通放大 + 阻尼，让你在陡方向不发散的前提下把标称值推高；SGD 没有预条件，所以它的 lr 被梯度尺度、batch size、loss scale 三重绑架 —— 小一点就真的不动。三套单位，三套数字，必须分开设。
