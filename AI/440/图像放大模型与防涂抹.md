| 项 | 选择 |
|---|---|
| 主干 | **保真残差 Transformer**（DAT 式双轴聚合 + 移位窗口注意力），输出 **在 Lanczos 基线上做残差** |

# 1. 先验工作：各自解决了什么，留下了什么坑

## 1.1 传统插值（Bicubic / Lanczos）

Bicubic 用三次卷积核（Keys 核，$a=-0.75$）；Lanczos 用窗化 sinc：$K(x)=\mathrm{sinc}(x)\cdot\mathrm{sinc}(x/a),\ |x|<a$（常用 $a=3$）。

- **数学性质**：线性、无先验、无幻觉。它在**通带内是最优的**（近似理想低通重构），但对 2× 放大其截止频率被限制在 $\pi/2$——**输出一定是带限的**，这就是“软”的物理来源，不是算法缺陷。
- **Lanczos 的负瓣**会产生**过冲/振铃**（halo），这在视觉上就是“锐”，也正是后来所有“锐化伪影”的祖先。
- **可借鉴的两点**：(a) 它们是“信任的基线”，SR 模型的职责是**只在阻带做出改进**，通带必须与插值一致（低频一致性）；(b) 插值应在**线性光**下做，否则 gamma 域重采样会放大边缘暗边与色偏。
- **局限**：0 bit 新信息，不可能恢复纹理；PSNR 尚可但 LPIPS 很差。

## 1.2 Real-ESRGAN（2021）

- **贡献**：RRDB + **高阶降质建模**（blur → resize → noise → JPEG 重复两阶，含 sinc 滤波模拟振铃、gray noise、shuffle order）、U-Net 判别器 + 谱归一化、pixel-unshuffle 做 HQ-LQ patch 配对、$\mathcal{L} = L_1 + \lambda_{percep}\text{VGG} + \lambda_{gan}\text{RaGAN}$。
- **它是“涂抹感”的教科书级反例**：GAN 权重相对感知损失过大 → 边缘过度锐化、内部被压平，形成“脆皮塑料感”；会**强行清晰化本该虚化的景深区域**；改变画风；小模型感受野不足时，在纹理密集区倾向保守平滑。
- **可借鉴**：降质管线设计、“sinc 滤波”这个细节、U-Net 判别器的局部聚焦能力、warm-up 式 GAN 权重斜坡。

## 1.3 Real-CUGAN（2022，bilibili）

- **结构**：魔改 Waifu2x 的 **CUNet（级联 U-Net）**，百万级动漫 patch 训练。
- **最有价值的不是结构，是产品化思路**：
  - 按降噪强度出多个模型（无降噪 / 1×/2×/3×）+ 独立的 **“保守版”**——保守版存在的唯一目的就是**不丢纹理、不改画风**；
  - `alpha` 参数：越大 AI 痕迹越小越模糊，越小越锐利但色偏对比度增强越大；
  - 明确把 **`tile` 分块与“切割线”** 列为质量风险（“无切割线版会造成更多纹理涂抹”）。
- **官方 README 自己点名了三种失败模式**：**地板纹理涂抹**、**线条中心/边缘虚实错判**、**虚化区域强行清晰化**。这三条几乎覆盖了我们后面要防的全部内容。
- **可借鉴**：强度可调、保守分支、“不要动我已有的东西”作为一个独立优化目标。

## 1.4 SeedVR（2025，ByteDance Seed，CVPR'25）

- **贡献**：扩散 **DiT** 做通用复原；核心是 **shifted window attention + 边界可变尺寸窗口**，让窗口注意力支持任意分辨率/长度（4K、长视频）；配**因果视频 VAE**、图像视频混合训练、**渐进分辨率训练**，并蒸馏到 1-step 使其可用。
- **可借鉴**：窗口注意力解决任意分辨率（这正是干掉 tile 接缝的正道）、渐进训练、一步蒸馏。
- **坑**：扩散的强先验在强引导下会**用“生成的纹理”替换“真实的纹理”**，观感上比 GAN 更“高级塑料”；计算成本高；确定性差（同一张图重跑轻微不同），对产品不友好。

## 1.5 DAT / DAT-2（ICCV 2023）

- **DAT 的核心**：**双轴聚合**——连续 block **交替**使用 spatial self-attention 与 channel self-attention（inter-block 聚合），配 **AIM**（两个注意力互传信息）与 **SGFN**（spatial-gate FFN，intra-block 聚合）。Channel attention 复杂度 $O(NC^2)$ 与分辨率解耦，因此在高分辨率下便宜且能提供**全局非局部证据**——这是“区分真纹理 vs 噪声”的关键能力。
- **DAT-2**：官方仓库中的变体，**11.21M 参数 / 216.93 GFLOPs / Urban100×4 27.86 dB**，与 DAT（14.80M / 275.75 G / 27.87 dB）几乎持平——本质是“同量级参数下，用更多 block 换深度”的对照实验，社区（neosr / chaiNNer / OpenModelDB）里广泛用作 checkpoint 名。
- **定位**：DF2K + **纯 L1 训练**的 PSNR 导向模型。**它是“保真天花板”，也是“涂抹感下限”**：L1 的最优解是条件均值，高频方差必然坍缩。所以它适合当**保真底座**，绝不适合当最终输出。

## 1.6 汇总对照

| 方法 | 保真度 | 锐度 | 纹理真实性 | 真实降质鲁棒性 | 可控性 | 主要残留问题 |
|---|---|---|---|---|---|---|
| Bicubic | 通带最优 | 低 | 无（不生成） | 好（不犯错） | 无 | 软，无纹理 |
| Lanczos | 通带最优+过冲 | 中高（假锐） | 无 | 好 | 无 | 振铃 halo |
| Real-ESRGAN | 中 | 高 | 中低（易幻觉） | 强 | 弱 | 过锐+塑料感+虚化被锐化 |
| Real-CUGAN | 中高 | 中高 | 中（动漫域好） | 强 | **强**（档位+alpha） | 纹理涂抹、tile 切割线 |
| SeedVR | 中 | 高 | **高**（生成） | 很强 | 中 | 生成替换真实纹理、成本/确定性 |
| DAT-2 | **最高** | 低 | 低（不生成） | 弱（仅 bicubic 降质） | 无 | 过度平滑 |

# 2. 先把“涂抹感”拆开：它是四个可测量成分的叠加

> **定义**：涂抹感不是“糊”，而是 **边缘过锐 + 内部过平 + 纹理同质化** 三者的**反差**造成的知觉判断。人眼判断“自然”靠的是局部对比度的**分布形态**，不是绝对锐度。

| 成分 | 可测量代理指标 | 主要成因 |
|---|---|---|
| ① 高频缺失 | 径向功率谱斜率 $\beta$ 偏大；$E_{hf}^{out}/E_{hf}^{gt}<1$ | L1/MSE 回归均值 |
| ② 高频不真实（同质化） | patch 级纹理多样性下降；Gram 矩阵 / 局部方差分布 KL 偏移 | 判别器全局最优解 = “边缘硬 + 内部平” |
| ③ 边缘过冲 | 局部极值越界率（overshoot ratio）；halo 检测 | 过强 GAN、USM 后处理、Lanczos 负瓣 |
| ④ 该糊的地方被锐化 | 输出高频 vs GT 高频的**符号一致性** | 模型不知道“虚化是内容” |

## 成因 → 干预点（这是全篇最核心的表）

| # | 成因机制 | 干预点 | 具体做法 |
|---|---|---|---|
| 1 | **回归均值**：$\arg\min \|y-f(x)\|_1$ 的解是条件中位数/均值 | 损失 | 对抗 + 感知 + **频谱能量匹配损失** + 噪声再注入 |
| 2 | **降质建模偏差**：训练用 bicubic 下采样，模型只学“bicubic 的逆”；遇到真噪声时去噪职责压过去 → 毛孔/胶片颗粒被抹 | 数据 + 条件 | 高阶真实降质 + **降质条件化** + 把“去噪”和“补细节”解耦 |
| 3 | **去噪能力溢出**：平滑是降 L1 最省力的路径 | 数据 + 门控 | 噪声图条件化；只对**超出 GT 噪声谱**的部分罚；保留颗粒目标 |
| 4 | **对抗坍缩**：整图判别器 → 全局一致的“脆皮”解 | 损失 | **频率分带判别器**（低/中/高频独立头）、RaGAN-LS、小权重、EMA |
| 5 | **架构低通偏置**：stride-2 下采样、转置卷积棋盘、**tile 重叠平均融合** | 结构 | 残差在基线上、pixel-shuffle、**全分辨率细节支路**、tile 用“裁切有效区”而非平均 |
| 6 | **感受野不足**：分不清“纹理”和“噪声” → 保守平滑 | 结构 | 双轴注意力（channel attention 提供全局证据）+ 多尺度 |
| 7 | **GT 频率缺口**：GT 本身被压缩/去噪/曾被放大过 | 数据 | **GT 质量闸门**（功率谱斜率 + 频谱陷波检测） |
| 8 | **色偏/对比度漂移**：gamma 域重采样 + 过度锐化 | 工程 | **线性光下重采样**；不做 USM 后处理 |

# 3. 架构设计：RDT-SR（Residual Detail Transformer）

## 3.1 总体：三段式 + 一个门控

```
LQ ──► [A] 降质感知前端 ──► z_d, σ_map, m_detail
                              │
LQ ──► Lanczos↑ ──► B ──► [B] 保真底座 ──► Î = B + g⊙R
                                                │
                                                ├──► [C] 纹理精修(可选) ──► Î + α⊙T
                                                │
                                                └──► [D] 收尾(颗粒/色管/校准) ──► HR
```

## 3.2 Stage A：降质感知前端（Anti-smear 的第一道闸）

小 CNN/U-Net（<2M 参数）：

- 输出**全局降质嵌入** $z_d\in\mathbb{R}^{64}$（模糊核类型与 $\sigma$、噪声 $\sigma$、JPEG 质量、重采样核、锐化强度）；
- 输出**逐像素噪声图** $\sigma_{\text{map}}$（信号相关 Poisson-Gaussian，用 heteroscedastic 头）；
- 输出**细节可恢复性图** $m_{\text{detail}}\in[0,1]$。

训练方式：合成数据上降质参数已知 → 直接监督（多任务）；真实数据上用估计值 + 一致性正则。**$m_{\text{detail}}$ 的 GT 由 GT 图的高频能量局部归一化得到**，这一条让网络学会“哪里真的有纹理”。

## 3.3 Stage B：保真底座（默认输出，主力）

- **输入**：$I_{LQ}$ 与 $\text{Lanczos}_s(I_{LQ})$ 的 concat；输出残差 $R$。
- **主干**：4 级 U 形 Transformer，顶层 12–16 个 **DAT 式双轴 block**：
  - 空间窗口注意力 $8\times8$，shift $(4,4)$（局部纹理，$O(Nw^2)$）；
  - 通道自注意力（全局证据，$O(NC^2)$，与分辨率解耦）；
  - AIM 交叉交互 + SGFN；
  - **移位窗口 + 边界可变窗口**（借 SeedVR），天然支持任意分辨率、**不需要 tile**。
- **上采样**：只在小分辨率下做 pixel-shuffle 的 ×2 递增，任意倍率 $s\in(1,4]$ 用 $\lceil\log_2 s\rceil$ 次传播；**不使用转置卷积**（棋盘伪影）。
- **细节支路全分辨率**，U-Net 编码器只提供上下文，不承担细节。
- 规模：~25–40M 参数；×2 输出 1080p 时约 300–450 GFLOPs。

## 3.4 Stage C：纹理精修（可选档，强降质/大面积纹理时启用）

- **一步蒸馏的 DiT**（SeedVR 式移位窗口），条件：$\hat I$ + $z_d$ + 纹理类型 token（自然/胶片/动漫平涂/屏幕内容）+ 强度 $\alpha$。
- 只输出**高频纹理层** $T$（残差），$I=\hat I+\alpha\odot T$，$\alpha$ 由 $m_{\text{detail}}$ 与用户旋钮共同决定（$\alpha=0$ 即退回纯保真档）。
- 训练：以强降质样本为条件，学习 $I_{GT}-\hat I$ 的高频分布；用 flow-matching 或 rectified flow，蒸馏到 1–2 NFE。
- **成本替代方案**（若算力受限）：用 GAN 训练的 **patch 纹理记忆/检索模块**（类似 TTSR 的 texture transformer，从 GT 池检索相似 patch 做特征迁移），可控性更好、无随机性。

## 3.5 ★ Trust-Region Gate：本方案的反涂抹核心

$$\hat I = B + g \odot R,\qquad g=\sigma(\text{conv}(f)) \cdot \big(1-\lambda\,\hat\sigma_{\text{map}}\big)\cdot m_{\text{detail}}$$

三个乘子分别对应：网络自己的置信度、**噪声越大允许注入的高频上限越低**、**GT 侧真有纹理才允许补**。

配套损失（“不该动的地方不要动”）：

$$\mathcal{L}_{\text{tr}} = \big\|(1-m_{\text{detail}})\odot R\big\|_1 \;+\; \Big(\big\|R\big\|_{hf} - \tau\,\big\|I_{GT}\big\|_{hf}\Big)_+^2$$

第一条把残差压到 0（ cielo、皮肤光滑区、虚化背景基本不动）；第二条是**高频注入上限**（相对 GT 能量的信任域），防止过锐。

## 3.6 关键设计原则（七条）

1. **残差在物理基线上**，永不重新合成整图；
2. **信任域门控**：高频注入有上限、有条件；
3. **双轴注意力**：靠全局证据区分纹理/噪声（DAT 教训）；
4. **降质条件化**：一个模型覆盖多档输入，避免“去噪 vs 补细节”的权重冲突；
5. **渐进倍率、共享权重**：×4 = 两次 ×2；
6. **细节走全分辨率路径**，编码器只供语义上下文；
7. **线性光下重采样**，杜绝 gamma 域 halo 与色偏。

# 4. 数据 Pipeline

## 4.1 数据源分层

| 层 | 内容 | 作用 |
|---|---|---|
| GT 主库 | LSDIR / DIV2K+Flickr2K / DIV8K / FFHQ / RAISE / 内部商业摄影 | 通用纹理与色彩 |
| 领域库 | 动漫帧、截图/UI、文档、商品图、老照片扫描 | 覆盖域外 |
| **真实配对** | 手机同场景 1× vs 2×/长焦（天然真实降质配对）；**burst 配对**（多帧平均→干净 GT，单帧→LQ） | 消除合成降质的分布偏差 |
| 无配对真实 LQ | 用户上传/线上回流 | 域适应、降质匹配校准 |

> burst 配对是我最推荐的真实数据来源：对齐精确、降质真实（含真实噪声/ISP 锐化）、可规模化，能显著降低“训练/测试降质错配”导致的过度复原。

## 4.2 GT 质量闸门（比模型结构更影响成败）

自然图像功率谱 $P(f)\propto f^{-\beta}$，$\beta\approx 2\text{–}2.5$。据此：

- ✅ 保留 $\beta\in[1.8,2.8]$、无频谱陷波（**陷波 = 曾被放大/重采样过**）、局部方差分布健康；
- ❌ 拒绝：AI 生成图、曾被 SR 的图、重压缩图（双 JPEG 检测）、强去噪图、运动模糊、过曝；
- ❌ **绝对不要对 GT 做降噪**——这是自毁纹理；
- 👤 人像子集额外要求**皮肤纹理可见**（否则模型必然学出“塑料脸”）；
- 去重（pHash + embedding）、美学分、content-type 标注。

## 4.3 合成降质（Real-ESRGAN 高阶 + 三项改进）

1. blur：各向同性/各向异性 Gaussian、plateau、disk（失焦）、motion，**加真实相机 PSF 核库**；
2. resize：bicubic/bilinear/area/Lanczos/nearest 随机核，含 down-then-up；
3. noise：**信号相关** Poisson-Gaussian + 色度噪声 + ISO 标定的读噪声 + banding；
4. JPEG/WebP/HEIF/AVIF，含色度子采样与**二次压缩**；
5. **★ 新增：过锐化输入**（USM halo 作为 LQ 的一种）→ 让模型学会“不重复锐化”；
6. **★ 新增：近无降质样本（10–20%）**，目标 = 恒等 → 好图不被糟蹋；
7. **★ 新增：降质分布校准**——用 Stage A 估计真实 LQ 测试集的降质参数，用矩匹配/最优传输把合成分布对齐到真实分布。**这一条直接削减“过度复原”型涂抹感**。

## 4.4 配比与规模

- GT patch：2–5M（$256^2$ 等效），按内容分层采样（人脸 15%、植被 15%、天空/平滑 15%、文字/UI 10%、建筑/纹理 20%、动漫 10%、其他 15%）；
- 样本降质强度：$\{0\%, 10\%, 30\%, 40\%, 20\%\}$ 对应 $\{$恒等, 轻, 中, 重, 极端$\}$；
- 真实配对：100k–500k 对；
- 分辨率桶化 + 渐进 patch（64→96→128→192）。

# 5. 训练 Pipeline

## 5.1 五个阶段

| 阶段 | 目标 | 数据 | 损失 | 规模 |
|---|---|---|---|---|
| **S0 保真预训练** | 通带对齐、不幻觉 | 全量合成 | $\mathcal{L}_1$ + FFL | 300–500k iters |
| **S1 感知/GAN 微调** | 找回高频 | 中/重降质 | $\mathcal{L}_1+\mathcal{L}_{percep}^{shallow}+\mathcal{L}_{RaGAN}+\mathcal{L}_{spec}$ | 100–200k |
| **S2 门控与恒等监督** | 学会“不动” | 含恒等样本 | $+\mathcal{L}_{tr}+\mathcal{L}_{gate}$ | 80k |
| **S3 纹理精修训练 + 蒸馏** | 生成真实纹理 | 极端降质 | flow-matching → 1-NFE 蒸馏 | 100k |
| **S4 偏好微调（关键）** | 显式惩罚“涂抹感”和“过锐” | 人工 A/B 对 | DPO / 奖励模型 | 20–50k |

> **S4 是我认为最被低估的一环**：把“自然感”做成可优化的偏好信号。构造三元组（同一输入：过平滑版 / 过锐版 / 人选的“最自然版”），用 DPO 类目标直接推开两种极端。这比调损失权重高效得多。

## 5.2 损失

$$
\mathcal{L}=\lambda_1\| \hat I-I_{GT}\|_{\epsilon}
+\lambda_2\mathcal{L}_{LPIPS}^{\text{shallow}}
+\lambda_3\mathcal{L}_{RaGAN}
+\lambda_4\mathcal{L}_{FFL}
+\lambda_5\mathcal{L}_{tr}
+\lambda_6\mathcal{L}_{spec}
$$

**频谱能量匹配损失**（直接对齐径向功率谱分带，反涂抹的直接抓手）：

$$
\mathcal{L}_{spec}=\sum_{b\in\text{bands}}\Big(\log\frac{\sum_{f\in b}|\hat X(f)|^2}{\sum_{f\in b}|X_{GT}(f)|^2}\Big)^2
$$

**判别器**：U-Net 结构 + 谱归一化，但**拆成低/中/高三个频带头**，各自独立判别——避免整图判别器把解推向“边缘硬+内部平”的单一模式。

**权重起点**（$L_1$ 归一）：$\lambda_1=1,\ \lambda_2=0.08,\ \lambda_3=0.05,\ \lambda_4=0.02,\ \lambda_5=0.5,\ \lambda_6=0.1$；GAN 权重用 StyleGAN 式斜坡 $\gamma$ 从 0 升到 1（前 20k iter）。

## 5.3 训练配置

- AdamW，$\beta=(0.9,0.99)$，lr $2\text{e-}4$（S0）→ $1\text{e-}4$（S1）→ 余弦退火；EMA decay 0.999；
- bf16 + gradient checkpointing；8–32×A100/H100，S0 约 4–8 GPU-days；
- 推理：TensorRT/ONNX fp16，1080p→4K 单卡 &lt;1s（Stage B），Stage C 使用一步；
- **分块策略**：能用全局窗口就分块；必须分块时用 **receptive-field-aware 裁切（取重叠区中心有效区）**，**绝不平均融合**（平均融和=低通滤波=接缝处涂抹）。

| 用户觉得“AI 痕迹重” | 无强度控制 | 暴露 $\alpha$ / CFG scale / 档位旋钮（Real-CUGAN 的 alpha 思路） |

# 8. 取舍与风险

| 决策 | 代价 | 缓解 |
|---|---|---|
| 双轴注意力（channel attention） | 显存与算力高于纯 CNN | 低分辨率层用 CNN，高分辨率层用 channel attention；层内分块 |
| Stage C 扩散精修 | 成本、不确定性、产品一致性 | 默认关闭 + 一步蒸馏 + 固定 seed + $\alpha$ 旋钮 |
| 真实配对数据 | 采集成本 | burst 合成配对可规模化 |
| 门控信任域 | 极端渣画质下“不敢修” | 用户可显式提高 $\alpha$，或走“强修复档”（= 关闭 $\mathcal{L}_{tr}$ 的独立 checkpoint） |
| 偏好微调 | 需要标注预算 | 先做 5k 对冷启动，用奖励模型放大 |

**一句话总结**：模型层面，把“放大”重塑成**在插值基线之上、带信任域的残差高频注入**；数据层面，用 **GT 频谱闸门 + 校准过的真实降质 + 恒等样本** 保证模型“知道该补多少”；训练层面，用**频谱能量匹配 + 频率分带判别器 + 人类偏好 DPO** 把输出从“既不过平也不过锐”的自然分布里拉回来。涂抹感不是靠“加锐化/减锐化”调出来的，而是靠**约束“允许生成多少高频”**设计出来的。
