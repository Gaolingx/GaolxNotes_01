# `at::Tensor` vs `torch.tensor`

这两个很不一样——**它们属于不同的语言层**，通常不该直接对比。一个是 **C++ 类型**，一个是 **Python 工厂函数**。

## 核心区别

| 维度 | `at::Tensor` | `torch.tensor` |
|------|-------------|----------------|
| **语言** | C++（ATen / LibTorch） | Python |
| **本质** | 类型（class / object type） | 函数（factory function） |
| **作用** | 表示一个张量对象 | 从数据**创建一个**新张量 |
| **调用方式** | `at::Tensor t = ...;` | `x = torch.tensor([1,2,3])` |
| **命名空间** | `at::`（ATen 库） | `torch.`（Python 包） |

## 1. `torch.tensor` —— Python 端的构造函数

它是一个**工厂函数**，用来从 Python 数据（list、numpy 数组等）创建张量：

```python
import torch

a = torch.tensor([1, 2, 3])          # 从 list 创建
b = torch.tensor([[1., 2.], [3., 4.]], dtype=torch.float32)
c = torch.tensor(np_array.numpy())   # 从 numpy 创建
```

要点：
- **总是拷贝数据**（除非用其他 API 如 `torch.as_tensor`）。
- 会**推断 dtype**（整数→int64，浮点→float32）。
- 是 `torch.Tensor` 类的构造函数接口，但 `torch.tensor` 是个函数，不是类本身。

## 2. `at::Tensor` —— C++ 端的张量类型

这是 ATen 库（PyTorch 的底层 C++ 张量库）中的**类型定义**，使用它需要 include C++ 头文件：

```cpp
#include <ATen/ATen.h>

at::Tensor t = at::randn({2, 3});          // 创建
at::Tensor t2 = t + 1;                      // 运算
std::cout << t2.sum() << std::endl;
```

要点：
- 它**不是一个函数**，而是表示"零维到 N 维张量"的句柄类型（内部是引用计数的 `TensorImpl`）。
- 你在 C++ 里创建张量用的是 `at::randn`、`at::zeros`、`at::tensor(...)` 等**工厂函数**，就像 Python 里的 `torch.randn`。
- `torch::Tensor` 是 `at::Tensor` 的别名（在 LibTorch 的 `torch::` 命名空间下）。

> 简单说：在 Python 中你写 `torch.tensor(...)` 来造张量；在 C++ 中对应的是 `at::tensor(...)`，而 `at::Tensor` 是这些函数**返回的类型**。

## 对应关系图

```
Python:   torch.tensor([1,2,3])   ──►  torch.Tensor (类型)
C++:      at::tensor({1,2,3})      ──►  at::Tensor  (类型)
```

## 容易混淆的点

1. **`torch.Tensor`（类） vs `torch.tensor`（函数）**
 - `torch.Tensor` 是张量**类**。
 - `torch.tensor` 是创建张量的**函数**（注意大小写）。
 - Python 里所有张量都是 `torch.Tensor` 实例，而 `at::Tensor` 就是它在 C++ 侧的对应类型。

2. **`at::` 是底层，`torch::` 是高层**
 - ATen（`at::`）是纯张量运算库；
 - LibTorch（`torch::`）在 ATen 之上加了 autograd、nn、JIT 等。

3. **性能/语义**
 - 两者最终操作的是**同一套 C++ 内核**——Python 的 `torch` 只是对 ATen 的绑定（通过 pybind11）。
 - 所以 `torch.tensor` 创建的张量，在 C++ 内部就是 `at::Tensor`。

## 一句话总结

> **`at::Tensor` 是 ATen 里的 C++ 张量"类型"，`torch.tensor` 是 Python 里用来"创建"张量的函数。** 它们不在一个层面，真正对应 `torch.tensor` 的 C++ 函数是 `at::tensor(...)`，而 `at::Tensor` 对应的是 Python 的 `torch.Tensor` 类型。
