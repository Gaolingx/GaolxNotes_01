# 投机解码无损但依赖草稿模型

### 🧑‍💻 User

为什么vllm/sglang等投机解码从从原理上是不会降低降低质量，最多接受率为0速度很慢？

---

### 🤖 Assistant

**投机解码（speculative decoding）从原理上是*无损*的（lossless），输出分布严格等于目标模型（target model）的采样分布，因此不会降低生成质量。最差情况下接受率接近0，只会因额外开销导致速度变慢，但质量与直接用目标模型采样完全一致。**

### 核心原理
投机解码使用一个小而快的**草稿模型（draft model）** 先生成多个候选 token（通常 \(\gamma\) 个），再用大而准的**目标模型**并行验证这些候选。验证采用**带残差修正的拒绝采样（rejection sampling with residual）**，保证最终接受/重采样的 token 分布与直接从目标模型采样**完全相同**。

标准流程（以 Leviathan et al. / Chen et al. 的 speculative sampling 为基础）：

1. 草稿模型自回归生成 \(\gamma\) 个 token：\(x_1, x_2, \dots, x_\gamma\)，并记录草稿概率 \(q(x_i \mid \text{prev})\)。
2. 目标模型对同一前缀 + 候选序列**一次前向**，得到目标概率 \(p(x_i \mid \text{prev})\)（可并行计算所有位置）。
3. 从左到右逐 token 验证：
   - 以概率 \(\min\left(1, \frac{p(x_i)}{q(x_i)}\right)\) 接受 \(x_i\)。
   - 若拒绝，则从**残差分布**中采样：
     $$
     p_{\text{residual}}(x) \propto \max\bigl(0,\, p(x) - q(x)\bigr)
     $$
     然后停止后续验证（后续候选作废）。
4. 若全部 \(\gamma\) 个都接受，再从目标模型额外采样 1 个 token（bonus token）。

**数学保证**：任意完整序列的生成概率严格等于目标模型 \(p\) 下的概率。接受/拒绝 + 残差采样精确校正了草稿模型的偏差，因此**分布等价**（distributionally identical）。这不是近似，而是精确等价。

- 对贪心解码（greedy / argmax）：等价于“草稿预测与目标 argmax 一致则接受，否则回退到目标”。
- 对带温度 / top-p / top-k 的采样：同样可严格保持目标分布（实现时需正确处理 logits 变换和归一化）。

因此，从原理上**不可能降低质量**（不会改变输出分布，不会引入额外偏差或幻觉模式）。质量 = 目标模型本身的质量。

### 最差情况：接受率 ≈ 0，速度变慢
- 如果草稿模型与目标模型差异极大（几乎每次都拒绝），则几乎总是“生成 \(\gamma\) 个草稿 → 全部拒绝 → 从目标模型采样 1 个 token”。
- 此时每个有效 token 的计算量 ≈ 草稿生成开销 + 目标模型验证开销 + 残差采样，比直接用目标模型自回归**更慢**（有额外开销）。
- 但输出 token 的分布**仍然严格等于**目标模型，质量不变。
- 接受率越高（草稿越准），加速比越大（常见 1.5–3× 甚至更高，取决于模型和任务）。接受率由草稿与目标的对齐程度、序列难度、温度等决定。

vLLM、SGLang 等框架中的实现（包括 n-gram、小模型草稿、EAGLE、Medusa 等变体）都遵循或扩展上述验证逻辑，并在 continuous batching、paged attention、tree attention 等工程优化下保持正确性。它们通常暴露 `num_speculative_tokens`、draft model 配置等参数，并报告接受率统计；质量由目标模型保证。

### 补充说明
- **不是所有“加速方法”都无损**。某些启发式近似（未经严格残差校正、或强行多 token 预测后直接用）可能牺牲质量，但标准投机解码及其主流工程实现（vLLM / SGLang 等）是无损的。
- 实际加速效果依赖：草稿模型质量/大小、目标模型、序列长度、硬件、batch 情况。接受率过低时，框架有时会动态调整或建议关闭投机。
- 自投机（self-speculative，如用目标模型自身的早期层或额外头）同样可以做成无损。
- 相关原始论文：Leviathan et al. “Fast Inference from Transformers via Speculative Decoding”；Chen et al. “Accelerating Large Language Model Decoding with Speculative Sampling” 等，都证明了分布等价性。

**总结**：投机解码通过精确的拒绝采样 + 残差修正，保证输出分布 = 目标模型分布 → 质量不降。接受率低只是效率问题（最差变慢），不是质量问题。在 vLLM/SGLang 中正确启用时，你得到的是“可能更快、质量相同”的推理。
