# 卷积神经网络（CNN）简介

**卷积神经网络**（Convolutional Neural Network，CNN）是一类专门用于处理**具有网格状结构数据**（如图像、音频频谱、时间序列）的深度学习模型。它通过"局部感受野"和"权值共享"两大核心思想，大幅减少参数数量，并能自动从原始数据中逐层提取特征。

---

## 一、为什么需要 CNN？

用普通全连接网络处理一张 $224 \times 224 \times 3$ 的彩色图片时，仅输入层到第一个隐藏层（假设 1000 个神经元）就需要：

$$224 \times 224 \times 3 \times 1000 \approx 1.5 \times 10^8 \text{ 个参数}$$

这会导致**参数爆炸**，且忽略了图像的**空间结构**（相邻像素相关性、平移不变性）。CNN 通过下面两个机制解决了这个问题。

---

## 二、核心组成部分

### 1. 卷积层（Convolutional Layer）

用一组可学习的**卷积核（滤波器）**在输入上滑动，做逐元素相乘再求和：

$$(f * g)(i, j) = \sum_{m}\sum_{n} f(m, n)\, g(i-m,\ j-n)$$

- **局部感受野**：每个神经元只看输入的一小块区域。
- **权值共享**：同一个卷积核在整个图像上复用，极大减少参数。
- **特征图（Feature Map）**：每个卷积核输出一张特征图，激活值表示某类特征（边缘、纹理等）出现的强度。

### 2. 激活函数（非线性）

通常使用 **ReLU**：

$$\text{ReLU}(x) = \max(0, x)$$

引入非线性，使网络能够拟合复杂函数。

### 3. 池化层（Pooling Layer）

对特征图进行下采样，降低空间维度、增强平移不变性：

- **最大池化（Max Pooling）**：取区域内最大值。
- **平均池化（Average Pooling）**：取区域内平均值。

### 4. 全连接层（Fully Connected Layer）

在网络末端，将提取到的高层特征展平并映射到输出空间（如分类类别），常配合 **Softmax** 输出概率。

---

## 三、典型结构（以 LeNet-5 为例）

```
输入图像
  → [卷积 → 激活 → 池化]  × 若干组
  → 展平 (Flatten)
  → [全连接 → 激活] × 若干层
  → 输出层 (Softmax)
```

**层级特征**：浅层学边缘/颜色 → 中层学纹理/部件 → 深层学物体/语义。

---

## 四、关键超参数

| 参数 | 含义 |
|------|------|
| 卷积核大小 | 常见 $3\times3$、$5\times5$ |
| 步长（Stride） | 卷积核滑动的间隔 |
| 填充（Padding） | 边界补零，控制输出尺寸 |
| 通道数（Filter 数量） | 输出特征图的深度 |

输出尺寸公式（输入 $W$、核 $K$、填充 $P$、步长 $S$）：

$$W_{out} = \left\lfloor \frac{W - K + 2P}{S} \right\rfloor + 1$$

---

## 五、经典网络演进

- **LeNet-5**（1998）：手写数字识别，CNN 鼻祖。
- **AlexNet**（2012）：ImageNet 夺冠，引爆深度学习。
- **VGG**（2014）：用堆叠的小卷积核加深网络。
- **GoogLeNet / Inception**（2014）：多尺度并行卷积。
- **ResNet**（2015）：引入**残差连接**，解决深层网络退化问题。
- **后续**：DenseNet、EfficientNet、以及视觉 Transformer（ViT）等。

---

## 六、主要优点

1. **参数共享** → 参数量少，训练更易。
2. **局部连接** → 保留空间结构信息。
3. **平移不变性** → 物体位置变化仍能识别。
4. **自动特征提取** → 无需手工设计特征。

---

## 七、典型应用

- 图像分类、目标检测、语义分割
- 人脸识别、医学影像分析
- 视频理解、姿态估计
- 也扩展到语音识别、文本分类、推荐系统等一维/二维信号任务

---

## 一句话总结

> CNN 是一种利用**卷积核滑动**提取局部特征、通过**权值共享**降低参数、再逐层组合成高层语义表示的神经网络，是计算机视觉及众多网格数据任务的主流模型。
