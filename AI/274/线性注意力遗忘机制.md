# 线性注意力的遗忘机制：为什么需要 & 如何实现

## 一句话回答

线性注意力的隐状态是一个**固定大小、不断累加**的记忆矩阵，如果不加遗忘机制，它会把所有历史信息无差别地叠在一起，导致容量冲突、状态无界、无法表达“近因优先”。遗忘机制（衰减门控）就是给状态更新乘一个 $<1$ 的因子，让旧信息指数淡出——本质是一个**可学习的、甚至内容自适应的软遗忘**。

---

## 1. 为什么需要遗忘：从线性注意力的 RNN 本质说起

线性注意力把 $O(N^2)$ 的 softmax 注意力改写成核函数形式，其因果递推是一个**矩阵状态的线性 RNN**：

$$
S_t = S_{t-1} + \phi(k_t)v_t^\top, \qquad o_t = \phi(q_t)^\top S_t
$$

其中 $S_t \in \mathbb{R}^{d_k \times d_v}$ 是隐状态。展开后 $S_t = \sum_{i=1}^t \phi(k_i)v_i^\top$ —— **所有 token 的贡献等权叠加、永不消退**。这带来四个问题：

| 问题 | 原因 |
|---|---|
| **状态饱和 / 干扰** | $S$ 的秩上限是 $d_k$，相当于一个有限容量的联想记忆；历史无限增长，旧键值对互相“稀释”，$\phi(q_t)^\top S_t$ 检索出的是模糊叠加而非精确值 |
| **无近因偏置** | 语言建模强依赖局部上下文，但 vanilla 形式下 1 万 token 前的内容和上一个 token 权重相同 |
| **状态无界** | 状态范数随 $t$ 线性增长，短序列训练 → 长序列推理时数值分布漂移，长度外推差 |
| **噪声污染** | padding、功能词等无关 token 也被永久写入记忆 |

加上遗忘门后，更新变为：

$$
S_t = G_t \odot S_{t-1} + \phi(k_t)v_t^\top
$$

当 $G_t$ 是固定标量 $\gamma \in (0,1)$ 时，并行形式变成：

$$
o_t = \sum_{i \le t} \gamma^{\,t-i}\, \phi(q_t)^\top\phi(k_i)\,v_i
$$

这**等价于给注意力加了一个随距离指数衰减的位置偏置**（类似 ALiBi，但可学习、可内容依赖），同时状态会收敛到有界稳态。这就是遗忘机制的全部动机。

## 2. 具体实现：五大流派

所有现代设计都可以归入这个统一模板：

$$
\underbrace{S_t = G_t \odot S_{t-1}}_{\text{写端遗忘（衰减/擦除）}} + \underbrace{b_t\, \phi(k_t)v_t^\top}_{\text{写入}}， \qquad \underbrace{o_t = g_t \odot \phi(q_t)^\top S_t}_{\text{读端遗忘（输出门）}}
$$

### ① 固定/逐头衰减 — RetNet、Mamba-2

```text
S_t = γ · S_{t-1} + k_t v_t^T        （γ 逐头固定，多头覆盖不同时间尺度）
```

- RetNet 给每个头一个固定的 $\gamma$（按几何间隔初始化，不同头对应不同记忆时间尺度）；
- **Mamba-2 (SSD)** 证明了 selective SSM 可严格重参数化为这种“标量衰减 + 线性注意力”，$\gamma$ 逐头标量。

### ② 逐通道衰减 — GLA、RWKV-4/5

$$
S_t = \operatorname{diag}(\alpha_t)\, S_{t-1} + \phi(k_t)v_t^\top, \quad \alpha_t = \sigma(Wx_t + b) \in (0,1)^{d}
$$

不同维度有不同遗忘速率，且 **$\alpha_t$ 由当前输入 $x_t$ 计算** —— 遗忘变成内容自适应：遇到新话题/新实体就快忘，重复性内容就保留。GLA 论文消融显示仅此一项就显著降低困惑度。

### ③ 数据依赖衰减（SSM 路线）— Mamba

$$
h_t = \underbrace{e^{\Delta_t A}}_{\in(0,1)^d,\ \text{逐通道衰减}} h_{t-1} + \Delta_t B_t x_t, \qquad \Delta_t = \text{softplus}(W_\Delta x_t)
$$

$A$ 是负对角阵，$e^{\Delta_t A}$ 就是逐通道遗忘门；$\Delta_t$ 依赖输入 → **遗忘速率随内容变化**，这就是 "selective" 的含义。RWKV-6 则用 LoRA 式低秩修正把基础衰减参数变成 token 级数据依赖，并用双指数 $e^{-e^{(\cdot)}}$ 参数化保证 $(0,1)$ 且动态范围大。

### ④ 定向遗忘（覆盖式更新）— DeltaNet / Gated DeltaNet

衰减是“一刀切”地淡化**所有**旧信息；delta rule 做**精准擦除再写入**：

$$
S_t = S_{t-1}\big(I - \beta_t k_t k_t^\top\big) + \beta_t k_t v_t^\top
$$

含义：先减掉旧记忆中沿当前 key 方向的分量（擦掉这个 key 原来对应的 value），再写入新 value。这等价于对联想记忆做**一步在线梯度下降**：

$$
S \leftarrow S - \beta_t\, k_t\big(k_t^\top S - v_t^\top\big)
$$

解决“同一 key 重复出现时取最新值”的关联检索任务（MQAR）远好于纯衰减。**Gated DeltaNet** 把两者结合：$S_t = \alpha_t\big[S_{t-1}(I-\beta_t k_tk_t^\top)\big] + \beta_t k_t v_t^\top$ —— 全局衰减 + 定向擦除互补。

### ⑤ 读端遗忘（输出门）

$$
o_t = \sigma(W_g x_t) \odot \phi(q_t)^\top S_t
$$

不修改记忆本身，只控制“这次读出多少”—— Mamba 的输出门、RWKV 的 receptance、GLA 的 gate 都属于此类，类似一个软复位，防止无关时刻泄露状态内容。

### 汇总对比

| 模型 | 遗忘门形式 | 数据依赖 | 定向遗忘 |
|---|---|---|---|
| Linear Transformer | 无 | ✗ | ✗ |
| RetNet | 逐头固定 $\gamma$ | ✗ | ✗ |
| Mamba | $e^{\Delta_t A}$ 逐通道 | ✓ ($\Delta_t$) | ✗ |
| GLA | $\sigma(\cdot)$ 逐通道 + 输出门 | ✓ | ✗ |
| RWKV-6 | 双指数 + LoRA 低秩 | ✓ | ✗ |
| DeltaNet / Gated DeltaNet | $I - \beta kk^\top$ 擦除项 | ✓ ($\beta_t$) | ✓ |

<details>
<summary><b>3. 并行训练的具体实现：分块（Chunked）算法（展开看细节）</b></summary>

递推形式是串行的，无法利用 GPU 矩阵乘。主流做法（GLA/Mamba-2/RetNet 同源）是**chunk 内并行 + chunk 间递推**：

设 chunk 大小为 $C$，记对数域累积衰减 $L_j = \sum_{s \le j} \log \alpha_s$（逐通道，用 `cumsum` 实现），则 chunk 内位置 $i$ 读块内位置 $j$ 的相对衰减是 $\exp(L_i - L_j)$：

$$
o_i = \underbrace{e^{L_i}\,\phi(q_i)^\top S_{\text{in}}}_{\text{跨块（前文记忆）}} \;+\; \underbrace{\sum_{j \le i} e^{L_i - L_j}\,\phi(q_i)^\top \phi(k_j)\, v_j}_{\text{块内（形如 attention）}}
$$

$$
S_{\text{out}} = e^{L_C} S_{\text{in}} + \sum_{j=1}^{C} e^{L_C - L_j}\, \phi(k_j) v_j^\top
$$

工程要点：
- **固定标量衰减**：$e^{L_i - L_j} = \gamma^{i-j}$，就是一个上三角衰减矩阵 $D$（RetNet 的写法）；
- **逐通道衰减**：必须在 log 空间做 `cumsum`，再用差值 `exp` 回来——直接连乘累积积会下溢；
- 另一条路线是 **associative scan**（Mamba 的 selective-scan CUDA kernel），把递推视为可结合的二元运算做并行扫描；
- 开源实现参考 `flash-linear-attention (FLA)` 库的 Triton kernel，结构与 FlashAttention 类似：只含 matmul、tile 化、显存友好。

</details>

<details>
<summary><b>4. 稳定性与初始化技巧（展开看细节）</b></summary>

- **门控参数化**：sigmoid 保证 $\in(0,1)$；RWKV-6 用 $e^{-e^{(\cdot)}}$ 双指数，能表达“几乎完全遗忘”到“几乎完全保留”的宽范围；
- **偏置初始化**：初始让 $\gamma$ 接近 1，训练起点≈vanilla 线性注意力，再逐渐学出遗忘；RetNet/LRU 则让多头按几何间隔初始化，覆盖不同时间尺度；
- **log 空间累积**：防数值下溢/溢出；
- **归一化**：Katharopoulos 版本有分母 $\phi(q)^\top z_t$，后续工作（GLA 等）普遍去掉分母、改用输出 LN，配合输出门稳定训练。

</details>

<details>
<summary><b>5. 理论视角：遗忘 = 权重衰减 / 在线优化（展开）</b></summary>

把线性注意力看作 **fast weight programming**：状态 $S$ 是一个正在被逐 token 更新的“快速权重矩阵”，在解一个联想记忆问题。

- **衰减门** $\Leftrightarrow$ weight decay / EMA（指数滑动平均）：旧梯度贡献指数消退，状态有界；
- **Delta rule** $\Leftrightarrow$ 对损失 $\frac{1}{2}\|Sk - v\|^2$ 做一步 SGD；
- **数据依赖门控** $\Leftrightarrow$ 自适应学习率（类似 Adam 里的逐参数速率）；
- 这也解释了 Test-Time Training (TTT) 系列：线性 RNN ≈ 内层梯度下降，遗忘机制就是内层优化的正则项。

</details>

## 小结

- **为什么遗忘**：固定容量的状态 vs 无限增长的历史 → 必须做压缩；遗忘提供有界状态、近因偏置（≈可学习 ALiBi）、抗干扰、覆盖式更新能力；
- **怎么实现**：统一为一个门控递推 $S_t = G_t \odot S_{t-1} + \phi(k_t)v_t^\top$，$G_t$ 从固定标量（RetNet）→ 逐通道（RWKV-5）→ 数据依赖（Mamba/GLA/RWKV-6）→ 定向擦除（DeltaNet）逐步演进，再配合输出门做读端控制；
- **怎么跑起来**：训练靠 log 空间 cumsum + chunked 并行（或 associative scan），推理就是 $O(1)$ 状态递推——这正是这类模型相对 softmax attention 的核心优势。
