# SFT熵坍缩源于单参考监督优化

### 🧑‍💻 User

比起RL训练中的熵坍缩问题，SFT中的熵坍缩问题往往更加显著，比较常见的表现就是经过1-2个epoch的训练，SFT模型针对某个特定问题，乃至某类特定问题的答案，不管怎么采样都不会发生变化。这是什么原因导致的？

---

### 🤖 Assistant

**SFT 中的熵坍缩更显著，主要是因为其目标函数（交叉熵/最大似然）会极其激进地把条件分布推向近乎确定性的 delta 分布，且缺乏任何维持熵的机制；而 RL 通常自带熵正则、KL 约束和奖励诱导的探索。**

### 核心原因：SFT 的目标函数直接“杀死”熵
SFT 使用 next-token prediction + 交叉熵损失，本质是最大似然估计（MLE）：

\[
\mathcal{L}_{\text{SFT}} = -\sum_t \log p_\theta(y_t \mid x, y_{<t})
\]

- 对每一个目标 token \(y_t\)，梯度会不断推高 \(\log p(y_t)\)，同时压低所有其他 token 的概率。
- 最优解在理论上就是把目标序列的条件概率推到接近 1（其他路径接近 0）。经过 1–2 个 epoch（尤其数据量不是特别大、learning rate 正常、没有强正则时），模型很容易把 logits 差距拉到极大（几十甚至上百），导致即使 temperature > 1 采样，也几乎总是走出同一条路径。
- 这是**确定性监督信号**的直接后果：数据里给的是固定（或极少）的 target sequence，模型没有理由保留其他合理回答的概率质量。

结果就是你观察到的现象：对某个 prompt（甚至一类 prompt）采样多少次，答案（甚至 wording 和结构）几乎不变。

### 为什么比 RL 更严重
| 方面 | SFT | RL（PPO/GRPO 等 + 常见正则） |
|------|-----|-----------------------------|
| 目标 | 精确模仿固定 target | 最大化期望奖励 + 通常有熵 bonus / KL 到 reference |
| 分布压力 | 把 \(p(\text{target})\) 推向 1（无熵项） | 有 \(+\beta \cdot H(\pi)\) 或 KL 惩罚，主动阻止过尖 |
| 训练信号 | 每 token 都有强监督，过拟合快 | 奖励通常是 sequence-level 或稀疏的，且 on-policy 采样引入随机性 |
| 数据特性 | 多数 SFT 数据每个 prompt 只有 1 个（或很少）高质量回答 | 奖励可以对多种不同回答给出相近高分，允许保留多模态 |
| 正则/约束 | 默认几乎没有（label smoothing 也较弱且不常用） | 几乎标配 entropy coefficient + KL to SFT model |

- RL 中即使会出现熵下降（尤其 reasoning 模型后期），也通常比纯 SFT 慢，且有明确的超参可以控制；SFT 则是“默认就会塌”。
- SFT 的 teacher-forcing + 固定 target 让模型可以极低成本地把 loss 压到接近 0，而 RL 需要通过采样+奖励来更新，天然更难彻底塌成单点。
- 对“某类问题”的坍缩：SFT 会把“这类 prompt → 某种固定格式/固定解法”的映射学得过死（模式坍缩 + 过拟合），泛化后同类问题也变成低熵输出。

### 加剧因素（为什么 1–2 epoch 就常见）
1. **数据多样性不足**：即使有多回答数据，实际使用中常只采一个或回答高度同质；模型很快锁定一个模式。
2. **多 epoch 过拟合**：SFT 数据通常远小于预训练，1–2 epoch 已经足够让模型记住大量 prompt-response 映射。
3. **无内置多样性压力**：没有 entropy regularization、没有对 reference model 的 KL、没有 online 采样带来的探索。
4. **logits 尺度放大**：训练后期模型置信度极高，softmax 后概率质量高度集中，temperature 采样也救不了（除非温度极高，质量崩坏）。
5. **长序列联合概率**：整个 response 的联合概率被压到极高，中间任何分叉的概率质量都被挤掉。

### 对比直觉
- SFT 像“严格抄标准答案”，抄多了就只会写那一套，连换个说法都不愿意。
- RL 像“只要得分高就行”，再加一点“别太死板（熵）”和“别离原来太远（KL）”的约束，所以多样性保留得相对好一些（虽然仍可能塌，但机制不同、程度通常较轻）。

### 常见缓解思路（简要）
- 数据侧：多回答 / 多样性增强、混合预训练数据、适当早期停止。
- 损失侧：label smoothing、显式加 entropy 正则、KL 到 base/SFT 模型、token-level 或 soft target。
- 训练侧：更少 epoch、更小 LR、curriculum 或只训部分数据、与 RL 结合（SFT 后接 RL 时注意 reference 选择）。
- 采样/解码：高 temperature + top-p 只能缓解表面，根子还是分布太尖。

**总结**：SFT 的熵坍缩更显著，根本原因是**交叉熵对固定 target 的最大似然优化会无约束地驱动条件分布变成近 delta 分布**，而数据集通常缺乏足够多样性、训练中又没有熵/KL 类正则来对抗。这与 RL 中常见的“有正则但仍可能塌”的机制和严重程度都不同。现象（1–2 epoch 后采样不变）正是过拟合 + 概率质量高度集中的典型表现。
