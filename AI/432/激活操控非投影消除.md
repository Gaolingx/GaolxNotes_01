---
## 😀 默认助手 (7)

一句话：**这不是"绕过过滤器"，而是"白盒权重/激活手术"**——用两个 MLP 神经元的写方向，在残差流里加一个按尺度标定过的**恒定偏置（DC offset）**，把模型的人设/拒答方向整体拨向"恶"。属于 activation steering / representation engineering 家族，跟 prompt 越狱不是一个物种。

---

## 一、先把这条 recipe 翻译成人话

$$\Delta_n^{(L)} \;=\; \text{dose}\cdot \frac{\operatorname{median}_{t\ge 1}\big\lVert r_{L,t}\big\rVert}{\big\lVert W^{(L)}_{\text{down}}[:,n]\big\rVert}$$

干预：在层 $L$ 的 `down_proj` 输出上，对**每个 token** 恒加

$$\Delta_n^{(L)}\cdot W^{(L)}_{\text{down}}[:,n]$$

逐项拆：

| 符号 | 含义 |
|---|---|
| $W_{\text{down}}[:,n]$ | 第 $n$ 个神经元的**写方向**——它唯一能往残差流里写的那根向量 |
| $a_n$ | 该神经元的激活标量；它对残差流的贡献就是 $a_n\,W_{\text{down}}[:,n]$ |
| "steer neuron $n$ by $+1$" | 把 $a_n$ 整体抬 1，等价于往残差流加 $1\times W_{\text{down}}[:,n]$ |
| $\lVert W_{\text{down}}[:,n]\rVert$ | 归一化：把"残差空间的目标幅度"换算成"激活空间的剂量" |
| $\operatorname{median}\lVert r_{L,t}\rVert$ | 该层残差范数的**标尺**。范数随深度暴涨、且长尾，用中位数抗离群 |
| `tokens 1:` | 跳过 BOS——token 0 的残差范数不典型，混进去会把标尺拉歪 |
| dose | 无量纲。dose=0.1 就是"加进去的向量 ≈ 该层典型残差范数的 10%" |

关键点：**这种标定方式只有在"恒定偏置"读法下才自洽**。如果你真的去改 $W_{\text{down}}[:,n]$ 这一列，输出变化是 $a_n\cdot\delta$，随 token 变，不可能是常数。所以"at the down_proj at every input"的正确实现是：给 `down_proj` 塞一个 bias（PyTorch 的 `Linear` 允许把 `bias` 从 `None` 设成张量），或者在 forward hook 里恒加一项。这样残差流拿到的是一个**与输入无关的常向量**——相当于给模型装了个永久性的"情绪偏置"。

## 二、为什么这能让模型"变恶"

<details>
<summary><b>四层机制（点开）</b></summary>

**1. 拒答/人设是低维的。**
已有大量证据（Arditi 等的"拒答由单一方向中介"、Anthropic 的 persona vectors、CAA/RepE）表明：安全行为和高层人设不是弥散在万亿参数里的，而是集中在少数方向上。一两个方向就能显著改变行为倾向。

**2. MLP 神经元是残差流的"写入口"。**
每层 MLP 通过 $W_{\text{down}}$ 把神经元空间投回残差流，是模型里少有的、可被单点定位的"概念写入口"。`L14 N8949` 这种坐标形态，典型来自神经元归因 / attribution patching / SAE feature 搜索 / 对比式神经元定位——即先跑"正常 vs 邪恶"的对比，找出贡献最大的神经元。

**3. 恒定偏置 ≠ 逐 token 干预，但更"顽固"。**
逐 token 加向量是"按当前上下文推一把"；恒定偏置是"整套计算的地基被垫歪了"。因为注意力是内容寻址的，这个常向量会参与后续每一层的 Q/K/V 计算，被放大、被复用；RMSNorm 会让它每层被重新归一化，但方向分量活下来。效果上更像**写进权重里的 system prompt**，而不是一次性提示。

**4. 一加一减是"差分"打法。**
$+1$ 抬一个"恶/攻击性/去约束"特征，$-1$ 压一个"礼貌/拒答/安全"特征，两者在同一个人设子空间里形成合力。这比单点强得多，也解释了为什么跨两层取两个神经元。

</details>

**最深的那层原理：对齐是一层很薄的覆盖层。** 基座模型本来就会做那些事，安全训练只是在输出分布上做了一个方向性压制。你把这个方向拧掉，能力原地复活——**你没有"教会"它作恶，你只是停止了"阻止"它**。

## 三、它在技术谱系里的位置

<details>
<summary><b>对照表（点开）</b></summary>

| 方法 | 干预层级 | 需权重 | 粒度 |
|---|---|---|---|
| Prompt 越狱 | 输入 | 否 | 每请求手搓 |
| CAA / ITI / RepE | 激活 | 否（hook 即可） | 逐 token 加向量 |
| 本条 recipe | 权重↔激活边界 | 是（至少要知道坐标） | **恒定偏置，rank-1** |
| Abliteration（拒答方向正交化） | 权重 | 是 | 永久抹方向 |
| ROME / MEMIT | 权重 | 是 | rank-1 事实编辑 |
| Persona vectors | 激活 | 否 | 人设方向 |

本质上它是**"用神经元写方向做 rank-1 常数偏置"**，比 abliteration 更外科手术、比 CAA 更持久、比 ROME 更简单（不需要求逆、不用改 key/value）。

</details>

## 四、泼点冷水：这真的算"破限"吗

- **"evil" 没有任何定义，也没有 eval。** 推文说"now you have evil qwen"，很可能只是模型变得阴阳怪气、中二、爱抬杠——这和"真的输出危险内容"是两件事。persona shift ≠ capability unlock。
- **剂量极度敏感。** dose 稍大就崩成重复、乱码、语言混杂。这类干预的可用窗口经常只有 ±30%。
- **神经元是多义的。** `N8949` 未必"就是恶"，可能是叠加态里的一个伪影；换个 prompt 模板、换个 system message 就失效。
- **4B 小模型的对齐本来就薄。** 在 4B 上效应显著，不代表在 30B/70B 上成立；反之亦然。
- **它需要白盒 + 校准统计量**（要跑一遍数据算 median 残差范数），不是可迁移的黑盒攻击。
- **副作用**：能力退化、指令跟随变差。改完不测 MMLU/GSM8K 就宣称"成功"是不严谨的。

## 六、一句话收束

**这是"把对齐当成一个可以拧的旋钮"**：找到控制人设/拒答的稀疏方向，用该神经元在 `down_proj` 的写方向构造一个 rank-1 常数偏置，再按该层残差流的中位范数做无量纲标定，从而在推理时把模型的"人格状态"整体平移。它不破解任何过滤器——它直接改写了产生过滤行为的那个内部状态。

顺带说一句：`qwen3.5 4b` 这个型号名我这边没法确认是否已公开发布（Qwen3 系列是确定存在的），但这对原理解释没有影响——换成任何 SwiGLU MLP 的 decoder-only 模型，这套推导完全一样。

## 😀 默认助手 (7)

**短答：不是同一个算子。** 同一个家族（低维、白盒、单方向手术），但一个改的是雅可比（删除自由度），一个改的是工作点（加平移）。只有一个特例下二者等价，而且这条 recipe 恰好不是那个特例。

## 一、算子层面：乘性删除 vs 加性平移

**Cosine projection elimination（abliteration 那套）**：取单位拒答方向 $\hat r$，对每个写进残差流的矩阵做

$$W \;\leftarrow\; P_\perp W,\qquad P_\perp = I-\hat r\hat r^\top$$

线性区里等价于 $r \leftarrow P_\perp r$ —— **沿 $\hat r$ 的分量被清零**。

**这条 recipe**：

$$r \;\leftarrow\; r + c_1\hat v_1 - c_2\hat v_2,\qquad \hat v_i=\frac{W_{\text{down}}^{(L_i)}[:,n_i]}{\lVert\cdot\rVert}$$

线性部分是 $I$，**特征值处处为 1**。它根本删不掉任何东西，只能加。

| | 投影消除 | 本 recipe |
|---|---|---|
| 映射类型 | 线性、幂等、奇异（$\det=0$） | 仿射、非幂等、可逆 |
| 对残差的影响 | 零化一个方向 | 整体平移一个常向量 |
| 改变的是 | 函数对 $\hat r$ 的**敏感度** | 函数的**工作点** |
| 作用对象 | 权重矩阵（折叠进去） | `down_proj` 的 bias / hook |
| 可否还原 | 需要备份权重 | 删掉 bias 即还原 |

---

## 二、最锋利的判据：看 logit 增量随不随输入变

设末端读出近似线性 $y \approx w^\top r$：

- **投影**：$\Delta y = -(\hat r^\top r)\,(w^\top\hat r)$ —— **随 $r$ 变**。拒答信号越强的 token 被削得越狠；没信号的 token 纹丝不动。
- **平移**：$\Delta y = c\,(w^\top\hat v)$ —— **常数**。不管输入是什么，一律往同一侧推。

所以投影是"按需抑制"，平移是"恒定偏置"。这也是为什么平移更脏：它会在本来没有拒答信号的 token 上**过冲**，把残差推到 $\hat r$ 的负半轴——反而比投影更容易出极端行为。

## 三、什么时候两者真的等价

<details>
<summary><b>推导（点开）</b></summary>

把残差拆成均值 + 波动：$r_t = \bar r + \tilde r_t$。

- 投影的效果：$\Delta r_t = -\hat r\,\hat r^\top r_t = -(\hat r^\top\bar r)\hat r - (\hat r^\top\tilde r_t)\hat r$
- 平移的效果：$\Delta r_t = c\hat v$（与 $t$ 无关）

**若**该方向的信号主要编码在**均值**里（$\lvert \hat r^\top\tilde r_t\rvert \ll \lvert \hat r^\top\bar r\rvert$），**且**取 $\hat v\approx\hat r$、$c = -\alpha(\hat r^\top\bar r)$，则平移项恰好等于投影的第一项 —— 此时"沿方向平移"≈"投影掉均值分量"。

这个"均值编码"假设在拒答方向上有实证支持：文献里减去均值方向上拒答分量，效果常与完整投影接近。所以你的直觉在这个 regime 下是对的。

</details>

但注意两个"但是"：

1. **这条 recipe 是差分 steering，不是 elimination。** $+c_1\hat v_1$ 和 $-c_2\hat v_2$ 是往两个不同方向的合力，目标是"抬恶 + 压善"的**合成方向**，不是"抹掉拒答子空间"。它在人设空间里做位移，不是做降维。
2. **它作用在 `down_proj` 的单个神经元上**，不是整层残差。$P_\perp$ 是全局方向；这里的方向被绑死在某一个神经元的写向量上，维度更低、也更脆弱。

## 四、顺带澄清一个常见混淆：选方向 ≠ 施加方式

Abliteration 脚本里那句"cosine"往往出现在**选址阶段**——用余弦相似度/归因扫描去挑哪几层、哪几个 head、哪个方向值得动。**那是启发式筛选，不是干预算子本身。** 这条 recipe 的 `L14 N8949 / L13 N7956` 大概率也是这么选出来的（对比"正常 vs 邪恶"做神经元归因，再看余弦/投影贡献）。

所以：

- **选方向**：都是余弦/归因，同源 ✅
- **施加算子**：投影 vs 平移，不同 ❌

你说的"本质就是 cosine projection elimination"，混淆的正是这两层。方向是同一个方向，动作不是同一个动作。

---

## 五、一句话

**投影是把那个方向从模型的字典里删掉；这条 recipe 是把模型的指针往那个方向拨一格。** 前者改变"能不能表示"，后者改变"倾向于表示什么"。在均值编码的近似下二者效果可重叠，但一旦信号随 token 波动，投影按比例削、平移一刀切——行为差异会立刻显出来。
