# 重构思维链蒸馏价值取决于教学信号质量而非原始性

## 🧑‍💻 User

我在想，根据指令和结果，猜测中间发生的思维链，即便得到的思维链不是原始思维链，这样的语料也是有蒸馏价值的，是这样吗（reasoning/agentic）

## 简要回答

这种语料有价值，但我认为你问的坐标轴不太对。“是不是原始思维链”几乎不是决定蒸馏价值的关键变量；真正关键的是它作为**教学信号**的质量。“猜测出来的思维链”可以非常好，也可以是有害的，差别跟“原不原始”关系不大。

一个直接的理由：学生模型从来看不到教师的原始思维链，它只看到一段 token 序列。所以“忠实性（faithfulness）”对**可监控性 / 安全**要紧，对**能力迁移**不一定要紧。Turpin 等人和 Lanham 等人证明 CoT 常常不忠实，但用这些不忠实的 CoT 做蒸馏依然涨点——这两件事并不矛盾。

---

## 更合适的框架：后验采样 vs 先验采样

形式化一点。标准的“从指令+结果猜过程”是从近似后验里采样：

$$c \sim q(c \mid x, y)$$

而 on-policy 自采样 + 按正确性过滤（STaR / rejection sampling）是从先验里采样再筛选：

$$c \sim p(c \mid x), \quad \text{keep if } \mathrm{verify}(y \mid x, c)$$

两者都是“重构”，但性质完全不同：

| | $q(c\mid x,y)$ 答案条件化 | $p(c\mid x)$ + 验证 |
|---|---|---|
| 单条样本的正确率 | 高 | 低 |
| 采样成本 | 低（一发命中） | 高（要多采） |
| 多样性 | 差，容易坍缩到单一路径 | 好 |
| 系统偏差 | **后见之明偏置**（下面讲） | 无 |
| 学生在推理时能否复现 | 可能 off-policy | 天然 on-policy |

所以问题不是“猜的 vs 真的”，而是**你在后验的一端还是先验的一端**。

## 两条价值通道，重构对它们的影响不同

思维链蒸馏的收益大致分两条独立通道：

1. **计算通道**：trace 的 token 就是额外的串行计算。这条通道的收益正比于 trace 里真正“搜索”的密度。
2. **策略/先验通道**：教学生“该尝试哪类程序、什么时候回溯、工具调用约定长什么样”。

关键的不对称在这里：**策略通道基本可以重构，计算通道不行。** 你从 $(x,y)$ 反推时，最难的那步搜索恰恰是最不可能被忠实写下来的——因为写的人已经知道答案，可以事后用一个断言跳过它。这会导致 $q(c\mid x,y)$ 系统性地**压缩关键步**：关键步的 surprisal 被压平，trace 的“搜索 token / 推导 token”比例失真。学生学到的是一个看起来很干净、但在难点上直接断言的过程。

这就是后见之明偏置的核心危害，而且它的危害恰好落在你最想要的那部分能力上。

## 高价值的重构语料需要满足哪些条件

我倾向于用四个条件来判定单条 trace 的价值：

$$\Delta(x,c) \;\approx\; \underbrace{H(y\mid x) - H(y \mid x,c)}_{\text{充分性}} \;\times\; \underbrace{\mathbb{1}\!\left[\log \pi_\theta(c\mid x) > -\tau\right]}_{\text{可学性}} \;\times\; \underbrace{\mathbb{1}[\text{verify}(c)]}_{\text{可验证}}$$

- **充分性**：给定 $c$，$y$ 几乎确定。这会自动排除“结论正确但推理是装饰”的样本。
- **可学性**：trace 不能远超学生当前分布。否则梯度全花在模仿表面形式，剩下的是 exposure bias。
- **可验证**：数学/代码/agent 环境中能逐步或整体复算。这是过滤器的来源，也是这类语料能规模化生产的根本原因。
- **信息增益**：学生**不看** $c$ 时失败、**看** $c$ 时成功。这一条最容易被忽略，但它决定了这条样本是“教了新东西”还是“只是在确认已有能力”。

再加两个**采样层面**的要求，往往比单条质量更重要：

- **多样性**：$(x,y)$ 是多对一的。只保留一条重构路径会把学生的推理策略坍缩成单模态，推理时丧失探索能力。多条互不相同的有效路径才有价值。
- **难度匹配**：只在学生“差一点就能做出来”的区间上采样，收益最高。

<summary>实证线索（为什么我倾向于“能用，但别指望它教搜索”）</summary>

- **STaR 的 rationalization** 就是答案条件化的重构：把正确答案作为提示喂回去生成 rationale，再按正确性过滤后训练。它确实有效——这说明“猜出来的”语料有真实价值。但注意它**仍然要过验证器**，而且论文里它主要救的是"原本就快做对"的题。
- **Distilling Step-by-Step**（Hsieh 等）显示 rationale 增强的蒸馏大幅优于纯标签蒸馏，且这些 rationale 是教师**采样**出来的文本，教师内部并没有这样一条链。
- **过程奖励 / PRM** 一侧的经验是：过程级监督在困难问题上优于纯结果监督——反过来说明“过程文本本身是否承载关键信息”是重要的，重构恰恰最容易在这里失真。
- 2025 年前后有一批分析指出，R1 式蒸馏的收益有相当一部分来自**格式与行为风格的迁移**（长度、回溯习惯、自我检查），而不是新能力的注入；在强基座上，增益会明显饱和，重心转向带可验证奖励的 RL。
- 反向证据：**无法验证的开放域**上，重构语料的风险显著上升，因为过滤器失效，你会把“自信的错误断言”当成过程知识喂进去。

这些都是方向性证据，具体量级我不认为有定论；我倾向于保留“trace 的边际贡献可能小于人们以为的、过滤器和难度选择贡献更大”这个怀疑。

## Agentic 场景的特殊性（这里我更乐观）

Agent 的 trace 不是自由文本，而是可执行的动作序列：

$$\tau = (a_1, o_1, a_2, o_2, \dots, a_T), \quad o_t = \mathrm{Env}(s_{t-1}, a_t)$$

这带来一个自由文本推理没有的强约束：**可回放性**。重构的轨迹必须在环境里 replay 一致，观测必须真的由动作产生。这意味着：

- 幻觉轨迹**可检测、可修复**（replay 失败就重放或换动作），而自由文本的推理幻觉几乎无法发现。所以 agentic 的重构反而更可控 —— 你可以做“回放-修补”式重构，而不是“猜”。
- 稀疏延迟奖励下的**信用分配难题，本质上就是轨迹重构问题**。你从“最终成功”反推“哪几步是承重的”，这本来就是重构。所以在这个场景，“猜测中间的思维链”不是蒸馏的近似手段，它就是必需的一环。

但有一个特有的坑：**干净路径偏置**。知道成功了再写轨迹，会把探索、试错、从失败中恢复的片段全部删掉，输出一条平滑的直线。学生于是学会了“一切顺利时的做法”，而这恰恰不是 agent 真正需要的能力——agent 的鲁棒性主要体现在**出错后怎么修正**。缓解办法是显式地注入失败-恢复片段，或直接采集真实探索日志（哪怕含无效步骤，用 replay 一致性过滤掉纯噪声）。

## 一个操作性检查表

生成重构语料时我会逐条过：

- [ ] 用**搜索**产生轨迹（best-of-N / MCTS / PRM 引导 / replay），不要用**事后叙述**产生轨迹
- [ ] 逐步可验证，能给每步打上“承重 / 冗余”标签；做 leave-one-step-out 消融，删掉非承重步
- [ ] 尽量**答案盲生成**，或至少做一次“答案不可见”的重推导，检测后见之明压缩
- [ ] 保留 $k$ 条互异路径，而不是 1 条最优路径
- [ ] 只保留 $\log \pi_\theta(c\mid x)$ 在合理范围内的样本，避免纯 off-policy 垃圾
- [ ] 按“学生不看 $c$ 会失败、看了会成功”做难度筛选
- [ ] agent 场景额外要求 replay 一致 + 含恢复片段
- [ ] 对无法验证的领域，要么放弃，要么把置信度标出来，别混进 SFT 主数据

## 结论

**有价值的，但价值高度依赖生产方式，而不依赖“是否原始”。**

一句话概括我的观点：从 $(x,y)$ 重构出来的语料，作为**策略先验、格式规范、工具使用约定**的教学材料非常划算，可以规模化；但它系统性缺失的恰是**难点上的搜索行为**，而这正是你想让学生获得的那部分。所以它可以作为主体，但不能作为全部——需要配上可验证性过滤、答案盲生成和难度校准，agent 场景还要加 replay 一致性和失败-恢复样本。

顺带说一句：真正决定收益的很可能不是你重构得多像原始思维链，而是**过滤器和难度选择的精度**。与其纠结忠实性，不如把验证器和难度估计做好。
