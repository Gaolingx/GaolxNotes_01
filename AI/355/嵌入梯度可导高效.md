## 🧑‍💻 User

## 🤖 Assistant

# 结论速览

| 概念 | 是 one-hot 吗？ | 可导吗？ |
|------|----------------|---------|
| `softmax` | ❌ 不是（是"软"的连续分布） | ✅ 处处可导（光滑） |
| `argmax` | — | ❌ 不可导（分段常数，几乎处处梯度为 0） |
| `onehot(argmax)` | ✅ 是硬 one-hot | ❌ 不可导（离散跳变） |
| 温度趋近 0 的 softmax | 近似 one-hot | ✅ 仍可导（数值上会饱和） |

一句话：**softmax 是 one-hot/argmax 的"可导软化版"，但它本身不是 one-hot，也不能直接变成 one-hot。**

---

## 1. softmax 不是 one-hot

**Softmax** 输出的是一个连续的概率分布，各分量在 $(0,1)$ 之间且和为 1：

$$\text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j} e^{z_j}}$$

**One-hot** 是把最大值位置置 1、其余置 0 的离散向量：

$$\text{onehot}(\arg\max_i z_i) = \big[\,i = \arg\max_j z_j\,\big]$$

区别在于：

- softmax 给的是"**软分配**"（例如 $[0.7, 0.2, 0.1]$），保留了相对大小信息；
- one-hot 是"**硬分配**"（例如 $[1, 0, 0]$），只有"选谁"的信息。

它们的关系是**极限关系**——引入温度 $\tau$ 后：

$$\lim_{\tau \to 0} \text{softmax}(z/\tau) = \text{onehot}(\arg\max z)$$

所以 softmax 是 argmax/one-hot 的**连续松弛（continuous relaxation）**，而不是它本身。

---

## 2. 可导性分析

### softmax：可导 ✅

对输入 $z$ 处处光滑可导，雅可比矩阵为：

$$\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j), \qquad J = \text{diag}(p) - pp^\top$$

梯度有良好定义，可直接反向传播。

### argmax / one-hot：不可导 ❌

- **argmax** 是**分段常数**函数：输入微小扰动通常不改变输出，因此梯度几乎处处为 $0$；只在"平局/边界"处发生跳变，那里梯度不存在（次梯度/不可微点）。
- **one-hot(argmax)** 同样是**不连续**的阶梯函数：输出只能取离散的基向量，微小扰动要么不变（梯度 0），要么突变成另一个基向量（无穷跳跃）。
- 梯度为 0 意味着**无法提供有效学习信号**，所以不能直接拿它做端到端梯度下降。

> 直觉：可导的前提是"输入的小变化 → 输出的连续小变化"。one-hot/argmax 恰恰是"输入变一点，输出可能完全不变或突变"，违背了这一前提。

<details>
<summary><b>严格一点：可微与连续的关系（点击展开）</b></summary>

- 可微 $\Rightarrow$ 连续，但连续 $\not\Rightarrow$ 可微。
- argmax/one-hot 连**连续**都不满足（存在跳跃间断点），因此必然不可微。
- softmax 既连续又光滑，所以定义域内处处可微。
- 温度 $\tau\to 0$ 时 softmax 值趋向 one-hot，但作为 $\tau$ 固定、关于 $z$ 的函数它仍然可导；只是在饱和区梯度会变得极小（梯度消失）。

</details>

---

## 3. 那"硬截断/one-hot"真要训练怎么办？

实践中用**替代梯度**或**可导松弛**来绕过不可导：

### (a) 直通估计器 STE（Straight-Through Estimator）

前向用硬结果，反向"假装"softmax 的梯度：

```python
y_hard = one_hot(argmax(z))          # 前向：硬
y_soft = softmax(z)                   # 用于梯度
y = y_hard + (y_soft - y_soft.detach())  # 前向=硬，反向=soft 的梯度
```

- 常见于 VQ-VAE 的量化、量化网络、可微近似等。
- 优点是简单；缺点是**梯度有偏（biased）**。

### (b) Gumbel-Softmax / Concrete 分布（可导采样）

给 logits 加 Gumbel 噪声再 softmax，实现"可导的近似采样"：

$$y_i = \frac{\exp\!\big((\log \pi_i + g_i)/\tau\big)}{\sum_j \exp\!\big((\log \pi_j + g_j)/\tau\big)}, \qquad g_i \sim \text{Gumbel}(0,1)$$

- $\tau \to 0$：样本趋近 one-hot；$\tau$ 越大越平滑。
- 前向可用硬 one-hot + STE，反向用软松弛，常用于离散隐变量、GAN、离散策略等。

### (c) 其它路线

- **REINFORCE / 得分函数估计器**：把离散选择当随机动作，用对数导数估计梯度（无偏高方差）。
- **Soft attention**：直接不做硬截断，全程用 softmax 权重（Transformer 就是典型）。
- **稀疏/近似 argmax**：如 sparsemax、entmax，仍是可导的稀疏松弛。

---

## 4. 小结

1. **softmax ≠ one-hot**：前者是可导的连续概率分布，后者是不可导的离散硬分配；二者由"温度趋于 0"的极限相连。
2. **softmax 可导**，雅可比为 $\text{diag}(p)-pp^\top$；**argmax/one-hot 不可导**（不连续、梯度几乎处处为 0）。
3. 需要"硬选择 + 能训练"时，用 **STE / Gumbel-Softmax / REINFORCE / 软松弛** 等手段来提供替代梯度或可导近似。

## 🤖 Assistant

# 为什么 softmax 可导，argmax 不可导？

核心就一句话：**可导要求"输入动一点，输出连续地动一点"，并且这个变化率要有一个确定的极限。softmax 满足，argmax 完全不满足。**

下面从可导的定义出发，把两者的差异拆开看。

---

## 1. 先回顾可导的定义

函数 $f:\mathbb{R}^n \to \mathbb{R}^m$ 在点 $z$ 可导，要求下面这个极限存在（且与方向无关）：

$$\lim_{h \to 0} \frac{f(z+h) - f(z)}{\lVert h\rVert}$$

它暗含两个必要条件：

1. **输出必须是"连续变化"的**（在 $z$ 处连续）；
2. **变化率 $f(z+h)-f(z)$ 必须随 $h$ 线性地趋于 0**，即存在雅可比 $J$ 使 $f(z+h) = f(z) + Jh + o(\lVert h\rVert)$。

只要其中任一条件破坏，就不可导。softmax 两个都满足，argmax 两个都违反。

---

## 2. softmax 为什么可导

softmax 是**初等光滑函数（exp、求和、除法）的复合**：

$$p_i = \frac{e^{z_i}}{\sum_k e^{z_k}}$$

- $\exp$ 光滑，求和光滑，$1/y$ 在 $y>0$ 处光滑；
- 分母 $\sum_k e^{z_k} > 0$ 恒成立，永远不为 0；
- 于是复合结果在**整个 $\mathbb{R}^n$ 上光滑（无穷可微）**，处处连续、处处有确定的线性主部。

直接求偏导也验证了这点。对 $z_j$ 求导，用商法则：

- 当 $i = j$：
$$\frac{\partial p_i}{\partial z_i} = p_i - p_i^2 = p_i(1-p_i)$$

- 当 $i \neq j$：
$$\frac{\partial p_i}{\partial z_j} = -p_i p_j$$

合并写成雅可比矩阵：

$$\frac{\partial p_i}{\partial z_j} = p_i(\delta_{ij} - p_j), \qquad J = \text{diag}(p) - pp^\top$$

**每一项都是有限确定的数**，说明无论输入在哪个点、往哪个方向扰动，变化率都有良好定义。这就是可导的实质。

> 关键：softmax 是**连续且平滑**的"软映射"，输入的小扰动只会让输出**按比例平滑地微调**，不会跳变。

---

## 3. argmax 为什么不可导

这里要小心：讨论的对象通常是 $\text{onehot}(\arg\max(z))$，因为它输出向量。它有**三重致命伤**。

### (a) 输出空间是离散的

$\arg\max$ 的输出是**索引**（属于离散集合 $\{1,\dots,n\}$），离散集合上没有"线性结构"，连 $\frac{f(z+h)-f(z)}{h}$ 都未必有意义。所以直接谈 argmax 的导数在定义上就不成立。

### (b) 在不连续点跳变

把 $\text{onehot}(\arg\max(z))$ 看成从 $\mathbb{R}^n$ 到基向量集合的映射。它把空间划分成若干**区域**，区域内 argmax 不变；**区域边界上发生平局（tie）**，输出会突然从一个基向量跳到另一个。

在边界处，$f$ 是**不连续的**。而不连续是可微的"一票否决项"：

$$\text{可导} \implies \text{连续} \quad\Longleftrightarrow\quad \text{不连续} \implies \text{不可导}$$

边界处左极限 $\neq$ 右极限，割线斜率会趋于无穷（跳变除以 $h\to0$），**极限根本不存在**。

### (c) 连续区域里梯度恒为 0

在区域内部，argmax 是**局部常数**——输入微扰不改变输出：

$$f(z+h) = f(z) \implies \frac{\partial f}{\partial z} = 0$$

所以即使绕过那些不连续的边界，梯度也**几乎处处为 0**。这意味着：**就算形式上"可导"，梯度也提供不了任何方向信息，无法做有效学习**。这是它不能用于梯度下降的根本原因。

---

## 4. 一个具体例子（n=2）

取 $f(z) = \text{onehot}(\arg\max(z))$，沿路径 $z(t) = (t,\, 0)$ 考察：

$$
f(z(t)) =
\begin{cases}
(1,0), & t > 0\\
\text{平局（不唯一）}, & t = 0\\
(0,1), & t < 0
\end{cases}
$$

- 在 $t>0$（或 $t<0$）的开区间上，$f$ 是常数 → 导数为 $0$；
- 在 $t=0$ 处，$f$ 从 $(0,1)$ 跳到 $(1,0)$，跳跃幅度非零 → 差商 $\frac{f(0+h)-f(0)}{h}$ 随 $h\to0^\pm$ 发散，**极限不存在**。

所以整条路径上，**要么导数为 0，要么不存在**，没有任何一点给出有效梯度。

---

## 5. 对比总结

| 性质 | softmax | onehot(argmax) |
|------|---------|----------------|
| 映射类型 | 连续光滑 | 分段常数 / 离散跳变 |
| 输出空间 | 概率单纯形（连续） | 离散基向量集合 |
| 连续性 | ✅ 处处连续 | ❌ 边界处不连续 |
| 梯度 | ✅ 处处存在，$J=\text{diag}(p)-pp^\top$ | ❌ 不连续点不存在；其余处为 0 |
| 方向敏感性 | 任何方向都有平滑变化 | 只在大区域内不变，跨界突跳 |
| 对学习的作用 | 提供有效梯度信号 | 梯度为 0，无学习信号 |

**一句话**：softmax 用 $e^{z_i}/\sum e^{z_k}$ 把"谁最大"这种**离散比较**替换成了**连续可微的软比较**；而 argmax 本质上就是那个离散比较本身，它**不连续、几乎处处零梯度**，所以不可导——这也正是人们要用 softmax 去**松弛（relax）**它的原因。

## 🤖 Assistant

# embedding 也是离散选择，为什么它可导？

关键不在"选择"这个动作本身，而在于：**这个离散量是"输入侧的常量"，还是"由连续参数计算出来的函数输出"。** 求导永远要问一句："对谁求导？"

embedding 里离散的是**输入索引**，连续的是**参数**；我们要更新的正是连续参数，所以可导。argmax 里离散的是**函数输出**，而我们要把梯度传回产生它的连续 logits，所以断裂。

---

## 1. embedding 到底是什么运算

embedding 表 $E \in \mathbb{R}^{V \times d}$，输入索引 $i$，输出是第 $i$ 行：

$$z = \text{lookup}(i) = E^\top e_i = \sum_{v=1}^{V} e_{i,v}\, E_v = E_i$$

其中 $e_i$ 是 $i$ 的 one-hot 向量，$E_v$ 是第 $v$ 行。

**注意：$e_i$ 是常量。** 它由数据（token id、词 id）给定，在整张计算图里是个**叶子常量**，不依赖任何待优化参数。它不是被某个可导函数"算"出来的，而是**喂进来的**。

---

## 2. 为什么它可导：对参数 $E$ 求导是线性的

把 embedding 看作以 $E$ 为参数、以 $i$ 为输入的函数。对参数求偏导：

$$\frac{\partial z_l}{\partial E_{v,l'}} = e_{i,v}\,\delta_{l\,l'}$$

- 当 $v = i$ 时非零（$\delta_{l l'}$ 的那个 1），其余全为 0；
- 这是一个**良定义的线性映射**，处处可导，梯度就是把上游梯度直接"灌"进第 $i$ 行。

所以：

- **对离散的索引 $i$**：当然不可导（也没必要）——$i$ 是数据，不是要优化的东西；
- **对连续的参数 $E$**：完全可导，而且是最简单的线性可导。

训练时反向传播只更新 $E$ 的第 $i$ 行（其余行此步得到 0 梯度），这正是 word2vec / embedding 层**稀疏更新**的由来。**梯度有去处、且有意义**，问题就解决了。

---

## 3. 和 argmax 的关键差别

把两者写成对比，一眼看出问题出在哪：

| | embedding | argmax |
|---|---|---|
| 离散量是什么 | **输入索引 $i$**（常量） | **输出索引** $\arg\max(z)$ |
| 离散量与参数的关系 | 无关，是喂进来的数据 | 是参数的**函数** $\arg\max(f_\theta)$ |
| one-hot 的角色 | 常量 $e_i$ | 变量 $\text{onehot}(z)$，随 $z$ 跳变 |
| 要更新的参数 | $E$（连续） | 上游 $z$ 前的参数（连续） |
| 需要 $\partial \text{输出} / \partial z$ 吗 | **不需要** | **需要**，而这正是 0/不存在的 |
| 结论 | 对 $E$ 可导 ✅ | 对 $z$ 不可导 ❌ |

一句话：

- embedding：**"从连续参数里按固定索引取一行"**——这是线性（选择）操作，对参数可导；
- argmax：**"按连续值比较，产出一个离散索引"**——这是比较操作，对连续值不可导。

**同样是"离散选择"，前者选的是参数的坐标（可导），后者选的是输出的标签（不可导）。**

---

## 4. 用计算图理解（最本质）

看反向传播时梯度会流经哪些边：

**embedding 场景**
$$
\text{index } i \ (\text{常量}) \;\longrightarrow\; \text{lookup} \;\longrightarrow\; z \;\longrightarrow\; \cdots \;\longrightarrow\; L
$$
参数 $E$ 是这条边上的"被取用对象"，梯度从 $z$ 回流到 $E$ 的第 $i$ 行。图里**没有 argmax/one-hot 这种不连续节点**，路径完全光滑。

**argmax 场景**
$$
z \ (\text{连续，含参数}) \;\longrightarrow\; \text{onehot}(\arg\max) \;\longrightarrow\; \text{后续} \;\longrightarrow\; L
$$
想让梯度从"后续"流回 $z$，必须穿过 `onehot(argmax)` 这个节点。而这个节点的导数要么为 0、要么不存在，**梯度到这里就断头了**。

> 判据：**不连续节点出现在"参数 → 输出"的必经之路上，才会致命。** embedding 的离散性出现在**输入端**，不在参数到输出的路径上，所以无害。

<details>
<summary><b>反例：什么时候 embedding 也不可导？（点击展开）</b></summary>

如果**索引本身是模型从连续量里选出来的**，那 embedding 就救不了你。典型场景：

- **硬注意力（hard attention）**：先算 attention logits，再 argmax 选一个位置，然后取该位置的 value。
- **VQ-VAE 量化**：编码器输出连续向量，再 argmin 找最近的码本向量（离散索引），然后查码本 embedding。
- **离散隐变量 / 硬采样**：从 softmax 分布里 argmax 或采样取一个类别，再 embed。

这时计算图变成：

$$
\theta \;\to\; z \;\to\; \arg\max/\text{采样} \ (\text{不连续}) \;\to\; \text{index} \;\to\; \text{embedding}.
$$

**离散索引成了参数的函数**，梯度在这一步断裂，embedding 再可导也白搭——因为它拿到的 index 已经"没有梯度来源"了。所以这些模型必须引入：

- **直通估计器 STE**：前向用硬 index 查表，反向把梯度近似地按到 logits 上；
- **Gumbel-Softmax**：用软的、可导的近似选择替代硬 argmax；
- **VQ-VAE 的 codebook loss + straight-through**：让码本能被更新。

**结论**：embedding 可导的前提是"索引来自外部数据、与参数无关"。一旦索引改由模型内部的离散选择产生，就退化成和 argmax 一样的不可导问题。
</details>

---

## 5. 总结

1. **可导性是对特定变量而言的**。embedding 对离散输入 $i$ 不可导，但对连续参数 $E$ **线性可导**。
2. embedding 的离散性是**输入侧的常量选择**（`one-hot × 矩阵`），不挡在"参数→输出"的反向路径上；
3. argmax 的离散性是**输出侧的、由参数算出的选择**，它挡在反向路径的咽喉处，且不连续、导数几乎处处为 0；
4. 所以判断"离散操作可不可导"，别只看"是不是选择"，要看：**这个离散量是不是待优化参数的函数，且是否立在梯度回传的必经之路上。**

# 不会消失。关键在于：参数 $E$ 和输入 ID 在计算图里是**并行的两个叶子**，$E$ 的梯度不需要"穿过"输入 ID。

你这句话里藏着一个默认假设——"梯度必须穿过去"。但实际上，embedding 的梯度是**分叉**出来的，不是**链式穿过**的。下面把它拆清楚。

---

## 1. 先澄清"One-hot 梯度为 0"到底在说什么

上一问说的"one-hot 梯度是 0"，精确含义是：

$$\frac{\partial\, \text{onehot}(\arg\max(z))}{\partial z} = 0 \quad(\text{a.e.})$$

**这要求 one-hot 是某个连续变量 $z$ 的函数**——它是被 argmax 算出来的**因变量**。

而 embedding 里的 $e_i$ **不是任何东西的函数**，它是从数据喂进来的**自由常量（计算图的叶子节点）**。对一个与参数无关的常量，"它的梯度"这个说法根本不成立——不存在"对谁求导"。所以那条"0 梯度"结论**在这里根本套不上**。

> 关键区分：一个是"**作为函数输出的 one-hot**"，一个是"**作为常量输入的 one-hot**"。前者卡在反向路径咽喉，后者只是个路由开关。

---

## 2. 计算图：并行分支，而不是链式穿越

embedding 前向：$z = E^\top e_i$。这里的 **$E$ 是参数，$e_i$ 是输入常量，二者是 $z$ 的两个并列父节点**：

```
        E  (参数叶子)          e_i  (输入常量叶子)
         \                     /
          \                   /
           →→→→    z    ←←←←←
                  |
            下游 loss  L
```

反向时，上游梯度 $g = \dfrac{\partial L}{\partial z}$ 在 $z$ 处**同时分给两个父节点**：

**① 到参数 $E$（训练真正要用的）：**

$$\frac{\partial L}{\partial E} = e_i\, g^\top$$

这是一个只有**第 $i$ 行非零**的矩阵。非零、良定义、**处处可导**。梯度**不需要经过 $e_i$**，因为它俩是兄弟节点，$E$ 直接是 $z$ 的父节点。

**② 到输入 $e_i$（自动微分也会算，但我们丢弃）：**

$$\frac{\partial L}{\partial e_i} = E\, g$$

注意——**这个也不是 0！** 它一般是非零的 $V$ 维向量。只不过 $e_i$ 是数据、不是参数，我们**不更新它**而已。

**所以并不存在"梯度穿不过 one-hot 导致消失"这回事**：
- 参数 $E$ 的梯度走①，畅通无阻；
- "穿过 one-hot 往上游走"指的是②，但 one-hot **上游是空的**（它是叶子），本来就没有需要更新的东西。

"消失"这个词只适用于"本该有梯度、却因某节点不可导而变成 0"。这里参数 $E$ 该拿到的梯度**一分不少**，谈不上消失。

---

## 3. 什么时候才真的会"断裂"

断裂只在一种情况下发生：**输入 ID 的上游还有待训练的参数**，即 ID 不是数据、而是被连续参数算出来的。

$$
\theta \;\longrightarrow\; z \;\longrightarrow\; \underbrace{\arg\max}_{\text{不可导}}\;\longrightarrow\; \text{ID}\;\longrightarrow\; \text{embedding}\;\longrightarrow\;\cdots\;\longrightarrow\; L
$$

这时梯度想回到 $\theta$，必须**穿过 argmax**，于是真的断裂——这才是硬注意力 / VQ-VAE 需要 STE、Gumbel-Softmax 的原因。

| | 标准 embedding | hard attention / VQ-VAE |
|---|---|---|
| 输入 ID 来源 | **外部数据**（叶子常量） | **参数算出来的**（$\arg\max$ 的输出）|
| ID 上游有参数吗 | 无 | 有（$\theta$）|
| 梯度要穿过 argmax 吗 | **不需要** | **需要** |
| 结果 | 参数 $E$ 正常收到梯度 ✅ | argmax 处断裂 ❌ |

**判据**：问题不在"有没有离散选择"，而在"**这个离散量上游是否挂着待优化的连续参数**"。标准 embedding 的 ID 上游是空的，所以安全。

---

## 4. 附赠：那条"被丢弃"的输入梯度其实很有用

前面 ② 得到 $\dfrac{\partial L}{\partial e_i} = E\,g \neq 0$。它**不是废的**——如果把硬 one-hot 换成软分布 $p \in \Delta^{V-1}$（对 embedding 做加权混合）：

$$\bar z = \sum_{v} p_v E_v = E^\top p, \qquad \frac{\partial L}{\partial p} = E\,g$$

- **输入是硬 one-hot（数据）**：这条梯度被丢弃，因为我们不更新数据——**不是消失，是不需要**；
- **输入是软分布 $p$（来自 softmax）**：这条梯度被使用并继续往上游传——这正是 **soft attention / 软 embedding 混合**能端到端可导的机制。

换句话说：embedding 到输入方向的梯度**一直都在**，只是硬输入时它停在数据边界；一旦输入变软且可导，梯度就顺着它流回去了。

---

## 5. 一句话总结

> **梯度不需要"穿过 one-hot 才能到达参数 $E$"。$E$ 是 $z$ 的直接父节点，走的是并行分支，拿到的梯度非零且良定义。消失的从来不是参数梯度，而是"往输入 ID 继续回溯"那条本就通向空节点的分支。**

**类比**：embedding 像一排可调旋钮（连续参数），one-hot 是"选哪个旋钮"的开关。开关位置是离散的、不需要梯度；被选中的旋钮是连续的，照样收到梯度。**梯度直接流向旋钮，根本不用穿过开关。** 只有当你想反过来用参数去"决定开关的位置"（即 ID 由模型自己选）时，才会撞上不可导的墙。

## 1. 把公式写精确一点

设 $z = W^\top x$（$x = e_i$ 是 one-hot，$g = \partial L/\partial z$ 是上游梯度），链式法则给出：

$$\frac{\partial L}{\partial W} = g\, x^\top$$

- **$x^\top$ 就是"选行器"**：因为 $x = e_i$，外积 $g\, e_i^\top$ 只在**第 $i$ 行**留下 $g^\top$，其余行恒为 0。
- 所以你说的"输出对 $W$ 的偏导是输入 $x$"——直觉正确：$\partial (Wx)/\partial W$ 里出现的正是 $x$，而 one-hot 的 $x$ 的作用就是**把梯度精确投送到第 $i$ 行**。

矩阵形式：

$$\frac{\partial L}{\partial W} = \begin{bmatrix} 0 \\ \vdots \\ g^\top \\ \vdots \\ 0 \end{bmatrix} \;\leftarrow\; \text{仅第 } i \text{ 行非零}$$

**结论**：对参数 $W$ 完全可导，且**梯度天然稀疏**（每步只有 $O(1)$ 行非零，而非 $O(V)$）。

---

## 2. 批内累计：同一 token 出现多次要"求和"

实际训练是一个 batch，同一个 token id 可能出现多次。第 $i$ 行拿到的是**所有出现处梯度之和**：

$$\Big(\frac{\partial L}{\partial W}\Big)_{i,:} = \sum_{b:\, x^{(b)} = e_i} g^{(b)\top}$$

这正是实现里用 **scatter-add / `index_add` / atomic add** 的原因（PyTorch 内部就是这么做的）：

```python
# 概念示意：反向其实是"把每个位置的梯度散射回对应行并累加"
grad_W.index_add_(0, indices, grad_out)   # indices 是 batch 里的 token id
```

不是"每个 token 覆盖写一次"，而是**累加**。

---

## 3. 工程高效性的两个细节

### (a) 稀疏梯度

因为梯度天然稀疏，可以用**稀疏表示**（`indices + values`）而不是稠密 $V\times d$ 矩阵，省内存、省计算：

```python
torch.nn.Embedding(vocab, dim, sparse=True)   # 生成稀疏梯度
```

### (b) ⚠️ 但"只更新对应行"取决于优化器

**梯度**确实只有第 $i$ 行非零；但**优化器**是否也只更新那一行，要看它有没有全局状态：

- **SGD（无 weight decay / 无 momentum 的纯 SGD）**：只更新有梯度的行 → 真正只动第 $i$ 行 ✅；
- **Adam / 带 weight decay 的优化器**：会对**所有**参数应用状态更新（比如权重衰减、动量），于是"零梯度行"也会被更新（通常是整体朝 0 收缩）❌ 这时并不"只更新一行"。

想要真正的稀疏更新，需要用**稀疏感知优化器**，例如：

- `torch.optim.SparseAdam`、Adagrad 的稀疏模式；
- 或对 embedding 单独用稀疏优化器，对其它参数用普通 Adam。

所以严谨说法是：

> **梯度是稀疏的、可导的，投送高效（只算 $O(1)$ 行）；但"只更新一行"还要求优化器支持稀疏更新。**
