---

### 🤖 Assistant

你记的那篇是 **Luma AI 的《Abra: Scaling Diffusion Image Training》**（arXiv:2608.17286，2026-08）。它专门给文生图扩散 Transformer 做了 compute-optimal scaling law，结论就是你印象里那条，而且原话更精确：

> 扩散模型最优训练点约在 **每参数 200 个 image token**（200 TPP），是 LLM Chinchilla 规则（约 20 TPP）的 **10 倍**；并且扩散模型 **"过训练几乎免费，欠训练是灾难性的"**。

下面拆开讲"怎么回事"。

## 0. 先对齐概念（否则 200 vs 20 没法比）

- 这里的 **image token = latent patch**，不是一张图。Abra 用 512×512 图 → f=8 VAE → 64×64 latent → 2×2 fold → $32\times32=1024$ 个 patch，每个 patch 是 16 通道的**连续向量**，就是一个 token。
- 所以 200 TPP 对 2B 模型 ≈ $2\text{B}\times200=4\times10^{11}$ image tokens ≈ **3.9 亿张图**（论文 Table 2：对 100M 图库过 3.85 个 epoch）；1B 模型 ≈ 2 亿张图。
- LLM 的 20 TPP：2B 模型只要 $4\times10^{10}$ 个 text token。

也就是说，**"每参数要的 token 多不少"不是指训练总量小，而是指"数据:参数"的平衡点大幅右移**——同样参数量，扩散模型要喂进约 10 倍的信息量才算"喂饱"。

## 1. 为什么扩散要 ~200 而不是 ~20（10 倍差距的机理）

论文本身主要确立**实证事实**，没给特别深的机制解释，但从它自己的证据（附录 C、§4.6）加一般原理，可以归纳成四点：

**① 监督信号类型不同：离散分类 vs 连续回归 + 随机目标**
- LLM：每个 token 目标是"下一个 token 的分类"，目标**确定、熵低**（一个 token 平均几到十几 bit），语言还有强组合先验，样本效率高。
- 扩散（flow-matching $v$-prediction）：每个 patch 的目标是**连续向量**，而且目标里还混着与数据独立的随机噪声 $\varepsilon$。要学到一个稳定的连续映射，得靠大量样本把噪声方差平均掉，信息效率天然低。

**② 一个样本只在一个噪声水平 $t$ 上学，且 $t$ 的信息含量极不均匀**
- 这是最被低估的一点。每次训练只采样一个 $t$，而 $t\in[0,1]$ 其实是一**族任务**。
- 论文附录 C 直接量了 per-timestep loss 响应曲线：$t=0$（干净图）和 $t=1$（纯噪声）两端几乎贴着 oracle 下界——因为此时 $x$ 和 $\varepsilon$ 相互独立，最优解就是"猜均值"，**几乎学不到任何关于数据分布的东西**；真正可约减的 loss 全挤在中间 $t$。
- 换句话说，200 token 里相当一部分被"无信息"的噪声水平消耗掉了，要把全噪声谱学完整，token 需求就被放大。

**③ 连续高维目标的维度灾难 + "回归到均值"的作弊捷径**
- MSE/flow-matching 的最优预测是**条件均值**。模型可以先学会输出一张"模糊的平均图"就拿到很低的 loss，但离好样本还很远；从"均值"走到"分布细节"这一步需要额外大量数据。
- 这同时解释了"loss 低 ≠ 生成质量好"（loss 与 FID 严重错位）。

**④ 分辨率越高，TPP 越高（信息密度越低）**
- 论文 §4.6：$256^2\to768^2$ 分辨率，最优 TPP 从 **165 → 247**。因为分辨率越高，每个 patch 的信息密度越低。这说明 TPP 本质上是在度量"**每参数需要吸收多少信息**"，而图像 patch 的单体信息密度低且随分辨率变化。

> 旁证：像素自回归图像模型（Yan et al. 2025）独立得出 200–400 TPP，并发工作 Chimera（Ge et al. 2026）也同意"扩散比 LLM 更吃数据"，所以 10 倍不是单篇论文的偶然。

## 2. 为什么"欠训练"对扩散是灾难性的（不对称性）

这是论文 §4.2 的核心图（Figure 6）想说的：**给定固定算力**，把"偏离最优 TPP 造成的 loss 惩罚"画成曲线——

- **扩散模型**：$<200$ TPP 一侧（欠训练）惩罚**急剧上升**；$>200$ TPP 一侧（过训练）**几乎平**（2× 过训练惩罚 < 0.5%）。
- **LLM**：两侧都明显上升，相对**对称**（比如 Gadre et al. 的 LLM，最大模型把最优 TPP 翻倍就吃 ~4% 惩罚，约为扩散的 20 倍）。

一句话：**扩散的曲线在欠训练侧是悬崖，过训练侧是平地；LLM 是两边都陡的谷。**

机理解释（这部分是我的推断，论文没展开）：

- 生成是在学**整个高维分布 $P(x|c)$ 的支撑面**，不是"给定上下文猜下一个 token"。欠训练 = 模型容量大、但没见过足够多的分布支撑，失败方式是**质变式**的：模式坍缩、发灰发糊、高频细节崩坏、prompt 不跟随——一处没学会整块塌。
- LLM 是**条件式预测下一 token**，语言有极强冗余和语法/组合先验，欠训练只是 perplexity 高一点、知识少一点，退化是**渐变式**的（graceful degradation），模型仍然能插值、能用。
- 换个角度看曲线形状：扩散的 loss 对数据量 $D$ 的边际收益在很大区间内**不递减**（给数据就降），而参数量 $N$ 在欠训练区被数据卡死；LLM 则要求 $N$、$D$ 一起平衡。

## 3. 实践含义（论文给的 rule of thumb）

> 算力受限时，**宁可"小模型 + 多数据"（overtrain），也不要"大模型 + 少数据"（undertrain）**。

这也解释了为什么工业界好的扩散模型（FLUX、SD3 等）相对参数量不大、但数据量堆得很夸张——直觉上是"欠训练容忍度低"逼的。

<summary>一些边角/注意事项（展开看）</summary>

- **早期结论相反**：Liang et al. (2024)（更早的 DiT scaling 研究，只到 $<10^{19}$ FLOPs）认为模型应比数据增长更快（$D$ 指数 < $N$ 指数），那会导致前沿尺度系统性欠训练。Abra 用大一个量级的算力 + 受控模型家族，发现其实是**均衡增长** $D\propto C^{0.5},\,N\propto C^{0.5}$。
- **"200"不是普适常数**：不同生成指标的最优 TPP 差很多——FID≈182、KID≈257、CLIPScore≈153、CMMD≈294，loss 参考值 ≈200。分辨率也改这个数。
- **token 定义口径**：Abra 只数 image token；若把 text token 一起数（multimodal TPP），数值会更高（约 250 起），所以和别的论文比数字时要看口径。
- **setup 限定**：结论基于 flow-matching + latent DiT + DataComp-1B + Qwen3-4B 文本编码器 + Adam，换优化器/VAE/文本编码器数值会漂移，但"10×"的定性结论目前与独立工作一致。
</details>

**一句话总结**：扩散模型要吃 ~10 倍于 LLM 的数据量才算喂饱，根因是它做的是"连续高维分布回归 + 噪声水平族任务 + 无信息噪声端占坑"；而它欠训练时是**悬崖式崩坏**、过训练时**几乎免费**，所以最优策略是"小模型猛灌数据"。
