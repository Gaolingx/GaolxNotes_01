# 可视化 LLM 的「参数激活」与「残差流」

先澄清一个容易混淆的点：**残差流（residual stream）** 和 **参数激活（activations）** 不是一回事，但它们是叠在一起观测的。

## 一、概念：残差流到底是什么

现代 Transformer 每条主干上都有一个 $d_{\text{model}}$ 维向量在层间流动，每一层只是**读取**它、算出一个修正量、再**加回去**：

$$x_{l+1} = x_l + \text{Attn}_l(x_l) + \text{MLP}_l(x_l)$$

- $x_l$ 就是**残差流**：它是模型"当前对下一个 token 的全部信念"的累积。
- $\text{Attn}_l$ / $\text{MLP}_l$ 的输出是**逐层的写入量（write）**，也就是大家说的"参数激活"。
- 每个注意力头、每个 MLP 神经元，都可以看成往残差流这个**共享总线上写一个方向向量**。

所以可视化基本分两个视角：**看总线（$x_l$）** 和 **看各个写入方（heads / neurons）**。

---

## 二、主流工具链

| 工具 | 定位 | 适合 |
|------|------|------|
| `TransformerLens`（Neel Nanda） | 事实标准，hook 一切中间张量 | 残差流、注意力、SAE、logit lens |
| `nnsight`（NDIF） | 支持远程大模型、pyvene 风格干预 | 大模型、因果实验 |
| `baukit`（David Bau） | 轻量 hook | 因果追踪 |
| `circuitsvis` | 浏览器端交互图 | 注意力头可视化 |
| `sae_lens` | 稀疏自编码器 | 特征级解释 |
| `Captum` / `shap` | 归因 | 输入/神经元归因 |

**建议**：小模型（GPT-2、Pythia、Llama-3-8B）用 `TransformerLens` 最省事；要跑 70B 用 `nnsight` 远程推理。

## 三、六类可视化做法

### 1. 残差流本身：范数与演化

最直接的是把 $x_l$ 的 **L2 范数**沿层画出来，能看到"某几层突然膨胀"（比如 induction 头出现处）。

```python
import torch
from transformer_lens import HookedTransformer
import plotly.graph_objects as go

model = HookedTransformer.from_pretrained("gpt2")
_, cache = model.run_with_cache("The capital of France is")

norms = [cache[f"blocks.{l}.hook_resid_pre"].norm(dim=-1).mean()
         for l in range(model.cfg.n_layers)]

fig = go.Figure(go.Scatter(y=norms, mode="lines+markers"))
fig.update_layout(title="Residual stream norm across layers",
                  xaxis_title="layer", yaxis_title="mean L2 norm")
fig.show()
```

更细的还可以做**残差流方向的 PCA / UMAP**，把每个 token 在某层的高维向量压到 2D 上色（看语义聚类是否随层形成）。

### 2. Logit Lens（把残差流翻译成人话）

残差流本身是抽象向量，用 unembedding 矩阵 $W_U$ 直接投影回词表，就能看到"每一层模型在想什么"：

$$\text{logits}_l = W_U \cdot \text{LN}(x_l)$$

```python
# TransformerLens 内置
logits, cache = model.run_with_cache(prompt)
for l in range(model.cfg.n_layers):
    resid = cache[f"blocks.{l}.hook_resid_post"]
    logit_lens = model.unembed(model.ln_final(resid))
    top = logit_lens[0, -1].topk(5)
    print(l, [model.to_string(t) for t in top.indices])
```

**Tuned Lens**（`tuned-lens` 库）给每层训练一个仿射探针，比朴素 logit lens 更准，适合画"预测演化热力图"。

### 3. 注意力模式

- **逐头注意力矩阵**：$\text{softmax}(QK^\top/\sqrt{d})$，用 `circuitsvis.attention_heads` 画成交互式小方格。
- **注意力熵 / 归纳头检测**：沿层统计熵，找 induction、previous-token 头。
- **QK / OV 电路**：`circuitsvis` 可画每个头在读写哪些 token 方向。

```python
import circuitsvis as cv
cv.attention.attention_patterns(
    tokens=model.to_str_tokens(prompt),
    attention=cache["pattern", 0],   # [n_heads, seq, seq]
)
```

### 4. MLP 神经元激活

- 每层挑出**激活最大的神经元**，看它们的 top 激活 token（Neuronpedia 风格）。
- 用**神经元激活热力图**：横轴 token，纵轴神经元索引。
- 巨模型上更实用的是 **SAE**：把残差流分解成稀疏可解释特征，再看哪些特征在哪些 token 上激活。

```python
from sae_lens import SAE
sae = SAE.from_pretrained("gpt2-small-res-jb", "blocks.8.hook_resid_pre")
feats = sae.encode(cache["blocks.8.hook_resid_pre"])
# feats: [batch, seq, n_features]，挑非零特征画热力图
```

### 5. 因果分析：Direct Logit Attribution / Activation Patching

光看激活是相关性，要做因果就得**干预**：

- **Direct Logit Attribution (DLA)**：把某层/某头对正确 token logit 的贡献分解出来，用条形图看谁是主角。
- **Activation Patching**：把 clean 的激活 patch 到 corrupted run，量化每个位置/头的因果影响，画成热度图。

```python
# DLA：注意力头对最终 logit 的贡献
logit_contrib = cache["blocks.7.attn.hook_result"] @ model.W_U[:, target_token]
```

### 6. 综合仪表盘

把上面拼起来做交互页面：

- **Streamlit + Plotly**：滑块选层、选头，实时更新。
- **Neuronpedia / TransformerLens 的 `tables`**：批量浏览。
- **BertViz**（HuggingFace）现成的注意力 dashboard，三视图（head/neuron/model view）。

## 四、工程与性能注意事项

<details>
<summary>勾选框展开（显存、hook 粒度、大模型）</summary>

- **显存**：`run_with_cache` 会存所有中间张量，8B 模型可能爆显存。用 `names_filter=` 只存你需要的层/张量。
- **hook 粒度**：想精细到"每个神经元写入"就用 `hook_mlp_out` 的分解；想整体趋势就只看 `hook_resid_pre/post`。
- **大模型**：本地方案用 `nnsight` 远程（NDIF）或量化后跑；纯可视化不需要梯度，`torch.no_grad()` 省一半。
- **batch/seq**：可视化通常只关心单个 prompt，取 `[^0]` 后压掉 batch 维，避免维度搞混。
- **SAE 训练**：如果目标模型没有现成 SAE，自己训很贵，优先用 `sae_lens` 已发布的（GPT-2、Pythia、Llama 都有）。
</details>

## 五、最小可跑模板

一条命令级流水线：

```python
from transformer_lens import HookedTransformer
import circuitsvis as cv
import plotly.express as px

model = HookedTransformer.from_pretrained("gpt2")
tokens = model.to_tokens("When Mary and John went to the store, John gave a drink to")
logits, cache = model.run_with_cache(tokens)

# 1) 残差流范数
norms = [cache[f"blocks.{l}.hook_resid_pre"][0].norm(dim=-1).mean().item()
         for l in range(model.cfg.n_layers)]
px.line(y=norms, markers=True, title="residual norm").show()

# 2) logit lens 预测演化
for l in range(model.cfg.n_layers):
    resid = cache[f"blocks.{l}.hook_resid_post"]
    pred = model.unembed(model.ln_final(resid))[0, -1].argmax()
    print(l, model.to_string(pred))

# 3) 注意力
cv.attention.attention_patterns(
    tokens=model.to_str_tokens(tokens[0]),
    attention=cache["pattern", 0],
)
```

**一句话总结**：把「残差流」当成共享总线看范数与 logit lens，把「参数激活」当成各个 head/neuron 的写入量看注意力矩阵、神经元热力图和 DLA；再做激活 patching 补足因果。工具首选 `TransformerLens` + `circuitsvis` + `sae_lens`。
