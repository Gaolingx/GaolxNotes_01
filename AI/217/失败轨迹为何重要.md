# Agentic RL 中"失败轨迹也很有价值"的原因

我检索了 arXiv 上 agentic RL（多轮 LLM agent 的强化学习）相关论文，下面是它们给出的核心论证。**一句话结论**：在长程、稀疏奖励的 agent 任务里，失败轨迹不是"要丢弃的负样本"，而是**信用分配、错误恢复、探索信号、纠错知识**这几类关键信息的**唯一或主要来源**。

## 总览：五条价值脉络

| 价值维度 | 失败轨迹提供了什么 | 代表论文 |
|---|---|---|
| 细粒度信用分配 | 失败轨迹里**被埋没的正确步骤** | GraphGPO、HCAPO |
| 错误恢复能力 | **第一个错误步骤** + 恢复路径 | Agent-R |
| 探索/不确定性信号 | 高熵、低置信度 token 的密集监督 | SELAUR |
| 更强/更可泛化的梯度 | 靠近能力边界的探索性推理 | ReNIO、RAGEN-2 |
| 纠错知识/根因 | root-cause failure 与 graph edit path | AgentDebug、EMG、ReSkill |

## 1. 轨迹级奖励太粗，失败轨迹里藏着"金子"

Group-based RL（如 GRPO）默认按**最终成败**做轨迹级归因。GraphGPO（`arXiv:2605.26684`）直接指出：这种粗粒度归因"**难以捕捉单步贡献，例如失败轨迹中被遮蔽的有价值步骤（valuable steps obscured within failed trajectories）**"。

它的做法是把所有 rollout 聚成一个统一的**状态转移图**，用图上的全局信息估计每个状态到目标的距离，再按"转移减少目标距离的程度"给每条边分配 advantage。也就是说——**一条失败的轨迹，只要其中某些转移在缩短到目标的距离，它们依然应该被正强化**。

> 直观理解：agent 最后失败了，但中间可能做对了 8 步、只在第 9 步崩了。如果整条轨迹按负样本处理，这 8 步的正确行为会被一起惩罚，这是极大的信号浪费。

## 2. 没有失败，就学不会"从错误中恢复"

Agent-R（`arXiv:2501.11425`）的核心洞见是：现有方法多靠行为克隆学强专家，**主要缺陷是"无法从错误中恢复"**。而 step-level 的批评（critique）数据又贵又难收集，于是它直接把失败轨迹变成训练数据：

- 用 MCTS 从**错误轨迹中构造出能恢复的正确轨迹**；
- actor 模型在失败轨迹中定位**第一个错误步骤**，从那里拼接修正路径。

关键点在于"及时修正"而非等到 rollout 结束——这正是通过失败轨迹才能学到的能力。**失败轨迹是"何时该纠偏"这一监督信号的自动来源。**

## 3. 失败是根因定位与纠错知识的载体

**AgentDebug / "Where LLM Agents Fail and How They can Learn From Failures"（`arXiv:2509.25370`）** 提出：

- **AgentErrorTaxonomy**：覆盖 memory / reflection / planning / action 的模块化失败分类；
- **AgentErrorBench**：首个在 ALFWorld、GAIA、WebShop 上系统标注的**失败轨迹数据集**；
- **AgentDebug**：隔离 root-cause failure 并给出 corrective feedback，让 agent 恢复并迭代改进，all-correct 准确率提升 24%。

论文强调 agent 架构会**放大级联失败**——单个根因错误沿后续决策传播。要诊断这种传播，**必须分析失败轨迹本身**，成功轨迹里看不到这个传播过程。

**EMG（`arXiv:2607.13884`）** 把这一思想形式化：把**失败的探索轨迹**和成功专家轨迹都转成有向图做匹配，提取公共成功子图 + **graph edit path**（在给定观察下该增加/删除/重标哪些动作），从而把它当作"如何修复失败"的知识存进记忆图。

## 4. 失败样本的梯度信号可能比成功样本更强

这篇最直接地回答了你的问题。**ReNIO（`arXiv:2606.23104`）** 在受控过滤实验中发现一个**一致的不对称性**：

> 在 on-policy distillation 和 self-distillation 中，**只用错误输出训练，效果反而优于只用正确输出训练。**

原因分析：只喂正确样本的模型倾向于生成**更短的推理链、反思行为更弱**；而**错误样本能更好地保留模型能力边界附近的探索性推理（exploratory reasoning near the model's capability boundary）**。

从 RL 理论看这也很自然——group-relative 的 advantage 是

$$\hat{A}_i=\frac{R_i-\text{mean}(\mathbf{R})}{\text{std}(\mathbf{R})}$$

**对比来自失败样本**：如果一组全成功或全失败，方差趋 0，梯度消失。**RAGEN-2（`arXiv:2604.06268`）** 把这个机制点名为 *Echo Trap / template collapse*：奖励方差过低会削弱任务梯度，让正则项主导、抹掉跨输入的推理差异。换句话说——**失败轨迹是维持训练信号信噪比（SNR）的必要成分**。

## 5. 失败中蕴含探索与不确定性信号

**SELAUR（`arXiv:2602.21158`）** 明确写道：不确定性反映模型置信度，"**即使在失败轨迹中也提供有价值的学习线索（offers valuable learning cues even in failed trajectories）**"。它把熵、最低置信度、margin 组合成 token 级不确定性，并通过 *failure-aware reward reshaping* 把信号注入 step 级与轨迹级奖励，提升探索效率与稳定性。

**HCAPO（`arXiv:2603.08754`）** 则以 **hindsight credit assignment** 处理稀疏奖励：把 LLM 本身当作事后评论家（post-hoc critic），**用事后推理去修正每一步的 Q 值**。失败轨迹一旦结束，反而更容易"事后诸葛"地判断出哪一步是致命的，这正是 hindsight 的来源。

## 归纳：失败轨迹为什么"有价值"

<details>
<summary><b>展开：把上面几张拼成一条逻辑链</b></summary>

1. **信号密度**：agent 任务奖励稀疏，最终成败是 0/1；失败轨迹提供了中间步骤与事后 Q 值的密集监督来源（GraphGPO、HCAPO）。
2. **对比与方差**：group-based RL 的梯度依赖组内成败对比；全成功会塌缩、全失败会塌缩，**失败样本提供必要的方差/SNR**（RAGEN-2、ReNIO）。
3. **能力边界**：失败恰好发生在模型能力边界附近，那里的探索性推理最有学习价值（ReNIO）。
4. **可恢复性**：错误恢复是一项技能，只能从"错误→修正"的配对中学到（Agent-R）。
5. **可诊断性**：级联失败只有通过回溯失败轨迹才能定位根因并生成纠错知识（AgentDebug、EMG、ReSkill）。

</details>

**一句话**：在 agentic RL 中，失败轨迹同时是 **信用分配的载体、错误恢复的教材、探索信号的发生器、以及纠错知识的数据库**——把它当纯负样本丢掉，等于扔掉了长程任务里最稀缺的那部分监督信息。
