# `torch.unsqueeze` 与维度广播（broadcasting）问题

下面先讲清广播规则，再讲 `unsqueeze` 如何"对齐"维度来解决广播失败的问题，最后给出常见场景模板。

---

## 一、先理解广播规则

PyTorch 的广播规则与 NumPy 完全一致，判断时**从最右（末尾）维度向左对齐**：

1. 让两个张量维度右对齐，较短的在**左侧补 1**；
2. 每一维满足以下之一即可广播：
 - 两者相等；
 - 其中一个是 `1`（会被拉伸到另一个）；
 - 其中一个**不存在**（即被补的那一维）；
3. 结果在每一维取两者的**最大值**。

我用脚本实测了几组形状（规则与 PyTorch 相同）：

| 形状 A | 形状 B | 结果 | 说明 |
|--------|--------|------|------|
| `(3,1)` | `(3,4)` | `(3,4)` ✅ | 中间的 `1` 被拉伸 |
| `(5,)` | `(3,5)` | `(3,5)` ✅ | 左侧自动补 1 |
| `(3,4)` | `(4,)` | `(3,4)` ✅ | 尾部对齐 |
| `(5,)` | `(3,)` | ❌ 报错 | `5≠3` 且都不为 1 |
| `(1,5)` | `(3,5)` | `(3,5)` ✅ | `unsqueeze(0)` 补成 `1` |
| `(3,1)` | `(3,4)` | `(3,4)` ✅ | `unsqueeze(1)` 补成 `1` |

关键结论：**广播失败的根因通常是"某一维既不是 1，也不相等，甚至根本对不齐"**，而 `unsqueeze` 就是把维度"对到正确的位置并补成 1"。

## 二、`unsqueeze(dim)` 做了什么

在指定位置插入一个**长度为 1 的维度**（不复制数据，只是改 stride/形状）：

```python
x = torch.arange(3)          # shape (3,)
x.unsqueeze(0)               # shape (1, 3)  → 补在最前
x.unsqueeze(1)               # shape (3, 1)  → 补在最后
x[None, :]                   # 等价写法 shape (1, 3)
x[:, None]                   # 等价写法 shape (3, 1)
```

`dim` 的取值范围是 `[-x.dim()-1, x.dim()]`，负数表示从右数。

## 三、典型广播问题与 `unsqueeze` 解法

### 场景 1：给 batch 加偏置（`(N,C)` + `(C,)`）
这种其实**不用** `unsqueeze`，尾部对齐即可：

```python
x = torch.randn(32, 128)     # (N, C)
b = torch.randn(128)         # (C,)
y = x + b                    # (32,128) 自动广播 ✅
```

### 场景 2：逐通道缩放，但偏置形状是 `(N,)` 想按"行"操作
```python
scale = torch.randn(32)      # (N,) 想对每一行分别缩放
# x: (N, C)
y = x * scale.unsqueeze(1)   # (32,1) → 广播成 (32,128) ✅
# 若直接 x * scale 会失败或语义错误
```

### 场景 3：外积 / 成对组合（两个 1D 张量）
```python
a = torch.randn(3)           # (3,)
b = torch.randn(4)           # (4,)
# a[:, None] * b[None, :]  → (3,1)*(1,4) = (3,4) ✅
outer = a.unsqueeze(1) * b.unsqueeze(0)
```

### 场景 4：成对距离矩阵（`(N,D)` 与 `(M,D)`）
需要把两者扩成 `(N,1,D)` 和 `(1,M,D)`：
```python
d = ((x.unsqueeze(1) - y.unsqueeze(0)) ** 2).sum(-1)  # (N,M) ✅
```

### 场景 5：`(5,)` 和 `(3,)` 这种硬冲突
两个向量直接相加必然报错（实测 ❌）。此时要**明确语义**再 `unsqueeze`：
```python
a = torch.randn(5)
b = torch.randn(3)
# 若想做 (5,3) 外积式运算：
c = a.unsqueeze(1) + b.unsqueeze(0)   # (5,1)+(1,3) → (5,3) ✅
```

## 四、用 broadcasting 检查自己对齐

一个实用技巧：打印形状确认，或显式用 `expand` 验证：

```python
def dbg(*ts):
    for t in ts:
        print(tuple(t.shape))
    try:
        torch.broadcast_shapes(*[t.shape for t in ts])
    except RuntimeError as e:
        print("❌", e)
```

`torch.broadcast_shapes(a, b)` 只计算广播后形状，不真正运算，方便调试。

## 五、相关替代/配合工具

| 方法 | 作用 | 与广播的关系 |
|------|------|--------------|
| `unsqueeze(dim)` | 插入长度 1 的维度 | 让维度**对齐位置**并补 1 |
| `x[None]` / `x[:, None]` | 同上，语法糖 | 等价 |
| `reshape` / `view` | 改变形状（不保证语义位置） | 有时可替代，但易错位 |
| `expand(*sizes)` | 把 `1` 维度**零拷贝**拉伸到目标 | 显式广播，配 `unsqueeze` 用 |
| `expand_as(other)` | 拉伸到另一张量形状 | 调试友好 |
| `torch.broadcast_tensors(*ts)` | 返回已广播好的张量 | 只广播不运算 |

示例：显式广播（不复制内存）
```python
a = torch.randn(3).unsqueeze(1)      # (3,1)
b = torch.randn(4).unsqueeze(0)      # (1,4)
A, B = torch.broadcast_tensors(a, b)
print(A.shape, B.shape)              # (3,4) (3,4)
print((a * b).shape)                 # (3,4) 隐式广播等价
```

## 六、记忆口诀

> **右对齐、补 1、相等或为 1 才通**；
> **对不齐就用 `unsqueeze` 把 1 放到对的位置**；
> **只想拷贝形状就用 `expand`，只想验证就用 `broadcast_shapes`。**
