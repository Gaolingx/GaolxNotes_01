# VLA虚假依赖场景导致泛化不足

## 🧑‍💻 User

为什么vla对场景有虚假依赖，简单来说就是换了场景泛化不足，以及各种各样别的不好泛化的点。

---
## 😀 默认助手 (7)

## 一句话：模型越大，问题也不是关键；真正的问题在于训练信号“不在乎”泛化

VLA 的虚假依赖（spurious dependence）是指：策略学到的并非“任务因果变量 → 动作”，更接近“场景外观统计 → 动作”。而这是模仿学习的目标函数、数据分布和表征先验共同造成的必然后果，并非偶然缺陷。

---

## 1. 机制：为什么 ERM 必然走向捷径

把观测拆成 $o_t=(s_t,n_t)$，其中 $s_t$ 是任务相关状态（物体位姿、可抓区域、目标），$n_t$ 是混淆变量（背景、光照、桌面纹理、相机内外参、场景身份）。真实策略只需要 $a_t=\pi^\star(s_t)$。

但行为克隆解的是：

$$\min_\theta \mathbb{E}_{(o,a)\sim\mathcal D}\big[\ell(\pi_\theta(o),a)\big]$$

在**有限、窄分布**的数据上，$n$ 与 $a$ 高度相关（因为 $n$ 几乎决定了“这是哪个场景、做什么任务”）。于是这个风险泛函的近似最优解**不唯一**：任何在 support 内与 $a$ 相关的 $n$ 的函数，也是合法解。

而优化有**简单性偏置（simplicity bias）**：背景色、纹理、物体的绝对像素坐标、机械臂的固定起始位形，在特征空间里比 3D 几何、接触约束、动力学更容易线性读出。所以模型先学到的是 $n\to a$ 的查表，$s\to a$ 只是“顺带”。

这正是 de Haan 等人说的 **causal confusion**：在 i.i.d. 采样下，模型没有任何动力把 $s$ 和 $n$ 分开。要让它分开，必须有**干预**（同一场景换 $n$、同一 $n$ 换 $s$）或**显式不变性约束**，而现有多数 VLA 数据两者都没有。

---

## 2. 数据侧：分布没有逼它学会不变性

- **场景高度集中**：Open X-Embodiment / RT-1 / BridgeData 的绝对多数是几个实验室的几张桌面。$p_{\text{train}}(n)$ 的支撑集极小，测试时 $n$ 一偏移就是 covariate shift，而策略从未被要求对 $n$ 不变。
- **没有反事实配对数据**：没有“同一条轨迹，换光照 / 挪物体 3cm / 抬高相机”的成对样本，就不存在可施加的 invariance 正则。
- **位置先验被当成因果**：桌面操作数据里机械臂常以固定位形、固定区域抓取，模型直接背 joint-space 轨迹并 condition on 场景身份 —— 这就是“训练厨房 90%、新厨房 0%”的典型来源。
- **长尾缺失**：恢复行为、失败后重试在 demo 里极稀少，模型学不会从偏离状态自救。

---

## 3. 表征侧：预训练编码器给的不是抓取需要的东西

- CLIP / SigLIP 这类编码器优化的是“**这是什么**”，不是“**在哪、多大、朝哪、能不能抓**”。它们在空间关系、朝向、计数、度量尺度上系统性偏弱（有 bag-of-words 现象），而操作恰恰全靠这些。
- **2D 像素丢掉了深度、接触、力**。策略只能靠外观统计推断动作；光照、阴影、相机内外参一变，外观统计就崩。
- **跨具身相机外参不同**：同一物理场景落到完全不同的像素分布，动作头却仍是具身专属的 joint/EE 空间 + 固定控制频率。

```text
理想：    像素 → [几何/affordance 表征] → 动作（对光照、纹理、相机高度不变）
实际：    像素 → [语义/外观表征]      → 动作（对场景身份高度敏感）
```

---

## 4. 动作侧：BC 自带的几种病

- **多模态平均**：同一观测下多种合理动作（左绕/右绕、不同抓点），$\ell_2$ 目标的最优解是**条件均值** $\mathbb E[a\mid o]$，平均出来的动作往往哪个都不是。扩散 / flow matching 能缓解，但更吃数据。
- **误差超线性累积**：BC 在无交互设定下的遗憾上界是 $\tilde O(T^2\epsilon)$ 量级。一旦偏出 demo 流形，虚假特征会**自信地**给出错误动作，而模型没有 OOD 感知能力，也不会纠正。
- **动作语义绑具身**：动作 token 的含义依赖具体机器人，跨具身重映射本身就有损。

---

## 5. 语言侧：指令经常被“忽略”

把 instruction 消融掉，很多 VLA 性能只掉一点点。这说明它更接近**场景条件的行为克隆**，并非**指令条件策略**。那么“新动词 + 新物体”的组合泛化就无从谈起：语言没有成为提供组合性的因素。

---

## 6. 目标侧：likelihood ≠ success

BC 最大化 demo 动作似然，而 demo 里的动作包含了“当时恰好这么做”的偶然选择（从左绕是因为当时左边没东西）。**优化这个目标，等于主动把 scene-specific 的偶然性固化进策略**。任务成功率从来不在损失函数里。

---

| 常见期待 | 实际行为 |
|---|---|
| “预训练见过海量互联网数据，泛化应该好” | 互联网数据与操作动作之间没有对齐信号，只帮了语义，没帮几何/动力学 |
| “多任务混合就能泛化” | 混合扩大了 $p(n)$ 但没破坏 $n\!-\!a$ 的相关性，可能只是学了更多张查表 |
| “语言是指令接口，所以能组合” | 语言常被忽略，模型在做场景识别 |
| “换场景只是 domain gap，加增广就行” | 症结是**因果结构错**，不是像素统计偏移；朴素增广可能强化捷径 |

---

<details>
<summary><b>缓解方向（展开）</b></summary>

“把模型做大”并非优先项，**改因果结构**才是：

1. **表征接地**：引入 depth / point cloud / 对象中心表征 / affordance 预测，让输入里显式含几何，模型就不必从纹理里猜。
2. **显式不变性**：对 $n$ 做物理一致的干预增广（重打光、换纹理、抖相机外参、挪干扰物），并加跨干预的方差惩罚
$$\mathcal L=\mathbb E[\ell]+\lambda\,\mathrm{Var}_{n}\big[\pi_\theta(s,n)\big]$$
3. **反事实/干预数据**：同场景同任务、只变 $n$ 的配对轨迹，是打破 causal confusion 最直接的药。
4. **多模态动作头**：diffusion / flow policy 解决条件均值问题。
5. **用任务 reward 微调**：RL 或偏好优化把 success 放进目标，替掉纯 likelihood。
6. **恢复数据与 DAgger 式交互**：让策略见过并学会脱离偏离流形。
7. **测试时自适应 / in-context 适配**：给几条新场景 demo 让它在线对齐。
8. **更严格的 benchmark**：held-out 场景、held-out 具身、held-out 指令组合（如 SimplerEnv、RoboArena、LIBERO 的跨场景划分），而不是同分布随机切分。

</details>

---

**一句话收尾**：VLA 的泛化瓶颈是“**数据里 $n$ 和 $a$ 绑得太死，而损失函数只奖励拟合、从不奖励区分**”，并非参数量问题。只要训练分布里“场景身份”仍是预测动作的最省力特征，换场景就必然失效——这跟模型是不是 VLA 关系不大，是模仿学习的老病。
