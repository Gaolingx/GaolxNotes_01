# Linux 查看所有用户历史命令

## 核心原理

每个用户的命令历史默认保存在其家目录下的 `.bash_history` 文件中：

- 普通用户：`/home/用户名/.bash_history`
- root 用户：`/root/.bash_history`

## 方法一：遍历所有用户的 history 文件（最常用）

```bash
# 查看所有用户（含 root）的历史命令
for user in $(cut -d: -f1 /etc/passwd); do
    home=$(eval echo ~$user 2>/dev/null)
    if [ -f "$home/.bash_history" ]; then
        echo "===== $user ($home) ====="
        cat "$home/.bash_history"
    fi
done
```

## 方法二：快速查看指定用户的最近命令

```bash
# 查看某个用户的最近 20 条命令
tail -n 20 /home/username/.bash_history

# 查看 root 用户的
tail -n 20 /root/.bash_history
```

## 方法三：用 find 批量搜索

```bash
# 查找系统中所有 bash_history 文件
find / -name ".bash_history" 2>/dev/null

# 结合 xargs 一起输出内容（显示归属文件）
find /home /root -name ".bash_history" -type f 2>/dev/null \
    | while read f; do echo "===== $f ====="; cat "$f"; done
```

## 方法四：当前用户直接执行

```bash
history                # 查看当前用户全部历史
history | tail -20     # 最近 20 条
history -c             # 清空当前会话历史（慎用）
```

## 补充技巧

<details>
<summary><b>📌 让 history 显示执行时间</b></summary>

默认历史不带时间戳，排查问题时可临时开启：

```bash
export HISTTIMEFORMAT="%F %T  "
history
```

写入 `/etc/profile` 可对所有用户生效。
</details>

<details>
<summary><b>📌 查看当前登录用户的实时命令（w / ps）</b></summary>

`.bash_history` 只在**退出会话时**才写入文件，正在线用户的命令看不到。可实时监控：

```bash
# 查看在线用户
w

# 跟踪某个终端正在执行的命令
ps -ef | grep pts/
```
</details>

<details>
<summary><b>📌 更严谨的审计方案</b></summary>

如果目的是**安全审计**（防止用户清空或篡改历史），建议：

1. **history 强制追加到 syslog**（写入 `/etc/bash.bashrc` 或 `/etc/profile`）：

```bash
export PROMPT_COMMAND='history -a; logger -t "bash[$$] user=$USER cmd=$(history 1 | sed "s/^[ ]*[0-9]\+[ ]*//")"'
```

2. **使用 `auditd`** 记录命令执行：

```bash
auditctl -a always,exit -F arch=b64 -S execve -k command_audit
ausearch -k command_audit
```

3. **防止用户删除历史文件**：

```bash
chattr +a /home/username/.bash_history   # 只允许追加
```
</details>

## ⚠️ 注意事项

| 问题 | 说明 |
|------|------|
| 权限不足 | 普通用户无法读其他用户的 `.bash_history`，需 `root` 或 `sudo` |
| 实时性 | 命令在会话退出前不会写入文件 |
| 其他 shell | zsh 的历史在 `.zsh_history`，fish 在 `.config/fish/fish_history` |
| 用户可能清空 | `history -c` + 删除文件会抹掉记录，重要场景请用 `auditd` |
