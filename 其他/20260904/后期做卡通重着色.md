# 后期做卡通重着色

## 🧑‍💻 User

卡通渲染后期合成（nuke ae 达芬奇）可以实现reshading吗

---
## 🤖 Assistant

# 短答

**能，但要分母是"哪种 reshading"。**

后期合成（Nuke / AE / DaVinci）可以做到 **"看起来像重新打光 / 重新着色"** 的效果（relight-look、换 ramp、换色调），前提是渲染时输出了 **AOV（Lighting Pass / Normal / Position / Albedo / Ramp / Outline）**。

但 **真正的"换光照方向 + 重投影角度阴影"**，单靠后期是做不到的——因为阴影遮挡关系、轮廓、投影像素在单张图里已经被"烘焙"进去了。要做就必须 **重渲** 或在合成里 **用 AOV 重建 3D 再打光**。

---

## 一、先说清"卡通渲染的 reshading"到底是什么

卡通（Cel / Toon）的着色本质是光照 $N\cdot L$ 经过一个 **硬阶跃 ramp**：

$$
C_{final} = \text{ramp}\big(\max(0, N\cdot L)\big) \cdot C_{base} + \text{outline} + \text{spec}
$$

它有两个特点，决定了后期能不能"重来":

| 特点 | 对后期 reshading 的影响 |
|------|----------------------|
| 着色是**硬阶跃**（几段平色） | ✅ 好消息：只要拿到法线 $N$，就能在后期**重新算 ramp**，甚至换光照方向 |
| 阴影/描边是**烘焙进像素**的 | ❌ 坏消息：换光后**阴影投射方向无法从单张图还原** |

所以结论是：**"重上色 / 重 ramp / 换光色"完全可行；"换光方向并正确重投影阴影"基本做不到，必须重渲。**

## 二、三个软件能力对比

| 能力 | Nuke | After Effects | DaVinci Resolve (Fusion) |
|------|:---:|:---:|:---:|
| 换色调 / 重 ramp（纯 2D） | ✅ | ✅ | ✅ |
| 用 Normal 重算 $N\cdot L$（换光方向） | ✅ 原生 `Relight`(NukeX) | ⚠️ 需插件/Expression | ✅ Fusion `Custom Tool` |
| 阴影重投影 | ⚠️ 需 Deep / Shadow Pass | ❌ | ❌ |
| 内建 3D 系统重渲 | ✅ | ⚠️ Element 3D / Stardust | ✅ Fusion 3D |
| 最适合的角色 | **主 reshading 平台** | 快速 look / 上色 | 最终 grade + 轻度 relight |

## 三、具体怎么做

<details>
<summary><b>Nuke（能力最强，主战场）</b></summary>

**需要的 AOV：** `N`（世界/相机法线）、`P`（位置）、`albedo`、`diffuse`、`shadow`、`outline`、`ramp`/`id`。

实现路径：
1. **换光方向**：`Shuffle` 把 `N` 拆出来 → `Expression` 或 `Merge(dot)` 做点乘
```
   NdL = N.x*Lx + N.y*Ly + N.z*Lz
   ```
2. **重 ramp**：把 `NdL` 丢进 `ColorLookup` / `VectorToColor` / `Expression`，做硬阶跃：
   ```
   shadow if NdL < t1; mid if NdL < t2; light otherwise
   ```
3. **NukeX `Relight` 节点**：直接吃 `P` / `N` / albedo，多光源 PBR 式重打光。
4. **重合成**：`新光照 × albedo` → `Merge(plus/screen)` 回原图 → 保留原 `outline` 叠加。
5. **阴影**：若没 shadow pass，只能用原阴影做 mask，**换光后方向不对**；要准必须重渲 shadow AOV 或走 Deep。

> 关键坑：`Expression` 是**逐通道**求值的，跨通道点乘要用 `Merge` 的 dot 模式或自定义节点，别指望一个 Expression 搞定 RGB。
</details>

<details>
<summary><b>After Effects（偏 look，真 relight 很别扭）</b></summary>

- 没有原生法线/矢量通道，AE 的 reshading 主要是 **"重新上色 + 重新排布明暗"**：
  - `Curves` / `Tritone` / `Levels` 换 ramp 与色带（最常用）。
  - `Set Matte` / `Track Matte` 用 Normal/ID 通道做面片隔离再分别调色。
  - 效果层：`Deep Glow`、`Saber`、`Optical Flares` 做高光/发光重塑。
- 真 relight 只能靠 **Element 3D / Stardust** 在 comp 内重新渲一遍（等于重渲）。
- 想用深度/法线生成器（如 Depth/Normal 生成类 AI 插件）只能得到近似法线，**点乘方向不够准**。

一句话：AE 能做 **"reshading 的 look 部分"**，但做不到物理正确的换光。
</details>

<details>
<summary><b>DaVinci Resolve（Fusion 做 relight，Color 页只做 grade）</b></summary>

- **Color 页**：只能 Reshade 的"调色"部分——`HSL Qualifier` 选暗部/亮部改色，换不了光方向。
- **Fusion 页**：能力接近 Nuke，关键武器是 **`Custom Tool`（像素级 kernel 数学）**：

  ```glsl
  // 输入 No = 法线图, L = float3 光源方向
  float NdL = nx*L.x + ny*L.y + nz*L.z;
  // 卡通硬阶跃
  float shade = NdL > 0.5 ? 1.0 : (NdL > 0.0 ? 0.5 : 0.15);
  o_rgb = albedo_rgb * shade;
  ```

  再配合 Fusion 的 3D 系统 + Merge 回原图，可做完整换光。
- 优势：**grade 与 fusion 在同一工程**，reshading 完直接进色版，管线最短。
</details>

---

## 四、边界（必须知道不能做什么）

- ❌ **换光方向后的正确投影阴影**：单张图无解，需要 shadow AOV 或重渲。
- ❌ **遮挡关系 / 轮廓变化**：新光产生的轮廓遮挡，后期无法凭空生成。
- ⚠️ **AO / 环境光**是烘焙的，换光后往往"对不上"，需要 `AO` pass 单独处理。
- ✅ 能做好的：**换 diffuse 色调、换 ramp 断点、换光色/光强、加/减高光、描边重上色、整体 relight-look**。

## 五、推荐管线

```
3D (Blender/UE/Maya, Toon Shader)
 │ 导出 AOV: N / P / albedo / diffuse / shadow / outline / ramp
 ▼
Nuke 或 Resolve-Fusion ← 做真正的 reshading / relight（主战场）
 │ 输出 flatten 后的镜头
 ▼
DaVinci Resolve Color ← 最终 grade、统一色调、镜头匹配
```

> **核心结论**：后期能实现**"重着色、换 ramp、换光色、relight-look"**的 reshading，且**卡通渲染因为硬阶跃 ramp，比写实更容易在后期重建**；但**换光照方向 + 阴影重投影**必须依赖 AOV 重建或 3D 重渲。Nuke / Fusion 做得到，AE 只能做 look 层面。

## 二、Blender 端：把"重渲染的原料"全烘出来

### 1. Cel Shader（GGST 风格）

```
Diffuse BSDF → Shader to RGB → ColorRamp(Constant, 3~4 段) → MixRGB(× 固有色) → Emission
最终 = ramp(N·L) × albedo
```
- **硬阶跃**：ColorRamp 插值设 `Constant`，做 3~4 段（shadow / mid-shadow / mid / light）。
- **几何描边（Inverted Hull）**：`Solidify`（负厚度、Flip normals）→ 指向纯黑 Emission 材质 → 开启 **Backface Culling**。比 Freestyle 快且可控。GeoNodes 版更好管理。
- **关键技巧**：用 **AOV Output** 把 `ramp值` 单独烘成一张 **灰度通道**，这样后期可以**一键换配色**（Genshin 那套）。

### 2. AOV 清单（这是炫技的核心资产）

| Pass | Blender 来源 | 合成用途 |
|------|-------------|---------|
| Beauty / Combined | 主渲染 | 基底 |
| **Normal (N)** | AOV / Normal pass | **重算 $N\cdot L$ 重打光** |
| **Position (P)** | AOV（Geometry Position） | 3D 重打光、屏幕空间阴影 |
| Depth / Z | Mist 或 Z | DoF、体积雾、景深合成 |
| Albedo / Diffuse Color | Cycles Diffuse Color | 重上色基底 |
| Diffuse Direct/Indirect | Cycles passes | 换光强度 |
| Specular | Glossy Direct | 高光重做 |
| **Ramp (灰度)** | AOV Output 自定义 | **LUT/渐变映射重上色** |
| Shadow | Shadow catcher | 阴影重调 |
| AO | AO pass | 接触阴影 |
| Emission | Emission pass | Glow / Glare |
| **Cryptomatte** | 自带 | 特效遮罩、隔离 |
| Vector / Motion | 自带 | 运动模糊 |
| ObjectIndex | IndexOB | 2D 特效遮挡 |

### 3. 导出规格（重点）

- **Format**：`OpenEXR Multi-part`，`16-bit Half Float`（够 HDR 且省空间）；需要极限就 32-bit。
- **色彩空间**：工作空间设 **ACEScg**（装 ACES OCIO config），导出**线性**EXR，`View Transform = ACES 1.3 sRGB` 仅预览。
- **Multi-part 而非 multichannel**：Resolve Fusion 的 `Loader` 能直接按 **part/layer** 选通道，别合成一张。
- 相机用 **FBX 或 USD** 导出，供 Fusion 3D 场景做 layout 匹配。

<details>
<summary><b>为什么坚持 ACES + 线性 EXR？（HDR 的前提）</b></summary>

卡通渲染的高光、Emission、火花亮度常 **> 1.0**。在 sRGB 显示空间会被直接切顶（clip），HDR 就没得玩了。走 ACEScg 线性 EXR：

$$
\text{linear}_\text{scene} \xrightarrow{\text{ACES tonemap}} \text{display}
$$

保留 >1.0 的能量，才能在 Resolve 里做 **HDR (PQ 1000nit)**、漂亮的 halation、以及不爆的高光——这正是"炫技"和普通后期的分水岭。
</details>

## 三、DaVinci / Fusion 端：四个炫技模块

### 模块 A — 重打光 / 重上色（Reshading）

<details>
<summary><b>玩法 1：Ramp 灰度通道 → LUT 重上色（秒换配色）</b></summary>

`Loader(EXR part: ramp)` → `Gradient Map / ColorLookup(LUT)` → `Merge(multiply, albedo)` → 叠加描边。
换配色只需换一张 LUT，**实时**。这就是 Genshin 换色皮肤的思路。
</details>

<details>
<summary><b>玩法 2：Normal 通道 → 重算 $N\cdot L$（真换光方向）</b></summary>

Fusion **`Custom Tool`**（像素级 kernel）：

```glsl
// No.rgb = 法线(0~1), 参数 L = 光方向, t0/t1 = ramp 断点
float3 n = normalize(No.rgb * 2.0 - 1.0);        // 0-1 → -1..1
float3 L = normalize(float3(0.4, 0.7, 0.5));     // 暴露为滑块
float NdL = dot(n, L);

float shade = (NdL > t1) ? lightVal
            : (NdL > t0) ? midVal
                         : shadowVal;

o_rgb = albedo_rgb * shade;
```

把 `L` 做成滑块并 K 帧 → 太阳在镜头前**实时旋转、ramp 跟着重算**，这就是 GGST 那种"重打光"卖点。

**进阶炫技**：用 `Position` 通道在屏幕空间**步进**投出方向阴影（fake directional shadow），换光时阴影也跟着动。
</details>

### 模块 B — 2D / 3D 特效 Layout

| 元素 | 做法 |
|------|------|
| 3D FX | Blender 渲体积斩击、冲击波、粒子，单独 EXR |
| 2D 手绘 FX | Fusion `Paint` / 导入手绘序列，做**冲击帧、速度线、烟尘**（GGST 灵魂） |
| **3D Layout** | 相机 FBX/USD 导入 Fusion 3D → 2D 特效贴到 **Card** 上匹配透视 |
| 深度整合 | Z 通道做 `Depth Blur`，让 2D 火花**进/出角色背后** |
| Cryptomatte | 隔离角色，特效只作用在指定物体 |

> 关键：用 **USD 节点**（Resolve 18+）把 Blender 场景导进 Fusion，2D FX 卡片和 3D 几何共享同一相机，透视 100% 对齐——非常"现代管线"的炫技点。

### 模块 C — 镜头特效（Lens / Optical）

- **Fusion**：`Lens Distortion`（匹配真实镜头畸变）、`Chromatic Aberration`、`Rays`、`Streak`、`Glow`、`Soft Glow`、运动模糊。
- **Resolve FX Light（Color 页）**：`Bloom`、`Halation`（**动漫发光的杀手锏**）、`Glow`、`Light Rays`。
- **DoF**：用 Z 通道驱动 `Defocus` + 自定义 **Bokeh** 形状（多边形光圈）。
- **胶片层**：`Film Grain`、`Vignette`、`Halation` → 让"数字渲染"立刻有电影感。

### 模块 D — ACES 色彩管理 + HDR 输出

1. **Resolve 自带 ACES**：Project Settings → Color Management → **Color Science = ACEScct**。
 - Input Transform：EXR 为 `ACEScg`（或按 OCIO 工作空间）。
 - Timeline：`ACEScct`。
 - Output：SDR → `Rec.709`；**HDR → `Rec.2100 ST2084 (PQ)` 或 `HLG`**，设峰值 **1000 nit**。
2. **HDR 交付**：开启 HDR 模式，用 **nits 波形图**监看；导出 **HDR10 (PQ)** 主版本 + SDR trim 版本。
3. 展示点：同一镜头切 SDR/HDR 对比，暗部保留、高光/火花在 HDR 里"炸出来"。

> 加分项：**Resolve 神经网络引擎**——`Magic Mask`（AI 抠角色）、`Depth Map`（给纯 2D 素材生成深度加景深）——都是可以放进展示的"黑科技"。

# 一句话结论

> **因为 MMD 本身就是"实时渲染器 + 内置后期(MME)"，而且它几乎不产出 AOV、也不走线性/ACES 色彩管理——后期合成的"原料和地基"它都没有；对绝大多数以音乐 PV 为目标的业余作者来说，"直出"不是偷懒，而是当前工具链下**性价比最高**的选择。**

下面从 **技术硬约束 → 人力成本 → 认知需求 → 社区生态** 四个层面拆开讲。

---

## 一、根本原因：MMD 是"出片工具"，不是"资产生产端"

传统电影/3D 管线的分工是：

```
DCC(资产+渲染, 输出 AOV/EXR) → 合成(Nuke/Fusion, 重打光/特效) → 调色/交付
```

而 MMD 的世界观是：

```
MMD(模型+骨骼+自带动画 + MME 实时特效) → 导出 → 加字幕 → 发布
```

**MME（MikuMikuEffect）把 Bloom、DOF、色差、AutoLuminous、描边、法线扰动等全塞进了实时渲染**，甚至直接叫 `PostEffect`。于是"后期"这件事在 MMDer 心智里**已经完成了**——画面上看到什么，导出就是什么。

所以不是"不用合成"，而是 **MMD 把合成的活提前用实时 shader 干完了**，只是方法完全不同。

---

## 二、技术硬约束（最关键，也是本质原因）

| 合成流程的前提 | MMD 现实 |
|------|------|
| 多通道 **AOV**（Normal/P/Depth/Albedo/Ramp…） | ❌ 基本不输出，MME 是**结果叠加**而非**分层导出** |
| **线性 / ACES / OCIO** 色彩管理 | ❌ sRGB/gamma 工作流，无 HDR headroom |
| **Multi-part EXR**、Deep、Cryptomatte | ❌ 没有 |
| 可重打光 / 重着色 | ⚠️ 只能在 MMD 内改 shader 参数重渲 |
| 单独 pass 渲染 | ⚠️ 需拆模型/拆特效，极其麻烦 |

这是**断层式的**：没有 AOV，Nuke 式合成根本无从下手。你要么在 MMD 里重渲，要么：

- 把 PMX 模型 + 动作导进 **Blender / UE**，重建材质和 AOV——**成本直接翻几倍**；
- 或者接受"直出"。

> 换句话说，**不是作者不想合成，而是 MMD 根本没给你合成的接口。** 强行拆只会"费力不讨好"。

<details>
<summary><b>为什么 MME 的效果无法替代真合成？</b></summary>

MME 的 Bloom/DOF 是**屏幕空间、单帧、烘焙式**近似：

$$
C_{out} = \text{Bloom}(C_{beauty})
$$

它作用在**已 flatten 的画面**上。而真合成里的 Bloom 需要 Emission pass 单独控制、DOF 需要真实 Z 深度、重打光需要法线。结果就是 MME 效果**可调性差、不能分层、不能事后再改**——但反过来，它**实时、便宜、所见即所得**，这正是业余作者最需要的。
</details>

## 三、人力 / 成本层面

| 维度 | MMD 直出 | 合成流程 |
|------|---------|---------|
| 学习成本 | 社区教程海量、门槛低 | Nuke/AE 节点、色彩管理、AOV 门槛高 |
| 反馈循环 | **实时预览，所见即所得** | 改完渲染完才知道对不对（盲做） |
| 存储 | 一个视频文件 | EXR 序列动辄 **TB 级** |
| 渲染 | 实时或短时 | 分层渲染耗时长 |
| 人力 | **1 人可完成全片** | 通常需要渲染/合成分工 |
| 迭代 | 改 shader 参数重导出 | 改合成需重读序列+调节点 |

MMD 社区的绝大多数是**爱好者 / 学生 / 个人创作者**，不是职业合成师。他们的目标是"**把一支 PV 做出来**"，不是"展示管线能力"。**能出片 > 学管线**是最理性的选择。

---

## 四、认知与需求层面

1. **内容需求简单**：MMD 视频主流是**音乐 PV / 舞蹈 / 剧情短片**，核心卖点是角色、运镜、动作、光影氛围。字幕、标题、滚动字幕用 **PR 的基本标题工具就够**，甚至属于"点缀"。
2. **画质天花板可接受**：1080p 音乐 PV 语境下，"MMD 感"是被观众接受的风格；做电影级合成**收益边际极低**。
3. **路径依赖**：MMD → MME → PMX Editor → PR/AE 是全社区共享的**默认管线**，教程、预设、插件、模板全围绕它。换管线意味着放弃整个生态。
4. **发布平台**：B 站/Niconico 的播放环境（1080p、SDR、有损压缩）**根本体现不出合成红利**。

---

## 五、地域差异：日本 AviUtl，中国 PR/AE

- 🇯🇵 **日本 MMDer 主流用 AviUtl**（免费 + 字幕/特效插件生态极强），PR 反而不是首选。
- 🇨🇳 **国内 MMDer 更常用 PR（字幕）+ AE（简单特效）**，因为教程、破解便利性、社区习惯。
- 两岸共同点：**都是"渲染器直出 + 轻量剪辑/字幕"**，合成软件只做边缘修饰，不做主力。

所以"渲染器直出 + PR 字幕"本质是 **MMD 文化 + 平台需求 + 工具生态**三者共同塑造的**区域默认范式**。

---

## 六、那什么时候大家才真的上合成流程？

| 场景 | 做法 |
|------|------|
| 顶级 PV / 商业 MV | MMD 模型 → **Blender/UE** 重建 → AOV → Nuke/Fusion 合成 |
| 需要 HDR / 电影感 | 迁移到 **UE + ACES + Resolve** |
| 大量 2D/3D 特效混合 | Blender 渲 3D + 手绘 2D → Fusion 整合 |
| 需要精细重打光 / 重着色 | 必须 AOV，只能换引擎 |

一旦作者开始追求 **HDR、真重打光、电影级镜头语言**，"MMD 直出"就会撞到天花板，转而走向 **Blender/UE + 合成**——这也是近年不少高端 MMDer 的迁移路径。

---

## 七、如果你（或读者）想升级管线

最务实的渐进路线：

1. **MMD → Blender 桥接**：用 PMX 导入插件的模型/动作，重建 toon 材质。
2. **补 AOV**：Blender 输出 Normal/P/Depth/Albedo/Ramp（Multi-part EXR）。
3. **保留 MME 的"实时感"**：用 Blender 的 EEVEE 保持所见即所得。
4. **只在必要环节上合成**：reshading、2D/3D 特效 layout、镜头光学交给 Fusion，其余仍直出。
5. **色彩升级**：ACES + HDR 交付，拉开与普通 MMD 的差距。

---

> **总结**：这不是"MMDer 不懂合成"，而是 **MMD 的工具哲学（实时、烘焙、单层、所见即所得）+ 内容需求（PV 级而非电影级）+ 社区路径依赖** 共同导致的**理性选择**。想让这拨人转向合成流程，需要的不是讲道理，而是**降低 AOV/色彩管理门槛**——比如更傻瓜的 MMD→Blender→AOV→Fusion 桥接工具。
