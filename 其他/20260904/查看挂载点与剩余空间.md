# 查看 Linux 挂载点与剩余空间

## 一、最常用：`df`

`df`（disk free）是查看**剩余空间**的首选命令。

```bash
# 人类可读格式（推荐）
df -h

# 同时显示文件系统类型
df -hT

# 只显示本地真实文件系统，排除 tmpfs、devtmpfs 等
df -hT -x tmpfs -x devtmpfs

# 按剩余空间排序，快速定位快满的分区
df -h | sort -k5 -hr
```

输出示例：

```text
Filesystem     Type  Size  Used Avail Use% Mounted on
/dev/sda1      ext4  100G   45G   50G  48% /
/dev/sdb1      xfs   500G  120G  380G  24% /data
tmpfs          tmpfs 3.9G  1.2M  3.9G   1% /run
```

关键列含义：

| 列 | 含义 |
|----|------|
| `Filesystem` | 设备名或逻辑卷 |
| `Size` | 总容量 |
| `Used` | 已用 |
| `Avail` | **剩余可用**（普通用户视角，含 root 保留块差异） |
| `Use%` | 使用率 |
| `Mounted on` | 挂载点 |

> 注意：`df` 的 `Avail` 可能小于 `Size - Used`，因为 ext4 等默认给 root 预留约 5%。

## 二、查看所有挂载点：`findmnt` / `mount`

`df` 只列出**有文件系统的挂载点**，若要看**全部**挂载（含 `proc`、`sysfs`、`cgroup`、绑定挂载等），用：

```bash
# 树状展示所有挂载点（推荐）
findmnt

# 只看块设备相关的挂载
findmnt -t ext4,xfs,btrfs,nfs

# 查找某个路径属于哪个挂载点
findmnt -T /var/log

# 传统方式：列出全部挂载
mount | column -t

# 直接读内核挂载表
cat /proc/mounts
cat /proc/self/mountinfo
```

---

## 三、查看块设备与磁盘结构：`lsblk`

了解**磁盘、分区、逻辑卷的层级关系**（不显示剩余空间）：

```bash
lsblk

# 带文件系统类型、UUID、挂载点
lsblk -f

# 显示设备大小和挂载点
lsblk -o NAME,SIZE,FSTYPE,MOUNTPOINT
```

输出示例：

```text
NAME   SIZE FSTYPE MOUNTPOINT
sda    100G
├─sda1 100G ext4   /
sdb    500G
└─sdb1 500G xfs    /data
```

## 四、组合用法（一眼看全）

```bash
# 挂载点 + 容量 + 文件系统类型，排除虚拟文件系统
df -hT -x tmpfs -x devtmpfs -x squashfs

# 设备结构 + 空间分开看
lsblk -f && echo "-----" && df -h
```

---

## 五、常见坑与技巧

- **`df` 卡住不动**：通常是有失联的 NFS/CIFS 网络挂载。可加 `df -h --local` 只查本地，或用 `timeout 5 df -h`。
- **`df` 显示有空间但写不进去**：可能是 **inode 用尽**，用 `df -i` 查看 inode 使用情况。
- **`du` 与 `df` 不一致**：文件被删除但仍被进程占用时，`du` 看不到、`df` 却没释放。用 `lsof +L1` 排查。
- **只想看某个目录所在分区**：`df -h /path/to/dir`。

---

## 小结

| 需求 | 命令 |
|------|------|
| 剩余空间（快速） | `df -h` |
| 剩余空间 + 类型 | `df -hT` |
| 所有挂载点 | `findmnt` 或 `cat /proc/mounts` |
| 磁盘/分区结构 | `lsblk -f` |
| inode 使用情况 | `df -i` |

日常最快的一条：**`df -hT`**；想看完整挂载树：**`findmnt`**。
