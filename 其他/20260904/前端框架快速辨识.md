# 用 F12 Console 快速分辨 Vue / React

## 最快结论（先记这两条）

选中一个元素后（Elements 面板点一下），在 Console 里：

- **Vue**：`$0.__vue__` 或 `$0.__vue_app__` / `$0.__vueParentComponent` 有值
- **React**：`$0.__reactFiber$xxx` / `$0.__reactProps$xxx` / `$0._reactRootContainer` 有值

原理：两者都会把内部实例挂到真实 DOM 节点上做扩展属性（expando），键名带各自的前缀/随机后缀，是**最可靠的指纹**。

---

## 方法一：一行命令查 DOM 扩展属性

```js
// 在 Console 直接跑，看根容器
const el = document.querySelector('#app, #root') || document.body;
Object.keys(el).filter(k => /^__react|^__vue/.test(k));
```

- 出现 `__reactFiber$...` / `__reactProps$...` → **React**
- 出现 `__vue__`（Vue2）或 `__vue_app__`（Vue3）→ **Vue**

---

## 方法二：看全局变量 / DevTools Hook

```js
{
  react:        !!window.React,
  reactHook:    !!window.__REACT_DEVTOOLS_GLOBAL_HOOK__,
  vue:          !!window.Vue,
  vueHook:      !!window.__VUE_DEVTOOLS_GLOBAL_HOOK__,
  reactVersion: window.React?.version,
  vueVersion:   window.Vue?.version,
}
```

> 注意：`React` / `Vue` 全局变量**只在开发构建**里存在，生产打包通常被摇掉；但 `__REACT_DEVTOOLS_GLOBAL_HOOK__`、`__VUE_DEVTOOLS_GLOBAL_HOOK__` 只要装了对应扩展就一直在（生产也有）。

---

## 方法三：看 DOM 特征（生产环境最灵的一招）

| 特征 | Vue | React |
|------|-----|-------|
| 元素上的作用域样式属性 | `data-v-<hash>`（SFC scoped CSS 必带） | 无 |
| 挂载容器 | `<div id="app" data-v-app>` | `<div id="root">` |
| 根容器实例属性 | `__vue_app__` | `__reactContainer$...` |

查 scoped 属性：

```js
[...document.querySelectorAll('*')]
  .some(el => [...el.attributes].some(a => a.name.startsWith('data-v-')));
```

- `true` → 基本可判定 **Vue**
- React 不会生成 `data-v-` 这种东西

---

## 方法四：一键检测脚本

<details>
<summary>点击展开：一个较完整的检测脚本（放到 Console 跑）</summary>

```js
(() => {
  const react = new Set(), vue = new Set();
  const els = [document.body, ...document.querySelectorAll('*')];
  for (const el of els) {
    for (const k of Object.keys(el)) {
      if (/^__reactFiber\$|^__reactProps\$|^__reactContainer\$/.test(k)) react.add('react-fiber');
      if (k === '_reactRootContainer') react.add('react-root(16/17)');
      if (k === '__vue__') vue.add('vue2');
      if (k === '__vue_app__') vue.add('vue3-app');
      if (k === '__vueParentComponent' || k === '__vnode') vue.add('vue3-dev');
    }
  }
  // scoped css 特征
  const scoped = [...document.querySelectorAll('*')]
    .some(el => [...el.attributes].some(a => a.name.startsWith('data-v-')));

  const result = {
    React:  [...react],
    Vue:    [...vue],
    scopedCSS: scoped,
    globalReact: !!window.React,
    globalVue:   !!window.Vue,
  };
  console.table(result);
  return result;
})();
```

**判读规则：**
- `React` 非空 → React
- `Vue` 非空 或 `scopedCSS === true` → Vue
- 两者都空 → 看方法五兜底

</details>

## 方法五：兜底技巧

1. **报错栈**：Console 里 `throw new Error()`，展开 stack，看有没有 `react-dom` / `vue.runtime` 相关帧（生产也一样）。
2. **资源列表**：
```js
performance.getEntriesByType('resource')
 .map(e => e.name).filter(n => /vue|react/i.test(n));
```
虽然会被 hash/压缩，但偶尔能命中。
3. **触发转场动画**：出现 `v-enter-active` / `v-leave-active` 类名 → Vue。
4. **`Elements` 面板**：选中元素，看右侧 `Properties` 或 Console 里 `$0.__vue__` / `$0.__reactFiber$`。

---

## ⚠️ 生产环境注意事项

- React 的 `__reactFiber$` / `__reactProps$` **生产构建仍然保留**（事件系统依赖它们），所以检测很稳。
- Vue 的 `__vue__`（Vue2）、`__vueParentComponent` / `__vnode`（Vue3）**大多只在 dev 出现**；生产里更可靠的信号是 `data-v-<hash>` 作用域属性和根容器的 `__vue_app__`。
- `window.React` / `window.Vue` 生产多半为 `undefined`，**不能作为否定依据**。
- 同时存在 React + Vue 的“混合/微前端”页面，可能两者指纹都有，需要看具体区域。

**一句话**：选中元素 → `$0.__reactFiber$` 有就是 React，`$0.__vue_app__` 或元素带 `data-v-` 就是 Vue。
