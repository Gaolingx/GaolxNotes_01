# Linux 扫描目录空间占用并排序

## 最快最常用：`du` + `sort`

```bash
# 扫描当前目录下各子目录大小，按占用从大到小排序（人类可读）
du -h --max-depth=1 ./ | sort -hr

# 扫描指定目录
du -h --max-depth=1 /var/log | sort -hr
```

关键参数说明：

| 参数 | 作用 |
|------|------|
| `-h` | 人类可读单位（K/M/G） |
| `--max-depth=1` | 只统计一层子目录（`-d 1` 简写） |
| `-s` | 只显示汇总总大小，不递归列出 |
| `sort -hr` | 按人类可读数值排序，`-r` 倒序（最大的在最前） |

---

## 常见变体

### 1. 只看每个子目录总大小（不显示文件明细）

```bash
du -h --max-depth=1 /path | sort -hr | head -20
```

### 2. 用 MB 数字排序（避免 `sort -h` 兼容性问题）

```bash
du -sm /path/* | sort -rn | head -20
```

### 3. 排除某些目录

```bash
du -h --max-depth=1 /path \
  --exclude='*.log' \
  --exclude=node_modules | sort -hr
```

### 4. 找出当前目录下最大的 10 个文件

```bash
du -ah /path | sort -hr | head -10
```

或更精确地按文件大小：

```bash
find /path -type f -printf '%s\t%p\n' | sort -rn | head -10
```

### 5. 磁盘整体使用情况

```bash
df -h
```

## 性能更好的替代工具

### `ncdu`（推荐，交互式）

```bash
# 安装
sudo apt install ncdu      # Debian/Ubuntu
sudo yum install ncdu      # CentOS/RHEL

# 使用
ncdu /path
```

交互式界面，可按键进入目录、删除、排序，比 `du` 直观得多。

### `dust`（现代替代品）

```bash
dust -d 2 /path
```

### `duf`（更好的 `df`）

```bash
duf
```

## 处理超大目录的性能技巧

```bash
# 并行统计（多核加速）
du -h --max-depth=1 /path 2>/dev/null | sort -hr

# 忽略权限报错
du -h --max-depth=1 /path 2>/dev/null | sort -hr

# 后台跑并输出到文件
nohup du -h --max-depth=1 / > /tmp/disk.txt 2>/dev/null &
```

---

## 一条万能命令

```bash
du -h --max-depth=1 /目标目录 2>/dev/null | sort -hr | head -20
```

- `2>/dev/null`：屏蔽 Permission denied 噪音
- `sort -hr`：从大到小
- `head -20`：只看前 20 名
