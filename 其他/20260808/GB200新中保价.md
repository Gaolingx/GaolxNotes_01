## 二、GB200 NVL72 的运输难点与要求

NVL72 Superpod 是机柜级交付的超算节点，单机柜重量可能超过 **3吨**，功率密度极高，对运输要求极为严苛：

1. **包装要求**：必须使用原厂木箱/托盘，内部需有防震角、防潮剂、湿度指示卡，外部缠绕防水膜。
2. **运输方式**：
   - **海运整柜 (FCL)**：20'/40' 特种柜或框架柜 (Flat Rack)，需防倾倒固定。
   - **空运包机/腹舱**：超大件计费，需使用主货舱板位 (Main Deck)。
3. **环境控制**：建议温度 $20^\circ\text{C} \sim 25^\circ\text{C}$，湿度 $30\% \sim 70\%$，全程 GPS 及震动监测。
4. **保险险种**：不能使用普通快递保价，必须购买**海洋/航空货物运输一切险 (All Risks)**，并附加**战争险、罢工险**，以及**碰损破碎险**。

## 三、保价/货运保险如何开启

GB200 NVL72 价值动辄数百万至上千万美元，保价流程必须按照合同执行：

### 1. 区分"快递保价"与"货运保险"
- **快递保价**：如 DHL/UPS 自带的保价上限通常为每票 $500 \sim \$100,000$，远远覆盖不了设备价值。
- **货运一切险**：必须通过第三方保险公司投保，承保金额为 CIF 价值的 **110%**。

### 2. 投保流程

<details>
<summary><b>步骤一：确定保险价值 (Insured Value)</b></summary>

- 计算公式：$\text{保额} = (\text{货值} + \text{运费} + \text{保险费}) \times 110\%$
- 需要提供：采购合同、商业发票、装箱单。
- 若货值超过 $\text{USD } 5,000,000$，通常需要保险公司（如人保财险 PICC、平安产险、安联 Allianz 等国际大型商业险公司）逐单核保。
</details>

<details>
<summary><b>步骤二：选择投保险种</b></summary>

GB200 这种精密电子设备建议投保：
- **海洋/航空运输货物一切险 (A条款)**
- **碰损、破碎、偷窃、提货不着险 (TPND)**
- **战争险、罢工险** (若经过马六甲等敏感海域必加)
- **内陆运输扩展条款** (新加坡仓到中国机房门全程覆盖)
</details>

<details>
<summary><b>步骤三：获取保单 (Certificate of Insurance)</b></summary>

投保后由保险公司出具正式保单或暂保单 (Cargo Insurance Certificate)，需注明：
- 航程：Singapore, Singapore → China (如 Beijing/Shanghai/Shenzhen)
- 工具：海运船名航次 / 空运航班号
- 唛头及箱号
- 免赔率 (通常高价值设备免赔额为 $\text{USD } 5,000 \sim \$10,000$，或损失金额的 $10\%$ 取大者)
- **理赔代理人**：在目的港（如中国）必须指定查验理赔代理。
</details>

<details>
<summary><b>步骤四：承运商签署责任限额豁免</b></summary>

按国际惯例（如《海牙规则》/《蒙特利尔公约》），承运人赔偿限额极低（海运约每公斤 2 SDR，空运每公斤 22 SDR）。必须：
- 在运输合同中明确**承运人全额赔偿条款**；
- 或要求承运商购买其 **Carrier's Liability Insurance（承运人责任险）** 并将托运方列为共同被保险人；
- **不要**仅依靠承运商赔偿，必须单独买货主自己的一切险。
</details>

## 四、新加坡到中国的实操建议流程

1. **预定舱位**：提前 3-4 周联系德讯或中外运预定舱位（海运优先，空运需协调主货舱装机）。
2. **打托加固**：在新加坡原厂或仓库由专业打包公司对机柜进行 **VCI 防锈 + 气泡膜 + 珍珠棉 + 木箱** 的多层加固。
3. **装柜/装机**：使用叉车或吊车操作，安装**震动记录仪 (ShockWatch / ShockLog)** 和 **温度湿度记录仪**。
4. **新加坡出口报关**：通过 Singapore Networked Trade Platform (NTP) 申报出口。
5. **运输启运**：投保生效，GPS 全程追踪。
6. **中国进口报关**：在口岸需申请 **3C 认证免办/备案**（超算设备通常符合科研用途免办），以及**机电产品进口许可证**。
7. **门到门交付**：清关后由气垫车送往国内数据中心机房。
8. **开箱验货**：在客户**及保险公司代表共同在场**情况下拆箱，检查震动仪数据，拍照留证。

## 五、关键提醒

> ⚠️ **不建议的方案**：绝对不要使用普通国际快递（如 DHL Express、SF Express 国际小包）直接发运 GB200。这类渠道无法处理 $3000\text{kg+}$ 的单件货物，且一旦在中转中心发生叉车跌落，赔偿上限仅几万美元，无法弥补损失。

> ✅ **推荐方案定位**：联系 **Kuehne+Nagel 或 DHL Global Forwarding**（注意是 Global Forwarding 大货部门，不是 DHL Express 快递部门），明确告诉对方货物是 **"NVIDIA GB200 NVL72 Server Rack, Net Weight > 3000kg, Value > USD X M, requires All-Risks Insurance and White-Glove Delivery"**，对方会提供定制化的 Project Cargo 报价。
