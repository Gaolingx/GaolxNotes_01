# 查看GitHub每日热度趋势

### 🧑‍💻 User

github每日热度趋势榜在哪看？

---

### 🤖 Assistant

**GitHub 每日热度趋势榜（Trending）直接看官方页面即可。**

### 官方入口（最推荐）
- **地址**：https://github.com/trending
- **使用方法**：
  1. 打开上面的链接。
  2. 页面顶部选择时间范围：
     - **Today**（今日 / 每日热度）
     - This week（本周）
     - This month（本月）
  3. 左侧可按编程语言筛选（如 Python、JavaScript、Go、Rust 等），也可以选 “All Languages”。
  4. 也可以直接看开发者趋势：https://github.com/trending/developers

这就是 GitHub 官方的“每日热度趋势榜”，按近期获得 Star 等活跃度排序，更新比较及时。

### 其他常用查看方式
| 方式 | 链接 / 说明 | 特点 |
|------|-------------|------|
| 官方 Trending | https://github.com/trending | 最权威，支持日/周/月 + 语言筛选 |
| 开发者趋势 | https://github.com/trending/developers | 看热门开发者 |
| 第三方增强站 | 如 Trendshift、GitHub Trending 相关工具站 | 有时提供更好的可视化或历史数据 |
| 中文相关 | HelloGitHub（hellogithub.com）等 | 更偏精选/月刊，不是严格每日实时榜 |

### 小技巧
- 想固定看“今日 + 某语言”，可直接访问类似：
  `https://github.com/trending/python?since=daily`（把 python 换成你需要的语言）。
- 可用浏览器书签、RSS 工具，或一些第三方机器人/频道自动推送每日 Trending。
- 页面数据基于近期 Star 增长、活跃度等综合计算，偶尔会有波动。

直接收藏 **https://github.com/trending** 就够用了，每天打开选 “Today” 即可查看最新热度榜。
