# SXM2 V100 NVLink带宽高于PCIe50x16

### 🧑‍💻 User

sxm2 v100的nvlink带宽和pcie5.0x16双向/单向的带宽分别是多少？

---

### 🤖 Assistant

## V100 SXM2 的 NVLink 带宽

V100 SXM2 使用 **NVLink 2.0**，共 **6 条链路**，每条链路 25 GB/s/方向：

| 项目 | 带宽 |
|---|---|
| 每条链路单向 | 25 GB/s |
| 每条链路双向 | 50 GB/s |
| 全部 6 条链路单向（单方向合计） | **150 GB/s** |
| 全部 6 条链路双向（双向合计） | **300 GB/s** |

## PCIe 5.0 x16 带宽（协议理论值）

PCIe 为全双工，双向带宽 = 2 × 单向带宽：

| 项目 | 原始速率（不含编码开销） | 有效载荷（含 128b/130b 编码） |
|---|---|---|
| 单向（每个方向） | 64 GB/s | ≈ 63.0 GB/s |
| 双向（合计） | 128 GB/s | ≈ 126 GB/s |

> 计算方式：PCIe 5.0 单通道 32 GT/s，x16 = 512 GT/s = 64 GB/s/方向；编码开销 128/130，故有效值约 63 GB/s/方向。

## ⚠️ 重要说明

**V100 SXM2 本身并不支持 PCIe 5.0**，它只有 **PCIe 3.0 x16** 接口，实际带宽为：

- 单向：**16 GB/s**（有效约 15.75 GB/s）
- 双向：**32 GB/s**（有效约 31.5 GB/s）

你问的 PCIe 5.0 x16 数值只是协议的通用理论带宽，不能直接套用在 V100 上。V100 的 NVLink（300 GB/s 双向）远高于其 PCIe 3.0 接口（32 GB/s 双向），这正是 SXM2 形态存在的意义——通过 NVLink 绕开 PCIe 瓶颈。
