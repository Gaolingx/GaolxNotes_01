# AV1低码率去色块原理

### 🧑‍💻 User

av1低码率基本看不到量化的色块了，这是怎么做到的？

---

### 🤖 Assistant

**AV1 在低码率下几乎看不到明显量化色块（块效应/blocking artifacts），主要靠“更强的预测 + 更灵活的划分与变换 + 强大的环内滤波 + 胶片颗粒合成”这一套组合拳。** 它不是简单提高压缩率，而是从源头减少残差、再智能清理伪影、最后用感知手段掩盖残留问题。

### 1. 更灵活的块划分与变换，从根源降低量化压力
- Superblock 最大 128×128，可递归划分到 4×4，支持四叉树、二叉树、T 型等多种不规则分割，比 H.264/HEVC 的固定方块更贴合物体边缘和纹理。
- 变换尺寸从 4×4 到 64×64，支持矩形变换，并有多种变换核（DCT、ADST、FlipADST、Identity 等），能根据残差特性自适应选择。
- 结果：残差能量更小、更集中，量化步长可以更大却不明显产生大块色块。预测准了，量化“伤害”自然小。

### 2. 更强的预测工具，进一步压缩残差
- **帧内**：更多角度模式 + Paeth、Smooth 等非方向模式，边缘和渐变预测更准。
- **帧间**：复合预测（平均、楔形、差分等）、仿射/全局运动、光流类工具、更多参考帧，运动补偿更精确。
- 还有 Chroma-from-Luma（CfL）等工具，让色度预测更依赖亮度，减少色度色块。
- 低码率时残差本来就小，量化后不容易出现大片平坦的色块。

### 3. 强大的环内滤波（Loop Filters）——直接“擦掉”块效应的关键
这是 AV1 低码率观感明显优于 H.264/VP9 甚至部分 HEVC 实现的核心原因之一：

- **改进的 Deblocking Filter**：针对块边界做平滑，强度自适应。
- **CDEF（Constrained Directional Enhancement Filter）**：方向性增强滤波。能检测边缘方向，在去噪/去块的同时尽量保留细节和锐度，对色度也有效。它比传统 deblock 更能处理复杂纹理，减少“糊成一团”或明显色块。
- **Loop Restoration（环路恢复）**：包括 Wiener 滤波和 Self-Guided Restoration（SGR）。在 deblock + CDEF 之后进一步恢复细节、抑制残余伪影，对低码率下的量化噪声和块效应清理效果显著。

这些滤波器是**环内**的（编码和解码端都做），既帮助率失真优化，又保证解码后直接可见的画面干净。色块（块边界不连续、色度跳变）会被大幅削弱。

### 4. Film Grain Synthesis（胶片颗粒合成）——低码率的“感知神器”
这是 AV1（以及后来 AV2 相关思路）在极低码率下“看起来干净”的重要法宝：

- 编码端通常会**去除**原始胶片/传感器颗粒（高频噪声很难压缩，吃码率还容易产生伪影）。
- 码流里只传少量颗粒参数（强度、相关性等）。
- 解码端用模型**重新合成**并叠加颗粒。

效果：
- 真实颗粒被去掉后，主信号更容易被高效压缩，残差更干净，量化色块更少。
- 合成颗粒会自然掩盖残留的细微块效应、色带和量化噪声，让画面看起来更“有质感”而非“塑料/色块感”。
- 对电影、剧集、自然视频尤其有效。很多 AV1 低码率内容观感好，颗粒合成贡献很大。

### 5. 其他辅助因素
- 更精细的自适应量化（包括 delta-q、矩阵量化等）和对色度的单独控制。
- 更好的熵编码与率失真优化，让有限码率优先保护重要区域。
- 原生对 10-bit 等高精度支持更好（减少色带，色带有时也会被误称为“色块”相关问题）。
- 屏幕内容工具（Palette、Intra Block Copy）对特定内容也有帮助，但通用视频主要还是上面几项。

### 总结对比直观感受
- 老编码器（尤其 H.264）低码率时大块划分 + 弱滤波 + 强量化 → 明显马赛克/色块。
- AV1：预测准 → 残差小 → 量化伤害可控；再经 CDEF + Loop Restoration 清理边界；最后颗粒掩盖残余 → 低码率下块效应大幅减弱，观感更接近“糊一点但干净”而不是“一块一块的”。

当然，**不是魔法**。极低码率（比如 1080p 几百 kbps 以下）仍会有模糊、细节丢失、偶尔轻微伪影，只是色块不再那么刺眼。实际效果还取决于编码器实现（libaom、SVT-AV1、rav1e 等）、参数（尤其是否开启 film grain、滤波强度、AQ）和内容类型。

如果你有具体场景（分辨率、目标码率、内容类型、用的编码器），可以进一步聊参数调优或对比。
