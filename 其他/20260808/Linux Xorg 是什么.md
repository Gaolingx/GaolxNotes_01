# Linux 中的 Xorg 是什么？

**Xorg**（X.Org Server）是 Linux/Unix 系统上最常用的**图形显示服务器**（Display Server），它是 X Window System（简称 X11）的开源实现。

## 核心作用

它负责管理你的屏幕显示和输入设备，工作流程大致是：

```
应用程序（如浏览器、终端）
      ↓ 通过 X11 协议发送绘制请求
   Xorg 服务器
      ↓ 输出到显卡/显示器，同时接收键盘鼠标输入
   屏幕 + 输入设备
```

简单说，**Xorg 是连接"图形应用程序"和"物理硬件"之间的中间层**。

## 关键特点

| 特点 | 说明 |
|------|------|
| **客户端/服务器架构** | 应用是客户端，Xorg 是服务器（注意与传统意义的"服务器"不同，它就在本地） |
| **网络透明** | 支持 X11 转发，可以远程运行 GUI 程序显示到本地（如 `ssh -X`） |
| **可扩展** | 通过扩展支持 3D 加速（GLX）、合成特效（Composite）等 |

## 常见误区

- ❌ 它不是桌面环境。GNOME、KDE、XFCE 是运行在 Xorg 之上的桌面环境。
- ❌ 它不是窗口管理器。窗口的装饰、移动、最小化由 WM（如 i3、Mutter）负责。
- ✅ 它是"地基"，桌面环境和窗口管理器都依赖它来真正把内容画到屏幕上。

## 现状与替代者

近年来，**Wayland** 正逐渐取代 Xorg 成为新一代显示服务器：

- **Xorg**：成熟稳定、兼容性极好，几乎所有老软件都能跑。
- **Wayland**：更现代、更安全、性能更好（无撕裂、更流畅），但兼容性仍有小问题。

大多数主流发行版（Ubuntu、Fedora 等）如今**默认使用 Wayland**，但 Xorg 仍作为备选保留——登录界面通常可以选择"Ubuntu on Xorg"这类会话。

## 如何查看/验证

```bash
# 查看当前使用的显示服务器（x11 表示 Xorg，wayland 表示 Wayland）
echo $XDG_SESSION_TYPE

# 查看 Xorg 进程是否在运行
ps aux | grep Xorg
```

---

**一句话总结**：Xorg 是 Linux 图形界面的"翻译官"，负责把应用程序的绘图指令变成屏幕上的画面，并处理键盘鼠标输入，是传统 Linux 桌面最核心的底层组件。
