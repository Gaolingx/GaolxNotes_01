# Mellanox ConnectX-3 (CX3) vs Intel E810 网卡对比

这两款是来自不同厂商、不同定位的网卡，下面对比说明。

## 总览

| 维度 | Mellanox ConnectX-3 (CX3) | Intel E810 |
|------|---------------------------|------------|
| 厂商 | Mellanox（现 NVIDIA） | Intel |
| 发布时间 | ~2012-2013（已 EOL） | 2020+ |
| 定位 | 高性能计算 HPC / InfiniBand | 数据中心以太网 / 云 |
| 架构 | PCIe 3.0 | PCIe 4.0 |
| 当前状态 | **已停产 (EOL)**，仅二手市场在售 | 当前主流产品，持续更新 |

## 关键技术对比

### 1. 接口与带宽

- **CX3**：最高 $40 \text{ GbE}$ 或 $56 \text{ Gb/s}$ FDR InfiniBand
  - 常见型号：`CX311A`（10GbE）、`CX311B`、`CX341A`（40GbE）、`CX354A`（40GbE+IB）
- **E810**：支持 $25/50/100 \text{ GbE}$，部分型号可达 $200 \text{ GbE}$
  - 常见型号：`E810-XXVDA2`（双口25G）、`E810-CQDA2`（双口100G）、`E810-2CQDA2`（双口200G）

### 2. 协议支持

| 特性 | CX3 | E810 |
|------|-----|------|
| Ethernet | ✅ | ✅ |
| InfiniBand | ✅（FDR 56G） | ❌ |
| RoCE | RoCE v1 | RoCEv2 ✅ |
| iWARP | ❌ | ✅ |
| RDMA | ✅ | ✅ |

### 3. 高级特性

<details>
<summary><b>CX3 特性（点击展开）</b></summary>

- **GPU Direct RDMA**：支持 GPU 与网卡间直接内存访问（需配对 Mellanox 交换机）
- **SR-IOV**：支持
- **DPDK**：支持
- **VxLAN / NVGRE**：支持
- 已无新固件更新，驱动维护停滞在老内核

</details>

<details>
<summary><b>E810 特性（点击展开）</b></summary>

- **DDP（Dynamic Device Personalization）**：可动态加载协议解析包，灵活支持新协议
- **Intel Ethernet Flow Director**：高级流量分发
- **eCPRI / 5G 前传**：支持（电信场景）
- **Precision Time Protocol (PTP)**：硬件时间戳，$1588v2$
- **ADQ（Application Device Queues）**：应用级队列隔离
- **SR-IOV / VMDq**：支持
- **IPsec / MACsec**：硬件加密卸载
- **ESN/可重构流水线**：通过 DDP 可现场升级解析能力

</details>

### 4. 驱动与生态

- **CX3**：使用 `mlx4_core` / `mlx4_en` 驱动，Linux 内核主线仍保留，但新特性不再 backport。`Mellanox OFED` 老版本支持。
- **E810**：使用 `ice` 驱动，内核主线持续更新；配合 `Intel Ethernet Software Suite` 和 `ice-compat` 包。

### 5. 适用场景

| 场景 | 推荐 |
|------|------|
| 老 HPC 集群、InfiniBand FDR | CX3（但已是 EOL，建议升级到 CX-6/CX-7） |
| 现代 SDN / NFV / 5G | E810 |
| 25G/100G/200G 以太网 | E810 |
| RoCEv2 高性能存储 | E810 或 CX-6/CX-7 |
| 预算敏感二手搭建 | CX3（性价比高） |

## 选型建议

> ⚠️ **重要提示**：CX3 已是 10 年前的产品，**官方已停止支持**。如果是新建生产环境，**不建议采购 CX3**。NVIDIA 当前对应替代产品是 **ConnectX-6 Lx / ConnectX-7**，与 E810 是真正的同代竞品。
