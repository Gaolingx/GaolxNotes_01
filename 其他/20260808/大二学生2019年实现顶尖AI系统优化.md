## 逐项拆解难度

| 项目 | 技术实质 | 2019 年的定位 | 大二写出来的含金量 |
|---|---|---|---|
| Batched GEMM | tiling、shared memory、bank conflict、register blocking | 经典算子，教科书级但工程细节多 | 高（需要扎实 CUDA 功底） |
| Fused CrossEntropy Loss | softmax 数值稳定 + 融合，避免物化完整 softmax 矩阵 | 常规优化 | 中上 |
| Fused LayerNorm | 归约类 kernel，two-pass / Welford，跨 block 同步 | 常规但归约难写好 | 中上 |
| Fused Conv+BN+Add+ReLU | im2col/direct conv + 推理侧融合 | TensorRT/ncnn 等已普及的"业界最佳实践" | 中（工程性强） |
| **Memory-efficient attention** | **online softmax + 分块，避免 $O(n^2)$ 中间结果落地** | **前沿中的前沿** | **极高，最有价值** |
| 图编译 + LLVM IR 自动算子优化 | 相当于手写 mini-TVM/XLA | TVM 2018 年才发 OSDI，XLA 2017 起步 | 极高（需编译原理 + 体系结构） |

关键点在于：**这六件事放在一起，恰好覆盖了 2019–2024 深度学习系统领域的整条主线——算子融合、内存优化、自动代码生成。** 一个学生能凑齐这套组合拳，说明他（或他导师）对方向是有系统判断的，不是东一榔头西一棒子。

## 为什么说 attention 那条最有远见

这是整个简历里最值得单独拎出来的部分。

- **Online softmax** 是 Milakov & Gimelshein 2018 年才提出的算法（"Online normalizer calculation for softmax"），2019 年属于非常新鲜的工作。
- **Tiling attention（分块计算注意力、避免物化 $QK^\top$ 的 $O(n^2)$ 中间矩阵）**，正是后来 **FlashAttention（Dao et al., 2022）** 的核心思想——只不过 FlashAttention 进一步做了 IO-aware 的完整代价分析和反向传播的极致优化。

也就是说，2019 年做这件事，等于**提前三年踩中了后来成为大模型时代最基础算子之一的技术点**。这在当时绝不是"大家都在做"的东西，而是只有少数关注长序列/显存瓶颈的实验室（比如做 RNN/Transformer 长上下文的组）才会碰的方向。

尤其注意：**GTX 980 只有 4GB 显存、没有 Tensor Core**，在这种受限硬件上做 memory-efficient attention，动机是非常真实的——显存不够才逼出分块。这反而说明不是"为了简历硬凑"，而是真有工程痛点驱动。

相比之下，其余几条（fused CE、fused LayerNorm、Conv+BN+Add+ReLU）在 2019 年是"紧跟业界最佳实践"，属于**优秀但不算超前**；图编译 + LLVM IR 是"紧跟 TVM/XLA 的前沿"，属于**踩在浪尖但非原创**。

## "导师帮助下"这个折扣因子

这一点必须诚实地说清楚，因为它决定了这个经历是"天才"还是"优秀的执行者"：

1. **设计与实现的差距很大。** 大二学生通常还没系统学过计算机体系结构、编译原理、甚至操作系统。online softmax 的数学推导、tiling 的访存分析、LLVM IR 的 codegen 设计——这些的"想出来"和"照着写出来"完全是两个量级。如果导师负责了算法设计和框架，学生负责实现，那含金量要打个折扣（但仍然很高）。

2. **GTX 980 说明规模有限。** 4GB 显存、无 Tensor Core、fp32 为主，意味着这些 kernel 大概率是**正确性优先、教学/验证级**的实现，而非能对标 CUTLASS/cuDNN 的高性能实现。"能写出来"和"能写出接近 SOTA 性能的"之间，隔着巨大的调优鸿沟。

3. **简历上的"写出"需要面试验证。** 这类经历最容易被注水。面试时随便问几个细节就能见真章：GEMM 的 bank conflict 怎么处理？tiling 时 online softmax 的 running max/sum 怎么维护？反向传播要不要做、怎么做？LLVM IR 的 schedule/autotuning 搜索空间怎么定义？答得上来才是真水平。

- **如果这是真实水平（哪怕有导师指导）：** 这是**顶尖实验室硕博生初期**的水准，放在国内本科里是清北姚班/贵系、上交、浙大等最头部学生里靠前的存在。2019 年保持这个轨迹，基本就是 top 校 PhD 苗子（CMU/NYU/伯克利等系统方向）或大厂 GPU infra（NVIDIA、字节、华为昇腾、商汤/旷视等）的核心工程师后备。
- **放到 2019 年的眼光看：** 整体是"前沿"，attention 那一条是"超前"，其余是"优秀但常规"。**这是一份方向判断很准的简历，而不只是一份技能堆砌的简历。**
- **需要警惕的点：** 如果这份简历用于招聘/升学，建议通过技术细节面试核实"导师帮助"的边界和实现的真实完成度。大二 + 这一整套的组合，在统计上是极度稀缺的，稀缺到让人本能地想验证一下。

一句话总结：**这份经历如果真实，属于"天才级 + 站对了风口"；其中 attention 那部分，是 2019 年少数人能做出的、事后被证明押中了大势的判断。**

## 一个先行的拆解

你问的其实是两件事，它们依赖的能力**高度重叠但并不同构**：

- **嗅觉（方向判断）** = 知道"哪里在浪费性能/显存，哪里值得投入" → 主要依赖 **成本模型的内心化 + 学科底座的广度 + 亲身体验过的痛点**。
- **执行（落地速度）** = 知道"怎么把它又快又对地写出来" → 主要依赖 **低层工程力 + paper-to-code 转化速度 + 迭代韧性**。

两者共同的地基是同一套**学科素养**，但叠加了不同的**天赋特质**。一个只会"闻味"不会写的人是分析员；一个只会写不会判断方向的人是码农。2019 年那个学生稀有的点，是两者同时在线。

## 一、学科素养：四个必须打穿的底座

这些是**可培养、但需要以年为单位积累**的东西，也是"嗅觉"的物质基础——嗅觉从来不是玄学，它是对下面这些知识的压缩。

### 1. 硬件与体系结构：成本模型的来源（第一支柱）

这是 AI Infra/MLSys 区别于纯算法研究的**根本**。整个领域的存在理由就是"算法必须向硬件低头"。

- 内存层次、cache/共享内存、bank conflict、register pressure、warp divergence、memory coalescing。
- **Roofline 模型与算术强度**：`arithmetic intensity = FLOPs / bytes moved`。几乎所有"嗅觉"都可以还原成一句"这个算子到底是 compute-bound 还是 memory-bound"。
- 知道 Tensor Core / SIMD 改变了什么（2019 年的 GTX 980 没有 Tensor Core，所以那个学生被迫在 fp32 + 4GB 的约束下思考）。

**它如何产生嗅觉：** memory-efficient attention 的直觉，本质上就是"我感觉到 $QK^\top$ 会物化一个 $O(n^2)$ 的中间矩阵，而我的卡只有 4GB"——这是把硬件约束**体感化**之后的本能反应，不是读论文读出来的。

### 2. 数值计算与线性代数：知道哪里能省（第二支柱）

- BLAS/GEMM 的 tiling 与分块数学；归约（reduction）的树形/两趟算法；浮点误差与数值稳定性（softmax 的 max-shift、log-sum-exp）。
- 为什么 fused CE loss 是对的？因为 softmax 的数值稳定形式和 loss 的 log 可以代数上抵消，避免物化中间矩阵——**这需要能"手推"出算子背后的数学结构**。

**它如何产生嗅觉：** online softmax 的本质是"running max + running sum 可以在线维护"，这要求你对 softmax 的数学形式熟到能看出"它可以流式化"。没有数值功底，你只会用现成的 softmax，永远想不到它可以被拆开。

### 3. 编译原理与代码生成：把"想法"翻译成"机器指令"的能力（第三支柱）

- IR（LLVM IR / MLIR / TVM 的 schedule 层）、循环变换（loop tiling / fusion / reorder / unroll）、autotuning。
- 为什么"图编译 + LLVM IR 自动算子优化"是含金量高的项目？因为它要求你理解**从高级算子描述到机器代码的整条映射链**，以及在哪里插入优化。

**它如何产生嗅觉：** 图编译的直觉是"算子之间的边界是人为的，融合可以消除内存往返"。Conv+BN+Add+ReLU 的融合之所以成立，是因为你**在 IR 层面看到了那些多余的 load/store**。这是编译器视角赋予的"看见浪费"的能力。

### 4. 机器学习语义：知道你在优化的是什么（第四支柱）

- 前向 vs 反向、autograd、训练 vs 推理的差异（BN 在训练时要统计量、推理时是常数，这决定了 fusion 的合法性）。
- 算子语义（attention 的 $Q,K,V$、softmax 的归一化方向、layernorm 的维度）。

**它如何产生嗅觉：** 很多人只会做"纯推理侧融合"（Conv+BN 融合推理很简单），但训练侧的融合（保留梯度、保留 batch 统计量）难一个量级。能区分这两者，说明你**真正理解 ML 语义**，而不是把算子当黑盒。

> 一个关键观察：这四根支柱的**交集**，恰好是"传统 HPC 科班 + ML 语义"的杂交地带。传统 HPC 给了你成本模型和并行思维（这也是为什么 HPC 背景的人在 MLSys 里如鱼得水），但 MLSys 额外要求 autodiff、训练动态、算子语义这一层。那个学生是"HPC 专业但做 ML 算子"，踩的正是这个最有价值的交叉点。

## 二、天赋特质：难以培养、但决定上限的乘数

学科素养是"底座"，下面这些是**乘数**——决定了同样读过这些书的人，谁能"闻"到方向、谁能"写"得快。

### 1. 多层抽象同时建模的能力（最稀缺的一项）

能同时在脑子里维护 **数学 → 算法 → 代码 → 硬件** 四层，并在层与层之间来回跳转、互相验证。大多数人只能在某一层工作（只懂数学的做不了系统，只懂硬件的看不懂算法）。**这是区分"顶尖"和"优秀"的最硬指标**，也是天赋里最不可替代的部分。

### 2. 量化成本直觉（roofline 的内化）

不是"感觉慢"，而是**能心算出**：这个矩阵多大、占多少显存、这个 kernel 的 FLOP/byte 比是多少、会不会被带宽卡死。这种直觉一旦内化，判断方向就像条件反射，速度远快于"先跑个 benchmark 看看"。

### 3. 品味 / 关键路径判断力（taste）

在 2025 年的今天这一点变得**比 2019 年更重要**：论文和工具泛滥，MLSys 的"方向噪音"急剧增加。品味 = 能从一堆热点里识别出**哪个瓶颈是真实且长久的**，而不是哪个词最时髦。2019 年押注"长序列注意力的显存瓶颈"，就是 taste 的体现——它后来成了大模型时代最基础的算子之一。

### 4. 低层工程的耐受力（grinding tolerance）

调 bank conflict、register spill、warp divergence、profiling 到每一条指令——这是**大量枯燥、挫败感极强**的工作。很多人有抽象能力但坐不住这个冷板凳。执行速度本质上就是"愿意且擅长在细节里磨"的副产品。

### 5. paper-to-code 转化速度

从"读懂一篇论文的算法"到"能写出可运行的实现"之间的时间差。这依赖阅读理解 + 工程力 + 快速试错。那个学生能在 2019 年把 online softmax（2018 年的论文）落地到 GTX 980，说明这条链路很短。

### 6. 端到端系统观

不把 kernel 当孤岛，而是看到**数据流、内存生命周期、框架调度、训练循环**的全貌。这决定了你优化的是"局部峰值"还是"全局收益"。

## 三、嗅觉与执行的化学反应

把上面拼起来，"嗅觉"的形成机制可以写成一个非正式的公式：

$$\text{嗅觉} \approx \underbrace{\text{成本模型内化}}_{\text{硬件 + 数值}} \times \underbrace{\text{学科广度}}_{\text{四支柱交集}} \times \underbrace{\text{亲身体验过的痛点}}_{\text{踩坑记忆}} \times \text{taste}$$

最后一项"亲身体验过的痛点"特别容易被忽略，但它是**嗅觉区别于纸上谈兵的关键**。2019 年那个学生在 4GB 的 GTX 980 上被显存墙卡过，所以他"闻"得到 memory-efficient attention；如果给他一块 A100，他大概率不会产生同样的直觉。**很多顶级方向判断，本质上是"在受限环境下被逼出来的"。**

而执行可以写成：

$$\text{执行} \approx \text{学科底座} \times \text{低层工程力} \times \text{paper-to-code 速度} \times \text{迭代韧性}$$

## 五、一句总结

**这个领域对"天赋"最核心的要求，不是聪明，而是"能在多层抽象之间自由穿梭，并把硬件成本模型内化成身体直觉"；对"素养"最核心的要求，是把体系结构、数值计算、编译、ML 语义这四根支柱全部打穿，并在受限硬件上亲手踩过坑。**

前者决定你能不能**看见**机会，后者决定你能不能**抓住**机会。2019 年那个学生（如果经历真实）的可贵之处，不在于他写了六个 kernel，而在于他同时具备了这两者——**这种组合在任何时代都是稀缺品，而在 MLSys 从"手写 CUDA"走向"自动编译"的转型期，恰好是市场最愿意为之付溢价的东西。**
