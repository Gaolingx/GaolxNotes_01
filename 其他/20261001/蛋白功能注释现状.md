# 微生物与真菌蛋白质结构–功能注释热点报告（2026）

## 摘要：五条核心判断

1. **结构已经变成"默认可得"的中间表示**，而不再是研究的终点。微生物/真菌全蛋白组结构覆盖已成常态，真正的瓶颈转移到"如何把结构转成可验证的功能断言"。
2. **注释的主力引擎从"序列同源"换成"结构同源 + 语言模型"**。Foldseek/3Di + ProstT5 一类结构令牌检索，正在被直接嵌入基因组注释流水线（典型：Phold、ProtPen、MorphologFinder）。
3. **酶功能注释是当前最集中的战场**，且正在从"给一个 EC 号"升级为"EC + 反应 + 底物 + 动力学"的多层预测，并开始正视**酶的多底物/多功能性**这一使传统单标签评测失效的本质问题。
4. **真菌方向出现了一批"结构驱动的功能发现"闭环案例**：CAZyme 折叠保守性、真菌–真菌寄生效应子、效应子–宿主界面"预测→晶体结构→小分子干预"。
5. **评测体系正在从"三年一次的竞赛"变成"持续在线评测"**（CAFA4 → LAFA），但"部分正确/部分新增"这类更贴近真实使用场景的评测恰恰是当前最弱环节。

---

## 一、为什么这个赛道此时升温：三个结构性变化

**变化 1：结构供给从稀缺变成过剩。**
AlphaFold DB 已进入"亿级"规模（>2 亿条预测结构，覆盖上百万个物种），微生物与真菌参考蛋白组基本被完整覆盖；ESM Metagenomic Atlas 首批即释放约 6 亿个宏基因组来源结构。这意味着对微生物而言，"蛋白有没有结构"已不再是问题，"结构可信到什么程度、能支持多强的功能断言"才是问题。

**变化 2：结构可以像序列一样被"检索"。**
3Di 字母表 + Foldseek 把结构比对压到序列比对同一量级，结构数据库第一次具备了"全库扫描"的实用性。于是出现了把结构检索当作**注释引擎**（而非验证工具）的一类新方法：`Phold` 用 ProstT5 + Foldseek + 136 万个带功能标签的噬菌体蛋白结构做注释，在平均噬菌体基因组上注释率超过 50%（古菌病毒约 40%），并提出"噬菌体蛋白常与生命树各处蛋白存在结构同源"（Nucleic Acids Res, 2026）。

**变化 3：蛋白语言模型的表征可以直接"零样本/少样本"接注释头。**
PLM embedding + kNN / 线性探针 / 轻量分类器，已经在相当多任务上逼近甚至超过基于 MSA 的传统流程，而成本低一到两个量级。

## 二、七个热点方向

### 2.1 全蛋白组尺度"结构 + 结构域 + 功能"一体化注释

**代表工作**：*Deinococcus indicus* DR1 的全蛋白组结构与功能普查（Biodegradation, 2026）。4128 个蛋白全部用 AlphaFold2 建模，其中 2145 个 pLDDT ≥ 90；CATH/InterPro 为 2735 个蛋白分配结构域；功能预测用 **DeepFRI（GNN）+ MorphologFinder（Foldseek 结构检索 + eggNOG-mapper）** 融合；最终为**超过 100 个此前完全未表征的蛋白**给出金属结合/转运/解毒等候选功能，并挑出 20 个高置信候选进入表达、突变、敲除验证，模型与查询服务整体上线（deinococcus.in）。

**为什么这是范式**：它把"结构预测"只是流水线第一环，真正的价值在**三层融合（结构域 → 结构同源 → 序列同源）+ 明确的实验优先级输出**。这类"一个基因组一篇论文"的工作在 2026 年迅速增多，正在成为微生物新物种描述的标配。

**风险**：融合规则多为经验性加权，缺少校准过的置信度；"候选功能"与"已证实功能"在文献中常被混用。

### 2.2 结构同源检索：远程同源的最后一公里

- 对**序列相似度 < 30%** 的远缘同源，结构检索的召回优势已被反复验证；有一项研究明确指出，纯口袋形状/物化性质的点云筛选能捞回 BLASTP 与 Foldseek 都漏掉的 13.9% 已知脱靶（Brief Bioinform, 2026）——说明**"结构相似"与"口袋相似"是两个互补信号**，不能互相替代。
- **配体层面**的功能注释也在跟进：`FunFOLD5` 用 Foldseek 做局部+全局模板检索，配合 BioLiP2 策展配体注释，在 CASP15/16 盲测靶点上对 69 个配体实例中的 56 个（81.2%）给出高精度预测，可用于**未表征蛋白的配体身份与结合位点推断**（Bioinformatics, 2026）。
- 落到具体生物学问题：肠道细菌**黏蛋白 O-聚糖降解酶**的分类，已可直接用快速结构检索完成家族级判定（PLoS Comput Biol, 2026）。

### 2.3 酶功能注释：从"一个 EC 号"到"条件化功能"

这是当前竞争最激烈、也最容易"指标好看但不可用"的方向。

| 进展 | 代表工作 | 关键数字/结论 |
|---|---|---|
| 覆盖度扩张 | `CLEAN` Database（Nucleic Acids Res, 2026） | 为 **5500 万+ 序列**提供酶功能覆盖；对比学习框架，显著扩大 EC 注释覆盖面 |
| 反应层一致性 | `GUTchetp`（Gut Microbes, 2026） | 用两个 EC 分类器的**预测一致性 + 反应相似性**重排序，隐藏集上准确率提升 **34.38 个百分点**；可复现 **68.42%** 已知肠道菌生物转化谱 |
| 真实世界的"多功能性" | CYP450 药基因研究（bioRxiv, 2026） | AlphaMissense 在 6 个关键 CYP 上落入"ambiguous"类的比例约为全蛋白组 **2 倍**，该类内与实测活性几乎无关（ρ = −0.130）；提出**功能应被定义为"底物条件化"的** |
| 结构域边界重定义 | PelADA 晶体结构（J Biol Chem, 2026） | 2.51 Å 结构直接确立 **两个新 CAZy 家族 CBM114 与 CE26**，并用 AF 模型提出跨膜螺旋–PelG 的装配模型 |

**趋势判断**：EC 号作为"单一真值标签"的范式正在松动。下一步的竞争点是**层级化输出（EC 四层 + GO + 反应式 + 底物谱）**，以及**判别"同家族不同底物"的能力**——这正是同源/结构相似度最高的区域，也是最容易出错的地方。

### 2.4 复合物与界面：微生物最"缺注释"的那部分功能

微生物大量功能写在**界面**上（效应子–宿主、毒素–免疫、黏附、分泌系统底物），这些蛋白往往序列高度分化、无同源可依。2025–2026 年的典型闭环：

- **衣原体 Inc 蛋白 CT226**：AlphaFold-Multimer 建模 + 突变验证，锁定其与宿主 LRRFIP1 N 端螺旋的静电界面，证明该互作调控包涵体大小与子代产量（mBio, 2026）。
- **真菌效应子 PevD1（大丽轮枝菌）**：AF-Multimer + MD 预测其与 NRP 死亡结构域的界面 → SPR 测得 KD 0.19 μM（远强于 CRY2 的 4.34 μM）→ 1.35 Å 晶体结构验证 → 基于界面虚拟筛选获得小分子 A6 阻断互作（J Biol Chem, 2026）。**这是"预测→结构→干预"的完整体**。
- **环境 metagenome 来源的双功能 β-内酰胺酶 LRA-13**：AF3 结构显示 N 端 class D 与 C 端 class C 结构域经短链接头串联，提示双催化位点这一新进化路径（Microbiol Spectr, 2026）。

**方法学要点**：ipTM/pTM 是"建模置信度"而非"功能置信度"；跨物种界面预测（尤其涉及糖基化、膜、无序区）仍系统性偏差，必须配 mutational validation 或交联质谱。

### 2.5 真菌专属战场：CAZyme、次级代谢、效应子组

真菌的注释难点与细菌不同：**模块化巨型酶（PKS/NRPS）、大规模基因家族扩张、分泌组/效应子组、以及"序列分化但折叠保守"**。

1. **CAZyme 的"序列分化、折叠保守"已被定量确认**：对比东非碱盐湖与反刍动物瘤胃的 34 个宏基因组、371 个 MAG，在 6 个 GH 家族中取 12 个代表酶用 **AlphaFold3** 建模，全部保持家族经典折叠（pTM 0.75–0.97），尽管序列已极度分化（mSystems, 2026）。**实践含义**：对真菌 CAZyme，结构层面的家族归属比序列层面的同源搜索更稳；因此 dbCAN 类 HMM 流程应把结构检索作为"兜底/仲裁"层。
2. **真菌–真菌寄生（mycoparasitism）的效应子结构线索**：对 50+ 高质量真菌基因组做 CAZyme 谱分析，AA3-2 与 AA9 与寄生习性相关；用 AlphaFold 结构聚类发现多个系统发育上相距很远的寄生真菌，其候选效应子在**三级结构上同源于**经典植物病原效应子，其中一个簇即属 AA9（Fungal Biol Biotechnol, 2026）。这类"结构同源跨生活方式迁移"是纯序列方法无法给出的。
3. **抗真菌靶点发现的结构侧翼**：小麦秆锈菌 *Puccinia graminis* f. sp. *tritici* 从 36,348 个蛋白出发，经减法蛋白组学 + AF2 建模 + 口袋对接，收敛到 4 个候选靶点（KRE6 同源物、AGS1、MFS 转运蛋白）（Comput Biol Chem, 2026）。
4. **次级代谢簇的结构化解读**仍未解决：模块化 PKS/NRPS 的结构域拼接、底物特异性口袋预测，是把 antiSMASH 类"基因簇预测"升级为"产物预测"的关键一步，目前仍是明显空白。

### 2.6 暗物质：宏基因组、噬菌体与"最小基因组"

- **病毒/噬菌体**是结构注释收益最高的对象：序列相似度衰减最快，结构保守性相对最好。除 Phold 外，已有综述系统论证 AI 结构预测在**照亮宏基因组病毒暗物质、为孤儿谱系定高阶分类、为高度分化蛋白推断功能**三方面的作用（Annu Rev Virol, 2026）。
- **"已测序 ≠ 已注释"的荒诞案例**：最小基因组 JCVI-syn3.0（原本 473 个基因中约 1/3 功能未知）经重新分析，仍被识别出**一批此前未被认识的膜转运蛋白与免疫因子**（mSphere, 2026）——说明教科书级模式生物的功能注释也远未饱和。
- **注释错误的"考古"同样是一类热点**：莱姆病螺旋体 BBE22 的晶体结构澄清了一个长期存在的注释错误（FEBS Open Bio, 2026）。这类"结构纠错"型工作数量在上升，并直接指向数据库质量控制议题。

### 2.7 与突变效应、抗性预测的合流

结构注释正在与"变异功能解读"合流，最典型的是**用蛋白结构上下文预测抗生素抗性突变**（eLife, 2026，结核分枝杆菌）：突变在结构中的位置（而非仅保守性）显著提升对抗性表型的预测力。这为微生物方向提供了一个高价值出口：**结构注释 → 靶点/抗性位点 → 临床或育种决策**。

## 三、评测与可信度：最容易被忽视的一节

**CAFA4 的结论值得每个做注释的人读**（bioRxiv, 2026）：148 个方法、70 个团队、46,205 个蛋白、5 年注释积累期。要点：

- 从 CAFA2 到 CAFA4，GO 三个方面的预测**确有实质进步**；
- 但新增的 **"部分知识"评测**（提交时已有部分实验注释、积累期内又在同一 GO 方面新增注释的蛋白）上性能明显下降 —— 这恰恰对应真实使用场景：**"我知道一点，需要补全"**；
- 排名在传统指标上稳定，在部分知识场景下不稳定。

**LAFA**（functionbench.net）把评测从"三年一次"变成持续性的容器化在线评测（Bioinform Adv, 2026），是基础设施层面的重要变化。

关键指标回顾：

$$
F_{\max} = \max_{\tau}\ \frac{2 \cdot \mathrm{pr}(\tau) \cdot \mathrm{rc}(\tau)}{\mathrm{pr}(\tau) + \mathrm{rc}(\tau)}
$$

其中 $\mathrm{pr}(\tau)$、$\mathrm{rc}(\tau)$ 为阈值 $\tau$ 下的精确率与召回率。**注意 $F_{\max}$ 会系统性奖励"广撒网"式预测**，这与微生物注释的实际需求（少而准、可实验验证）存在结构性错配——这是当前评测体系最需要改的地方。

## 四、五个真实瓶颈

1. **结构置信度 ≠ 功能置信度。** pLDDT/pTM/ipTM 无法告诉你"这个折叠对应哪个 EC 号"。领域缺少经过校准的**功能层面不确定度**（conformal prediction 类方法几乎缺席）。
2. **注释错误的自我传播。** 结构检索的参考库本身由历史注释构成，错误会被结构相似性"洗白"并放大（BBE22 只是被发现的一例）。
3. **同家族不同功能。** 酶学中"折叠保守、底物分化"是常态，结构相似度在此处给出的是**误导性高置信**。
4. **无序区与多结构域蛋白被系统性忽视。** 微生物/真菌蛋白中 disordered 区域比例高，AF 对其基本无信息；而许多调控功能正写在这里。
5. **实验验证吞吐量。** 2026 年的主流工作流已能一次产出上百个候选，但下游验证仍是"20 个候选、一年周期"的量级。**干湿闭环的产能错配**是全领域最硬的约束。

## 五、值得投入的六个选题（含可操作切口）

1. **"结构注释 + 校准置信度"的流水线**：在现有 DeepFRI/Foldseek/PLM 融合框架上引入 conformal prediction，给出"可复现的错误率保证"，并配一个微生物基准集。
2. **底物条件化的酶功能预测**：以 CYP/CAZyme/β-内酰胺酶三类"底物分化剧烈"的家族为试验田，把"功能"定义为（反应, 底物谱）而非 EC 号。
3. **模块化巨型酶的结构解析式注释**：PKS/NRPS 结构域拼接 + 底物口袋预测 → 直接对接 BGC 产物预测（真菌次级代谢的最大空白）。
4. **真菌效应子组的结构同源迁移图谱**：把 mycoparasite 那类"跨生活方式结构同源"做成可查询资源，覆盖 100+ 真菌基因组。
5. **注释质量审计学**：以"结构纠错"为方法，系统扫描公共库中高影响微生物/真菌蛋白的注释冲突，产出可被 UniProt 采纳的修正集。
6. **把评测搬到真实场景**：构建"部分知识补全"型微生物基准（对应 CAFA4 的 partial knowledge 场景），并纳入实验可验证性作为评测维度。

## 四、这条路线三个已知的硬失效场景（写文章/审稿必被问）

1. **同家族不同底物**：结构相似度最高处，恰是功能分化最剧烈处（CYP、CAZyme、β-内酰胺酶）。已有证据显示同源/保守性类方法在此系统性失效。

**已被占的**：①"同折叠不同功能"的生物学实证（很多）；②low-homology / unseen-label 的评测子集（EnzymeHunter、EnzPlacer）；③序列-结构解耦的定量框架（PNAS 2026）。

这就是你的题目真正的位置。它值一篇 benchmark 论文，但**必须在三个地方和上面划清界限**，否则审稿人会判"与 EnzymeHunter 的 low-homology 设置重叠"：

<details>
<summary><strong>展开：如果要真做，基准必须这样设计才立得住</strong></summary>

**1. 负例分三层，而不是一个"难"字**

| 层 | 定义 | 为什么必须单独一层 |
|---|---|---|
| L1 近负例 | 同一 CATH superfamily，EC 前三位相同、第四位不同 | 测"底物特异性"分辨率，对应 GNAT/PAAT、CAZyme 的真实难点 |
| L2 中负例 | 同一 fold（CATH topology 级），EC 第一位不同（如 GNAT 内的乙酰转移酶 vs 其他） | 测"折叠决定论"的失效边界 |
| L3 远负例 | 结构相似（TM-score/Foldseek bitscore 高）但**分子功能类型不同**：酶 vs 结合蛋白、moonlighting、结构域被重利用 | 这层几乎没人系统做过，也是最有发表价值的一层 |

**2. 必须做"相似度匹配"，否则 hard negative 会退化成"低序列相似度"的代理**
按序列一致性、结构相似度、口袋相似度三个维度做**分层抽样平衡**，确保每个难例层的结构相似度分布与正例重叠。否则你测到的其实还是"序列差异大 ⇒ 难"，不是"形状像但功能不同"。

**3. 必报"shape-only oracle"与 Δ**
不只报 $F_{\max}$，要报：只用结构特征（3Di/结构相似度/口袋几何）能达到的上界，以及"加序列后"的增量 $\Delta$。这才是"Function Is Not Shape"真正的量纲。

**4. 切分必须按 fold/EC 层级 + 时间双切**
按 CATH fold 切分防泄漏；按 CAFA 的时间积累切分防"未来注释泄漏"。并对 UniProt 修剪做敏感性分析（引用上面那篇 NAR GAB）。

</details>

**最容易被忽略的两个坑**：ground truth 本身就是错的（Schnoes 那条线的核心论点）；以及负例一旦公开发布就会被当成训练数据，基准会迅速饱和——**需要考虑 held-out 部分不公开**。
