# RISC-V Bulk Normalization Algorithm (RVBNA) 页面导读

这是 Substack 博客 **"What are you optimizing for?"**（作者 **FPRox**，计算机体系结构/计算机算术方向）在 2026 年 10 月 11 日发布的一篇技术文章，标题为《RISC-V Bulk Normalization Algorithm (RVBNA)——一种可扩展的点积求值方案；Round to Odd 胜出！》。

文章介绍 RISC-V 为多个扩展项目（含部分 fast track）新引入的 **RVBNA**：一种用于近似点积（dot product）计算的数值算法规范，并用大量实验把它与其他方案做误差对比。

## 1. 要解决的问题

目标是设计一种**高效、灵活、可扩展**的浮点类格式点积算法，要求：

- 可从 2、4 个元素扩展到 128 甚至更多元素
- 规范清晰、可实现，跨实现结果**可预测一致**（确定性）
- 支持小格式（binary16、BFloat16、OFP8）和**非对称格式**（左侧向量格式与右侧不同）

背景：线性代数（如矩阵乘法）大量依赖点积，其实现效率直接决定系统整体性能；而效率受规范所定的格式、舍入、求值方案约束。文中先回顾了几种经典点积方案。

## 2. 已有的点积求值方案对比

| 方案 | 特点 |
|---|---|
| **FP MUL + FP ADD 线性链** | 每次乘、加各一次舍入；加法串行深度 = 点积维度，关键路径长 |
| **FP MUL + FP ADD 二叉树** | 4 元素时关键路径比线性链少一次 FP Add；因浮点加法不满足结合律，数值行为不同 |
| **FMA 链** | 只有一次最终舍入，中间乘积不舍入，误差更小；但累加延迟高于"分离 MUL+ADD"方案（后者累加延迟只取决于 FP ADD 延迟，可放松 MUL 的时序压力、减小面积）。FMA 的 addend 通路需要 2 倍有效位宽 |
| **正确舍入点积** | 理论最优，但需先算出精确结果；对宽指数范围格式（如 BF16）代价极高。即使 half-precision / OFP8 E5M2 的 Kulisch 式定点累加器也要约 80 位 |

> 关键提示：精确点积不能只考虑**结果**的指数范围，还要考虑**每个乘积**的指数范围——两个大乘积可能超出目标格式的 emax，但若幅值精确且符号相反，完全抵消后和不溢出。

## 3. RVBNA 算法本身

RVBNA 在**精度与实现成本**之间取不同折衷：牺牲部分理论精度（相对 FMA 或全精度累加的 MUL+ADD），换取更简单、对点积维度更可扩展的实现。它追求实现速度与延迟，舍入完全确定但**每次点积包含多步舍入**，每步都改用 **Round-to-Odd（RTO，向奇数舍入）** 而非就近舍入。

核心机制：

1. **中心定点累加器**：大小取决于待累加乘积个数 $n$；定点"小数点"位置由**最大参考指数**决定。
2. **乘积参考指数**：为简化对齐，不使用每个乘积的精确指数（不考虑次正规数的前导位位置），而用各操作数**编码后的偏置指数**构造参考指数——免去前导零计数，加快求最大值（最大参考指数）。该设计面向采用单一编码指数表示次正规数的偏置指数格式（IEEE-754、OCP OFP8）。
3. **对齐 + RTO 舍入**：对齐到最大参考指数后，每个乘积用 Round-to-Odd 舍入一次。
4. **定点累加**：低有效位一侧按 $\lceil \log_2(n) \rceil$ 加保护位（guard bits）；高有效位一侧充分扩展以容纳可能的溢出（溢出不会降低累加精度）。
5. **最终舍入**：累加结果再次用 Round-to-Odd 舍入到目标精度。

RVBNA 的两点特殊定义（偏离通行的 RTO 定义）：零结果恒为 **+0**；若未舍入指数超出目标格式范围，溢出按符号舍入为 **无穷大**（而非 RTO 常见的 omega 值 = 最大有效数），即**不饱和溢出**。

另外，RVBNA **只做点积，不做 dot-product-accumulate**——不含独立 addend，预期由后续一次单独的浮点加法加入。

## 4. 精度预期与实验

理论上：RTO 在相同精度下比就近舍入（RNE）精度差，最大误差可达 **1 ULP**（RNE 为 0.5 ULP），所以 RVBNA 对部分输入至少比正确舍入差半个 ULP；不过它有**中间额外精度**补偿：定点累加器精度 = 目标精度 + $\log_2(\text{最大元素数})$ 位（静态常数，向上取整）。

**实验设置**：BFloat16 输入、binary32 输出，高斯随机数据，比较 6 种方案：
(A) 正确舍入点积；(B) binary32 FMA 链（4 个 32 位 FMA）；(C) 舍入到 BF16 的乘法 + 精确累加；(D) BF16 乘 + BF16 加法树；(E) binary32 乘 + binary32 加法树；(F) RVBNA（2 个保护位）。

以"相对误差绝对值排序后的 log₂ S 曲线"呈现（精确结果为 -1）：

- **4 元素（均值 0、标准差 5）**：低精度 BF16 乘法两方案最差；正确舍入、FMA 链、大精度 MUL+ADD 树、RVBNA 四个方案有 **>97.5%** 样本精确。正确舍入最好，FMA 与大精度 MUL+ADD 次之；RVBNA 精确样本更多，但非精确情形略差（不到 1 ULP 的差距）。
- **64 元素（6 个保护位）**：精确样本比例大幅下降；正确舍入与 RVBNA 仍有约 **40%** 精确。累加器比 4 元素宽 4 位，累加精度提升，优于 FMA 与 MUL+ADD。RVBNA 对定点位置固定的**大幅抵消**更敏感，但总体上优于 FMA 与 MUL+ADD，表现接近正确舍入。
- **改变分布均值（A、B 均值改为 5）**：RVBNA 与正确舍入仍有约 9.8% 精确样本（FMA 7.4%、MUL+ADD 9.2%），但 RVBNA 多数样本精度下降，接近 FMA 链；此设置下大精度 MUL+ADD 树反而仅次于正确舍入。关键因素是**乘积分布的均值**。

**误差对称性**：文中还给出 Split Biased Log₂ Error、4-Way Split 等图，以及误差统计表（带符号绝对/相对误差平均与总和、正负误差数、正负结果数、符号与正确结果相反的结果数），用于判断方案是否引入符号偏差。指出 RTO 的舍入方向取决于结果有效数最低位的奇偶性——偶数时向远离零方向，奇数时向零方向，因此误差符号分布取决于有效数符号分布与最低位取值分布（后续文章会继续探讨）。

## 5. 结论与落地

- 误差绝对值方面，RVBNA 数值行为合理，有时可与最精确的正确舍入方案相比；中间更宽的累加器带来额外精度，在输入分布以零为中心时效果尤其明显。
- 结合易实现性，RVBNA 是（深度）点积实现、特别是小格式的好候选。
- 已被集成进两个 RISC-V 扩展项目：**Vector Matrix Extension (VME) 草案的 Zvt 系列**；**Large and Batched Dot Product Extension Families 草案的 Zvdota/Zvbdota**。
