# SBAS 使用指南 + 手机为什么用不了

## 一、SBAS 是什么

**SBAS（Satellite-Based Augmentation System，星基增强系统）** 是一套通过**地球静止轨道（GEO）卫星**向用户广播差分改正数和完好性信息的广域增强系统，最初为航空精密进近设计。

典型系统：

| 地区 | 系统 | 备注 |
|---|---|---|
| 美国 | WAAS | 最成熟 |
| 欧洲 | EGNOS | 支持 SoL 服务 |
| 日本 | MSAS | |
| 印度 | GAGAN | |
| 俄罗斯 | SDCM | |
| 中国 | BDSBAS | 依托北斗 GEO，含 L1/L5 |
| 韩国 | KASS | |
| 澳新 | SouthPAN | |
| 非洲 | ASECNA | 在建 |

### 系统组成

```
地面参考站网 (GMS/RCV)  →  主控站 (MCS)  →  上行注入站 (GUS)  →  GEO 卫星  →  用户
     监测所有 GNSS 卫星误差      计算改正+完好性     把报文发上天      广播
```

### 信号特征

- **L1 频点**：1575.42 MHz，GPS L1 C/A 类信号，**PRN 号 120–158**，数据率 **250 bps**
- **L5 频点**：1176.45 MHz（DFMC 双频多星座，新一代，抗电离层更强）
- GEO 卫星发射功率低、波束宽，到达地面信号通常比 GPS 弱很多

## 二、SBAS 提供什么

1. **差分改正**：卫星星历/钟差修正（MT25）+ 电离层格网延迟修正（MT26）
2. **完好性**：实时误差上界，输出保护级 $HPL$ / $VPL$，这是航空最看重的
3. **额外测距源**：GEO 可当作一颗"卫星"参与定位，增加可见星数

**典型精度**：水平 $1\text{–}3\ \text{m}$、垂直 $2\text{–}4\ \text{m}$。航空上可支撑 **LPV / LPV-200** 类垂直引导进近。

保护级概念：

$$
HPL = K_H \cdot d_{\text{major}}, \qquad VPL = K_V \cdot \sigma_V
$$

接收机把改正后残差投影到水平/垂直方向，乘以系数得到包络，保证真实误差以极高概率落在里面。

<summary>SBAS 报文类型（Message Types）速查</summary>

| MT | 内容 |
|---|---|
| 1 | PRN 掩码 |
| 2–5 | 快变改正（卫星钟差快速改正） |
| 6 | 完好性信息 |
| 7 | 降级因子 |
| 9 | GEO 导航电文 |
| 10 | 降级参数 |
| 12 | SBAS 网络时间 / UTC 偏移 |
| 18 | 电离层格网点掩码 |
| 25 | 长期卫星星历/钟差改正 |
| 26 | 电离层延迟改正 |
| 27 | 服务报文 |
| 28 | 钟差-星历协方差矩阵 |

</details>

## 三、怎么用 SBAS（接收机侧）

### 硬件前提

1. **接收机芯片支持 SBAS**（如 u-blox NEO-M8N/M9N/F9P、NovAtel、Trimble 等）
2. **能收到低仰角 GEO**：需要较好的天空视野，天线朝上、无遮挡
3. **正确配置**：很多模块默认**关闭** SBAS，必须手动开启

### u-blox 配置示意

```text
UBX-CFG-SBAS  : mode = enabled
                usage = range + diffcorr   # 既测距也用差分改正
UBX-CFG-GNSS  : 使能 SBAS / 允许搜索 PRN 120-158
```

命令行工具可用 `ubxtool`/`gpsbabel`，或用 u-center 图形界面勾选 "SBAS"。

### 观察是否生效

- **NMEA `GSV`**：出现 PRN ≥ 120 的卫星即为 SBAS GEO
- **NMEA `GGA`**：定位质量和精度因子改善
- **u-blox `UBX-NAV-SBAS`**：查看 SBAS 系统、跟踪状态、改正是否应用
- **`UBX-NAV-PVT`**：看 `diffSoln` / `carrSoln` 标志

### 实际应用场景

- **航空**：LPV 进近（唯一"生命安全"级用法，需认证设备）
- **航海/测绘/农业**：亚米级~米级定位，作为 RTK 的廉价替代
- **时间同步**：部分授时设备

> ⚠️ 注意：SBAS 精度远不如 RTK（RTK 是 $1\text{–}2\ \text{cm}$，SBAS 是 $1\text{–}3\ \text{m}$），它真正的价值在于**完好性**而非极高精度。

## 四、为什么手机 GNSS 用不了 SBAS

这是核心问题。**技术上手机芯片常常"支持"，但实际几乎不用**，原因分几层：

<details>
<summary><b>1. 芯片默认不启用 / 不暴露</b></summary>

主流手机 GNSS 芯片（Qualcomm、Broadcom BCM47755、MediaTek 等）硬件上大多具备 SBAS 能力，但：
- 固件默认**关闭** SBAS 以省电、加快首定位
- 定位解算由芯片内部"黑盒"完成，**不把 SBAS 改正/保护级暴露给 OS 和应用**
- 你看到的多星 NMEA 里通常只有 GPS/GLONASS/Galileo/BDS/QZSS，没有 PRN 120+

</details>

<details>
<summary><b>2. GEO 信号对手机极不友好</b></summary>

- SBAS GEO 信号**功率低**（波束宽、EIRP 小），比 GPS 弱十几 dB
- GEO 是**静止轨道**，在中高纬度**仰角很低**（可能 10°–30°），城市里基本被建筑遮挡
- 手机天线**小、增益低、圆极化性能差**，且用户手持姿态任意，手/头/身体随时遮挡低仰角信号
- 城市峡谷多径严重，弱信号根本无法稳定跟踪

</details>

<details>
<summary><b>3. 有更好、更便宜的替代方案</b></summary>

手机定位实际依赖的是**网络辅助**路线，而不是 SBAS：
- **A-GNSS / SUPL**：从基站/Wi-Fi 快速获得星历、粗略位置，秒级首定位
- **3GPP / SUPL 标准里根本没有 SBAS 位置解算流程**
- **双频（L1+L5）**：手机已能收 L5/E5a，电离层误差自然消掉一大半
- **载波相位 + 网络 RTK/RTK**（如 Google 的高精度定位、各厂商的 PPP）：可达分米~厘米级，远胜 SBAS
- **众包/3D 地图修正**：城市环境更有效

> 结论：SBAS 能给的（~1 m + 完好性），手机用"网络 + 双频 + 载波相位"能做得更好。

</details>

<details>
<summary><b>4. 需求错配</b></summary>

- SBAS 的核心价值是**完好性（生命安全）**，用于航空进近
- 手机**不做生命安全**应用，不需要 $HPL/VPL$ 认证
- 手机要的是：快、省电、够用（几米），而不是米级 + 完整性保证

</details>

<details>
<summary><b>5. 工程与法规成本</b></summary>

- 搜索额外的 GEO PRN 会增加**功耗**和**首定位时间**
- SBAS 设备认证体系面向航空，消费电子没有动力去走
- 各厂商还倾向用**自家/运营商的高精度服务**，形成生态壁垒

</details>

### 一句话总结

> 手机不是"物理上绝对不能"收 SBAS，而是**收不好（信号弱、遮挡多）+ 不需要（有更好的网络增强）+ 厂商没启用（芯片黑盒、SUPL 不含）**，三重因素叠加导致消费级手机 GNSS 基本不用 SBAS。

## 五、值得关注的例外与趋势

- **部分 Android 设备**在 `GPSTest` 等 App 里能显示 SBAS 卫星（如 Broadcom 芯片），但通常**不参与可见的位置解**。
- **SBAS L5（DFMC）**：双频多星座是新方向，理论上手机 L5 硬件可复用，但目前**手机侧仍未实现**。
- **北斗 PPP-B2b**：这是与 SBAS **不同的东西**——北斗三号 GEO 在 B2b 频点（1207.14 MHz）播发**精密单点定位（PPP）**改正，部分新手机已能接收，可做到分米级。它证明"手机从 GEO 收增强"并非不可能，只是走的是 PPP 而不是传统 SBAS。

<details>
<summary><b>SBAS vs 手机主流增强方案对比</b></summary>

| 方案 | 精度 | 成熟度(手机) | 主要用途 |
|---|---|---|---|
| SBAS | 1–3 m | 几乎不用 | 航空完好性 |
| A-GNSS/SUPL | 5–10 m | 标配 | 快速定位 |
| 双频 L1+L5 | 1–3 m | 标配 | 电离层改正 |
| 网络 RTK/PPP | dm–cm | 逐步普及 | 高精度 |
| 北斗 PPP-B2b | dm | 部分新机 | 高精度 |

</details>
