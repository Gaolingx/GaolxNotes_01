# AutoConference是否值得参与

## 🧑‍💻 User

AutoConference的目的是打造Auto Research时代的新一代arxiv和OpenReview平台，现在参与打造平台的研究者已经有100多人，最终会效仿HLE在月底推出自己的Tech Report，所有的contributor 都会作为co-author列入，年底前会投递一篇研究论文到NS子刊。
参与这个有必要吗

## 先给结论

**值得"低成本参与"，不值得"重投入押注"。** 这是一张便宜且有上限的期权：下行成本可控（几周的 token 费用 + 一台常开机器），上行是"auto research 早期建设者"的公开可查记录。但如果你指望它当申博/求职的硬通货，那**一本 HLE 式的百人共著 Tech Report，单篇署名价值极低**——真正值钱的是你在这件事里**可识别的具体贡献**。

---

## 我实际查到的公开事实

我只读了公开页面（`autoconference.ai` 的首页、`/contributors`、`/run` 的前 40 行），以下都可自行复核：

| 项目 | 公开信息 |
|---|---|
| 形态 | AI agent 之间投稿、互评、做决定的滚动式会议；agent 跑在**你自己的机器上**（Windows 须先装 WSL），每轮约两周，每周开新一轮 |
| 当前进度 | Beta 2（10/10–10/25），累计约 1,411 篇投稿、4,462 条 review、664 个注册 agent |
| 署名门槛 | 你的某个 agent 在**任一轮会议完成一个完整 round**：①有论文进入 review；②交齐自己该交和收到的 review（漏期不算）；③所有产出附带 work record。AC/PC 以 chair 工作替代。撤回/删除即失效 |
| 署名承诺 | 勾选后列入 "contributor/co-author of our official tech report, aimed at a top journal, like **Humanity's Last Exam in Nature**" |
| 公开榜单规模 | **26 行，其中 22 人已勾选署名**（多为 UIUC / Zhejiang / Pitt / Purdue / Columbia / NUS / UW 的学生，1 位来自 Amazon AGI） |
| 成本 | 明确写 "Taking part is free; your agent uses your own model account"——即**你自己掏 token 钱**，且机器要常开 |

两点需要你注意：

1. **"100 多人"与公开榜单对不上。** 现在真正达到署名门槛的只有 26 人（22 人署名）。"100 多"大概是注册/意向人数。这既说明项目比你想象的更早期（早期红利更大），也说明"人多势众"这个理由不成立。
2. **"投递 NS 子刊" ≠ "被接收"。** 站点自己的说法是 "aimed at a top journal, like HLE in Nature"，而你的描述是"投 NS 子刊"——正刊和 *Nature Communications* / *Scientific Reports* 级别的差距很大，且 Nature 系子刊接收率通常远低于 20%。**投出去这件事本身在你的 CV 上几乎不可验证，别把它当成果写。**

## 收益与成本，摊开算

### 你能真正拿到的东西

- **署名**：按 $N$ 位共同作者计，单篇的可分配信号大致按 $V/N$ 衰减；$N$ 上百时，个人边际信号趋于一个很低的底。评审委员会对 consortium 论文的折扣是公开的秘密。
- **可验证的角色**：这是最大的一块。如果你不是"跑个 agent 挂名"，而是负责 agent kit、评测协议、复现关卡、数据/文档、论文某一节，那你拿到的是**能讲清楚的工作 + 公开记录**，这远比署名值钱。
- **网络与信息差**：现在的榜上有 Pitt 副教授、Amazon AGI 等真实身份的人。这是处于热度中心的早期圈子，认识人的价值通常高于署名本身。
- **技能**：多智能体协作、自动评审、复现与 trust 机制——如果你做 agent 方向，这些是能复用到自己研究里的。

### 你的实际付出

- 数周的 token 账单 + 一台机器常开（还有 WSL 折腾的时间）；
- 两周一轮、容错极低的**准时交 review** 压力（漏一次就不计 round）；
- 机会成本：同样的时间做你自己的**一作论文**，期望收益通常更高。

## 决策框架

$$\text{EV} = P(\text{论文发表})\times V_{\text{列表}} \times s - C_{\text{算力+时间}} - C_{\text{机会成本}}$$

其中 $s$ 是你个人的署名份额。关键不是 $P$，而是 $s$：**当 $s \to 1/N$ 且 $N \to 100$ 时，整个乘积趋近于零。**

用这个式子看你属于哪一类：

| 你的处境 | 建议 |
|---|---|
| 本科生/低年级研究生，缺经历、缺人脉、方向就是 agent/auto research | **参与，但争取具体角色**。成本低、下限不亏 |
| 已有一定发表记录，正在憋一作 | 只投入最小成本挂名（一轮 round 即可），把主力时间留给自己的论文 |
| 想靠这篇署名冲博士申请/教职 | **不要以署名为目的参与**。去争取能被引用的独立产出或推荐信 |
| 已经在做 auto research / agent 评测 | **值得深度参与**：这个平台本身可能成为你研究的实验床与引用来源 |

<summary><strong>如果决定参与，先问清这 6 个问题（点击展开）</strong></summary>

1. **作者排序与分层？** 是纯字母序、按贡献分层、还是所有人平铺？HLE 那类是分层 + 大量 listed contributors，个人 distinguishable 程度差别很大。
2. **Tech Report 的发布渠道与时间？** 有无 DOI / arXiv / 会议投稿计划？"月底推出"如果只是网站上一份 PDF，其价值要重新评估。
3. **NS 子刊的具体目标刊和通讯作者是谁？** 谁在写、谁投、投稿失败后的 fallback 是什么？
4. **我的贡献边界在哪？** 如果我只贡献 agent 的运行，你们如何区分我和"跑脚本的人"？
5. **能否撤名、能否指定打印名、贡献记录是否公开可查？** （站点说可以改/取消，确认一下是否覆盖 Tech Report 之后）
6. **组织者与治理结构？** 公开页面看不到 team / 机构 / 资金信息。谁是 PI、有没有机构背书、这个平台的长期计划是什么。

</details>

## 一句话

把它当成**一张便宜的入场券**而不是**一篇成果**：花最小的成本跑通一轮、拿到署名和圈子入场资格，同时把省下的时间投进你自己的可识别贡献——**署名会随作者数稀释，工作量不会。**
