## 😀 默认助手 (7)

# ImGui 里做圆角 + 液态玻璃

先给结论：**你笔记里那套几乎全部不能搬过来，但核心数学可以。** 网页方案里 80% 的复杂度（`feImage` 生成 displacement map、PNG/dataURL 缓存、`ResizeObserver` 重算、`userSpaceOnUse`、UA 嗅探、伪元素层叠上下文）在 ImGui 里**根本不存在**——因为你有自己的渲染器，可以直接在 pixel shader 里解析式算 SDF。`feDisplacementMap` 变成 3 次 texture tap，`feGaussianBlur` 变成一次全屏 mip 链，圆角直接由 SDF 给出。

下面按「改动成本从低到高」分档，你按需要停在哪一档都行。

## 0. 前提：ImGui 的圆角是免费的

```cpp
ImGuiStyle& s = ImGui::GetStyle();
s.WindowRounding    = 14.0f;
s.ChildRounding     = 10.0f;
s.FrameRounding     = 8.0f;
s.PopupRounding     = 10.0f;
s.GrabRounding      = 8.0f;
s.TabRounding       = 8.0f;
s.ScrollbarRounding = 12.0f;
s.WindowBorderSize  = 1.0f;
s.AntiAliasedLines  = true;
s.AntiAliasedFill   = true;
s.WindowShadowSize  = 0;   // 阴影交给后面的玻璃光照自己做，避免双重描边
ImGui::GetIO().ConfigDpiScaleFonts = true;
```

`AddRectFilled(min, max, col, rounding)` 的 rounding 在 AA 开启时是正确抗锯齿的，`AddImageRounded` 同理。**圆角本身不用写 shader**，难点只在「让圆角处的背景折射对」。另外每帧通过 `PushStyleVar` 可以按窗口覆盖圆角，所以不同面板不同半径很容易。

> 唯一注意：`rounding` 越大，tessellation 越多。如果你有几百个面板，把静态面板的圆角矩形缓存进 `ImDrawList` 的共享几何（1.90+ 的 `ImDrawListSharedData` / `ImDrawListSplitter`）或者干脆降一点 `CurveTessellationTol`。

## 档 1：模糊贴图 + `AddImageRounded`（半天，零自定义 shader，全后端可用）

这是性价比最高的一步，**不写任何 shader**，只要你能拿到一张「本帧的、被模糊过的屏幕画面」纹理。

渲染顺序：

```
1. 场景渲染  -> sceneRT (离屏)
2. 降采样 + 两次可分离高斯 -> blurRT（半分辨率就够）
3. ImGui::Render()，但每个玻璃窗口用 AddImageRounded(blurRT, ...) 铺底
```

窗口里这样用：

```cpp
ImGui::SetNextWindowBgAlpha(0.0f);          // 关掉默认不透明底
ImGui::Begin("Inspector");

ImDrawList* dl     = ImGui::GetWindowDrawList();
ImVec2      mn     = ImGui::GetWindowPos();
ImVec2      mx     = ImVec2(mn.x + ImGui::GetWindowSize().x,
                            mn.y + ImGui::GetWindowSize().y);
ImVec2      uv0    = (mn - viewportOrigin) / screenSize;   // 屏幕空间 UV
ImVec2      uv1    = (mx - viewportOrigin) / screenSize;
float       radius = ImGui::GetStyle().WindowRounding;

// 1) 模糊背景
dl->AddImageRounded(blurTexID, mn, mx, uv0, uv1, IM_COL32(255,255,255,180), radius);

// 2) 顶部微光 sheen（可选，一条渐变就够了）
ImU32 a = IM_COL32(255,255,255,26), b = IM_COL32(255,255,255,0);
float band = mx.y - mn.y;
dl->AddRectFilledMultiColor(mn, ImVec2(mx.x, mn.y + band), a, a, b, b);

// 3) 1px 内描边
dl->AddRect(mn, mx, IM_COL32(255,255,255,38), radius, 0, 1.0f);

// ... 正常写你的控件 ...
ImGui::End();
```

要点与坑：

- `SetNextWindowBgAlpha(0.0f)` 只是把 `ImGuiCol_WindowBg` 的 alpha 置 0，并不阻止 ImGui 画那个矩形。这样 `AddImageRounded` 叠在它上面即可，**不需要动 ImGui 源码**。
- `AddImageRounded` 的 UV 是屏幕空间的，多视口（docking + viewports）下每个 viewport 要在自己的 framebuffer 里偏移，`viewportOrigin` 别忘了减。
- `ImTextureID` 在 1.92 之后叫 `ImTextureRef`，需要走 `ImGui::GetIO().Fonts->TexRef` 那套纹理管理 API，绑定裸指针的旧代码要跟着改。
- 模糊是全屏一次、每帧一次，**成本与面板数量无关**——这是它比网页方案（每面板一个 dataURL）强的地方。

## 档 2：真·液态玻璃 —— SDF 折射 + 色散 + 边缘高光

<details>
<summary><b>核心 pixel shader（HLSL / D3D11，约 60 行）</b></summary>

对应你网页方案里的四个 filter：SDF 折射、三通道色散、`feColorMatrix`、伪元素光照。**不需要 displacement map 纹理**，SDF 与梯度全解析算。

```hlsl
cbuffer GlassCB : register(b0)
{
    float2 screenSize;      // 当前 RTV 尺寸
    float2 rectMin;         // 面板屏幕坐标
    float2 rectMax;
    float4 cornerRadii;     // TL, TR, BR, BL
    float4 tint;            // rgb = 染色, a = 染色强度
    float  refractStrength; // 边缘最大偏移(px)
    float  chroma;          // 色散强度
    float  bevelWidth;      // 边缘"倒角"宽度(px)
    float  blurStrength;    // 边缘最大模糊半径(px)
    float  saturation;
    float  contrast;
    float2 lightDir;        // 屏幕空间光照方向，可随鼠标动
    float  _pad;
};

Texture2D    SceneTex : register(t0);   // 清晰场景(near/clamp)
Texture2D    BlurTex  : register(t1);   // 带 mip 的模糊链(progressive blur)
SamplerState LinearClamp : register(s0);

// 四角独立半径的圆角矩形 SDF：< 0 在内
float sdRoundBox(float2 p, float2 b, float4 r)
{
    float2 rr = (p.x > 0.0) ? ((p.y > 0.0) ? r.zz : r.yy)
                            : ((p.y > 0.0) ? r.ww : r.xx);
    float2 q = abs(p) - b + rr;
    return min(max(q.x, q.y), 0.0) + length(max(q, 0.0)) - rr.x;
}

float2 sdfGrad(float2 p, float2 b, float4 r)
{
    const float e = 1.0;
    float dx = sdRoundBox(p + float2(e, 0), b, r) - sdRoundBox(p - float2(e, 0), b, r);
    float dy = sdRoundBox(p + float2(0, e), b, r) - sdRoundBox(p - float2(0, e), b, r);
    return normalize(float2(dx, dy) + 1e-6);
}

float4 PSMain(float4 pos : SV_Position) : SV_Target
{
    float2 p = pos.xy - (rectMin + rectMax) * 0.5;   // 局部坐标
    float2 b = (rectMax - rectMin) * 0.5;            // 半尺寸
    float  d = sdRoundBox(p, b, cornerRadii);        // <0 在内部

    // ---- 1. 倒角高度场 -> 法线 --------------------------------------
    float  inside = -d;                              // >0 在内部
    float  t      = saturate(inside / bevelWidth);   // 0=边缘, 1=内部平坦
    float  slope  = (1.0 - t) * (1.0 - t);           // dh/dn，边缘最陡
    float2 N      = sdfGrad(p, b, cornerRadii) * slope;

    // ---- 2. 折射偏移 + 色散（代替 3 张 displacement map）-------------
    float2 uv  = pos.xy / screenSize;
    float2 duv = N * refractStrength / screenSize;
    float3 dc  = float3(-1.0, 0.0, 1.0) * chroma;    // R / B 反向偏

    // ---- 3. 渐进模糊：越靠边越模糊，直接选 mip ------------------------
    float  blurPx = blurStrength * (1.0 - t);
    float  lod    = log2(max(blurPx, 1.0));

    float3 col;
    col.r = BlurTex.SampleLevel(LinearClamp, uv + duv * (1.0 + dc.r), lod).r;
    col.g = BlurTex.SampleLevel(LinearClamp, uv + duv,                 lod).g;
    col.b = BlurTex.SampleLevel(LinearClamp, uv + duv * (1.0 + dc.b), lod).b;

    // ---- 4. feColorMatrix 的等价：饱和 + 对比 + tint ------------------
    float lum = dot(col, float3(0.2126, 0.7152, 0.0722));
    col = lerp(float3(lum, lum, lum), col, saturation);
    col = (col - 0.5) * contrast + 0.5;
    col = lerp(col, tint.rgb, tint.a);

    // ---- 5. 边缘高光 / 菲涅尔 / 内阴影（代替伪元素光照）---------------
    float2 g   = sdfGrad(p, b, cornerRadii);
    float2 L   = normalize(float2(-lightDir.y, lightDir.x));
    float  spec = pow(saturate(dot(g, L)), 6.0);
    float  fres = pow(1.0 - t, 3.0);

    col += spec * fres * 0.55;                        // 顺光侧亮边
    col -= (1.0 - spec) * fres * 0.10;                // 背光侧内阴影
    float rim = smoothstep(1.5, 0.0, inside) * 0.12;  // 1px 轮廓光
    col += rim;

    // ---- 6. SDF 自带 AA，不需要 MSAA --------------------------------
    return float4(col, saturate(0.5 - d));
}
```

</details>

<details>
<summary><b>模糊链：可分离高斯 + mip（progressive blur，两趟全屏）</b></summary>

```hlsl
cbuffer BlurCB : register(b0) { float2 texelDir; };  // (k/w,0) 或 (0,k/h)
Texture2D Src : register(t0);
SamplerState S : register(s0);

static const float W[5] = { 0.227027, 0.194595, 0.121622, 0.054054, 0.016216 };

float4 PSBlur(float4 pos : SV_Position, float2 uv : TEXCOORD0) : SV_Target
{
    float3 acc = Src.Sample(S, uv).rgb * W[0];
    [unroll] for (int i = 1; i < 5; ++i)
    {
        acc += Src.Sample(S, uv + texelDir * i).rgb * W[i];
        acc += Src.Sample(S, uv - texelDir * i).rgb * W[i];
    }
    return float4(acc, 1.0);
}
```

推荐管线（成本恒定 O(屏幕)，跟面板数无关）：

1. 场景 RT → 半分辨率 `blurRT` 第 0 级（同时 1/2 降采样 + 模糊）；
2. 对第 0 级做横向 + 纵向两趟，得到第 0 级；
3. `GenerateMips(blurSRV)` 或自己逐级降采样，得到 mip 0..N；
4. shader 里用 `lod = log2(blurPx)` 选级 → 天然渐进模糊。

`GenerateMips` 是 box filter，做背景虚化足够；想要更干净就每级各做一趟高斯/Kawase。**注意：`BlurTex` 必须是带 mip 的 SRV，且不能包含 UI 本身**，所以务必在 ImGui 绘制前抓场景。

</details>

## 3. 怎么把 shader 塞进 ImGui 的绘制流

<details>
<summary><b>用 <code>ImDrawList::AddCallback</code> 注入一个全屏三角形（推荐做法）</b></summary>

不要试图精确构造四边形——**让 shader 用 `SV_Position` 自己算 SDF**，你只需要画一个覆盖全屏的三角形，用 scissor 裁掉面板外的部分。这样视口、DPI、缩放全都自动正确。

```cpp
struct GlassParams {
    ImVec2 mn, mx;
    float  radii[4];
    ImU32  tint;
    float  refract, chroma, bevel, blur;
};

struct GlassArena {                     // 关键：回调数据必须活到帧末
    std::deque<GlassParams> storage;
    void Reset() { storage.clear(); }
};
static GlassArena gGlassArena;

static void GlassCallback(const ImDrawList*, const ImDrawCmd* cmd)
{
    auto* gp = (GlassParams*)cmd->UserCallbackData;
    MyRenderer::DrawGlassQuad(*gp, cmd->ClipRect);   // 设 scissor 后画全屏三角形
}

// 在窗口 Begin() 之后、任何控件之前调用
void PushGlassPanel(ImDrawList* dl, ImVec2 mn, ImVec2 mx, float rounding, ImU32 tint)
{
    gGlassArena.storage.push_back({ mn, mx, {rounding,rounding,rounding,rounding},
                                    tint, 40.0f, 0.05f, 28.0f, 24.0f });
    dl->AddCallback(GlassCallback, &gGlassArena.storage.back());
    dl->AddCallback(ImDrawCallback_ResetRenderState, nullptr);  // 让 backend 恢复状态
}
```

后端回调里必须自己重做这些事（ImGui 不会帮你恢复）：

```cpp
void MyRenderer::DrawGlassQuad(const GlassParams& gp, const ImVec4& clip)
{
    D3D11_VIEWPORT vp { 0, 0, (float)rtW, (float)rtH, 0, 1 };  // 全屏视口
    ctx->RSSetViewports(1, &vp);

    D3D11_RECT scissor {
        (LONG)clip.x, (LONG)clip.y,                       // 注意：ClipRect 已是 framebuffer 坐标
        (LONG)(clip.x + clip.z), (LONG)(clip.y + clip.w)
    };
    ctx->RSSetScissorRects(1, &scissor);
    ctx->RSSetState(noCullState);

    // 绑定自己的 shader / CB / sceneRT SRV / blurSRV / sampler
    FillGlassCB(gp);
    ctx->VSSetShader(glassVS, nullptr, 0);   // 输出全屏三角形，PS 靠 SV_Position 取 p
    ctx->PSSetShader(glassPS, nullptr, 0);
    ctx->IASetPrimitiveTopology(D3D11_PRIMITIVE_TOPOLOGY_TRIANGLELIST);
    ctx->Draw(3, 0);
}
```

坑位清单：

| 坑 | 处理 |
|---|---|
| 回调数据生命周期 | `ImDrawCmd` 只存 `void*`。数据必须活到 `ImGui::Render()` 执行完（帧末）。用 per-frame arena（上面 `std::deque`），每帧 `Reset()`。**用局部变量必崩**。 |
| 状态污染 | 调完必须发 `ImDrawCallback_ResetRenderState`，否则后面的控件用错 shader/font texture。 |
| `cmd->ClipRect` | 已经是 framebuffer 像素坐标，且是窗口 clip 与所有 `PushClipRect` 的交集 —— 直接拿去当 scissor，圆角由 SDF 的 alpha 兜底。 |
| 多视口 | docking + `ImGuiConfigFlags_ViewportsEnable` 下每个 viewport 是独立 swapchain，`sceneRT` / `blurRT` / `screenSize` 都要按 viewport 分别准备。 |
| 顺序 | 玻璃回调必须是窗口内的**第一条** draw command（`Begin()` 后立刻 push，`WindowBg` alpha 设 0），否则背景会盖住控件。 |
| 后端 | OpenGL 用同一个思路（FBO + 全屏四边形 + `glScissor`）；Vulkan 记得把 `sceneRT`/`blurSRV` 放进 descriptor set 并在回调里更新。 |

</details>

<details>
<summary><b>替代方案：不用回调，改成「渲染完 UI 再来一遍全屏合成」</b></summary>

如果你想完全避开回调的状态管理，可以：

1. 场景 → `sceneRT`；2. 模糊 → `blurRT`；
3. **关掉所有玻璃面板的背景**，只把每个玻璃面板写进一张 `R8_UINT` 的 "glass ID" RT（用 stencil 或直接输出 ID）；
4. ImGui 渲染到 `uiRT`；
5. 最后一遍全屏 pass：读 `glassID`，如果非 0 就去 CB 的 rect 数组里查参数，做同样的玻璃着色，再和 `uiRT` 合成。

优点：状态干净，和 ImGui 解耦，方便以后加 SSAO/景深复用 `sceneRT`。缺点：要维护 ID 缓冲和参数数组，面板数多时有上限。**面板数量大、或者引擎本身就有后处理管线时选这个。**

</details>

## 档 3：让它从「玻璃」变成「液态玻璃」

- **颗粒 / frosting**：加一张 tiled noise（128×128，R8），低 alpha 叠在上面，强度随 `1 - t` 变化。液态玻璃的高级感一半来自颗粒，别省。
- **鼠标视差光照**：`lightDir` 每帧向鼠标位置做 `lerp` 阻尼插值，高光会「跟着你动」，廉价但效果爆炸。
- **动画 specular sweep**：`spec` 里加一个沿对角线扫过的 `smoothstep` 高光带，进门动画/加载态用。
- **厚度色（dispersion tint）**：在边缘 `fres` 处混一点偏蓝/偏紫，模拟厚玻璃的色散，比单纯 RGB 偏移更「真」。
- **阴影**：因为关掉了 `WindowShadowSize`，在玻璃 pass 里用 SDF 向外做 `smoothstep` 得到软阴影，偏移 `lightDir`，这样阴影方向和高光一致。

## 网页方案 ↔ ImGui 方案对照

| 你笔记里做的事 | ImGui/GPU 里的等价物 | 备注 |
|---|---|---|
| `feImage` 生成 displacement map（PNG/dataURL、按尺寸缓存） | **不生成**。shader 里解析算 rounded-box SDF + 梯度 | 省掉 `ResizeObserver`、缓存键、`userSpaceOnUse`、data URL |
| `feDisplacementMap` 三通道 | 一次做 3 次 texture tap，UV 各偏一点 | 色散方向随便取，成本几乎为零 |
| `feGaussianBlur` / `backdrop-filter: blur()` | 场景离屏 RT + 降采样高斯 + mip 链 | 每帧一次全屏，**与面板数无关** |
| `feColorMatrix` 饱和/对比 | lum 混合 + `(c-0.5)*k+0.5` | |
| 伪元素做 rim / specular | SDF 梯度当法线 + fresnel + `pow` | 无 `position: relative`、无层叠上下文问题 |
| `ResizeObserver` 重生成纹理 | 不需要，即时模式每帧重算参数 | |
| UA 嗅探 / Chromium-only | 不存在，渲染器是你的 | |
| 黑+白 overlay 合成成一个 RGBA 层 | 直接在 shader 里一次算完 | |
| 边界像素只算 band、其余填常数 | 靠 scissor + SDF alpha 天然做到 | 更省，且没有 band 接缝 |

**一句话：你花在「生成和缓存 displacement map」上的全部复杂度，在 ImGui 里被一行 `sdRoundBox` 替代了。** 真正要重写的只有「怎么抓背景、怎么模糊、怎么把 pass 插进 ImGui 的绘制流」这三件事。

## 性能与工程建议

- 模糊**永远**在 1/2 或 1/4 分辨率做，全屏两次。玻璃 pass 是 fill-rate bound，别在 4K 全屏做。
- 玻璃面板重叠会重复着色。把相邻面板合并成一个大玻璃背板（一个 rect），或限制同屏玻璃数量。
- `sceneRT` 用 `R11G11B10_FLOAT` 或 `R8G8B8A8_UNORM` 即可；别用 HDR RT 直接进 UI shader（除非你要 bloom 残留）。
- 开 MSAA 时记得先 Resolve 再给 `BlurTex` 采样，否则 `SampleLevel` 对 MSAA 纹理是未定义的。
- 想要「半透明窗口 + 场景里也有玻璃物体」时，注意 `sceneRT` 必须是不含 UI 的版本，否则会自我采样。

**落地顺序建议**：先做 `s.WindowRounding` + `AddImageRounded(blurRT)`（半天出效果）→ 加 sheen/rim 描边（再加半天，已经能骗过 90% 的人）→ 最后才上档 2 的 shader。很多「modern engine debug UI」其实只做到第一步，剩下的是靠字体、间距、配色、图标撑起来的观感，别把预算全砸在折射上。
