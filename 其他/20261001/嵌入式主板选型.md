## 一、先分清两大阵营

| 阵营 | 代表 | 本质 | 有没有操作系统 |
|------|------|------|----------------|
| **MCU 单片机** | ESP32 / STM32 / 树莓派 Pico | 一个芯片,裸机跑程序 | ❌ 无 Linux |
| **SBC 单板计算机** | 树莓派 5 / RK(香橙派) / Jetson | 一台小电脑 | ✅ 跑 Linux |

> **核心判断法**:你的任务需要"实时、省电、直接控制引脚"→ 选 MCU;需要"跑操作系统、联网服务、AI、多任务"→ 选 SBC。

## 三、按需求对号入座(最实用)

```text
你的核心需求是什么?
│
├─ 电池供电 / 无线联网 / 传感器节点 ………… ESP32
│
├─ 电机控制 / 工业实时 / 精密时序 / CAN总线 … STM32
│  (要求硬实时、μs 级响应、必须绝对可靠)
│
├─ 学习编程 / 便宜 / 需要精密IO(PIO) / 教学 … 树莓派 Pico
│
├─ 通用 Linux / 媒体中心 / 家庭服务器 / 入门AI … 树莓派 5
│
├─ 高性价比 Linux / NAS / 边缘AI推理 / 多屏 … RK(香橙派)
│
└─ 视觉AI / 自动驾驶 / 机器人 / 跑CNN大模型 … Jetson
   (需要 CUDA + TensorRT)
```

## 四、各板详细定位

<details>
<summary><b>ESP32 —— 无线 IoT 之王</b>(点击展开)</summary>

- **芯片**:乐鑫 Xtensa 双核 / RISC-V(C3/C6),240MHz
- **杀手锏**:WiFi + 蓝牙/BLE **芯片内集成**,价格极低
- **典型场景**:智能家居、传感器网关、可穿戴、远程采集
- **开发**:ESP-IDF、Arduino、MicroPython
- **缺点**:算力弱,不适合复杂算法;WiFi 功耗较高(但可深度睡眠)
- **一句话**:凡是要"联网的电池设备",先想它。
</details>

<details>
<summary><b>STM32 —— 工业实时控制标杆</b>(点击展开)</summary>

- **芯片**:ST 的 ARM Cortex-M 全系列(M0 到 M7/H7)
- **杀手锏**:外设极其丰富且精准——高级定时器、多路 ADC/DAC、CAN-FD、USB、以太网;工具链成熟(CubeMX/HAL)
- **典型场景**:电机 FOC 控制、机器人关节、PLC、汽车电子、医疗
- **缺点**:通常无无线(需外挂),生态偏"寄存器/HAL"门槛稍高
- **一句话**:要**硬实时 + 高可靠**,它是标准答案。
</details>

<details>
<summary><b>树莓派 Pico —— 便宜好玩的学习利器</b>(点击展开)</summary>

- **芯片**:RP2040(双核 M0+)/ RP2350(双核 M33)
- **杀手锏**:**PIO 可编程 IO**,能硬件级生成任意时序(WS2812、自定义协议超方便)
- **典型场景**:教学、DIY、精密脉冲、复古游戏机
- **缺点**:无系统、内存小,复杂网络功能弱
- **一句话**:预算几十块做逻辑/时序实验,它最香。
</details>

<details>
<summary><b>树莓派 5 —— 通用 Linux 万金油</b>(点击展开)</summary>

- **芯片**:BCM2712 四核 A76 @2.4GHz,配 PCIe、USB3、双 4K 输出
- **杀手锏**:**生态第一**——教程、系统、配件、社区碾压对手;GPIO 兼容性极好
- **典型场景**:学习 Linux、家庭服务器、媒体中心、原型验证、入门 AI(需外接加速)
- **缺点**:价格被国产板卷,纯算力性价比不如 RK
- **一句话**:不知道选什么、又想要省心,选它不会错。
</details>

<details>
<summary><b>RK 开发板(香橙派等)—— 性价比暴力选手</b>(点击展开)</summary>

- **芯片**:瑞芯微 RK3566 / RK3588 等
- **杀手锏**:RK3588 八核 + **6 TOPS NPU** + 大内存 + 大量 IO(SATA/PCIe/多屏),同价位性能常超树莓派
- **典型场景**:NAS、软路由、边缘 AI 推理、多屏广告机、安卓盒子
- **缺点**:**软件生态和文档不如树莓派**,驱动/BSP 有时坑多,需折腾
- **一句话**:要性能拉满、愿意折腾,选它。
</details>

<details>
<summary><b>Jetson Orin / AGX —— AI 计算核弹</b>(点击展开)</summary>

- **芯片**:NVIDIA ARM CPU + **Ampere GPU** + DLA/AI 加速器
- **算力档位**:Orin Nano 20~40 TOPS → Orin NX 70~100 → AGX Orin 最高 **275 TOPS**
- **杀手锏**:**完整 CUDA / TensorRT / DeepStream 软件栈**,能直接跑 PyTorch 模型
- **典型场景**:机器人、自动驾驶、机器视觉、SLAM、实时目标检测
- **缺点**:贵、功耗高(15~60W)、需要散热
- **一句话**:只要沾"**视觉 AI + CUDA**",就它,没得选。
</details>

## 五、常见组合套路(现实项目怎么搭)

1. **MCU + SBC 分级架构**:ESP32/STM32 做实时采集与执行 → 通过串口/网络汇总给树莓派/RK 做上层逻辑。这是最经典的智能硬件架构。
2. **纯 MCU 低功耗方案**:ESP32 深睡 + 定时唤醒上传,电池撑数月。
3. **边缘 AI**:RK3588 跑轻量模型(性价比高)→ 复杂模型才上 Jetson。
4. **机器人**:STM32 控关节电机 + Jetson 做视觉决策(上下位机)。

---

## 六、避坑提醒

- ❌ **别用 SBC 做硬实时**:Linux 调度抖动大,μs 级控制会翻车,交给 STM32。
- ❌ **别用 MCU 跑大模型**:内存和算力都不够,强上只会卡死。
- ⚠️ **RK/香橙派务必确认内核 BSP 支持**:买前查驱动、社区活跃度。
- ⚠️ **Jetson 价格 = 算力**,先算清你到底需要多少 TOPS,别为用不上的算力买单。
- ⚠️ **无线不是 SBC 强项**:SBC 联网靠 WiFi 模块/USB,不如 ESP32 内置省心。

> **联网省电**→ ESP32;**实时控制**→ STM32;**便宜学IO**→ Pico;**省心通用**→ 树莓派5;**性价比/NAS**→ RK;**视觉AI**→ Jetson。
