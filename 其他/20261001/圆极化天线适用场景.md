# 圆极化天线的适用场景

圆极化（CP）天线最核心的价值只有一句话：**用 3 dB 的确定代价，换取对"极化状态不可控"的免疫力。** 只要能证明链路两端的极化是可预测、可对齐的，就不该用圆极化。下面把判断逻辑和典型场景分开说。

---

## 一、判断是否该用圆极化的四个物理依据

<details>
<summary><b>1. 极化失配风险不可控（最常见的理由）</b></summary>

线极化发—线极化收，两者夹角 $\alpha$ 时，极化失配损失为

$$L_p = 20\log_{10}(\cos\alpha)\ \text{dB}$$

- $\alpha=0°$：0 dB
- $\alpha=45°$：$-3\ \text{dB}$
- $\alpha=90°$：$-\infty$（完全收不到）

而圆极化对**任意线极化**只有固定的 $-3.01\ \text{dB}$（或对反向圆极化为完全隔离）。所以当终端姿态、朝向、安装角度随机或随时间变化时——手持机、无人机、车载、船舶、旋转机械、无线麦克风——圆极化把"可能归零"变成"必定 -3 dB"，这是极划算的保险。

**典型：** RFID 读写器（标签贴在哪、什么角度都可能）、UHF 手持电台、无线图传、可穿戴设备（弯曲变形会改变线极化方向）。
</details>

<details>
<summary><b>2. 传播媒质会旋转极化方向</b></summary>

- **电离层法拉第旋转**：线极化波穿过电离层时偏振面会随时间、频率、仰角、太阳活动旋转，可达数十度甚至多圈。地面站若用线极化，增益会周期性衰落。圆极化的两个正交分量同时到达，旋转只体现为相位变化，幅度不受影响。
  - **典型：** GNSS（GPS/北斗）、卫星测控 TT&C、低轨卫星数传、深空探测上行/下行。
  - 北斗/GPS 卫星发射的就是 RHCP，地面天线必须同旋向。
- **雨滴、冰晶去极化（rain depolarization / ice depolarization）**：Ku/Ka 以上频段，非球形雨滴会让线极化产生交叉极化分量，XPD 恶化。圆极化（尤其是高频、强降雨链路）对去极化的容忍度更好。
  - **典型：** 卫星通信上行、VSAT、星地馈电链路。

</details>

<details>
<summary><b>3. 需要抑制多径</b></summary>

这是最被低估的一个理由，也是 GNSS 工程里的核心手段。

圆极化波经**奇数次反射**后旋向反转（RHCP → LHCP）。一个同旋向的圆极化接收天线，天然对地面、建筑物、车顶反射回来的镜像分量产生很强的抑制，而对直射波几乎无损失。多径抑制可以带来若干 dB 的等效 C/N₀ 改善和定位精度提升。

**典型：**
- GNSS 测量型接收机（配合扼流圈 choke ring 地面板）
- 室内定位 / UWB
- 反射面天线馈源（反射面会反转旋向，所以馈源旋向要和"经一次反射后"的旋向匹配——这是选型的常见坑）

> ⚠️ 注意：正因反射反转旋向，**发射 RHCP 的前向链路经一次面反射后必须用 LHCP 馈源接收**。卡塞格伦天线的副面反射会让主面场反转一次，算旋向时要数清楚反射次数。
</details>

<details>
<summary><b>4. 极化复用 / 抗干扰</b></summary>

- **双圆极化（DCP）频率复用**：同一频点用 RHCP/LHCP 承载两路独立数据，理论隔离度可做到 20~30 dB 以上。卫星通信、深空测控常用。（线极化双极化也常用，但圆极化的交叉极化对姿态旋转不敏感。）
- **抗干扰 / 抗欺骗**：GNSS 抗干扰天线阵列常配圆极化阵元，抑制反向旋向的干扰信号。

</details>

## 二、典型应用横向对照

| 应用 | 为什么用圆极化 | 常用天线形式 |
|---|---|---|
| GNSS 接收 | 卫星发 RHCP + 多径抑制 | 微带贴片、四臂螺旋、扼流圈 |
| 卫星通信 / VSAT | 法拉第旋转 + 雨去极化 + 姿态变化 | 螺旋、喇叭、抛物面馈源 |
| 深空测控 | 法拉第旋转、姿态任意、极化复用 | 大口径抛物面 + CP 馈源 |
| RFID 读写器 | 标签朝向随机 | 微带阵列、圆极化板状天线 |
| 无人机 / 图传 | 机体姿态任意 | 四叶草（cloverleaf）、斜盘 |
| 卫星导航干扰机/接收阵 | 抗反向旋向干扰 | 贴片阵 + 调相馈电网络 |
| 气象雷达 | 抑制雨杂波（雨滴回波旋向部分反转） | 圆极化波导缝隙阵 |
| FM/电视广播 | 便携/移动接收、抗多径 | 交叉偶极子 + 90° 移相 |
| EMC 辐射抗扰度测试 | 消除被测物对极化方向的敏感性 | 圆极化对数周期/喇叭 |

## 三、**不该**用圆极化的情形

这一点比"什么时候用"更容易出错：

1. **两端线极化可对齐**：如果发射和接收都是固定安装、极化已对准，用了 CP 反而白丢 $-3.01\ \text{dB}$。地面微波接力、固定点对点回传、Wi-Fi 路由器与终端，都用线极化。
2. **频谱效率优先的 MIMO 系统**：LTE/5G/Wi-Fi 用双线极化（±45° 交叉极化）做极化复用和分集，比双圆极化更省硬件、更易做信道建模。
3. **极化信息本身是观测量**：全极化 SAR、极化气象雷达（双线极化）需要精确的 H/V 相位关系，用圆极化会引入额外变换。
4. **链路预算极其紧张**：3 dB 有时就是生死线，而此时如果能保证极化对齐，就该用线极化。
5. **窄带、低成本消费电子**：线极化天线（单极、PIFA、IFA）结构简单、成本低，圆极化需要 90° 功分/移相网络，有额外插损和带宽限制。

## 四、选型与工程要点（速查）

<details>
<summary><b>旋向（handedness）必须端到端核对</b></summary>

定义按 IEEE：沿传播方向看去，电场矢量逆时针旋转为 RHCP。**不同厂商、不同教材对"观察方向"的定义有差异**，这是实际工程中最常见的低级错误。务必用同一标准（IEEE 或 ARRL）核对，尤其是"经反射面反射"的链路。
</details>

<details>
<summary><b>轴比 AR 与带宽的权衡</b></summary>

$$AR = 20\log_{10}\!\left(\frac{E_{max}}{E_{minor}}\right)\ \text{dB}$$

- 理想圆极化 $AR=0\ \text{dB}$，工程上 $AR\le 3\ \text{dB}$ 通常就算合格圆极化。
- $AR$ 恶化直接带来极化损失：

$$L_{pol} = 10\log_{10}\!\left[\frac{1+AR^2+2AR\cos(2\tau)}{2(1+AR^2)}\right]$$

其中 $\tau$ 为两个椭圆极化之间的夹角。$AR=3\ \text{dB}$ 时最坏额外损失约 0.5~1 dB。

- **轴向模螺旋**、**四臂螺旋**天然宽带圆极化；**微带贴片**窄带（单点馈电约 1~3%），需用双馈 90° 电桥、缝隙耦合或多层结构展宽；**十字偶极子 + 90° 移相**适合广播频段。
</details>

<details>
<summary><b>关键指标清单</b></summary>

- 旋向（RHCP/LHCP）、轴向比 AR vs 频率与波束角
- 3 dB 轴比波束宽度（AR beamwidth）——常比增益波束窄，是实际覆盖瓶颈
- 端口隔离（双圆极化时）、交叉极化鉴别率 XPD
- 馈电网络插损（90° 电桥、Wilkinson 功分器会吃掉 0.3~1 dB）
- 相位中心稳定性（GNSS 测量型天线关键）
- 前后比、多径抑制能力（GNSS 要求交叉极化抑制好）
</details>

## 一句话总结

**当"极化状态不可控"时用圆极化——姿态在变、媒质在转（电离层/雨）、多径在反、或者你要做极化复用；当极化可预测且链路预算紧张时，老老实实用线极化。**
