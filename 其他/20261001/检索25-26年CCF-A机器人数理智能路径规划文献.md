## 三、共性问题分析（核心）

### P1. 空间表征鸿沟：2D 语义先验 ≠ 3D 度量精度

- **现象（评测侧证据）**：`SpinBench` 指出 43 个 VLM 的**自我中心偏置**与旋转理解缺陷是系统性而非偶然；`Spatial-DISE` 在 28 个 VLM 上发现多步多视角推理差距最大；`SpatiaLab` 中 InternVL3.5-72B 为 54.93%，人类为 87.57%；`OmniSpatial` 显示基础左右远近已趋饱和，而动态推理、视角采择仍困难。
- **根因（本届最重要的两项诊断）**：
  1. `Camera-aware MLLM`（ICLR 2026 Oral）指出，RGB-only 将**物体物理属性与相机视角纠缠**，形成不可解歧义，模型只能过拟合训练相机分布；相机内参是跨相机泛化的**必要条件**。
  2. `Real-3DQA` 指出 SQA3D 可被纯文本 QA 微调超越，说明基准本身在奖励语言捷径。
- **向动作的传导**：`3D HAMSTER` 给出最清晰的因果链：VLM 输出的 2D 末端轨迹若喂给 3D 点云策略，每个 waypoint 只能取“正下方表面”的深度，导致**度量上被压扁或拉伸的畸变轨迹**；`RoboBrain 2.5` 因此把监督目标从“像素相对坐标”改为“深度感知的绝对度量坐标 + 有序关键点 3D 轨迹”。
- **主流解法谱系**：显式深度/点云输入 → 作为辅助监督（`QDepth-VLA`、`UniLACT`）→ 隐式轻量深度编码（`Evo-Depth` 0.9B、`StereoPolicy` 双目）→ 几何基座分层注入（`StrataVLA`，几何调用减 88%）→ 3D Gaussian token（`GaussVLA`）→ 重建作代理任务（`VGGT-Ω`）。
- **未解**：几何注入的**计算与延迟代价**，以及“显式深度噪声脆弱、隐式编码又不可解释”的两难（`StereoPolicy` 明确以此立论）。

### P2. 动作表征三角：保真度、可学性、可控性不可同时最优

这是 2026 年最密集的战场，离散与连续两派的问题在结构上对偶：

| 维度 | 离散 token（自回归） | 连续生成（diffusion / flow matching） |
|---|---|---|
| 优势 | 复用 LLM 词表与 next-token 目标；跨本体统一（`Holo-M`） | 多峰分布表达强、动作平滑 |
| 固有缺陷 | 量化误差；**早期 token 错误不可回溯**（`DFM-VLA`）；码本与本体状态无关（`SA-VLA` tokenizer：RoboTwin 0.29 到 0.56） | 各向同性高斯先验与异构动作分布**结构性错配**（`LAFM`）；固定采样深度（`π0-EqM`） |
| 2026 解法 | `ReAT`（残差职责化）、`TOAST`（随机多 tokenization）、`ProAct`（面向策略的 tokenizer 训练） | `LAFM`（学习先验库）、`FAFM`（DCT 频域 + Sobolev 平滑）、`OptimusVLA`（检索式先验记忆 2.9×） |
| 融合路线 | `Discrete Forcing`（离散定粗结构、连续精修）、`DFM`（离散流匹配迭代改 token） |

- **最值得记住的一句结论**：`ProAct` 通过系统实验证明“**动作重建足够精确只是策略成功的一部分**”，还必须保证“策略能预测出正确 token”和“错 token 也能解码成合理动作”，因此 tokenizer 应被当作**策略接口**而非压缩器来设计。这与 `COAST` 的发现（VLA 隐状态保留任务知识，瓶颈在动作专家解码）相互印证。
- **另一条被长期忽视的几何问题**：`Lie Diffuser Actor` 指出把 $SE(3)$ 位姿展平成 $\mathbb{R}^{12}$ 会产生流形漂移、等变性破坏与非测地轨迹，须在 $SE(3)$ 上做左不变 SDE 与切空间 score。
- **时间维度的隐性权衡**：`AAC` 证明 chunk 长度在“响应性”与“模式跳变/抖动”之间不可能同时最优，且现有模型几乎都用**经验固定值**。

### P3. 监督信号贫乏：只会模仿成功轨迹，导致不可恢复、不可知进度

- `AFIL`（NeurIPS 2026）与 `FLARE`（CVPR 2026）都指出只做成功轨迹 BC 的后果：**微小误差指数级复合，无法从抓空、掉物、碰撞中恢复**。
- 相关共识正在形成：**失败数据是一等资源**。`VINE` 用失败演示做可行性打分剪枝；`AFIL` 把失败轨迹当负向引导；`OGPO` 把“逐步动作标签”改写为“关键状态可达性”。
- 奖励侧：`Feat2Go`（世界模型 patch 相似度造进度奖励）、`SafeDojo`（拉格朗日约束 GRPO）、`CoRe`（VLM 反馈构形式奖励 + 残差奖励）。
- **最尖锐的负面结论**：`RoboSemanticBench` 在控制住抓取成功率后发现，VLA 选对语义目标的比例**接近甚至低于随机**——说明 backbone 的语义能力**没有传导到动作决策**，训练目标（步骤级动作模仿）本身在惩罚语义推理。这是“空间智能+VLA”这条线最根本的监督悖论。

### P4. 层级接口设计与频率失配

- **频率失配是路径规划方向的头号共性问题**：`AirHunt` 直言 VLM 推理与实时规划存在**数量级频率差**；`LaTraNav` 用“慢 VLM + 快规划器”异步架构把路径更新率提 6.05×；`APPLV` 干脆不让 VLA 输出动作、只输出经典规划器参数；`CaPE` 让 VLM 写**可被模型规划器验证的路径编辑程序**；`NUDGE` 在推理期把 SDF 梯度注入策略。
- **“接口用什么表示”本身成为独立研究问题**：语义子目标（`VINE`）→ 2D waypoint（被 `3D HAMSTER` 证伪）→ 3D 度量轨迹 → costmap 对象级补丁（`NavPatch`）→ 规划器参数（`APPLV`）→ 代码程序（`CaPE`）→ 动作 token 计划（`Coarse-to-Control`）→ 图像空间路径掩码（`VENTURA`）。
- **双系统的调度理论缺位**：`TUD` 证明固定频率调用通用模型是浪费，用跨步动作重预测的离散度作不确定性信号可减 75% 调用；`LaRA-VLA` 用隐式 CoT 把显式推理延迟降 90%；`RD-VLA` 用权重共享递归深度实现恒定显存的测试时算力自适应。三者共同指向：**“何时思考、思考多深”应成为一等设计变量**。
- **部分可观测与记忆**：`AVA-VLA` 明确指出历史无关的马尔可夫假设与真实控制不符，用递归信念状态重构；`SOMA` 处理视野外目标；但 `RoboMME` 的结论很冷静——**记忆表示的有效性高度任务相关，没有普适最优**。

### P5. 评测失效：静态 VQA 分数与闭环成功率脱钩，且基准快速捷径化

这一条横跨全部子方向，是当前最严重的方法论问题：

1. **捷径化**：`Real-3DQA`（3D 基准可用纯文本绕过）、`RoboSemanticBench`（评估可被视觉或指令-动作捷径解出）。
2. **代理指标失准**：`RoboWM-Bench` 证明世界模型的**视觉逼真度与具身可执行性不相关**，瓶颈集中在空间推理、接触预测、非物理几何畸变；`AWM-VLA` 也批评像素级未来重建“昂贵且被任务无关细节主导”。
3. **横向不可比**：`VLAFlow` 明确指出模型在架构、数据、动作空间、评测协议上各不相同，导致预训练范式之间**根本无法比较**，需统一框架。
4. **饱和与泛化幻觉**：`BiGym 2.0` 在统一全身控制器与同一视角下比较，VLA 微调九任务均值最好，但跨工作台堆叠等任务仍全面失败；`ManiSoft` 显示干净场景尚可、随机化后大幅掉点。
5. **缺“空间能力到任务成功率”的因果链**：几乎所有空间基准只报 VQA 准确率，只有 `XVR`（作为 VLA backbone 迁移到 RoboCasa）与 `MultihopSpatial`（RL 后训练迁移到下游操作）真正闭合了这条链。

### P6. 数据与跨本体：动作空间设计是泛化的第一性问题

- `Equivariant VLA` 直接把跨本体预训练形式化为**对本体构型变换等变的策略设计**，并给出动作空间等变性理论。
- `UniDex` 的 `FAAS`（功能-执行器对齐空间）把功能相似的执行器映射到共享坐标，跨 8 种灵巧手迁移。
- `Qwen-VLA` 用 embodiment-aware prompt 条件化，把操作、导航、轨迹预测**统一进一个动作-轨迹预测框架**；`RynnBrain 1.1` 用 embodiment-specific masking。
- 人类数据规模化：`UniDex` / `UniLACT` 从 egocentric 人类视频做隐动作或重定向；`VLAFlow` 的结论很有操作价值——**语言监督保住 VLM 泛化、未来隐表示对齐平滑异构动作监督**，两者互补。
- 共性问题：**动作空间与数据金字塔的设计目前还是经验性的，没有可判定的准则**。

### P7. 效率与空间的张力：token 预算既要用语义又要保坐标

- `OxyGen`（统一 KV cache，4090 上同时 70Hz 动作 + 200 tok/s）、`SAPrune`（剪 87.5% 视觉 token、1.718×）、`AdaVLA`（流量曲率判置信，免训练 1.87×/2.24×）、`OptimusVLA`（2.9×）。
- **但**：`IVC-Prune` 发现 LVLM 通过 RoPE 隐式建立视觉坐标系，某些 token 就是“隐式视觉坐标”，**纯语义相关性剪枝会精准剪掉空间推理所需 token**。这把“效率”与 P1 直接绑定：加速手段若无空间感知，就是在削弱 P1 所急需的能力。

### P8. 安全与可靠性：视觉-语言-动作的耦合面即攻击面

- `UPA-RFAS`（CVPR 2026）：单个物理 patch 可跨架构、跨微调变体、跨仿真-真机迁移攻击 VLA。
- `FlowHijack`（CVPR 2026）：针对流匹配**向量场动力学**的后门，通过 $\tau$ 条件注入 + 动力学模仿正则，使恶意动作在运动学上不可区分。它同时说明：**离散自回归与连续生成的安全面完全不同**，不能把旧的防御直接搬过来。
- `Hide-and-Seek`（NeurIPS 2026）做运行时失效检测；`FLARE` 做 Retry/Reset 恢复并引入 MLLM 在线监控仲裁。
- 共性：一旦空间 grounding 出错，动作序列不可逆，因此“**执行中监控**”必须与“**策略前训练**”同等对待。

## 四、可切入的研究缺口（我的判断）

1. **度量级 3D 表示 × token 效率的联合设计**：目前 depth / pointmap / Gaussian / register 四条路线各自最优，但没人给出“给定控制频率与显存预算下的空间保真度上限”理论（`IVC-Prune` + `StrataVLA` + `OxyGen` 三者的交叉点是空白）。
2. **“空间能力→闭环成功率”的因果评测协议**：只有 `XVR`、`MultihopSpatial` 做了迁移验证；缺标准化诊断集（应同时报告 VQA、grounding IoU、闭环 SR 三者的一致性）。
3. **动作 tokenizer 的“策略接口”理论**：`ProAct` 给出了经验证据但无形式化；结合 `COAST`（解码瓶颈假说）与 `Lie Diffuser Actor`（几何谬误）可望形成“动作解码器的容量-几何-鲁棒性”三元理论。
4. **异步双系统的调度理论**：`AirHunt`、`LaTraNav`、`TUD`、`APPLV` 各自提出启发式；缺“给定延迟预算与任务熵”的最优触发策略。
5. **失败数据与过程奖励的标准化**：`AFIL`、`VINE`、`OGPO`、`Feat2Go`、`FLARE` 都在自建管线；没有公开的、统一的失败-恢复轨迹数据集与过程奖励基准。
6. **跨相机/跨本体的硬等变约束**：`Camera-aware MLLM` 与 `Equivariant VLA` 分别从感知与动作侧逼近，尚无统一框架。
