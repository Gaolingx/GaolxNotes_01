# 未激活可以投稿吗

## 😀 默认助手 (7)

## 简短回答

**基本上是的。** ICML、NeurIPS、ICLR 这三个会议的投稿**全部都在 OpenReview 上进行**，而 OpenReview 的投稿必须绑定一个“已激活（active）”的 profile。如果你的注册仍处于审核或拒绝状态（profile 未激活），你确实**不能作为提交者（submitting author）提交论文**。

不过，“不能投稿”和“不能参与这篇论文”是两回事，下面分情况说明。

---

## 三种情况要分清

| 状态 | 能不能投稿 | 说明 |
|---|---|---|
| Profile 待审核（pending moderation） | ❌ 不能提交，也不能作为“确认作者” | 系统会提示 profile 未激活或无法被添加为作者 |
| Profile 被拒绝（rejected） | ❌ 同上 | 通常是材料无法核实，不是永久封禁 |
| Profile 已激活 | ✅ 正常 | — |

**关键差别在于**：如果导师或合作者拥有已激活的 profile，就**可以由他提交**，先把你的名字和邮箱填进作者列表；你会收到“确认作者身份”（authorship confirmation）邮件。但只要你没有在 OpenReview 内确认作者身份，这篇论文的作者列表就不算完整——NeurIPS、ICLR、ICML 都要求**所有作者在截止前拥有自己的 OpenReview profile 并确认作者身份**，否则该论文可能被**直接拒稿（desk reject）**或影响后续 camera-ready。

所以现实结论是：

> **你本人可以不操作“提交”这个动作，但你必须有一个通过审核的 profile，并且在截止前确认作者身份。**

---

## 为什么会被“卡住”

<details>
<summary>常见原因和推进方法（点开）</summary>

**1. 邮箱域名触发人工审核**
用 `gmail.com`、`qq.com`、`163.com` 这类公共邮箱注册时，系统大概率会进入人工审核队列，因为无法自动关联机构。用学校或公司的机构邮箱（`@*.edu.cn`、`@*.ac.cn`、企业域名）通常能自动或更快通过。

**2. 信息无法核实**
审核员会核对：姓名是否与 DBLP、Google Scholar、机构主页一致；主页链接是否可访问；教育和工作经历是否与论文署名匹配。只填姓名、什么都不填的 profile 很容易被拒绝。

**3. 重复账号**
用两个邮箱注册两个 profile 是很常见的失败原因，会被合并或停用。**不要重开账号**，直接在原账号上补充材料。

**4. 名字拼写与论文不一致**
中文名拼音顺序（`Zhang San` 与 `San Zhang`）、曾用名，都要在 profile 里配置好，否则作者身份匹配会出问题。

**加速方法：**
- 补全机构邮箱、个人主页、Google Scholar、DBLP、ORCID；
- 在主页上放一句 “I am XX, PhD student at YY” 之类可自证的文字；
- 直接发邮件到 `info@openreview.net` 说明会议名、截止时间、profile 链接，通常比干等快；
- 让导师先把你加为合作者，有时能加快匹配。

</details>

---

## 时间上的坑（最重要的实操建议）

审核在**截稿前一到两周会非常拥堵**，而会议方通常明确写着：*“We cannot extend the deadline because your profile is pending.”* 也就是说，**profile 审核延迟不构成延期理由**。

因此务必：

1. **至少提前 2–3 周注册**（如果你用公共邮箱，提前一个月）；
2. 在 CFP 公布后立刻确认自己的 profile 状态是 active；
3. 截稿前一周内不要指望新账号能及时通过。

---

## 一点提醒

具体的作者政策（是否强制全作者确认、是否允许仅提交者拥有 profile）**每个会议、每一届都可能微调**，请以当届 CFP 的 “Submission / Author guidelines” 和 OpenReview 上的实际提示为准。ICML 近两年也在调整作者流程，不要拿旧经验套用。

## 先给结论

**不是。没有 edu 邮箱，完全不影响你投稿 ICML、NeurIPS、ICLR。**

OpenReview 从规则上**从来不要求机构邮箱**，实际审核看的是「**你能不能证明你是你**」；它并不看「**你的学校够不够好**」。两者完全是两件事。

真实情况是：**大量顶会论文的作者邮箱是 gmail**。审稿是双盲的，审稿人看不到你的邮箱和学校；提交系统那端的审核员也只会核对你的身份信息是否自洽。

## 直接回答“双非没邮箱怎么办”

<details>
<summary><b>第一步：先确认真的没有（很多学校有，只是学生不知道）</b></summary>

`.edu.cn` 域名只有中国高校能注册，所以**只要学校有 `.edu.cn` 域名，基本就有邮箱系统**，很多双非也有，只是入口藏得深：

- 学校官网 →「信息化中心 / 网络信息中心 / 图书馆 → 邮箱服务」
- 常见格式：`学号@stu.xxx.edu.cn`、`学号@xxx.edu.cn`、`姓名@xxx.edu.cn`
- 有些是**入学时自动开通**但需要手动激活，或者只发给研究生、不发给本科生
- 校友邮箱（毕业后仍可用，部分学校提供）

打电话问网络中心，一次就能问清楚。**如果确实没有，再走下一步。**

</details>

## 没有机构邮箱时，用什么“替代证据”通过审核

OpenReview 的 moderation 本质是核实身份，所以只要你能形成**一条可交叉验证的证据链**，公共邮箱同样能过：

| 材料 | 作用 | 怎么弄（成本都很低） |
|---|---|---|
| **个人主页** | 最有用的单项材料 | GitHub Pages / Notion / 博客，写上真实姓名、学校、院系、导师、研究方向，写明“I am a undergraduate at XX University” |
| **arXiv 预印本** | 证据充分 | 挂一篇 preprint，作者栏写学校全称。审稿人看不到，但审核员能查到 |
| **DBLP 条目** | 证据充分 | 有 arXiv 或 DOI 的论文后，去 DBLP 提交收录申请，通常几天到两周 |
| **GitHub 主页** | 辅助材料 | bio 里写真实姓名和学校，放公开的项目 |
| **ORCID** | 辅助材料 | 免费注册，绑定单位 |
| **Google Scholar** | 辅助材料 | 用 gmail 注册即可 |
| **证明材料** | 备用材料 | 学生证、在读证明、导师推荐信；审核员有时会发邮件要求补材料 |

**组合建议**：个人主页、arXiv 论文、ORCID。这三项齐全，用 gmail 通过审核基本没有悬念。

> 如果用的是 qq 或 163 邮箱，也不会被拒绝，但邮件沟通和后续流程会不太方便；建议注册一个 `姓名拼音@gmail.com` 或 `姓名@outlook.com`，看起来更像学术身份。

## 如果还是被卡住，有几个保底办法

1. **让有 profile 的导师或合作者先提交**，把你作为 co-author 加进去（用你的邮箱）。你会在之后收到确认邮件；不过在确认作者身份时，你仍然需要一个 active profile，所以这件事要**提前解决，不要等到 camera-ready**。
2. **直接发邮件给 `info@openreview.net`**，写清楚：会议名、截稿时间、profile 链接、你的学校和个人主页。人工处理的效率远高于等待队列。
3. **不要重复注册**。用多个邮箱创建多个账号，是导致审核长期无法通过的最常见原因。
4. **提前 2–4 周注册**。截稿前一周新注册的 profile 大概率来不及审核，而会议方明确不会因为 profile 未通过而延期。

## 顺便纠正一个隐含假设

“投稿顶会”的入场券**从来不是邮箱，也不是学校牌子**。真正挡人的是：

- 有没有导师或合作者能带你走完第一次投稿流程；
- 有没有算力、数据和足够时间做实验；
- 能不能读懂一篇顶会论文的“标准”在哪里；
- 英文写作和 rebuttal 的经验。

这些都能通过**加入实验室、找远程合作、参与开源项目、找师兄师姐带**来补，而一条邮箱几十分钟就能解决。

另外提醒：**不是所有顶会都用 OpenReview**。AAAI 用 CMT，部分机器人方向会议用 PaperPlaza，都不需要 OpenReview profile。所以哪怕一时被卡，也不存在“无缘”这种情况。

---

## 一个诚实的补充

审核不是 100% 机械的，个别情况下确实会出现“材料齐全但没通过”的个例，原因可能是姓名拼写与 DBLP 不一致、疑似重复账号、主页无法访问等。所以：

- **尽早做，留出余量**；
- 用**真实姓名拼音**，与论文署名严格一致；
- 主页要能打开、要能看出你是谁；
- 被拒后**在原账号上补材料并邮件申诉**，而不是重新注册。
