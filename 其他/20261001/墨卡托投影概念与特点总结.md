# 墨卡托投影（Mercator Projection）

**一句话概括：** 一种「圆柱 + 保角」的地图投影。它把地球表面投影到一个与赤道相切的圆柱面上再展开，特点是**局部形状和角度不变形、等角航线（恒向线）画成直线**，代价是**高纬度地区面积被严重放大**。由佛兰德地理学家 **赫拉尔杜斯·墨卡托（Gerardus Mercator）于 1569 年**编制世界航海图时创立。

---

## 一、数学定义

设地球半径 $R$，经度 $\lambda$、纬度 $\varphi$，中央经线 $\lambda_0$。

**正算（经纬度 → 平面）**

$$
x = R\,(\lambda - \lambda_0)
$$

$$
y = R \ln \tan\!\left(\frac{\pi}{4} + \frac{\varphi}{2}\right)
= R \operatorname{artanh}(\sin \varphi)
$$

**反算（平面 → 经纬度）**

$$
\lambda = \frac{x}{R} + \lambda_0, \qquad
\varphi = 2\arctan\!\left(e^{\,y/R}\right) - \frac{\pi}{2}
$$

要点：

- 经线（子午线）是**等间距的垂直直线**；
- 纬线是**水平的等间距？不——间距随纬度急剧增大的直线**。y 方向的拉伸正好抵消圆柱投影固有的东西向压缩，这是保角的条件；
- $\varphi \to \pm 90^\circ$ 时 $y \to \pm\infty$，所以**两极永远无法表示**，任何完整墨卡托地图都必须截断纬度。

> 令 $\psi = \ln\tan\left(\frac{\pi}{4}+\frac{\varphi}{2}\right)$ 称为**等距纬度**（isometric latitude），则墨卡托投影就是把 $(\lambda, \psi)$ 当成平面直角坐标。其反函数 $\varphi = 2\arctan(e^{\psi}) - \frac{\pi}{2}$ 就是**古德曼函数**的逆，即 $\varphi = \operatorname{gd}(\psi)$。

## 二、核心性质

| 性质 | 说明 |
|---|---|
| **保角（conformal）** | 局部角度不变，微小图形与实地相似；经纬线处处正交 |
| **等角航线为直线** | 固定的罗盘方位即一条直线，航海/飞行时"定住罗盘走"即可 |
| **面积严重变形** | 面积比例因子 $= \sec^2\varphi$，越靠两极放大越夸张 |
| **长度变形** | 比例因子 $k = \sec\varphi = 1/\cos\varphi$（各方向相同） |
| **方向不变** | 图上任意方向的方位角 = 实地方位角，无子午线收敛角 |
| **非等积、非等距** | 只适合导航与局部量测，不适合统计面积 |

**长度/面积比例因子（局部尺度）**

$$
k(\varphi) = \sec\varphi, \qquad \text{面积比} = k^2 = \sec^2\varphi
$$

| 纬度 | $\lvert\varphi\rvert$ | $0°$ | $30°$ | $45°$ | $60°$ | $75°$ | $80°$ | $85°$ |
|---|---|---|---|---|---|---|---|---|
| 长度放大 | $1.00$ | $1.15$ | $1.41$ | $2.00$ | $3.86$ | $5.76$ | $11.5$ |
| 面积放大 | $1.00$ | $1.33$ | $2.00$ | $4.00$ | $14.9$ | $33.2$ | $132$ |

这就是"格陵兰看起来和非洲差不多大"的原因：格陵兰实际面积约 216 万 km²，非洲约 3020 万 km²，相差约 14 倍，但在标准墨卡托世界图上二者视觉面积相近。

**为什么保角？** 圆柱投影天然把经度方向按 $R\cos\varphi$ 压缩，纬度方向若按 $dy/d\varphi = R\sec\varphi$ 拉伸，两个方向的局部比例因子就都等于 $\sec\varphi$，于是微小圆仍映射为圆、角度不变——这正是上面那个 $\ln\tan(\cdots)$ 公式的来由。（注意：墨卡托**不是**几何透视投影，而是数学推导出来的。）

## 三、常见变体

- **横轴墨卡托（Transverse Mercator）**：圆柱改与某条子午线相切、轴线旋转 $90°$。中央经线附近变形极小，是 **UTM 分带（60 个 $6°$ 带）** 和多数国家大地坐标系统的基础。
- **Web 墨卡托（Web Mercator, EPSG:3857）**：互联网地图（Google Maps、OpenStreetMap、Bing Maps 等）的瓦片标准。它把 **WGS84 椭球当成球体**处理，用球面公式配 $R = 6\,378\,137\ \text{m}$，因此**严格来说并不保角**，中纬度有约 $0.33\%$ 的尺度误差；但计算快、切片规则统一。纬度被截断在

$$
\varphi_{\max} = 2\arctan(e^{\pi}) - \frac{\pi}{2} \approx 85.05113°
$$

这样整幅图正好是正方形。

- **椭球墨卡托（EPSG:3395 / 经典海图）**：使用椭球偏心率的精确级数，保角性严格成立。

## 四、怎么用 / 怎么不用

<details>
<summary><strong>适用场景（点击展开）</strong></summary>

- **航海与航空导航**：等角航线为直线，量取方位角最方便（大圆航线的"大圆改正量"另算）。
- **Web 地图与瓦片金字塔**：小比例尺、局部浏览时变形可接受。
- **需要局部保角的测绘图件**（多为横轴墨卡托）。

</details>

<details>
<summary><strong>不适用场景（点击展开）</strong></summary>

- **世界级面积/密度对比**：用等积投影，如 **摩尔威德（Mollweide）、罗宾逊、高尔-彼得斯、等距圆柱（Plate Carrée）**。
- **全球形状正确的专题图**：用 **温克尔（Winkel Tripel）、罗宾逊（Robinson）**。
- **中高纬大区域专题图**：用 **兰伯特等角圆锥（Lambert Conformal Conic）**、**阿尔伯斯等积圆锥（Albers）**。
- **极区**：用 **极射赤面（Stereographic）** 或 **兰伯特方位等积**。

</details>

## 五、一个最小实现（Python）

```python
import math

R = 6378137.0  # Web Mercator 用的球半径（米）

def forward(lon_deg, lat_deg, lon0=0.0):
    lam = math.radians(lon_deg - lon0)
    phi = math.radians(lat_deg)
    x = R * lam
    y = R * math.log(math.tan(math.pi / 4 + phi / 2))
    return x, y

def inverse(x, y, lon0=0.0):
    lon = math.degrees(x / R) + lon0
    lat = math.degrees(2 * math.atan(math.exp(y / R)) - math.pi / 2)
    return lon, lat

def scale_factor(lat_deg):
    return 1.0 / math.cos(math.radians(lat_deg))   # k = sec φ
```

## 六、记住这三点就够了

1. **它是保角投影**，不是等积投影；
2. **等角航线上是直线**，所以为航海而生；
3. **面积在高纬被 $\sec^2\varphi$ 放大**，所以别拿它做全球面积比较。
