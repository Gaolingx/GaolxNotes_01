## 一句话结论

用**个人邮箱**（Gmail 等）注册没问题，但在填写 Profile 时**必须在 "Career & Education History" 里把 Position 选成 `Independent Researcher`**，并且**不能只填这一条**——还要补上你过去的教育/工作经历，否则会被人工审核拒掉。个人邮箱会进入人工审核队列（可能长达约 2 周），你的 Google Scholar / ORCID / arXiv 正是加速审核的关键证据。

---

## 具体注册步骤

1. **入口**：打开 `openreview.net/signup`，输入真实姓名 → 勾选确认框 → 填**个人邮箱** → 设密码 → 点 "Sign Up"。
2. **收邮件激活**：去邮箱点 "OpenReview Signup Confirmation" 邮件里的链接，进入 Profile 注册页。
3. **填写 Profile（最关键的一步）**：
   - 在 **Career & Education History** 里点添加记录；
   - **Position 下拉选择 `Independent Researcher`** —— 选中后系统会**自动锁定** Institution Domain 为 `independent-researcher.org`，并禁用 Institution Name 字段，你不用手填；
   - **再额外添加至少一条历史记录**（例如你之前就读的学校、之前任职的公司），Position 用真实角色（如 PhD Student、Research Engineer），这条可以是过去时（填 End Date）。⚠️ **只写 "Independent Researcher" 一条会被拒绝**。
   - Start date 必填；当前经历 End date 留空。
4. **Profile links 填上你的学术主页**（Google Scholar、ORCID、arXiv、GitHub、个人主页都算有效 homepage）。有效 homepage 需要能看出**你的姓名、单位/身份、你注册用的邮箱**。
5. **点 "Register for OpenReview"** → 要么立即激活，要么进入 moderation（审核）。

## 你能用的资产 & 作用

| 你现有的 | 在 OpenReview 里的作用 |
|---|---|
| **Google Scholar 主页** | 可作为**有效个人主页**填进 links，证明学术身份 |
| **ORCID** | 可**一键导入论文**到 Profile，同时作为可信链接 |
| **arXiv** | 可作为链接 / 手动补充发表记录 |

> 审核人员判断"这人是真实研究者"时，最看重的就是：主页能对上名字+邮箱、发表记录、履历完整。

## ⚠️ 常见踩坑（官方明确警告）

- **别拿"过去的学校/机构"当当前职位** —— 会拖延审核。
- **如果有公司/组织邮箱，优先用它**（比个人邮箱快得多）。
- **不要用机构邮箱重复注册第二个账号** —— 会触发重复信息报错。正确做法是把机构邮箱**添加到待审核的账号里**并完成验证码确认。
- **确认邮箱时不要关闭当前标签页** —— 验证码要在同一个窗口里输入。

<details>
<summary><b>补充：如果你之后拿到了学校/公司邮箱，如何最快激活</b></summary>

官方"加速激活"流程要求三步都完成：
1. 打开邮件里的激活链接（过期就重发）；
2. 在 Profile 里添加机构邮箱并点 **Confirm**；
3. **不要关闭当前窗口**，把收到的验证码粘贴回同一标签页点 **Verify**。

只要机构邮箱变成已验证状态，激活速度会大幅提升。
</details>

<details>
<summary><b>补充：从 ORCID 导入论文</b></summary>

Profile 编辑页的 Publications 部分，选择从 ORCID 导入，粘贴你的 ORCID iD 即可把外部来源的论文记录导入。也可用 DBLP URL 或手动上传补充。
</details>
