## 😀 默认助手 (7)

# 这类岗位的定位与画像

你描述的职责——**与 Mentor 共同推导核心架构、提出新路由/长文本注意力变体、写核心实验代码、跑通 Baseline、探索 Scaling Law**——本质上不是普通"算法工程师"岗，而是**基础模型预训练（Foundation Model Pretraining）方向的研究型岗位**。它的产出物是"新架构论文一作 + 可复现的实验"，因此招聘标准也更接近**研究科学家（Research Scientist）**。

下面分层说明。

<details>
<summary><strong>一、岗位类型：通常是这几类（点击展开）</strong></summary>

| 岗位名称 | 典型团队 | 工作重心 |
|---|---|---|
| **预训练算法研究员 / Research Scientist** | 大模型基础架构组 | 架构设计、Scaling Law、论文产出 |
| **研究工程师（Research Engineer）** | 同上 | 侧重工程实现、大规模训练跑通 |
| **Agent / 架构方向算法工程师** | 部分团队并入 | 偏应用但含核心模块创新 |
| **校招"明星计划"岗位** | 见下方专项计划 | 研究自由度最高 |

> 关键区分：**"预训练"而非"微调/对齐/应用"**。只有预训练架构组才会让你主导"新 attention 变体""新 MoE 路由"这种底层创新。做 SFT/RLHF/Agent 的岗位一般不会给你这个权限。

**大厂常见的人才专项（最容易匹配这类 JD）：**

- 字节跳动 **Top Seed 大模型顶尖人才计划**
- 华为 **天才少年**
- 阿里巴巴 **阿里星 / 通义实验室**
- 腾讯 **青云计划 / 混元**
- 美团 **北斗计划**、百度 **AIDU**
- 以及各家（DeepSeek、月之暗面、智谱、MiniMax、上海 AI Lab 等）的 **Research Intern / 校招研究员**

</details>

<details>
<summary><strong>二、什么样的应届生能胜任</strong></summary>

核心结论：**绝大多数是"顶尖博士 + 架构方向强一作论文"的组合**；只有极少数天赋型硕士/本科能破格拿到。

**学历分布（经验性判断）：**
- 约 70–85%：海内外顶尖高校 **博士**（CS/AI/数学/物理背景）
- 约 10–20%：**硕士**（通常已有顶会一作或大厂核心实习经历）
- 少数：**本科直博前就被锁定**的竞赛/科研奇才

**真正的筛选信号（按权重排序）：**

1. **架构方向的一作顶会论文**
   - 不是"用了 Transformer 做了个任务"，而是**改进模型结构本身**
   - 目标会议：NeurIPS / ICML / ICLR / ACL / EMNLP，或系统类 MLSys
   - 加分：论文被开源复现、有 GitHub star、被大模型团队引用

2. **大规模训练的工程能力**
   - 能独立跑通 Baseline：Megatron-LM / DeepSpeed / FSDP / veRL
   - 懂并行策略（TP/PP/DP/EP）、显存优化、通信瓶颈
   - **这是最容易被忽视、又最能拉开差距的一项**——很多"论文漂亮"的人跑不动真实集群

3. **数学与推导功底**
   - 能自己推导注意力复杂度、MoE 负载均衡、梯度稳定性
   - 熟悉信息论、优化理论、概率建模者优先

4. **Scaling Law 的实操经验**
   - 做过小规模→大规模的拟合外推、超参迁移
   - 理解 Chinchilla 类规律并能自己设计实验

5. **科研品味（Research Taste）**
   - 能判断"哪个方向值得做"，这恰恰是 Mentor 最看重、也最难教的

</details>

<details>
<summary><strong>三、典型候选人画像（三个真实感较强的模板）</strong></summary>

**模板 A：架构论文型博士**
- 顶校博士，方向为高效注意力 / MoE / 状态空间模型
- 有一篇 ICLR/NeurIPS 一作，提出过新的稀疏注意力或路由机制
- 实习期间在字节 Seed / 阿里通义 跑过 baseline

**模板 B：系统 + 算法双修型**
- 硕士或博士，工程极强（写过训练框架、CUDA kernel）
- 论文未必最多，但能"把别人的 idea 高效训出来"
- 常被 Research Engineer 岗录取，也能转研究

**模板 C：竞赛/开源型天赋选手**
- 信息学/物理竞赛金牌，或开源项目作者
- 通过专项计划（Top Seed 等）直通，Senior Mentor 亲自带

</details>

## 一句话总结

这类岗位是 **"基础模型预训练方向的研究型校招岗"**（Research Scientist / Research Engineer / 明星计划），能胜任的应届生标准画像通常是：

> **顶尖高校博士（或极优秀硕士）＋ 架构方向一作顶会论文 ＋ 能独立跑通十亿级以上训练的工程能力 ＋ 强数学推导与 Scaling Law 直觉。**

三者缺一，往往就会从"主导架构"降级为"执行实验"。

<details>
<summary><strong>四、给想冲这类岗位的人的实操建议</strong></summary>

1. **尽早锁定一个架构子方向**（如线性注意力、MoE 路由、长上下文、SSM），深耕而非广撒网。
2. **亲手从零训一个中小模型**（1B 级别即可），完整走一遍数据→训练→Scaling 拟合→消融，形成可展示的 repo。
3. **刷通工程栈**：Megatron / DeepSpeed / FSDP + 分布式调试，这是面试硬门槛。
4. **争取一段核心团队实习**（Seed、通义、DeepSeek 等），实习产出往往直接决定校招评级。
5. **准备"讲清楚你的 idea 为什么有效"**——面试官考的是推导链条和科研判断，不是结果数字。

</details>
