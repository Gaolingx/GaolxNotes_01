## 一、最小可编译文档骨架

```latex
\documentclass[12pt,a4paper]{article}   % 或 ctexart / IEEEtran / elsarticle

% ---- 宏包区 ----
\usepackage[UTF8]{ctex}      % 中文支持（XeLaTeX 下用 ctex；纯英文可去掉）
\usepackage{graphicx}        % 插图
\usepackage{booktabs}        % 三线表
\usepackage{amsmath,amssymb} % 数学
\usepackage{hyperref}        % 超链接（一般放最后）
\usepackage{geometry}
\geometry{margin=2.5cm}

% ---- 标题信息 ----
\title{论文题目}
\author{张三\\ 某某大学 \\ \texttt{zhangsan@example.edu}}
\date{\today}

\begin{document}
\maketitle
\begin{abstract}
这里是摘要……
\end{abstract}

\section{引言}\label{sec:intro}
正文……

\bibliographystyle{plain}
\bibliography{refs}          % 对应 refs.bib

\end{document}
```

**文档类选择建议：**
- 通用 → `article`
- 中文期刊/学位论文 → `ctexart` 或 `ctexbook`
- IEEE 会议/期刊 → `IEEEtran`
- Elsevier → `elsarticle`

## 二、图片：插入与"链接"

### 1. 基本插图

```latex
\begin{figure}[htbp]              % h=here t=top b=bottom p=page
  \centering
  \includegraphics[width=0.7\textwidth]{figures/result.png}
  \caption{实验结果对比}\label{fig:result}
\end{figure}
```

- **文件路径**：相对 `.tex` 所在目录，例如 `figures/result.png`。建议所有图片放一个 `figures/` 文件夹。
- **`\graphicspath{{figures/}}`** 可预设搜索路径，之后直接写 `result.png`。
- **格式**：矢量用 `.pdf` / `.eps`（论文首选，放大不失真），位图用 `.png` / `.jpg`。
- **宽度**：`0.7\textwidth`（正文宽度的 70%）、`0.5\linewidth` 等。

### 2. 子图（多图并排）

```latex
\usepackage{subcaption}

\begin{figure}[htbp]
  \centering
  \begin{subfigure}{0.48\textwidth}
    \includegraphics[width=\linewidth]{figures/a.png}
    \caption{方法 A}\label{fig:a}
  \end{subfigure}
  \hfill
  \begin{subfigure}{0.48\textwidth}
    \includegraphics[width=\linewidth]{figures/b.png}
    \caption{方法 B}\label{fig:b}
  \end{subfigure}
  \caption{两种方法对比}\label{fig:ab}
\end{figure}
```

### 3. 在正文里"链接"引用图片

```latex
如图~\ref{fig:result} 所示，准确率显著提升。
见图~\ref{fig:a} 和 \ref{fig:b}。
```

> 注意用 `~`（不换行空格）避免"图"和编号被拆到两行。

## 三、表格：三线表与跨列

```latex
\begin{table}[htbp]
  \centering
  \caption{不同模型性能对比}\label{tab:perf}
  \begin{tabular}{lcc}          % l左 c中 r右；|加竖线
    \toprule
    模型 & 准确率 & F1 \\
    \midrule
    BERT   & 0.91 & 0.90 \\
    Ours   & \textbf{0.95} & \textbf{0.94} \\
    \bottomrule
  \end{tabular}
\end{table}
```

**常用增强：**

```latex
\usepackage{multirow,array}

% 跨列 \multicolumn{列数}{对齐}{内容}
% 跨行 \multirow{行数}{*}{内容}
\begin{tabular}{lcc}
  \toprule
  \multicolumn{3}{c}{数据集统计} \\
  \midrule
  \multirow{2}{*}{方法} & 训练 & 测试 \\
                        & 80\% & 20\% \\
  \bottomrule
\end{tabular}
```

**宽表处理**：`\begin{tabular}{...}` 外包 `\resizebox{\textwidth}{!}{...}` 或改用 `tabularx`。

**表引用：** 如表~\ref{tab:perf} 所示……

## 四、交叉引用与编号体系

| 对象 | 环境 | 引用写法 |
|------|------|----------|
| 章节 | `\section` | `\ref{sec:intro}` |
| 图 | `figure` | `\ref{fig:x}` |
| 表 | `table` | `\ref{tab:x}` |
| 公式 | `equation` | `\eqref{eq:x}` |
| 算法 | `algorithm` | `\ref{alg:x}` |
| 页码 | — | `\pageref{...}` |

**规则**：`\label` 必须放在 `\caption` **之后**（图/表）才能得到正确编号。用 `\ref` 自动生成编号，**千万别手写"图1"**，否则增删内容后全乱。

配合 `hyperref`，`\ref` 会变成可点击的彩色链接（提交盲审时可用 `hidelinks` 去掉颜色框）。

## 五、脚注

```latex
这是一句话\footnote{这是脚注内容，可写英文 Abbreviation (Abbr.)。}
```

**常见进阶：**

```latex
% 1. 多个脚注指向同一处：用 \footnotemark 与 \footnotetext
正文提到方法A\footnotemark[1]，后文又提方法A\footnotemark[1]。
\footnotetext[1]{方法A的定义……}

% 2. 表格内脚注（普通 \footnote 在表格里编号会异常）
\begin{table}\centering
内容\footnotemark
\end{table}
\footnotetext{表内脚注内容}

% 3. 无编号脚注
\footnotetext[0]{致谢信息}
```

**调整编号**：`\renewcommand{\thefootnote}{\alph{footnote}}`（a,b,c…）或 `\fnsymbol{footnote}`（*,†,‡…）。

**脚注与引用分离**（推荐学术写法）：脚注里放单位/通讯作者，参考文献用 bib 而非脚注。

引用：如式~\eqref{eq:loss} 所示。

多行对齐：
\begin{align}
  a &= b + c \\

\end{align}

## 七、参考文献

**推荐用 BibTeX / biblatex 管理**，而非手写。

`refs.bib`：
```bibtex
@article{vaswani2017attention,
  author  = {Vaswani, Ashish and others},
  title   = {Attention is all you need},
  journal = {NeurIPS},
  year    = {2017}
}
```

正文：`\cite{vaswani2017attention}` 或 `\citep{...}`（natbib）。

```latex
\usepackage[numbers]{natbib}   % 数字引用
\bibliographystyle{plain}
\bibliography{refs}
```

引用型样式：`plain, unsrt, abbrv, ieeetr, apalike`，或期刊指定的 `.bst`。

> 若用 `biblatex`：加载 `\usepackage[backend=biber,style=ieee]{biblatex}`，正文 `\cite{}`，文末 `\printbibliography`。

## 八、怎么编译输出 PDF

关键在于**引擎选择**，因为涉及中文和参考文献：

### 引擎对照

| 场景 | 引擎 | 命令 |
|------|------|------|
| 纯英文 | pdfLaTeX | `pdflatex main` |
| 中文（ctex） | XeLaTeX | `xelatex main` |
| 中文 + unicode | LuaLaTeX | `lualatex main` |

**中文务必用 XeLaTeX 或 LuaLaTeX**，不要用 pdfLaTeX。

### 命令行完整编译（含引用、交叉引用）

```bash
# 英文 + BibTeX
pdflatex main
bibtex main
pdflatex main
pdflatex main        # 多编一次以更新交叉引用和页码

# 中文（XeLaTeX + BibTeX）
xelatex main
bibtex main
xelatex main
xelatex main
```

> 为什么要编多次？第一次生成 `.aux`（标签信息），BibTeX 读 `.aux` 生成 `.bbl`（参考文献），后面几次把编号、目录、引用填回去。看到 `LaTeX Warning: Label(s) may have changed. Rerun` 就再编一次。

**或者用 `latexmk` 一条命令自动跑够次数：**

```bash
latexmk -xelatex main.tex        # 中文
latexmk -pdf main.tex            # 英文
latexmk -c                       # 清理中间文件
```

**用 biblatex(biber)：**
```bash
xelatex main
biber main
xelatex main
xelatex main
```

### IDE 一键编译
- **Overleaf**：网页右上角直接选 XeLaTeX + 点 Recompile。
- **VS Code + LaTeX Workshop**：`Ctrl+Alt+B` 编译，配置 `latexmk -xelatex` 为默认 recipe。
- **TeXstudio / MacTeX**：设置默认引擎，按 F5 编译。

## 九、常见坑速查

| 问题 | 原因 / 解决 |
|------|-------------|
| 图/表跑到别处 | `[htbp]` 允许浮动；强制固定用 `\usepackage{float}` + `[H]` |
| 引用显示 `??` | 标签未编好，重新编译；或 `\ref` 用了错的 `\label` |
| 图片找不到 | 检查路径、大小写、扩展名；设 `\graphicspath` |
| 中文乱码/不显示 | 换 XeLaTeX，加载 `ctex` |
| 参考文献不出现 | 忘了跑 `bibtex`，或 `\bibliography` 名字不对 |
| 表格太宽出界 | `tabularx` / `\resizebox` / 缩小字号 |
| 脚注编号重复 | 用 `\footnotemark` + `\footnotetext` 手动配对 |
