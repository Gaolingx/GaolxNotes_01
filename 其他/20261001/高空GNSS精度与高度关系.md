# 高空GNSS精度与高度关系

## 🧑‍💻 User

随着高度越来越高（100km+），gnss定位精度会越来越低吗

---
## 😀 默认助手 (7)

# 结论先行

**不是"越高越差"。** GNSS 定位精度随高度变化是**非单调**的，大致分三段：

| 高度区间 | 精度趋势 | 主导原因 |
|---|---|---|
| $0 \to \sim100\text{ km}$ | 基本持平，**略好** | 对流层误差逐渐消失，电离层几乎不变 |
| $\sim100 \to 3000\text{ km}$（LEO 段） | **继续变好**（最佳区） | 电离层误差显著减小 |
| $>3000\text{ km}$，尤其超过星座高度 $\sim20200\text{ km}$ | **急剧恶化** | 几何构型崩溃、只能收到"漏"过来的弱信号 |

所以 **100 km 恰好是"对流层刚消失、电离层还在"的交界点，精度大致等于地面，不会明显变差。**

---

## 一、各误差源随高度怎么走

| 误差源 | 地面 | 100 km | 400 km (LEO) | 高于星座 |
|---|---|---|---|---|
| 对流层延迟 | ~2.4 m 天顶 | 0 | 0 | 0 |
| 电离层延迟 | 大（主导） | 几乎不变 | 显著减小 | 很小 |
| 多径 / 遮挡 | 有 | 无 | 无 | 无 |
| 几何构型 DOP | 一般 | 略优 | 优 | 急剧变差 |
| 信号可用性 | 好 | 好 | 好 | 差（靠地球另一侧泄露） |
| 动力学 / 多普勒 | 小 | 中 | 大 | 大 |

### 1. 对流层：纯收益（变好）
水汽与中性大气集中在 $0\text{–}50\text{ km}$。到 100 km 已进入热层底部，射线**不再穿过对流层**，天顶约 $2.4\text{ m}$ 的对流层延迟、以及低仰角约 10 倍的映射放大全部消失。

### 2. 电离层：100 km 几乎没改善
TEC 主要分布在 $>100\text{ km}$ 的 F 层（峰值约 $250\text{–}350\text{ km}$），100 km 以下的电子含量很少。所以接收机放在 100 km，穿过电离层的柱含量和地面**几乎一样**：

$$\Delta\rho_{ion} = \frac{40.3}{f^{2}}\cdot \text{TEC}$$

$1\ \text{TECU}$ 在 L1（$1575.42\text{ MHz}$）约 $0.162\text{ m}$；典型 TEC 为 $10\text{–}50\ \text{TECU}$ → 天顶 $1.6\text{–}8\text{ m}$，低仰角再放大约 3 倍 → **几十米**。双频可消除一阶项 $>99\%$，但 100 km 处电离层误差与地面**同量级**，仍是单频接收的主导误差。

### 3. 几何构型：略优，但有坑
从高度 $h$ 看地球的地平线下沉角为

$$\theta=\arccos\!\frac{R}{R+h}\approx 10.1^\circ \quad (h=100\text{ km})$$

即能"看到" $-10^\circ$ 仰角的卫星，可见星更多。**但这些负仰角射线几乎贴着地球边缘掠过，穿过整层大气，延迟与弯曲极大**，实际会被仰角掩模滤掉。因此 100 km 的**有效**几何与地面差别不大，DOP 略好。

### 4. 反而恶化的因素
- **高动态**：亚轨道/轨道速度下多普勒可达 $\pm$ 几十 kHz、多普勒率几百 Hz/s，超出普通接收机跟踪环带宽，容易失锁。
- **天线与信号**：高空气球/高超声速平台常只能装低增益、空域受限的天线。
- **电离层闪烁**：高纬或赤道区加剧，穿越电离层时相位快速抖动。

<summary><b>二、分区间详细说明（点击展开）</b></summary>

- **$0\text{–}100\text{ km}$（对流层内 → 热层底）**：随高度上升对流层延迟单调减小，到 $\sim50\text{ km}$ 基本可忽略；电离层几乎不变；无多径。净效果：**缓慢变好**。

- **$100\text{–}500\text{ km}$（LEO）**：逐渐升到 F 层峰值以上，头顶以上的 TEC 大幅减少，电离层延迟明显下降；无对流层、无多径，几何好。这是**精度最优区**，LEO 卫星的 GNSS 精密定轨可达 **厘米级**（如 GRACE、CHAMP、Sentinel）。

- **$500\text{–}3000\text{ km}$**：电离层误差很小，几何仍可用。这一段就是 GPS 定义的 **空间服务域（SSV，约 $3000\text{–}36000\text{ km}$）** 下边界附近，信号可用性开始成为约束。

- **$>3000\text{ km}$ 直至超过星座高度 $\sim20200\text{ km}$**：头顶方向的卫星逐渐消失——你比卫星还高，只能接收**从地球另一侧"漏"过来的主瓣边缘/旁瓣**信号：信号弱、可见星少、构型极差，DOP 巨大，**精度骤降**。这是真正"越高越差"的区间。

</details>

## 三、一句话回答

在你的场景（100 km 附近的高空平台）里，**精度不会因为高度而明显变差**：丢掉了对流层误差（变好），电离层误差却和地面一样（没变好），几何略优但低/负仰角卫星不可用。真正"越高越差"发生在**数千公里以上、尤其高于导航星座**时，那时几何构型和信号可用性才彻底崩坏。

> 想让 100 km 处精度再上一层，关键不是"避开高度"，而是：**双频消电离层** + **合理仰角掩模** + **适配高动态的接收机跟踪环**。

# 结论

**速度本身不会直接降低 GNSS 定位精度**——观测方程里根本没有速度项。真正让精度下降的，是与高速**绑定出现的两件事**：高动态（大加速度/加加速度）和（在大气层内时的）**等离子鞘套**。在 100 km 这种稀薄大气里以 Mach 19 巡航，只要接收机是双频高动态型，仍能做到**分米—米级**。

---

## 一、为什么"速度"不进入误差方程

伪距观测方程：

$$\rho = \lVert \vec r_s(t_s) - \vec r_r(t_r)\rVert + c(\delta t_r - \delta t_s) + I + T + \varepsilon$$

右边没有速度项。电离层 $I$、对流层 $T$、多径、钟差、星历误差都不因平台速度而改变。速度本身反而是**可解的量**，GNSS 测速精度很高（静态 cm/s 级）。

---

## 二、随速度"耦合"恶化的因素

### 1. 多普勒与多普勒率 → 跟踪环（核心机制）
相对视线速度最大可达约 $10\text{ km/s}$（卫星 $3.9\text{ km/s}$ + 平台 $\sim7\text{ km/s}$），L1 多普勒：

$$f_d^{max}=\frac{10^4}{3\times10^8}\times1.575\times10^9\approx 52.5\text{ kHz}$$

多普勒率 $\dot f_d \approx \dfrac{a_{los}}{c}f$：

| 视线加速度 | 多普勒率 |
|---|---|
| $50\ \text{m/s}^2$（约 5 g，上升段） | $\sim262\ \text{Hz/s}$ |
| $200\ \text{m/s}^2$（再入减速） | $\sim1\ \text{kHz/s}$ |

普通 3 阶 PLL（带宽 ~18 Hz）只能跟住几百 Hz/s → 上升段通常没问题，**再入段就可能失锁**。

更关键的是**带宽–噪声折中**：要跟高动态必须加宽环路带宽 $B_n$，而热噪声相位抖动

$$\sigma_\phi^2 \propto \frac{B_n}{C/N_0}$$

带宽越宽、噪声越大、测距/测相精度越差。**这才是"动态 → 精度下降"的真正来源。**

### 2. 大加速度 / 加加速度
环路阶数有限，高阶动态（jerk）产生稳态误差；Kalman 滤波为跟上机动必须放大过程噪声，平滑/平均能力随之下降。

### 3. 等离子鞘套（大气层内高马赫，主导因素）
气动加热使激波层电离，等离子频率 $f_p \approx 8.98\sqrt{n_e}\,\text{Hz}$（$n_e$ 单位 $\text{m}^{-3}$）。当 $f_p$ 逼近 L 波段（$1.5\text{ GHz}$）时信号被衰减/反射，形成**再入黑障**，可能直接收不到星。严重程度取决于高度与密度：**100 km 很稀薄、鞘套较弱；真正穿过 60–80 km 稠密层时最严重。**

### 4. 相对论与地球自转（正确建模则无影响）
- 接收机钟的狭义相对论频移 $\dfrac{v^2}{2c^2}\approx2.7\times10^{-10}$（$7\text{ km/s}$），表现为钟漂，被钟差未知数吸收。
- 信号传播约 $67\text{ ms}$ 内平台移动可达 $\sim$ 数百米，但标准模型以**接收时刻**位置结算 + Sagnac 改正即可，**建模正确就没有额外误差**。

### 5. 天线与平台约束
气动外形限制天线增益与安装位置；气动加热还会影响天线与接收机工作。

### 6. 载波相位"相干时间"变短
静态接收机可长时间平均获得 mm–cm 级；高速平台相干时间短、易周跳、观测弧段短，PPP/RTK 的平滑收益大幅缩水——**精密定位层面精度确实下降**。

## 四、一句话回答

"速度越快精度越低"**并不准确**。速度本身不影响观测精度，精度下降来自三件事：① 为适应高动态而加宽跟踪环带宽引入的噪声；② 大加速度导致的失锁/周跳；③ 稠密大气中高马赫产生的等离子鞘套。所以在 100 km 稀薄大气、Mach 19 的条件下，主要考验的是**接收机的高动态跟踪设计**，而不是几何或大气误差——速度和高度都不是决定精度的直接变量。

# 先给结论

**民航不是"迷信"地面导航，而是因为 GNSS 天然不适合当唯一导航源。** 航空要求的是"完整性、连续性、可用性"三性同时达标，而 GNSS 是一个**信号极弱、易被干扰/欺骗、且是单一共模源**的系统。地面 VOR/DME/ILS 网络的作用是**保底与冗余多样性**。

至于"地面导航全失效能不能靠机载设备不降级"——**要分阶段看**：

- **航路 / 终端区**：能，GNSS + IRS 可继续 RNP 导航，**基本不降级**。
- **精密进近 / 自动着陆（CAT II/III autoland）**：**会降级**。因为机载 GNSS 单独不满足 CAT III 的完整性与连续性，autoland 传统上必须靠 ILS 或 GLS(GBAS)。

---

## 一、为什么民航仍要依赖无线电导航而不是纯 GPS

### 1. GNSS 的先天脆弱性
- **信号极弱**：到达地面的 GPS L1 C/A 约 $-158\ \text{dBW}$（$\approx-128\ \text{dBm}$），**低于热噪声底**，靠扩频增益才捞得出来。所以极易被干扰（jamming）和欺骗（spoofing）。
- **共模失效风险**：所有卫星、所有信号、所有接收机都是**同一个来源**。一个区域性干扰机就能瘫痪整个区域的 GNSS——这正是近年中东等地真实发生的事。
- **空间天气**：电离层风暴会显著影响单频信号。
- **可用性波动**：单星座单频时，RAIM 故障检测有时**卫星数不够**，无法保证完整性。

### 2. 航空的"三性"要求极严
| 指标 | 含义 | 纯 GNSS 单机 |
|---|---|---|
| 完整性 Integrity | 出错时能否及时告警 | 需 RAIM/SBAS/GBAS |
| 连续性 Continuity | 进近过程中不中断 | 单频难保证 |
| 可用性 Availability | 任何时刻能用 | 几何受限 |

精密进近要求完整性达 $10^{-7}$ 量级/进近，CAT III 更严。**纯 GNSS 自己达不到**，必须靠 SBAS（WAAS/EGNOS，星基）或 GBAS（地基）增强。

### 3. 认证、法规与基础设施惯性
- 传统无线电导航（VOR/DME/ILS/NDB）有几十年的适航与运行批准，网络庞大。
- 法规（ICAO/FAA）强调**"导航源多样化"**，不把鸡蛋放一个篮子。
- 地面一次雷达监视**完全不依赖机载 GNSS**，是 ATC 保底。

### 4. 过渡成本
VOR 正在大面积退役（被 GNSS + DME/DME 替代），但过渡期内必须并存，且很多机场仍以 ILS 为精密进近主力。

---

## 二、地面无线电导航"全部失效"时，机载设备能撑到什么程度

关键是把"哪些设备依赖地面"分清楚：

| 设备 | 依赖地面？ | 地面导航全失效后的状态 |
|---|---|---|
| GNSS 核心星座（GPS 等） | **否** | ✅ 仍可用 |
| SBAS（WAAS/EGNOS） | 否（依赖 GEO 卫星） | ✅ 仍可用（可达 LPV） |
| GBAS / GLS | **是** | ❌ 失效 |
| ILS / VOR / DME / NDB / TACAN | **是** | ❌ 失效 |
| IRS / INS（惯导） | 否（机载） | ✅ 可用，但**会漂移** |
| 大气数据 / 气压高度表 / 无线电高度表 | 否 | ✅ 可用 |

### 分层结果

<details>
<summary><b>点击展开：不同飞行阶段的能力对照</b></summary>

| 阶段 | 依赖 | 地面导航全失效后 |
|---|---|---|
| 航路 / 终端区 RNP 2/1 | GNSS + IRS | ✅ 继续，不降级 |
| RNP AR APCH (0.1–0.3 NM) | GNSS + IRS | ✅ 可继续 |
| LPV 进近（最低约 200 ft） | SBAS | ✅ 若 SBAS 在，可继续 |
| LNAV/VNAV（APV，约 250 ft+） | 纯 GNSS | ✅ 可继续，但最低标准较低 |
| CAT I（约 200 ft） | ILS / GLS | ❌ 失效则降级 |
| **CAT II/III autoland（0–50 ft）** | **ILS 或 GLS** | ❌ **必须降级** |
| 监视 | ADS-B（依赖 GNSS）/ 一次雷达 | 一次雷达保底 |

</details>

### 关键结论

1. **地面无线电全失效、但 GNSS 正常**：大部分运行可继续，**但精密进近与自动着陆会降级**。autoland 必须靠 ILS/GLS，两者都没了就做不到"不降级"。
2. **如果 GNSS 同时被干扰**（战区常见共模场景）：只能靠 IRS，随时间漂移（现代激光陀螺约 $0.5\text{–}2\ \text{NM/h}$），最终降级到非精密进近甚至目视/备降。
3. **IRS 的角色是"桥接"**：它不依赖外部的特性，使它能在这类场景中维持短时可用，但无法长期替代地面或星基的绝对基准。

## 三、现实中的验证

- 中东地区曾出现大范围 **GPS 干扰/欺骗**，机组普遍**转回传统导航程序**——这正是"多样性"设计的价值。
- FAA 推动 VOR 退役时，安全论证的核心争点就是：**GNSS 被干扰时还剩多少地面备份**。
- 业界在讨论 **eLoran** 等地基备份，作为 GNSS 的补充（覆盖有限）。

---

## 四、未来趋势

- **多星座多频**（GPS + Galileo + GLONASS + BeiDou）：显著提高抗干扰与可用性，但不解决"同一物理原理"的共模问题。
- **ARAIM**（Advanced RAIM）：有望支持 LPV-200、CAT I 级别。
- **CAT III autoland**：短期内仍离不开 ILS 或 GLS 提供的**地面完整性监测**。

---

## 一句话回答

民航依赖无线电导航，不是因为 GPS 不准，而是因为 **GPS 不够"抗打"**：信号弱、可被干扰欺骗、且是单一共模源，达不到航空精密进近所需的完整性/连续性/可用性。地面导航全失效时，**航路和 RNP 进近可以靠机载 GNSS+IRS 不降级继续**，但 **CAT II/III 自动着陆一定会降级**——因为那一档的完整性基准，目前只能由地面（ILS/GLS）或星基增强来提供。
