## 先说结论

中转服务器（frps / DERP）的瓶颈**只有两个：回国线路质量和流量额度**。CPU/内存完全不重要，1核1G 跑 frps 能转发几百 Mbps。所以别为“高配”付钱，把钱花在**带宽、线路和流量**上。

一句话推荐：
- **省心、自用、几个人**：腾讯云或阿里云**香港轻量**，约 ¥24–40/月（20–30Mbps 峰值 + 1TB/月）。
- **极致省钱、能忍延迟**：RackNerd / CloudCone 年付 $11–20（美西，约 150–200ms）或 **Oracle Cloud 永久免费**（首尔/大阪，需抢）。
- **不想买机器**：先试 **Cloudflare Tunnel + Tailscale 官方 DERP**，很可能你根本不需要中转机。

## 一、先确认：你可能不需要这台机器

| 需求 | 免费替代 | 说明 |
|---|---|---|
| 把内网 HTTP/SSH 服务暴露出去 | **Cloudflare Tunnel**（`cloudflared`） | 完全免费、无需公网 IP、无需买 VPS，替代 90% 的 frp 场景；但只能走 HTTP/HTTPS/SSH，不能做通用 UDP/TCP 中转 |
| 异地组网 | **Tailscale / ZeroTier 官方中继** | 官方 DERP 免费且全球有节点；打洞成功时根本不走中继 |
| 家宽有公网 IPv4 或 IPv6 | **直接端口映射 / DDNS** | 国内三大运营商 IPv6 已普及，Tailscale 支持 IPv6 直连打洞，零成本 |
| 大文件/视频中转 | 不建议自建 | 流量费比机器贵，这类场景优先考虑直连或对象存储 |

**自建 DERP 的真实价值**：国内直连官方 DERP 通常绕香港/东京，晚高峰丢包严重。自建香港或日本 DERP 能把延迟压到 30–60ms，这才是值得花钱的理由。

> 部署前先跑 `tailscale netcheck`，看当前实际用的哪个 DERP、延迟多少——很多人发现其实够用。

---

## 二、选型的核心指标

1. **回国线路**（最关键）：CN2 GIA、9929、CMIN2、香港/日本/韩国 BGP 优先；普通国际线路晚高峰可能从 100Mbps 掉到几百 KB/s。
2. **流量额度与超额价格**：DERP 中继大流量时月流量轻松上 TB。阿里云轻量超额约 ¥0.8/GB，**流量超了账单会崩**。
3. **峰值带宽 vs 保证带宽**：“30Mbps 峰值”≈ 3.75MB/s，多人看视频会卡。
4. **是否需要备案**：国内机房用 80/443 必须备案；境外机房无此限制，frp 走高端口 + IP 甚至不需要域名。

## 四、两种用途的部署差异

**frps（简单）**
- 只需开放一个端口（如 `7000`）+ 转发端口，用 IP 直连即可，**不需要域名和证书**。
- 成本几乎全在带宽上。

**自建 DERP（要求多）**
- **必须有域名 + 有效证书 + 443/TCP**（DERP 是 HTTPS/WSS，Cloudflare 代理会中断长连接，要 DNS 直连）。
- 用官方 `derper` 或 `tailscale/derper` 镜像，配置 `verify-clients` 防止被人白嫖带宽。
- 在 Tailscale ACL 里通过 `derpMap` 指定自定义中继。

<details>
<summary><strong>五、避坑清单（点开）</strong></summary>

- **流量超额刺客**：香港轻量套餐外流量按 GB 计费，DERP 全量中继 + 看视频能一夜刷爆。买之前先看超额单价。
- **“峰值带宽”是共享的**：晚高峰实际可能只有标称的 20%。
- **小厂超售**：香港/日本低价小鸡晚高峰掉到 1Mbps 是常态，别买“终身/永久低价”。
- **DDoS 停机**：中转机端口暴露，被打就封 IP（小厂尤其），最好只开必要端口 + 用非标端口。
- **Oracle 免费机有回收风险**：闲置或违反条款会被清理，重要链路留备用。
- **别买“大内存”**：中转不吃内存，2C2G 甚至 1C1G 完全够。
- **美西 vs 欧洲**：Hetzner 流量大但 200ms+ 延迟，只适合大文件，不适合远程桌面/游戏。
- **国内机备案**：用域名 + 80/443 必须 ICP 备案，否则会被拦。

</details>

## 我的建议

如果你是**个人自用 + 少设备**：直接上**腾讯云或阿里云香港轻量 ¥24/月那一档**，一个机器同时跑 frps + 自建 DERP，30Mbps 够 2–4 人日常用，关掉不必要的转发端口。这是“省心/性能/价格”最平衡的点，别为省几十块钱去折腾年付美西小鸡。

如果**只想零成本验证**：先用 Cloudflare Tunnel 替代 frp，Tailscale 官方 DERP 兜底，观察 `netcheck` 数据，确认确实需要低延迟中继再买机器。
