## 先给结论

**能实现，但“稀疏”必须落在具体环节，而不能笼统地说“把 PME 换成稀疏矩阵/稀疏 FFT”。** 按可行程度分三档：

| 层次 | 可行度 | 说明 |
|---|---|---|
| 实空间部分稀疏化（近邻表、紧凑支撑插值） | ✅ 已经在用 | PME 的实空间部分本来就只发生在一小部分近邻上，实际就是稀疏的 |
| 频域剪枝、降低所需模式数（pruned FFT、更好的核函数、PSWF 等） | 🟡 可行且有真实收益（约 1.5–3×） | 约 80–95% 的傅里叶模在数值上没有贡献，因此有剪枝空间 |
| 用稀疏数据结构的 FFT 或稀疏矩阵乘法替代 3D FFT 本身 | ❌ 对常规致密体系基本不成立 | 电荷网格是**满的**，势场输出也是**满的**，FFT 是稠密进、稠密出 |
| 换成分层/低秩算法（MSM、FMM、Kronecker-PME、张量列） | ✅ 可行，成熟度不一 | 这才是工程上实现线性复杂度（O(N)）的主流路线 |

## 关键理由：PME 中哪一步是“稠密的”

PME 一轮的计算如下（括号中是复杂度）：

1. **电荷铺展**：每个原子只影响 $P\times P\times P$ 个网格点（$P=4\sim6$ 的 B 样条支撑）→ 散射累加，**天然稀疏**，成本 $O(NP^3)$
2. **3D FFT**：$O(M^3\log M^3)$，$M^3$ 为网格点总数 → **唯一稠密、全局耦合的一步**
3. **乘影响函数** $B(\mathbf{k})$：在 k 空间是对角的，不构造矩阵，只做逐点乘法
4. **逆 FFT + 求导插值**：紧凑支撑，**稀疏**

因此，唯一值得讨论的点只有第 2 步。而第 2 步之所以不能简单地稀疏化，是因为：

<details>
<summary><b>为什么不能稀疏：两个定量反证（点击展开）</b></summary>

**(a) 空间域不稀疏。** 稀疏 FFT 要求输入输出是 $k$-稀疏的。buck 水这类致密体系里，原子均匀铺满整个盒子；当 $NP^3 \gtrsim M^3$ 时，网格占用率接近 100%（例如 $L=6.7$ nm、$h=0.125$ nm 时 $M^3\approx1.6\times10^5$，而 1 万个水分子按 $P=4$ 也铺满全部网格）。势场输出更是布满整个网格，**两个方向都不稀疏**。只有在高度稀释体系（真空/气相、大空腔、稀溶液）里，空间稀疏性才成立。

**(b) 频域“物理上稀疏”，但这是剪枝问题，还不是稀疏 FFT 问题。** 真正需要的模只有 $|\mathbf{k}|\le k_{\max}$ 的球内部分。设 $s = k_{\max}/(\pi/h)$（即相对于 Nyquist 的截断比例，PME 常取 0.4–0.7 来做过采样）：

$$\frac{\#\{|\mathbf{k}|\le k_{\max}\}}{M^3}=\frac{(\pi s)^3/6}{\pi^2}=\frac{\pi}{6}s^3\approx 0.52\,s^3$$

$s=0.5$ 时只有约 **6.5%**；$s=0.7$ 时约 **18%**。也就是说，$M^3\log M^3$ 的变换里有八成以上的模从未被用到。**这是“剪枝”（pruned / partial FFT）的有效空间，而不是数据依赖的稀疏 FFT 空间。**

代价是：一是剪枝破坏基-2/基-r 的规整结构，实际加速远低于“跳过 93% 工作量”的理想值；二是大规模并行下 3D FFT 的瓶颈是 **MPI 通信与带宽**而不是浮点运算（GROMACS 2022 的 phase breakdown 已明确指出这一点），剪枝省下的 flops 难以转化为墙钟时间。

</details>

## 目前在用的四类“稀疏/分层”路线

### 1. 分层 O(N) 方法，直接替代 PME（最成熟）

多级求和（MSM）用**带状的插值算子**在多层格点上做插值/限制，不用 FFT，复杂度 $O(N)$。

- `LAMMPS`：`kspace_style msm`
- OpenMM 生态中的 MSM kernel（Hardy/Skeel 系）
- **msmJAX**（2025）：JAX 实现、GPU、可微分、线性标度，专为与 MLIP 结合设计

**Fast Multipole（FMM）** 系列（ScalFMM、ExaFMM、**ANKH** 2023）是 FFT-free 的 $O(N)$ 插值 Ewald，在中小体系上打不过 PME，在大规模分布式上更占优势。

### 2. 用低秩/结构化算子替换 FFT（不需要“稀疏”）

- **Kroneckerised PME**（2026）：用 Sum-of-Kronecker-Products 替换 FFT，牺牲 linearithmic 复杂度换取并行友好性
- **DMK**（dual-space multilevel kernel-splitting）：FMM + Ewald + MSM 的混合框架
- **张量列/量子化张量（quantics TT）** 的格点求和：对格点数可到 $O(\log N)$，但目前主要用于静态格点势，还没进入带移动电荷的 MD 生产程序

### 3. 频域剪枝与更优核函数（收益最“便宜”）

- 更好铺展核 → 降低所需 $k_{\max}$。例如 **PSWF-LR**（2026）用椭球波函数做 mollification，显式减少所需傅里叶模，报告约 3× 加速，并突破常规 MLIP 长程项的内存上限
- IK 微分、解析影响函数、混合精度 FFT
- 这些是**正交于**“稀疏”的独立优化，通常比稀疏化更值得先做

### 4. MLIP 场景：真正的“稀疏”发生在别处

2025–2026 年的趋势是 **可微分 PME**（`torch-pme` / `jax-pme` / DIMOS），而不是稀疏 PME。此时稀疏性体现在：

- 近邻图（实空间）天然稀疏
- 电荷稀疏性：大量中性原子对长程项的贡献 $\approx 0$，可整块跳过
- 可学习长程模块（Latent Ewald Summation、EquiEwald）把长程变成低秩/稀疏 k-space 通道

## 不该做/做了会出事的做法

<details>
<summary><b>四条硬约束（点击展开）</b></summary>

1. **误差预算太紧**：PME 的目标是 $10^{-4}\sim10^{-5}$ 的相对力误差。任何数据依赖的截断都会引入结构化噪声。
2. **平滑性 > 渐近复杂度**：稀疏化必须保持 **pair 对称 + $C^1$ 光滑**，否则能量漂移（energy drift）会毁掉 NVE/NVT 长轨迹。这是 90% 的“稀疏 PME”原型失败的真实原因。
3. **相对收益区间很窄**：$N$ 在 $10^4\sim10^6$ 的致密均相体系里，PME 已接近该精度下的最优；稀疏/分层方法通常要体系极不均匀或极大规模才追上。
4. **可移植性**：剪枝和稀疏格式难以同时适配 FFTW/MKL/cuFFT 的快速路径，工程成本高。

</details>

## 按场景的选择建议

| 你的场景 | 建议 |
|---|---|
| 致密均相体系，$N<10^6$ | 保留 PME/P3M；优先做核函数优化 + 频域剪枝 + 混合精度 |
| 超大 $N$、分布式超算 | 换 **FFT-free**：FMM / MSM / ANKH / Kronecker-PME，不必走“稀疏 FFT”路线 |
| 稀释/真空/大空腔/界面 | 空间稀疏性成立 → 自适应网格、NUFFT、2D-Ewald；这里有真实收益 |
| MLIP/可微框架 | 用可微分 PME + 电荷稀疏 + 近邻图稀疏；长程用 LES/PSWF-LR |
| 只有少量带电组分 | **分而治之 Ewald**：只对带电子系统跑 PME，其余用 reaction-field 修正 —— 这是工业界最实用的“稀疏策略” |

**一点需要澄清的地方**：你说的“稀疏策略”具体指哪一种？

1. 稀疏**FFT**/稀疏网格（算法层）
2. 稀疏**近邻表/空间哈希**（实现层，GPU 内核）
3. 稀疏**电荷/子系统**（物理层，跳过无贡献的原子）
4. MLIP 里的**稀疏图表示**（表示层）

这四种的可行性差异很大：第 2 种实际没有稀疏化空间（本来就稀疏）；第 1 种收益有限且要承担平滑性风险；第 3、4 种是当前真正有空间且已在生产的做法。告诉我你的目标（体系规模、精度要求、是否 MLIP、目标硬件），我可以给出更具体的方案与实测预期。
