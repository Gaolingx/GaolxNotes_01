# 中国市场 Android 手机的预装组件数据外传：公开可核验的证据

**先说结论**：公开、可复核的证据主要来自一项 2023 年对国行固件的系统级抓包研究（爱丁堡大学 / 都柏林圣三一学院，arXiv:2302.01890）。该研究发现：**即使用户在开机时拒绝「发送使用与诊断数据」、不登录任何厂商账号、不启用云服务、不使用第三方可选服务**，小米、OPPO/realme、一加三家国行机型的系统应用与系统服务仍会向厂商服务器、**中国移动/中国联通**的设备管理服务器、以及高德/百度等第三方域名持续上报，内容包括 IMEI、IMSI、手机号、GPS 坐标、基站 LAC/CID、周边 Wi-Fi 列表、已安装应用清单，甚至**通话与短信的对象号码和时长**。之后没有同类的公开复测（截至 2026 年，arXiv 上仍无更新版本），因此下面区分「已实测确认」与「属行业结构推断」。

## 一、已实测确认：哪些数据 → 哪些服务器

测样为 **Redmi Note 11（MIUI）、OnePlus 9R、realme Q3 Pro（ColorOS）** 国行固件，全部出厂重置、无账号、关闭分析开关。

### 1. 设备标识类（几乎所有通道都在带）

| 数据 | 去向（实测域名） | 触发时机 |
|---|---|---|
| IMEI | 厂商服务器 + **中国联通** `dm.wo.com.cn` + **中国移动** `a.fxltsbl.com` | 出厂重置后、插入 SIM 时 |
| OAID / VAID / Android ID / 临时 ID | `tracking.miui.com`、`i6.weather.oppomobile.com`、`confe.dc.oppomobile.com` 等 | 常驻后台周期上报 |
| **已安装应用列表** | 中国移动 `a.fxltsbl.com/accept/sdkService`、厂商商店/更新通道 | 周期性；用途厂商未说明 |
| 机型、CPU、屏幕、系统版本、补丁级别 | 各家更新与统计接口（如 `log.avlyun.com` 载荷内含 `OnePlus9R_CH`、内核版本） | 每次上报都附带 |

### 2. 位置类

| 组件 | 端点 | 内容与频率 |
|---|---|---|
| 高德定位服务 `com.amap.android.location`（预置，**默认授予后台定位**） | `apsrgeo.amap.com/rgeo/r`、`aps.amap.com/APS/r` | GPS 坐标、MCC/MNC、LAC/CID、当前 Wi-Fi 的 MAC+SSID、**周边 Wi-Fi 列表**；约 **13 次/天**，附 `adiu` 长期标识 → 可还原轨迹 |
| ColorOS 天气服务 `com.coloros.weather.service` | `i6.weather.oppomobile.com` | 经纬度 + OAID/VAID，约 **5 次/天**；天气 App 从未被打开 |
| 小米统计 `com.miui.analytics` | `tracking.miui.com/track/v4` | MCC/MNC、GPS、周边 Wi-Fi（含信号强度）；**即使开机时关闭了定位，定位服务仍会运行并上传** |
| 小米网络定位 `com.xiaomi.metoknlp` | `api.map.baidu.com/geocoder/v2`（`from=BaiduNLP`） | GPS 坐标换取街道信息（该请求内未见设备标识） |
| Wi-Fi 安全检测 | `log.avlyun.com/logupload` | 当前 SSID + MAC |

### 3. 用户画像与社交关系类

- **小米**：`tracking.miui.com/track/v4` 在设置、笔记、录音机、电话、短信、相机被打开时逐条上报 `pkg`、首次启动时间、使用起止时间、Activity 停留时长，并携带 `imsis` 字段 → 连续使用会形成**行为链条**。论文明确指出：**关闭「发送使用与诊断数据」不影响这类上报**。
- **一加 / realme**：预置电话 `com.ted.number` 与短信 `com.android.mms` 向 `sms.ads.heytapmobi.com/new/v5/phone` 上报**本机号码、对方号码、通话时长、响铃时长、最近联系时间、是否在通讯录**。这直接泄露社交关系图。
- **运营商 SDK**：`com.mobiletools.systemhelper`（联通）在出厂重置后 **10 分钟内**上传手机号、IMSI、ICCID、位置；`com.miui.dmregservice` / `com.coloros.regservice`（移动）在**未与该运营商签约、甚至未插卡**时仍上传 IMEI。

### 4. 广告通道

`api.ad.xiaomi.com/brand/pushConfig` 的载荷中，国行固件为 `{"country":"CN","isPersonalizedAdEnabled":true}`，国际版为 `false` —— 该字段**不受用户退出「使用数据/体验计划」控制**，由后端决定。

> 论文另一组对比：国行固件预置的**第三方**应用数量是国际版的 **3–4 倍**，被授予的权限是 **8–10 倍**；且厂商会**默认预授权**运行时危险权限（例如 `com.tencent.soter.soterserver` 被自动授予 17+ 项，含读短信、读通讯录、读通话记录）。

## 二、为什么「没授权」也会传

技术上并不需要用户点同意，原因有四点，与具体品牌无关：

1. **预置在 `/system/priv-app`**，可用普通应用申请不到的 `privileged` 权限；
2. **厂商把危险权限「默认授予」**，用户从未看到弹窗（论文用 `dumpsys` 在纯出厂状态下验证）；
3. **同意是「打包式」的**：开机向导把「系统改进」「运营商服务」「定位」捆在一个「不同意就不能用手机」的界面上，且没有拒绝按钮；小米的 `com.miui.analytics` 甚至无法在「设置-应用」中被管理；
4. **载荷加密**：AES 密钥硬编码在 APK、或把密钥拼在密文尾部、或 RSA 封装，使普通抓包看不到内容，也让「用户自查」几乎失效。

法律上，这类行为落在两个文件的交叉处：
- 《个人信息保护法》第 13、14、17 条：处理个人信息需**单独、明确、自愿**的同意，且应告知接收方；
- 工信部、国家网信办《关于进一步规范移动智能终端应用软件预置行为的通告》（工信部联信管函〔2022〕269 号，2023-01-01 起执行）：**除「基本功能软件」（系统设置、文件管理、摄录、通话/短信/通讯录/浏览器、应用商店）外，预置应用必须可卸载**，且预置行为须遵循「最小必要」、保障知情权与选择权。

按此标准，「天气」「高德定位」「Wi-Fi 安全检测」「运营商注册服务」既不属于基本功能软件，其后台定位与标识符上报也很难解释为「最小必要」。**但要注意**：以上是研究者在 2023 年观测到的行为，厂商固件迭代频繁，公开证据不足以断言今天每台机器仍如此，也不足以直接认定某款机型违法——这需要监管抽检结论。

## 三、证据的边界（重要）

<details>
<summary><b>方法、样本与不确定性</b></summary>

- 样本仅 **3 款机型**（小米/OPPO 系/一加），未覆盖华为、荣耀、vivo、魅族、中兴、传音等；但华为、vivo、荣耀的系统服务结构（云空间、推送、统计、广告、系统更新 + 运营商 SDK + 预置三方 SDK）与样本同源，**很可能**存在同类上报，不过这一点没有被公开抓包验证，属推断而非结论。
- 数据经 **mitmproxy + Frida/EdXposed** 获取，厂商侧存在硬编码密钥、自定义协议，少数通道可能未被解出 → **实际外传量只会更多，不会更少**。
- 论文的威胁模型刻意排除了云服务、账号登录、可选三方服务，因此结论是**下限**（"privacy-aware user" 的基线）。
- 作者明确指出：国行固件的所有端点**都位于中国境内**（PIPL 跨境限制所致）；而一年前采集的国际版 traces 中，小米域名曾解析到**新加坡** IP——即「出境后仍被追踪」主要不是靠境外服务器，而是靠**同一批境内服务器 + 设备继续联网**。
- 目前**不存在**覆盖全品牌的官方或第三方定期审计报告；2026 年的执法通报（网信办/工信部/公安部「个人信息保护系列专项行动」逐月通报数十款 App）针对的是**应用**，不是**预置系统服务**。

</details>

## 四、如果你想自己验证或收敛

<details>
<summary><b>可操作清单</b></summary>

1. **先关再测**：关闭「用户体验改进计划」「发送诊断数据」「个性化广告」，然后用 `PCAPdroid`（免 root，抓 App 级流量）或 PC 端 mitmproxy 观察是否仍有周期性 POST——按论文结论，**关掉开关不等于停止上报**，这一点很值得亲自复现。
2. **看域名而不是看内容**：即便载荷加密，DNS/SNI 也能暴露接收方。重点盯 `tracking.*`、`*.ad.*`、`log.*`、`weather.*`、`amap.com`、`map.baidu.com`、`dm.wo.com.cn`、`fxltsbl.com`、`avlyun.com` 这类主机名。
3. **飞行模式/无卡对照**：论文中「未插该运营商 SIM 卡仍上传 IMEI」是判定「非必要收集」的最有力证据。
4. **卸载权**：依 269 号通告，天气、音乐、浏览器之外的预置应用都应可卸载；若「设置-应用」里只能停用不能卸载，本身就是可投诉的点（12321 / 当地通管局）。
5. **降低指纹熵**：重置广告标识符（OAID）、关闭精确定位、关闭 Wi-Fi 扫描（「Wi-Fi 扫描始终可用」是周边 AP 列表的来源）。

</details>

---

**一句话总结**：在国行 Android 生态里，「未授权」不等于「未采集」。已被实测确认的外传组合是——**IMEI/IMSI/OAID + GPS 与基站/Wi-Fi 指纹 + 应用列表与使用时长 + 手机号与通话短信元数据**，流向**厂商统计与广告域（`tracking.miui.com`、`api.ad.xiaomi.com`、`i6.weather.oppomobile.com`、`sms.ads.heytapmobi.com`）、第三方服务（`amap.com`、`api.map.baidu.com`、`log.avlyun.com`）、以及运营商设备管理平台（`dm.wo.com.cn`、`a.fxltsbl.com`）**；且这些行为**不受相关隐私开关约束**、设备出境后**照旧持续**。
