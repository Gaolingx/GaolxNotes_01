# 零基础前后测出题指南

## 🧑‍💻 User

如果我要做前后测，给初学者或者0基础做测验，能测到知识点的学习或者逻辑思维，但是又不能变成完全的逻辑题目（因为这样不用学就能知道答案了），怎么出题目比较好呢

---
## 😀 默认助手 (7)

## 一句话结论

**别去避开“直觉答案”，要去让“直觉答案变成错的”。**

你觉得“纯逻辑题不用学就能答对”，本质是：**不学的人凭直觉也能选到正确答案**。所以好题的设计判据可以反过来写成一句可执行的话：

> 每道题都要有一个“聪明的外行一定会选的选项”，而这个选项必须是错的。
> 直觉答案 $\neq$ 正确答案 $\Rightarrow$ 这题只能靠学。

这一条同时解决了你两个担心：它既不是纯逻辑题（因为外行会答错），也不是纯记忆题（因为光背结论不一定选得对，得理解为什么）。

---

## 一、先说清楚前后测各自在干什么

很多人出题出歪，是因为把前测当成了“迷你后测”。

| | 前测的功能 | 后测的功能 |
|---|---|---|
| 目的 | 定位起点、**暴露直觉/迷思** | 测增量、测迁移 |
| 期望表现 | 允许大量错误，**但不要大面积空白** | 显著高于前测，且难题分层 |
| 关键指标 | 错误选项的**分布**（错在哪一类） | 与前测的**同维度差值** |
| 常见事故 | 太难 → 学生挫败、乱填 | 太简单 → 天花板，人人满分，测不出东西 |

0 基础学员的前测本来就会贴地板（floor effect），这不是问题——**问题是你从前测里读不出任何信息**。所以前测题必须做到一件事：**没有任何知识的人也能给出一个答案**（哪怕是错的）。这就是为什么“直觉陷阱题”在前测里特别宝贵。

---

## 二、五种主力题型（可迁移的“配方”）

这五种题型的共同点是：**推理形式极简（1～3 步），但每一步的“零件”必须是刚学的知识点**。用个比喻：逻辑是螺丝刀，知识是被拧的螺丝。螺丝刀谁都会用，但手里没那颗螺丝就什么也拧不成。

| 题型 | 测什么 | 为什么不会变成纯逻辑题 |
|---|---|---|
| **① 最小对比题** | 是否抓住关键特征 | 两题只改一个条件，必须真的知道“哪个条件是关键的”才能判断翻转 |
| **② 陌生情境迁移** | 规则的可迁移性 | 情境是没见过的，规则是课上的；外行没有规则 |
| **③ 两段式（答案＋理由）** | 是否“蒙对” | 选对答案但理由错 = 没学会，直接扣分 |
| **④ 纠错题（找错步）** | 程序性知识的内部结构 | 需要知道正确步骤才能定位错误 |
| **⑤ 预测题（给条件问结果）** | 因果/机制模型 | 直觉模型和正确模型给出不同预测 |

### 对照示例（同一知识点，坏题 vs 好题）

````markdown
# 坏题：纯逻辑 / 纯常识，不学也能做
“所有 A 都是 B，有些 B 是 C，能否推出有些 A 是 C？”
→ 外行用生活直觉 + 一点逻辑就能答，测的是智力不是学习。

# 好题：形式一样简单，但零件换成了新知识
“某商品需求价格弹性为 0.3。若厂商降价 10%，
 总收益最可能（上升 / 下降 / 不变）？”
→ 直觉答案：降价 → 销量涨 → 收益涨（错）。
   正确：缺乏弹性时降价反而减收。
   推理只有一步，但没有这条知识，聪明人也必错。
````

````markdown
# 最小对比题（成对出现，必须两题都答对才算掌握）
题 5a：某地冰淇淋销量与溺水人数高度正相关。据此可推出？
   A. 吃冰淇淋导致溺水  B. 溺水导致吃冰淇淋
   C. 存在共同原因（气温）  D. 无法判断

题 5b（只改一个条件）：
  研究者已控制“气温”后，销量与溺水仍高度相关。据此可推出？
   A. 吃冰淇淋导致溺水  B. 溺水导致吃冰淇淋
   C. 存在共同原因  D. 相关不能说明方向与因果
→ 关键：5a 选 C、5b 选 D 的人，是真懂“控制变量”；
   两题都选“相关即因果”的人，是没学；
   两题都选 D 的人，是学过但过度保守（也要能诊断出来）。
````

**注意**：最小对比题的杀伤力在于——外行会给出**同一个答案**（因为他不区分那个条件），学过的人会给出**不同答案**。这个“答案翻转”本身就是测量信号，而且完全靠不住猜。

## 三、四个技术手段，专门防止“不用学就能答”

1. **常识剥离**：出题前逐项自问“这个选项能不能用生活经验排除？”能排除的，删掉或改成反直觉。
2. **禁止应试技巧线索**：不要出现“一定/所有/永远”这类绝对词集中的错误项，不要出现最长选项即正确项，不要三个短一个长。这些技巧会让外行以高于随机的概率答对。
3. **反直觉正确项**：让正确答案违背朴素直觉（但要能从课上内容严格推出）。这是区分度最高的做法。
4. **多步但每步简单**：单步太白痴、三步四步就变成智力测验。**最优区间是 2～3 步，且每一步都踩在一个知识点上**。

---

## 四、反过来：怎么保住“测逻辑思维”而不滑向纯记忆

你想同时测到“知识点学习”和“逻辑思维”，那就要在**同一个知识点上架不同推理高度**的题：

| 层级 | 题干形态 | 例子（以“平均数/中位数”为例） |
|---|---|---|
| L1 识别 | 定义直问 | 中位数的定义是？ |
| L2 应用 | 给数据算 | 给 7 个数据求中位数 |
| L3 判断 | 选合适指标 | 收入数据含 1 个极端值，用哪个指标描述“典型收入”更好？ |
| L4 推理/迁移 | 反事实 | 若把最大值再放大 10 倍，平均数和中位数各怎么变？为什么？ |

**同一份卷子里 L2:L3:L4 大致按 3:5:2 配比**，就能既避免“纯记忆”，又不会因为全考 L4 而让 0 基础学员全军覆没。

再补一条很关键的：**L4 题要用“因为所以”结构强制暴露推理链**，而不是只留一个字母。哪怕 0 基础学员也能写半句，评分时按“用到了哪个知识点”给部分分，区分度会立刻打开。

## 五、前后测的工程化安排（这几条最容易漏）

<details>
<summary><b>点开：等值、梯度、防记忆、POE 结构（实操细节）</b></summary>

1. **等值不同题（parallel forms）**：前后测用同一张“蓝图”（见下节），但具体情境、数字、选项顺序都换。否则后测测的是记忆痕迹，不是能力。
2. **难度梯度 30/50/20**：三成保底题（让 0 基础的人不至于一题不会而放弃）、五成核心题（主要区分带）、两成全迁移题（拉开头部）。别全是中等题——中等题最容易被猜。
3. **每题加“信心标记”**：答完标“确定 / 不确定 / 猜的”。统计时单列“猜对率”。**猜对＋标猜的 = 0 分处理**，这是最省事的反猜测手段，比设计一百道难题都实用。
4. **两段式计分**（科学教育里的 two-tier test 成熟做法）：第一层选项、第二层选理由。只有“答案对＋理由对”才算掌握；“答案对＋理由错”归入迷思诊断，比单纯扣分更有信息量。
5. **前测不给分、不公布**：前测是诊断工具，一旦变成评价，学生会乱猜或焦虑，数据就废了。
6. **POE 结构**（预测–观察–解释）：前测只收“预测＋理由”，后测同题重问。**学习指标 = 从直觉答案迁移到正确答案的人数比例**。这正好把“前测必须能在 0 基础下作答”变成了优点。
7. **先备知识筛查题放最前**：3～5 题，判断学员是不是连前提都不具备。否则前测全错你会误判成“教学无效”，其实可能只是“没学过更早的东西”。
8. **别在前后测里放同一道原题**（除 POE 设计外）。学生记得住，你也分不清是学会还是记住了。

</details>

## 六、最实用的质检方法（出完题就做这一步）

**把整份后测卷给 3～5 个“聪明但没学过”的人做**（同年龄、同教育水平的其他班学生、朋友、甚至你自己扮演“聪明的外行”）。

然后看两个数：

- **外行通过率**：应该接近随机水平 $\frac{1}{k}$（$k$ 为选项数，四选一即 25%）。若某题外行通过率 $>50\%$，这题不合格，删或改。
- **外行与学员的差值**：单题差值 $<20$ 个百分点的题，区分力不足。

这一步做完，你会砍掉大约三到四成的题——**这是正常的，也是必要的**。很多人出的“情境题”其实只是换了背景故事的选择题，外行照样能做对，自己却察觉不到。

## 七、蓝图模板（建议先填这张表再出题）

出题的顺序必须是：**学习目标 → 知识点 → 可观察行为 → 题型**，而不是“先想几道好玩的题”。

| 知识点 | 目标层级(L1–L4) | 可观察行为（学员能做什么） | 对应题型 | 直觉陷阱选项是什么 |
|---|---|---|---|---|
| 相关≠因果 | L3 | 能指出共同原因而非因果 | 最小对比 | “相关即因果” |
| 需求弹性 | L3 | 能判断降价对总收益的影响 | 迁移/预测 | “降价必增收” |
| 中位数 | L2 | 能给含极端值的数据选对指标 | 判断＋说理由 | “平均数更准” |

最后一列**必须填**。它填不出来，说明这题没有区分力，改到能填出来为止。这一列就是你说的“不能变成纯逻辑题”的落地检查点。

---

<details>
<summary><b>常见坑速查（出完卷对照一遍）</b></summary>

- ❌ 情境很花哨，但去掉情境后答案不变 → 假情境题
- ❌ 错误选项靠“明显荒唐”区分 → 外行秒排
- ❌ 正确项是常识答案 → 不学也答对
- ❌ 全套题都是“是什么/定义” → 只测记忆，测不到逻辑
- ❌ 后测全是 L4 → 天花板以下一片空白，均值无意义
- ❌ 前后测用原题 → 测的是记忆不是学习
- ❌ 没有理由/信心层 → 猜对无法识别，数据失真
- ❌ 前测公布成绩 → 后续数据不可信

</details>
