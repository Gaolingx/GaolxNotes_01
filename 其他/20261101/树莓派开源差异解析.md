# 树莓派开源差异解析

## 🧑‍💻 User

树莓派pico2开源吗 为什么树莓派3/4/5不开源

---
## 😀 默认助手 (7)

## 先说结论

**树莓派 Pico 2 属于“部分开源”**：软件、文档和板级设计的开源程度都很高，但**芯片本身的 RTL（即寄存器传输级代码，也就是芯片设计源码）不开源**。

**树莓派 3/4/5 不开源不是选择，而是“没资格”**：芯片 IP 属于博通（Broadcom），还混合了 ARM、Imagination 等第三方授权 IP，法律上不允许公开。

<details>
<summary><b>一、Pico 2 到底哪些开源、哪些不开源（点击展开分层清单）</b></summary>

| 层次 | Pico 2 / RP2350 | 状态 |
|---|---|---|
| 软件开发工具包 SDK（C/C++）| `pico-sdk` | ✅ 开源，BSD-3-Clause |
| 启动 ROM（bootrom）源码 | `pico-bootrom-rp2040`、`pico-bootrom-rp2350` 仓库 | ✅ 源码公开（许可证是树莓派自定义条款，不是标准 OSI 许可证） |
| 芯片数据手册 | RP2350 Datasheet，1300+ 页，含寄存器级细节 | ✅ 极其详尽（业界罕见） |
| 板级设计 | Pico 2 原理图、PCB 参考设计、BOM | ✅ 公开可复刻 |
| 工具链、调试器 | `picotool`、`debugprobe`、OpenOCD 支持 | ✅ 开源 |
| RISC-V 核 | Hazard3（树莓派工程师 Luke Wren 设计） | ✅ 开源 RTL |
| **ARM Cortex-M33 核 RTL** | Arm 授权 IP | ❌ 闭源 |
| **RP2350 整体 RTL（PIO、总线、外设、PHY）** | 树莓派自研 | ❌ 闭源（商业选择） |
| 掩膜版 / GDSII / 工艺库 | — | ❌ 闭源 |

**关键点**：RP2350 里那颗 RISC-V 核心（Hazard3）是真正开源的 RTL，这是个有意思的细节，说明树莓派**有能力也有意愿开源自己拥有的东西**，不开源的只是它不想开或不能开的。
</details>

<details>
<summary><b>二、为什么 Pico 系列能开放这么多</b></summary>

1. **芯片是自己设计的**：RP2040/RP2350 完全由树莓派自己的团队设计，知识产权（IP）在自己手里，因此想公开什么就公开什么。
2. **树莓派的商业模式是卖板子，而不是卖 IP**：开源 SDK 和文档能带来生态、教育和销量，收益远大于风险。
3. **没有必须替别人保密的约束**：不必替博通保密 IP 清单，也不必隐藏 DRM 认证细节。
4. **芯片本身有护城河**：PIO（可编程 I/O）和双核架构的**实现细节**仍不公开，别人能复刻板子，但无法复制芯片。
5. **安全启动与 OTP 设计允许“透明度换信任”**：树莓派敢搞 DEF CON 悬赏破解大赛（$10k/$20k，2025 年 1 月公布结果），也敢公开 bootrom 源码。
</details>

## 三、为什么 3、4、5 不开源：五条无法绕开的硬性限制

### 1. IP 归属：芯片不是你家的

| 型号 | SoC | 谁设计 |
|---|---|---|
| Pi 3 | BCM2837 | Broadcom |
| Pi 4 | BCM2711 | Broadcom |
| Pi 5 | BCM2712 + RP1 | Broadcom + 树莓派自研 RP1 |

树莓派在这些产品里的角色是 **“大客户 + 定制需求方”**，而不是 IP 所有者。博通与树莓派的合同通常带 NDA（保密协议），公开 RTL 就等于违约。Pi 5 的 RP1 是树莓派自研，所以近年公开了它的寄存器级外设文档，但**同样没有 RTL**。

### 2. 第三方授权 IP 在法律上不能转授权

一颗 SoC 里塞着：

- **Arm Cortex-A53/A72/A76**：Arm 的授权明确禁止公开 RTL（这也是 RP2040 的 Cortex-M0+ 同样不能开源的原因，树莓派只开了外围自研部分）
- **VideoCore GPU**：Imagination 系血统与博通自研混合
- **DDR/PCIe/USB3 PHY、显示控制器**：多来自 Synopsys/Cadence 等
- **标准单元库 / TSMC PDK**：NDA 保护，红区，连截图都违规

哪怕树莓派想开源自己的那部分，**综合出的网表也不能合法发布**，因为物理实现依赖授权工艺库。

### 3. 闭源固件还涉及 DRM 和认证

- VideoCore 固件（`start*.elf`、Pi 5 的 SPI EEPROM bootloader）闭源，内核侧的 DRM/KMS 驱动是开源的，**固件不是**
- **HDCP、Widevine、H.265/HEVC 硬件解码授权**这些都要签合规协议，实现必须封闭
- Wi-Fi/蓝牙（Cypress/Infineon 芯片）的固件闭源
- 树莓派从未公开 VideoCore VI/VII 的完整 ISA 与 3D 流水线文档（2014 年公开的只有 **VideoCore IV** 的 3D 核文档，那还是在社区压力下由博通放出的，且只到 Pi 1 那一代）

### 4. 商业护城河：树莓派 2024 年 6 月在伦敦上市了

树莓派有限公司（Raspberry Pi Ltd）是商业公司，利润率靠 **“$35～$80 的板子卖量”**。一旦 SoC RTL 公开，华强北能立刻做出更便宜的克隆品，把价格打穿。相比之下，Pico 的 $4/$5 定价靠的是 RP2350 的 $0.8 批发价，而 RP2350 本身仍是独家供货。

### 5. 成本上根本不现实

把一个包含数十亿晶体管、几十个 IP 模块的 SoC 文档化到“可复现”的程度，工作量远超树莓派全公司规模，且没有商业回报。开源社区也接不住这种维护负担。

## 四、常见误解澄清

- ❌ “Pico 是开源硬件（OSHW）”，严格说**不是**：它没有 OSHWA 认证，芯片 RTL 也不开放。正确说法是 **“软件与文档高度开放（open SDK + open docs + open board design）”**。
- ❌ “Pico 2 全面开源，树莓派双标”：能开的（自有 IP、软件、文档、bootrom、Hazard3）都开了，不能开的（Arm 核、工艺库、整体 RTL）和 Pi 5 的限制原因**本质相同**。
- ✅ 真实差别在于：**Pico 的芯片 IP 主权在自己手里**，所以“能开”的比例高出一个数量级。

## 五、如果你的需求是“真开源硬件”

| 需求层级 | 可选方案 |
|---|---|
| MCU（文档+SDK 开源，RTL 闭源）| RP2350、ESP32-C6、STM32（同上，RTL 都不开）|
| 开源 RISC-V 核 + 自建 SoC | Hazard3、CVA6、OpenTitan、Chipyard |
| 真正开源的完整芯片 | OpenMPW/Shuttle 流片的开源芯片（如 Fomu）、TinyTapeout 项目 |
| 开源 SBC | BeagleBone（TI 文档极全）、RISC-V 派系（StarFive/Milk-V，文档开放但 RTL 闭源）|

---

**一句话总结**：Pico 2 属于“**软件、文档和生态开源，芯片设计闭源**”，这在嵌入式圈已算第一梯队；Pi 3/4/5 连文档都只能部分开放，因为它们的灵魂（SoC）从一开始就属于博通——**开源的前提是拥有，而树莓派只拥有 Pico 的芯片**。
