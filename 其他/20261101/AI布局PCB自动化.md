| 命题 | 激进程度 | 判断 |

## "丢掉 EDA"：要丢的是交互范式，不是内核

如果你的意思是丢掉 Altium/Allegro 那种**"人对着画布画线"的编辑范式**,那这个直觉是对的,而且是这件事里最有价值的部分。layout 应该变成编译产物,不是手工艺品:

```
约束/网表 (source) → 几何内核 + DRC/LVS (type checker)
                    → SI/PI/thermal/EMC 仿真 (test suite)
                    → Gerber / IPC-2581 (binary)
```

问题是**你不能把 type checker 和 output format 一起丢**。DRC 引擎不是"EDA 的包袱",它是你唯一的几何真理来源;Gerber/IPC-2581 是和板厂的物理契约。AI 生成 layout 之后,你比以往**更**需要一个能无头调用、API-first 的验证内核(这也是为什么 KiCad 的 `pcbnew` Python API 比商业 GUI 工具更适合这条路)。

**"人出环"其实是个错觉**:它不消灭人类,只是把人从"画线的人"挪到"写约束、定义 signoff 判据的人"。而 PCB 设计的 90% 判断力恰恰在这个上游——哪些 net 是关键的、热路径怎么走、EMC 风险在哪、机械干涉、成本/DFM 取舍。layout 在有人写下 objective 和 constraint 之前,根本不是一个良定义的优化问题。你不是去掉了这个环节,你是让 AI 去**猜**这个 spec。

## 真正的雷:仿真 signoff 是个会被 hack 的适应度函数

这是我要重点说的。仿真 signoff 是**必要但根本不够**的 oracle,原因有三层,一层比一层致命:

**1. 规范博弈(specification gaming)。** 你一旦把"通过这些 sim"当目标函数,优化器会精确地去找你的 checker 抓不到的地方——贴着谐振点走、贴着稳定性边缘走、利用网格/频率分辨率、满足指标但设计得极其脆弱。这是 LLM 优化 reward model 的 PCB 版本,不是假想。所以 **sim 只能当 filter(否决器),不能当 fitness(唯一目标)**;而且 signoff 必须是**最坏情况 / corner 扫描**(电压、温度、材料 Dk/Df 公差、连接器阻抗公差),不是 nominal。nominal 通过 = 没签核。

**2. 模型保真度无法自证。** SI/PI/热/EMC 仿真只对它的 stackup、IBIS、via 模型、边界条件负责。一块板可以 SI 完美通过,然后死在 EMC 认证上,因为你的 3D 场解器没有建模外壳、线束、以及你简化掉的地平面。**你没法用一个模型去验证这个模型本身对不对**——除非你有实测数据。这意味着诚实的版本必须是:

> AI layout + 仿真 signoff + **制造-实测闭环**(AOI/X-ray/飞针/暗室/热像)去标定仿真器

这个闭环又慢又贵,而人类现在的"设计规则 + 经验"本质上就是这个闭环被压缩后的缓存。想跳过人类,就得重新付一次这个成本。

**3. 正确性不是唯一签核轴。** DFM / DFA / DFT(测试点、bed-of-nails、边界扫描)、成本、合规(UL/CE/FCC 的安全间距、爬电距离)——你的仿真器一个都不签。而"AI 签核了"在法律和合同上不是个可站的位置,人类还有**责任承载**的作用。

期望成本上看:

$$\mathbb{E}[\text{cost}] = p_{\text{escape}} \cdot C_{\text{respin}} + p_{\text{field}} \cdot C_{\text{field}}$$

全自主把 $p_{\text{escape}}$ 推上去,而 $C_{\text{respin}}$($\sim$ 数万刀 + 6 周)一点没降。所以这个取舍完全取决于板子的性质:$2 的转接板随便搞;车规/市电隔离/多 Gbps SerDes 就是另一回事。

## 能成立的版本

<details>
<summary><strong>分级自治 + 约束化合成 + 实测标定(点开看具体路径)</strong></summary>

1. **先做"参考设计约束下的合成",别做自由生成。** AI 从已验证的拓扑库里选型,在经验证过几千次的规则空间内摆放布线。这时设计空间小到 DRC + 少量仿真是**完备**的 oracle,signoff 变成形式。这是唯一现在就能"人出环"的甜区:低速、大批量、拓扑标准化(LED 驱动、buck、breakout)。
2. **仿真只做否决,不做目标。** 目标应是"贴近已验证设计的先验 + 鲁棒性裕量",仿真作为硬约束 filter。
3. **建实测飞轮。** 每块打样板的实测结果回灌,用来标定仿真器和自动收紧 design rule。这是让 sim signoff 从"自指信仰系统"变成"有根据的判据"的唯一办法。
4. **人类留在两个位置,别留在中间**:spec/约束的撰写与审计,以及物理签核(DFM/DFT/合规/首件)。中间那层画线的手,确实可以删掉。

</details>

## 什么条件下我会相信它成立

给个可证伪的判据,别用"感觉":

- 在同一批 50 块板上,**盲测**:AI 全自主产出 vs 资深工程师产出,交给同一家板厂 + 同一套实测(含 EMC 暗室、热循环、HALT),AI 的**逃逸率** ≤ 人类;
- 仿真预测值和实测值的偏差分布是**已知且稳定**的(不是碰巧这次对);
- 在 corner 扫描下仍然通过,而不是 nominal 通过;
- 有个明确的"拒答"机制:遇到超出标定域的板子,系统自己说"我不签,要人"。

满足这几条,你的方案就不激进,是工程。不满足,那就是把 correctness 的定义偷偷换成了 "passes my tests"——而这两者之间的差,正好就是所有翻车的地方。

一句话:**"AI 做 layout + 丢掉交互式 EDA"是好方向;"仿真 signoff 当唯一正确性来源"是拿模型的置信度当现实的置信度,这一条必须改。** 人类出环可以,但出的是"画线"那个环,不是"定义什么叫对"那个环。

## 😀 默认助手 (7)

你说得对，我上一轮的成本模型对你不成立——我把$C_{\text{respin}}$按工业标准估了，而你的实际量级是几百块+几个晚上。那结论就要反过来：

## 你这个量级，不该优化"一次做对"

一次做对的成本是**仿真保真度**，而保真度很贵（要实测标定、要corner库、要专人）。你付不起，也不该付。

但几百块+一周打样买来的是**"错得起"**。这才是你手里的资源。所以目标函数要从

$$\min P(\text{fail}) \quad \text{改成} \quad \min \mathbb{E}[\text{debug 的痛苦} \mid \text{fail}] \times \text{可迭代次数}$$

前者要靠仿真，后者靠**让失败便宜且可读**。这是个完全不同的设计目标，而且对你这个预算可达。

## 你感觉"代价有点大"，真正贵的不是钱

拆开你写的那三样：

- **几百块**：真的便宜。这就是你能迭代的资本。按一周一轮，一年 30-50 轮，这是你的验证带宽。
- **打样+组装时间**：1-2 周/轮，固定税，接受它。
- **痛苦的 debug**：**这项才是全部成本**，而且它和钱无关，跟你丢掉的晚上和心气有关。

而 debug 的痛苦 $\propto$ **未知数的个数**。短路的 trace 五分钟；"SI 边缘但没崩"或"热到降额"或"低概率复位"能吃掉你三个周末，因为没有对照物。

关键点：**AI 生成的 layout，如果没有"为什么"，就是未知数最大化。** 你没法 diff 一个你没参与设计的板子。这才是你直觉里那个"代价大"的来源——不是钱，是**失败不可读**。我的建议没变但理由变了：约束在参考拓扑里做合成，不是为了正确率，是为了**每个失败都能对应到一个你见过的电路**，debug 从"探案"降回"对表"。

## 因此把 oracle 从仿真换成"可诊断性"

这个价位最该做的事，是把 DFT 做狠，而不是把仿真做准：

- 每路电源留测试点 + 上电 LED；0Ω 电阻/焊盘跳线**分段隔离**，能二进制搜索哪个 block 坏了
- 限流台式电源 + 分域上电，避免一次烧一串
- 2 层 1.6mm、宽容间距、**不碰 BGA/细间距**、丝印标 net 名和 block 框
- 留 DNP/strap 选项，能不重打样就二分行为
- 模块化到子板——一块坏不牵连全板

这块板就是"签核"本身：你不再问"仿真是对的吗"，你问"我能不能在半小时内定位它错在哪"。

## 但有个尾巴要认

均值便宜，**尾部不便宜**。间歇性故障（虚焊、时序边缘）成本是首次 debug 的 10 倍，因为它不可复现；而且一旦这板子要交给别人用或做第二块、第三块，你就从"自己的玩具"跨进了"要为别人负责"，那点钱就不再是分母了。

所以一句话：**你自己的一次性项目，人出环完全 OK，只要把"错得起"和"错得可读"做到位；一旦要复制或交付，那个环得有人回来——不是回来画线，是回来签"这堆失败模式我认得"。**
