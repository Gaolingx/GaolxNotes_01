## 😀 默认助手 (7)

先对这个前提提出一点反对意见：**分子模拟的“理论”远没有定型，最活跃的部分恰恰在理论尚未解决的区域**。很多所谓“加速”，其瓶颈其实也是理论问题：采样为什么收敛不了、粗粒化为什么不可迁移、长程为什么学不出来，这些是理论问题，而非工程问题。真正进入纯工程量领域的，只有积分器、并行 I/O 和部分 GPU kernel。

下面按“理论仍然活跃”的程度排序，给你一张方向地图，再展开几个我认为最值得深入做的方向。

## 一、采样：理论仍在活跃的地方（不限于“加速”）

<details>
<summary><b>展开：自由能误差分解、CV 学习、非平衡采样</b></summary>

### 1. 自由能的误差预算（我认为最被低估的方向）

现在几乎所有自由能计算（FEP、TI、MBAR、metadynamics）报的都是“均值±统计误差”，但**系统误差从未被严肃分解**。一个干净的框架是：

$$\sigma^2_{\text{total}} \approx \sigma^2_{\text{model}} + \sigma^2_{\text{sampling}} + \sigma^2_{\text{estimator}} + \sigma^2_{\text{NQE}} + \sigma^2_{\text{finite-size}}$$

每一项都有可做的工作：
- $\sigma^2_{\text{model}}$：力场误差如何传播到自由能？这不是线性传播，因为 $\Delta G$ 对参数高度非线性。
- $\sigma^2_{\text{estimator}}$：MBAR/BAR 的渐近方差理论在“重叠差”的情况下会失效，有严格界吗？
- $\sigma^2_{\text{sampling}}$：**没有真实的情况下如何判断收敛**？MSM 的 Chapman–Kolmogorov 检验、VAMP-2 score、块平均，都只是启发式。

> **可深挖点**：给出一类可观测量下，误差各分项的**可计算上界**。谁先做出“我能告诉你这个 $\Delta G$ 的误差主要来自哪一项、有多大”，谁就占住了这个方向。

### 2. 集合变量作为学习问题

理想反应坐标是**committor** $p(\mathbf{x})$，它是唯一“充分”的 RC。于是问题变成监督学习：

- 用 $p=0.5$ 的曲面定义过渡态，比任何几何判据都严谨。
- 学习 $p(\mathbf{x})$ 的难点是**标注成本**（每次算 committor 要打大量短轨迹），所以这是主动学习/半监督的天然舞台。
- 信息论角度：什么样的 CV 是“足够”的？存在 $I(\text{CV};\text{committor})$ 的意义下的最优维度下界吗？这块理论几乎是空的。

入口：VAMPnets / Deep-TDA / 谐波 LDA 已有雏形，但**“最优 RC 的维度和可识别性”**没有被回答。

### 3. 非平衡采样与最优输运

Jarzynski/Crooks 之后，真正没做透的是**最优驱动协议**：给定时间预算，如何设计非平衡过程使耗散最小？这本质是最优控制/最优输运问题。已有一些理论工作，但和实际 MD 的对接还很粗。

</details>

## 二、力场：调整参数并不是全部，关键在于“可迁移性”

这是我建议你重点看的地方。下面按“问题深度”排：

<details>
<summary><b>展开：力场的五个真正开放问题</b></summary>

### 1. 参数的“环境依赖性”应当被形式化

同一个分子在气相、水、蛋白口袋里，部分电荷不同——这不是 bug，而是**有效哈密顿量的本性**。但现行力场把它**冻结成一个数**。于是：

- 可迁移性失败的本质，是**忽略了对环境的响应**（charge flux、极化、色散变化）。
- 真正该做的：把参数写成环境泛函 $\theta = \theta(\rho_{\text{env}})$，然后问“这个泛函有多光滑、能学多准、需要多少数据”。
- 可极化力场（AMOEBA、Drude、 fluctuating charge）是一条路，但**成本与稳定性**是致命伤。另一条路是让 ML 势自己学出“响应”，如 4G-HDNNP 的电荷平衡。

> **可深挖**：量化“冻结参数”引入的误差，作为体系极化率的函数。这是一个干净的可发表问题。

### 2. 长程相互作用的可学习性（我认为最硬的一块）

任何**局域**的 ML 势在构造上就无法正确给出长程静电与色散。现在的补丁（D3/D4、MBD、latent Ewald、LODE）各解决一半。开放问题：

- 局域描述符**在原理上**能表示多长程的相互作用？（信息论/表示论意义上的界）
- 如何让 ML 势学出**随环境变化的电荷**，且保证能量守恒与导数一致？
- 周期边界下，Ewald 的“倒空间”部分能不能作为可微模块塞进网络？

这块理论没做完，是很好的切入。

### 3. 通用势（foundation model）的失效模式

MACE-MP-0、CHGNet、M3GNet、MatterSim 这类“通用势”出来后，问题从“能不能拟合”变成了：

- 它在**外推**时错在哪里？如何**检测**自己在分布外（OOD）？
- 声子、缺陷、相稳定性、表面能——这些“二阶可观测量”通用势真的对吗？
- 微调（fine-tune）与从头训练，哪个在什么数据量下更优？几乎没有系统答案。

> 这里有个**高性价比**的活：建立一套“通用势体检基准”，专门测外推、守恒律、长程、热电。基准论文的影响力常被低估。

### 4. 水与离子：**仍然没有解决**

水模型几十年来一直在改（TIP4P/2005、MB-pol、AMOEBA），但**离子水合、Hofmeister 序列、界面 pH** 这些体系仍普遍偏差大。这不是“再调一个参数”能解决的，根源是极化与电荷转移。如果你做生物/电化学，这里是长期富矿。

### 5. 参数拟合范式：从点估计到贝叶斯

现在主流还是“最小化加权残差”。但更应该问：**参数的后验分布**是什么？给定噪声，哪些参数可辨识？

- BayesFF 是一条路；ForceBalance 是另一条。
- 关键问题：**能量拟合得好，是否意味着可观测量拟合得好？** 答案常常是“不”。这个反直觉的结论值得系统研究。

</details>

## 三、粗粒化：理论层面最大的开放问题

<details>
<summary><b>展开：为什么 CG 是理论富矿</b></summary>

粗粒化不是“把几个原子并成一个珠子”的工程，它在理论上有个硬核：

- **相对熵 / 力匹配 / IBI** 给出的 CG 势，**天然不可迁移**（换个温度、换个组成就失效）。为什么？因为 CG 势是对被消去自由度的**积分**，它对热力学状态有隐式依赖。
- 这和**重正化群**是一个问题：CG 势的“跑动”（running）如何写？有没有类似 $\beta$ 函数的描述？

值得做的：
1. 把“CG 势的状态依赖性”写成显式的泛函，并给出可计算的修正项。
2. ML 粗粒化（CGnet 一类）能不能学出**可迁移**的 CG 势？如果不能，理论障碍在哪？
3. **“表示性”（representability）**：给定 CG 映射，哪些可观测量在原理上可以精确重现？哪些一定错？这是可以严格回答的问题，但几乎没人系统做。

> 这块的优点是：**结论可以是负面的**（“这类映射不可能重现这个量”），负面结论同样能发好文章，而且很难被推翻。

</details>

## 四、非马尔可夫动力学 / 记忆核

<details>
<summary><b>展开：Mori–Zwanzig 仍是活跃理论</b></summary>

当你把系统投影到少数自由度（CV、CG 珠子、隐变量）上，动力学必然变成**广义朗之万方程**：

$$m\ddot{q} = -\nabla U(q) - \int_0^t K(t-s)\dot{q}(s)\,ds + \eta(t)$$

$K(t)$ 是记忆核，$\eta$ 是彩色噪声。问题：

- 如何从 MD 数据**学出** $K(t)$？这本质是一个反问题，且对噪声极敏感。
- 学习到的 GLE 是否满足涨落耗散定理？**一致性**如何保证？
- 投影本身的选择（用哪些 CV）会改变 $K$——有没有最优投影？

这是理论+数值双料富矿，且和“粗粒化可迁移性”是同一个问题的两面。

</details>

## 五、特殊系综与条件：被忽视的高价值区域

<details>
<summary><b>展开：恒电势、电化学、极端条件</b></summary>

### 恒电势 / 电化学界面

这是我认为**未来五年最热**的方向之一，因为：
- 能源材料（电催化、电池）需求巨大；
- 理论**不成熟**：恒电势系综的统计力学、电极-电解液界面的力场、电位对反应路径的影响，都缺严格框架。
- ML 势在这里几乎没用起来，因为需要**显式电子**或**电位依赖的参数**。

可做：恒电势下的 enhanced sampling、电位依赖的 ML 势、双电层结构的基准。

### 极端条件（高压、高温、冲击）

- 高压下力场普遍失效（近邻原子数变化大，局域描述符外推）。
- 相图、熔化线、超离子态——理论+势函数都不成熟。

### 恒 pH / 恒化学势

- 质子化态耦合采样，理论上是个**半巨正则**问题，实现上很脏，理论上的严格处理很少。

</details>

## 六、可微模拟与端到端反演

<details>
<summary><b>展开：对实验可观测量求梯度</b></summary>

传统流程是：拟合能量 → 跑 MD → 和实验比。中间断了。可微模拟把整条链打通：

$$\frac{\partial \mathcal{L}(\text{实验})}{\partial \theta_{\text{FF}}} = \frac{\partial \mathcal{L}}{\partial \text{obs}}\cdot\frac{\partial \text{obs}}{\partial \text{traj}}\cdot\frac{\partial \text{traj}}{\partial \theta}$$

- 难点在 $\partial \text{traj}/\partial \theta$ 的**长时程不稳定性**（混沌放大），以及内存。
- 可做的：短轨迹 + 伴随法、随机微分方程视角下的梯度估计、用可观测量的**系综平均**而非单条轨迹来稳定梯度。
- 应用：直接从 NMR、散射、ITC、量热数据反演力场参数。**这是“调参数”的正确高级形态**。

入口：JAX-MD、TorchMD、DiffMD 提供了工具，但**理论（梯度的方差、偏差）几乎没做**。

</details>

## 七、几个“容易被忽视但很有潜力”的角落

| 角落 | 为什么值得做 |
|---|---|
| **误差传播到可观测量** | 力场误差 → $\Delta G$ / 熔点 / 扩散系数 的映射，非线性且几乎没人做严格分析 |
| **有限尺寸效应** | 界面、成核、相变的 finite-size scaling 在 MD 里常被粗暴处理 |
| **成核理论** | 经典成核理论细节上是错的；ML 辅助的成核路径/自由能是活跃区 |
| **守恒律与对称性** | E(3) 等变网络保证了旋转/平移，但**动量守恒、时间反演、热力学一致性**常被破坏 |
| **负结果与可复现性** | 系统性的“哪些方法在哪些体系上失败”的基准，影响大且稀缺 |
| **隐式溶剂** | 从 PB/GB 到 ML 隐式溶剂，精度和物理一致性都还差得远 |

## 如何判断一个方向值不值得深入

我的判据（按重要性）：

1. **有没有一个形式化的对象**？误差界、泛函、可识别性、守恒量——有对象才能证明，才能反驳。
2. **能不能给出负面结论**？“这类方法在原理上做不到 X”比“我改进了 X 0.3 kcal/mol”更有分量。
3. **有没有干净的验证方式**？有 ground truth（小体系精确解、实验）的方向优先。
4. **是否连接更大理论**？连到重正化群、最优输运、信息论、统计学习理论的方向，长期回报高。
5. **五年后是否仍成立**？纯拟合型工作（“我把某个体系的力场调好了”）会被通用势吞掉；理论型工作不会。

## 我的具体建议排序

如果你的目标是**做出有辨识度的工作**，我会这样排：

1. **长程/环境依赖力场的理论界限**（第二节 1、2 条）—— 硬、有理论、有应用。
2. **粗粒化的可迁移性理论**（第三节）—— 可给出严格结论，竞争少。
3. **自由能的误差预算**（第一节 1 条）—— 门槛不高但极稀缺，容易建立“标准”。
4. **可微模拟的梯度理论**（第六节）—— 工具已成熟，理论空白。
5. **恒电势/电化学的框架**（第五节）—— 需求驱动，窗口期还在。

> 至于“加速”本身：真正能做深的是**模型简化**（粗粒化/降维/记忆核）和**采样理论的收敛性**，而不是把积分器写快 20%。后者是工程，前者是科学。

如果你告诉我你的背景（偏生物体系 / 材料 / 电化学，以及你手上有什么算力和数据），我可以把上面某一条拆成具体的 3–5 个可执行的子问题，包括该读的原始文献和能立刻上手的小实验。
