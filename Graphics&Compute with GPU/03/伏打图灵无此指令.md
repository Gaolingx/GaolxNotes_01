因此：

1. **Volta（`sm_70`）** 是**不支持** `ldmatrix` 的，因为它的 compute capability 只有 7.0，低于 7.5。
2. **Turing（`sm_75`）** 是**支持** `ldmatrix` 的，Turing 架构正是 `ldmatrix` 首次引入的架构。

## 补充说明

`ldmatrix` 属于 warp 级矩阵加载指令，用于从 shared memory 中加载矩阵到寄存器，配合 `mma`（matrix multiply-accumulate）指令使用。它是在 PTX ISA 6.5 版本（CUDA 10.2）中引入的，对应 Turing 架构（`sm_75`）。

需要特别注意的一点是：**Volta（`sm_70`）虽然支持 `wmma` 指令**（Volta 是首个引入 Tensor Core 的架构，支持 `wmma.load`/`wmma.mma`/`wmma.store`），但**不支持 `ldmatrix` 以及 `mma`（`mma.sync` 系列）**，因为这些是针对 Turing（`sm_75`）及以后架构的指令。

简而言之，你的问题答案就是：**Turing 支持，Volta 不支持**，分界线在 `sm_75`。
