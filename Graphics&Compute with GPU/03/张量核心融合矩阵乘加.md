# 张量核心融合矩阵乘加

### 🧑‍💻 User

nvidia tensorcore是matmul+acc合在一起的吗？

---

### 🤖 Assistant

**是的，NVIDIA Tensor Core 本质上就是一个将“矩阵乘法（matmul）”与“累加（accumulate）”融合在一起的硬件单元。**
它直接在一个指令中完成 $D = A \times B + C$ 的混合精度矩阵乘累加操作。

---

### 🔍 具体拆解

Tensor Core 执行的运算可以统一写为：

$$D = A \times B + C$$

- **$\mathbf{A \times B}$：矩阵乘法**
  硬件在一个时钟周期内完成一个固定尺寸（例如 4×4）的小矩阵乘法。
- **$\mathbf{+ C}$：累加**
  乘法的结果并不是直接输出，而是**加到一个已有的累加器矩阵 $C$** 上，实现 `matmul` 和 `add` 的融合。
- **单指令完成**
  这一切通过一条 `mma.sync` 或 `wmma` 指令触发，不会把乘法和加法拆成两步，从而大幅减少寄存器读写和延迟。

### ⚙️ 硬件上的“合在一起”具体指什么？

在传统的 CUDA Core 上，要完成 $A \times B + C$ 可能得先做点积（多次乘加），再手动加回累加器。而 Tensor Core 是**专用硬件电路**，在同一流水线中完成：

1. 读取 $A$、$B$ 分块
2. 完成矩阵乘法的乘累加（内部使用 fused multiply-add，即每次乘法后立即累加到部分和）
3. 最后再把整个分块的结果**累加到输入矩阵 $C$** 中，得到输出 $D$

这个 $C$ 既是输入累加器也是输出目标，所以叫 **Matrix Multiply-Accumulate (MMA)**。
常见的用法正是用 Tensor Core 逐步累加：

初始 $C$ 置零 → 每次加载一块 $A$、$B$ 做 `D = A×B + C` → 把 $D$ 再当作下一轮的 $C$ 继续累加，直到整层算完。

### 📦 典型混合精度模式

Tensor Core 支持多种精度，例如：
- **FP16 乘，FP32 累加**（最常见）
  $D_{FP32} = A_{FP16} \times B_{FP16} + C_{FP32}$
- **TF32 乘，FP32 累加**（Ampere 引入）
- **INT8 / INT4 乘，INT32 累加**
- **FP64 乘，FP64 累加**

无论哪种，**乘法与累加始终是融合在一条 Tensor Core 指令中的**，这正是“合在一起”的含义。

### 📌 一句话总结

> Tensor Core 不是“先 matmul 再 acc”的两段式操作，而是**硬件原生的矩阵乘累加融合计算单元**，一条指令直接输出 $A \times B + C$。
