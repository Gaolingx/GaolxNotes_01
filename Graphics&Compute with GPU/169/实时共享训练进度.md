## 🤖 Assistant

# 在 W&B 上分享正在运行的 Run / "直播"训练

## 先说结论

W&B 没有专门的"直播推流"功能（不像 Twitch），但它的 **run 页面和 workspace 本身是实时刷新的**：只要 run 还在跑，打开链接的人就能每隔几秒自动看到最新的 loss / accuracy / 系统指标曲线。所以"直播"的本质 = **让别人拿到一个能实时刷新的 run/project 链接**。

有权限的人打开 `https://wandb.ai/<entity>/<project>/runs/<run_id>` 就能实时围观。

下面按"对方是否登录、是否需要账号"分几种方案。

---

## 方案对比

| 方案 | 对方需要 W&B 账号吗 | 是否实时 | 适用场景 |
|------|:---:|:---:|------|
| 项目设为 **Public / Open** | ❌ 不需要 | ✅ 实时刷新 | 公开演示、论文复现、群发链接 |
| **邀请成员**加入 Team | ✅ 需要 | ✅ 实时刷新 | 团队内部协作 |
| **Report + 只读 magic link** | ❌ 不需要 | ⚠️ 以图表刷新为准（偏快照） | 给外部/stakeholder 看结果 |
| **iframe 嵌入** | 看项目可见性 | ✅ 实时 | 官网/Notion/大屏直播 |

---

## 方案一：把项目设为公开（最简单的"直播链接"）

这是最直接的"直播"方式——任何人拿到链接都能看，且曲线实时更新。

**操作步骤：**

1. 打开你的 W&B 项目页面
2. 点项目名旁边的 **可见性图标**（铅笔/眼睛图标）
3. 在 **Project Visibility** 下拉框里选择作用域，点 **Save**
4. 把 `https://wandb.ai/<entity>/<project>` 或具体 run 的链接发给别人

**四种可见性作用域：**

| 作用域 | 谁能看 | 谁能提交 run/report |
|--------|--------|---------------------|
| **Open** | 任何知道项目的人 | 任何人 |
| **Public** | 任何知道项目的人 | 仅你的 team |
| **Team** | 仅父 team 成员 | 仅 team 成员 |
| **Restricted** | 仅被邀请的成员 | 仅被邀请的成员 |

⚠️ 注意：
- 如果组织管理员关闭了 **Public**，你就选不了它（GitHub issue #3764 也确认：**单条 run 无法单独公开，必须整个项目公开**）。
- 如果某个 team 开启了 *"Force all projects in this team to be private"*，需要到 `wandb.ai/settings` 关掉才能公开。

---

## 方案二：团队内部实时围观（保留私有）

如果不想公开，直接**邀请对方加入 team / project**即可。加入后他们打开的 run 页面同样是实时刷新的，看着跟"直播"没区别。

- Team 成员：默认可看整个 team 的 **Team** 项目
- **Restricted** 项目：需要单独邀请（Project → Overview → Project roles 里管理成员和角色）

> 把项目从宽松改成更严格的可见性后，可能需要**重新邀请用户**才能恢复访问。

---

## 方案三：给外部人看——Report + 只读 Magic Link

当对方**没有 W&B 账号**、又不方便公开整个项目时，用**只读报告链接（view-only / magic link）**：

1. 先建一个 **Report**，把关心的图表放进去（也可以直接把 workspace 的 section "Export section to report"）
2. 打开报告 → 点 **Share**
3. 生成分享链接 → 调整权限 → 点 **Copy report link**
4. 把带 token 的链接发出去

**特性：**
- 链接里含 secret token，**任何人打开即可查看，无需登录**
- 只读模式下可以：查看图表、hover 看 tooltip 数值、缩放、横向滚动表格
- 只读模式下**不能**：新建图表、跑新查询、点进 run 页面、看到分享弹窗
- ⚠️ magic link **只对 Private 和 Team 项目可用**；Public/Open 项目本身就是公开的，不需要也不支持开关这个链接

> 想临时给某人看，也可以直接在 Share → **Invite** 里填邮箱（**不必是团队成员**），选 *Can view* 或 *Can edit*。

---

## 方案四：iframe 嵌入——真正的"直播大屏"

想把它放到官网、Notion、Confluence、Hugging Face Spaces、Gradio 里当"直播大屏"，可以用 **iframe 嵌入**：

- 单个 **Panel** 可以嵌入（面板菜单里选 Embed）
- 整个 **Report** 也可以嵌入（`<iframe>` 方式，见文档 *Embed a report*）

只要浏览器页面开着，嵌入的图表就会随训练实时更新。

---

## 直播训练的最佳实践

<details>
<summary>点开看实用技巧</summary>

1. **固定一个 panel 布局**：提前在 workspace 里排好 loss / lr / grad_norm / GPU 利用率等关键曲线，别让观众自己找。
2. **给 run 起可读的名字**：`run.name = "baseline-lr3e-4"`，比随机 ID 友好得多。
3. **用分组（Group）**：把同一组实验按 group 聚合，观众看到的是均值 ± 方差，更直观。
4. **日志别太稀疏**：`wandb.log()` 每步或每若干步记一次，曲线才"活"起来。
5. **保留 console logs**：`models/app/console-logs` 可以围观 stdout，主播会更有"直播感"。
6. **大屏用全屏 URL**：在 report 里点开某个 panel 拿到的全屏 URL，发给别人会自动全屏打开。

</details>

---

## 关键限制速记

- ❌ 不能只公开**单条 run** —— 必须公开整个项目
- ⚠️ magic link 只适用于 **Private / Team** 项目
- 🔒 W&B Local（私有云）部署下，这些链接依然被防火墙挡着，只有又在内网、又有链接的人能看
- 🕐 "实时"依赖页面保持打开并自动刷新；run 结束后页面就是静态回顾了

---

**一句话选择：**
> 公开演示 → **项目设 Public**；团队内部 → **邀请成员**；给外部无账号的人 → **Report + magic link**；挂到外站当大屏 → **iframe 嵌入**。
