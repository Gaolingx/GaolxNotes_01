# Python 在 CMD 中执行整段代码的几种方法

## 一、最常用：保存为 `.py` 文件后运行

这是标准做法。把整段代码保存为 `hello.py`，然后在 CMD 中：

```bat
python hello.py
```

如果系统安装了多个版本：

```bat
py hello.py
```

> 提示：先 `cd` 到文件所在目录，例如 `cd /d D:\myproject`，再执行。

---

## 二、临时执行：不保存文件

### 方法 1：`-c` 参数（适合短代码）

```bat
python -c "print('hello'); import math; print(math.pi)"
```

多行时用分号或 `\n`。但引号嵌套很麻烦，**不适合整段代码**。

### 方法 2：管道 / 重定向（适合较长的临时代码）

```bat
echo print('hello') | python
```

或把代码文件内容通过管道传入标准输入：

```bat
type code.py | python
python < code.py
```

### 方法 3：CMD 中直接进入交互模式逐段粘贴

```bat
python
```

进入 `>>>` 后，可以粘贴多行代码。若要粘贴**整段含缩进的代码块**（如函数/循环），建议：

- 先输入 `if True:` 之类的顶层块，或
- 使用 `import` 方式，或
- 直接改用 `.py` 文件方式（推荐）。

---

## 三、把代码直接写在 CMD 批处理里（`.bat`）

可以创建 `run.bat`：

```bat
@echo off
python -c "import sys; print('Python version:', sys.version)"
pause
```

复杂代码不推荐嵌入 bat，容易踩到引号转义坑。

---

## 四、常见问题排查

| 问题 | 解决 |
|------|------|
| `'python' 不是内部或外部命令` | Python 未加入 PATH。安装时勾选 "Add to PATH"，或用 `py` 命令，或写完整路径 `C:\Python312\python.exe` |
| 中文乱码 | 执行前 `chcp 65001`，并在代码首行加 `# -*- coding: utf-8 -*-` |
| 找不到文件 | 用 `cd /d 盘符:\目录` 切换，或给绝对路径 `python D:\code\hello.py` |
| 需要传参数 | `python hello.py arg1 arg2`，代码里用 `sys.argv` 读取 |

---

## 五、推荐做法总结

```bat
:: 1. 切到代码目录
cd /d D:\myproject

:: 2. 解决中文乱码（可选）
chcp 65001

:: 3. 运行整段代码文件
python main.py
```

**结论**：执行"整段代码"最稳妥的方式是——把代码保存成 `.py` 文件，然后用 `python 文件名.py` 运行；临时短代码才用 `python -c "..."` 或管道方式。
