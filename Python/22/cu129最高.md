## 结论

**最后一个（也是当前最新）提供 `cu129` wheel 的 PyTorch 版本是 `2.13.0`**，即 `torch-2.13.0+cu129-*.whl`。

### 依据

我查询了 PyTorch 官方 wheel 索引 `https://download.pytorch.org/whl/cu129/torch/`，其中所有带 `+cu129` 的 torch 发行版按版本排序如下：

| 版本 | Python 支持 | 说明 |
|------|-------------|------|
| `2.8.0+cu129` | cp39–cp313（含 win_amd64） | **cu129 首次出现**的版本 |
| `2.9.0+cu129` | cp310–cp314 | |
| `2.9.1+cu129` | cp310–cp314 | |
| `2.10.0+cu129` | cp310–cp314 | |
| `2.11.0+cu129` | cp310–cp314 | |
| `2.12.1+cu129` | cp310–cp314 | 注意跳过了 2.12.0 |
| **`2.13.0+cu129`** | cp310–cp315 | ✅ **最新 / 最后一个** |

列表中 `2.13.0` 是最高的版本号，没有 `2.14.x` 或更高版本出现，因此它是目前 cu129 的最后一个版本。

### 需要注意的两点

- **cu129 并非最新 CUDA 分支。** 根索引 `https://download.pytorch.org/whl/` 中已存在 `cu130`、`cu132`、`cu134` 等更新的 CUDA tag。也就是说，`2.13.0` 之所以仍是"最后一个 cu129 版本"，是因为 cu129 是一条**仍在维护的旧 CUDA 兼容分支**，而更新的 CUDA 版本通过 cu130+ 分支发布。
- **平台差异：** `2.8.0`/`2.9.0` 还提供 Windows（`win_amd64`）的 cu129 wheel；从 `2.9.1` 起 cu129 wheel 仅剩 Linux（`manylinux_2_28`，含 x86_64 与 aarch64）。

### 安装示例

```bash
# 指定最后一个 cu129 版本
pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu129

# 或安装该分支下最新的 cu129 版本（会解析到 2.13.0）
pip install torch --index-url https://download.pytorch.org/whl/cu129
```

> 建议：如果硬件/驱动支持，优先考虑升级到 `cu130` 及以上的分支，以获取更完整的新版本支持；若必须锁定 CUDA 12.9 运行时，则使用 `2.13.0+cu129`。
